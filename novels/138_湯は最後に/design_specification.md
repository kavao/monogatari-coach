# design_specification.md — 「湯は最後に」

## テーマ

不便を人の手で解決した手が、村の誰かの生業を止める。

## コンセプト

資材倉庫の店員だった悠希は、魔法使いの維持魔法が切れた村で水を分け、炉を組み、石鹸を作り、最後に湯を溜める。その間に村の木が減る。

## 主軸

- 目的: 悠希が、湯の出る風呂を一番最後に作る。
- 計測単位: 湯が当番表の時間に桶へ溜まった回数（0 / 1）
- 現在値 / 終端値: 0 / 1

## 第1章「泥混じりの水を二本の桶に分ける」

分量目安: 3,000字

### 確定出来事

1. 悠希が石倉庫の跡で目覚め、ノラが維持魔法の切れを告げる。（本文済）
2. 悠希が壊れた火台の脚を直して火を起こし、井戸水を布一枚→二重→四重で濾し、三度目で底の見える水にする。（本文済）
3. （未）沸かし、飲める水と汚れた水を二本の桶に分ける。
4. （未）棚順の表。湯の出る風呂を口にする。炉の失敗とルーベン。
