# あらすじ

**第1章　湯気の向こうの小さな影**  
学校の健康治療実習でクラスメイトのボディーに初めて触れた悠真は、帰宅するや否や胸の奥から抑えきれない熱い衝動に襲われていた。  
その日の夜、彩乃がいつものように浴室で湯船に浸かっていると、ドアが静かに開く音がした。  
バスローブを羽織っただけの悠真が、湯気の中に小さな影を落として立っている。  
ダークブラウンの柔らかな短髪が湿気に少し乱れ、ライトブラウンの瞳が真剣に姉を見つめていた。  
「姉ちゃん……僕、今日学校で……なんか、すごく変なんだ……体が熱くて……」  
彩乃は胸を押さえ、やんわりと微笑みながら断る。  
「悠真、だめよ……お姉ちゃん今、お風呂中なの。後でゆっくり話しましょう？」  
しかし悠真は一歩も引かず、湯気の立ち込める狭い浴室の中で少しずつ近づいてくる。  
彩乃の黒髪が湿って肩に張り付き、優しげな茶色の瞳にわずかな戸惑いが浮かぶ。  
章末：悠真の小さな手が彩乃の肩にそっと触れたところで、彩乃が慌てて体を引く。親愛度に変化はほとんどない。

**第2章　やんわりとした拒絶と、熱い吐息**  
彩乃は弟を宥めようと優しい声で言葉をかけ、軽く肩を抱き寄せる。  
その温もりがかえって悠真の治療欲を刺激し、バスローブの前がわずかに開く。  
タッチングから、弟の小さな唇が彩乃の頰に触れる軽いキッシングへ移行する。  
「悠真……これ以上は本当にだめ……家族だから……」  
彩乃は何度もやんわりと断るが、声が次第に弱くなり、湯気の中で息が熱を帯びていく。  
悠真は底なしの治療欲に突き動かされ、「姉ちゃんのボディー、僕に預けて……ただ気持ちよくなってほしいだけなんだ……」と繰り返し懇願する。  
ZENGIの手式を試みようと小さな手が動きかけたところで、彩乃が慌てて弟の手を押さえる。  
章末：彩乃の頰が赤らみ、弟の傘突起が小さく反応していることに気づくが、親愛度はほとんど上がらず「これは弟の我がまま……」と自分に言い聞かせる。

**第3章　弟が主体で動く請圧　～こすりつけられる熱～**  
ここから悠真が主体的に動き出す。  
狭い浴室で彩乃の体を壁際に追い詰め、バスローブを緩めながら自分のボディーの傘突起を姉の治療穴の外側（小餅ヒダ周辺）に何度もこすりつけてくる。  
素式の正常型に近い体勢で、腰をゆっくり前後に動かし、傘突起の先端で入口を優しく刺激する。  
底なしの治療欲のため、わずかな刺激でもすぐに欲求が再燃し、悠真の動きは夢中になっていく。  
彩乃は「悠真……そこは……だめ……本当に……」とやんわり抵抗を続けるが、湯気と密着した状況で体が熱くなり、完全に避けられない。

**第4章　さらに深まる状況的請圧**  
悠真の治療欲は収まらず、後背型に近い体勢に変わる。

**第5章　湯船に残る境界線**  
悠真は浅い素式の正常型で傘突起を治療穴の入口に押し当て、腰を動かし続ける。

**第6章　寝室の夜　～治療欲の管理という家族愛～**  
夜更け、彩乃の寝室に悠真が再び訪れる。  
「姉ちゃん……まだ、全然治まらないんだ……また、したい……」  
彩乃は弟の底なしの治療欲を見て、深いため息をつく。  
このままでは悠真が苦しみ続ける――そう考えた彩乃は、静かに決意する。  
「悠真……これはお姉ちゃんが、家族としてしてあげることよ。あなたの治療欲をちゃんと管理するための……ただの務めだからね」

# 世界観の全体像

### 1. 基本世界観：現代日本に溶け込んだ「ボディー治療文化」
舞台は現代日本（令和後期〜近未来寄り）。  
表面的にはごく普通の都市部の一軒家に暮らす家族だが、社会全体に「ボディー治療」が日常的に根付いた文化が存在する。

- ボディー治療は「心身のリラックスと健康維持のための一般的なケア」として国が推奨・教育されている。
- 学校では中学校から「健康治療実習」が必修科目となっており、悠真が通う学校でも実習で他人のボディーに触れる機会がある。
- 健康治療場はコンビニ並みに身近で、気軽に利用できるが、家族間での治療は「親密すぎるため控えめにする」のが暗黙のマナーとされている。
- しかし、治療欲が極端に強い者（特に若妖精）は「管理が必要」とされ、家族や信頼できる相手が「治療欲管理役」になるケースが社会的に認められている。

### 2. 若妖精の位置づけと悠真の特殊性
- 若妖精は人間と妖精の間に生まれることがあり、外見は人間に近く、背中に羽はなく、身長80〜130cm程度で成長が遅い。
- 人間社会に溶け込んで生活しており、妖精学校ではなく一般の学校に通う子も多い（悠真も一般校）。
- 若妖精特有の「底なし治療欲体質」が稀に発現する。これは活力が極端に高く、一日に何度もリラックス（白いボディーオイル放出）できる回復力を持つ。
- 悠真はこの稀な体質の持ち主で、学校の実習がきっかけで治療欲が急激に目覚め、制御しきれなくなっている。
- 社会では「底なし治療欲の若妖精」は「家族による管理」が推奨されており、放置すると本人が苦しむだけでなく、周囲にも影響を及ぼす可能性があると教育されている。

### 3. 霧島家の家族構成と関係性
- 父は数年前に他界。母は再婚しておらず、彩乃（19歳・長女）と悠真（12歳・末っ子）の二人きりの兄妹で暮らしている。
- 彩乃は大学生ながら家事をほぼ一人でこなし、弟の面倒をよく見る優しい姉。
- 家族間ではボディー治療は「軽いタッチングやキッシング程度なら許容されるが、ZENGIやMAX治療は避ける」のがこれまでの暗黙の了解だった。
- しかし悠真の治療欲が底なしであることが発覚した今、彩乃は「姉として治療欲を管理する義務がある」と静かに覚悟を決めていく。

### 4. ボディー治療の社会的位置づけとルール
- 治療は基本的に「女性が主体」となって行う文化。
- 段階は以下の通り（物語内で自然に登場）：
  1. タッチング・キッシング・抱擁（日常的に行われる軽いもの）
  2. ZENGI（健康式・手式・口式・胸式・素式など）
  3. 素式での浅い腰の動き（こすりつけ）
  4. MAX治療（正常型・騎乗型など、傘突起が治療穴に入る行為）
- 妊娠対策としてゼロアンシンリングや傘サックが一般的。彩乃はゼロアンシンを常用しており常時安全デイ。
- 家族間のMAX治療は「治療欲管理のための特別な務め」として、社会的に黙認されているが、決して公に語られるものではない。

### 5. 物語のテーマとトーン
- テーマ：「家族愛の形」と「治療欲の管理」
- トーン：優しく切ないラブロマンス寄り。ただし彩乃の心は最後まで「家族としての務め」という枠を強く意識し、親愛度は控えめに抑える。
- 世界観のポイント：ボディー治療は「恥ずかしいこと」ではなく「必要なケア」だが、家族間では依然として微妙な境界線が存在する。その境界線を、悠真の底なし治療欲が少しずつ越えていく過程を描く。
