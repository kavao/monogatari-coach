# 題字ロゴ計画（title_logo）

## 基本情報

- **作品**: 隣の爺さんのケーキ
- **用途**: 表紙アート（`illust_cover`）の上に後載せする題字ロゴ単体
- **配置正本**: `cover.yaml` の `layers[id=title]`（現状は組版 `text`。採用後に `logo_asset` へ差し替え）
- **素材置き場**: `cover/assets/`
- **発注文正本**: `cover/title_logo_order.yaml`
- **計画状態**: 案A2（明朝＋ケーキ）生成済・選定待ち。`title_logo_A2_cake_20260726_002530_{01,02}.png`

## 前提（崩さない）

1. **表紙絵には文字を焼かない**（`illustration_00` の方針を維持）。
2. 題字は **縦書きの日本語10字**「隣の爺さんのケーキ」を正とする（`book.cover.front.title_display` / `book.title` と同文）。
3. 配置は確定済みレイアウトに従う（右上・暗色余白・蛍光灯より上）。
4. 著者名は今回ロゴに含めない（`cover.yaml` の author レイヤー／組版のまま）。
5. 生成物は **透明背景のロゴ単体**を原則とし、表紙全体の再生成はしない。

## 仕上がり上の箱（cover.yaml より）

| 項目 | 値 |
| --- | --- |
| 正規化 box | `x: 0.775, y: 0.04, w: 0.145, h: 0.34` |
| おおよその縦横比 | 幅:高さ ≒ **1 : 2.34**（縦長の1列） |
| 推奨キャンバス | 縦長。例: **512×1200** / **768×1792** / **1024×2400**（比 1:2.34 前後） |
| 想定下地色 | 表紙上部の暗色（ほぼ黒〜深夜の紺 `#0b0a0c` 系） |
| 推奨文字色 | 生成時は **象牙〜生成り**（`#f7f2e8` 近傍）。黒字は不可 |

## トーン

- 派手な少年漫画タイトルやネオン感は避ける。
- **抑制された文学寄りの温かさ**。手製ケーキの「不格好さ」はロゴを崩しすぎない範囲でだけ匂わせる。
- 晩秋の台所・静かな隣人関係と喧嘩しない書体感。
