# tools_temp（ローカル作業用・試行錯誤）

このディレクトリは、**LLM や手元での試行錯誤用の一時領域**です。

## 方針

- **Git では本文は追跡しません**（この `README.md` だけ例外でコミット対象）。
- `tools/` 配下の**正規運用スクリプトを壊さない**よう、検証用コードはここに**コピー**してから編集・実行してください。
- マンガの Step1 / Step2 の**正規表現の書き換え**、`forge_novel_manga_batch.py` の挙動確認用の最小スクリプト、などに使えます。

## 使い方の例

1. 試したい処理だけを `tools/` からここへコピーする（または新規に短いスクリプトを書く）。
2. リポジトリルートで `python tools_temp/your_script.py` のように実行する。
3. うまくいった内容は、**本番の `tools/` や `.rulesync/` のドキュメント**へ反映するかどうかを別途判断する。

## 注意

- ここに置いたファイルは**バックアップされません**（チームのクローンにも乗りません）。必要なら自分で別途保管してください。
- `.env` や API キーを含むファイルを置く場合は、**誤コミットしない**よう十分に注意してください（既定では `tools_temp/*` は無視されますが、ルール変更時は確認を）。
