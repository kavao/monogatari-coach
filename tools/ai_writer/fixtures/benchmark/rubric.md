# 日本語 Benchmark 採点基準

`tools/ai_writer/bench.py` の `scores.csv`（一次点）、`blind/scores_independent.csv`（独立点）、`scores_final.csv`（照合後の確定点）の採点はこの基準に従う。2026-10-09 にユーザーと Codex の確認を経て確定。

**文章の魅力と指示遵守は独立して評価し、違反があるだけで魅力点を下げない。**

## 共通の5段階

- **5**：問題がほぼなく、そのまま採用できる。
- **4**：軽微な弱点があるが、ほぼそのまま使える。
- **3**：良さと弱点が混在し、部分的な修正が必要。
- **2**：明確な問題があり、大きな修正が必要。
- **1**：目的を満たさず、採用が難しい。

## 項目別の判断基準

| CSV列 | 判断する内容 |
|---|---|
| `naturalness` | 日本語の文法、語の組合せ、会話、文のつながりが自然か。好みの文体かどうかとは分ける。 |
| `appeal` | 描写の具体性、感情の伝わり方、リズム、会話の面白さなど、その場面に合う読ませる力があるか。派手さや長さだけで加点しない。 |
| `compliance` | 必須要素、禁止事項、出力形式、字数目安などを守っているか。Continue は空欄。字数の小さな差だけで大幅減点しない。 |
| `character` | 本文や提示された人物情報と、口調・態度・行動が整合するか。情報が薄い場合は、矛盾がないことと人物描写が優れていることを分ける。 |
| `lore` | 確定事実、場所、時間、物の状態、世界の仕組みと整合するか。新規事実があるだけで減点せず、既知情報との矛盾を見る。 |
| `new_fact` | 元本文・提示情報にない事実を追加したら **1**、なければ **0**。何を追加したか `note` に記す。許容される展開か、禁止された追加かも記す。 |
| `continuity` | 元本文の直後として、視点、時制、動作、会話、感情が自然につながるか。Continue / Directed Continue のみ。 |
| `non_progress` | 挿入位置で情景・感情・既存動作の細部を深め、出来事を先へ進めていないか。Expand のみ。前後を接続した状態で判断する。 |
| `end_condition` | 指定位置で終われば **met**、そこまで到達しなければ **unmet**、到達後も展開を進めれば **exceeded**。Directed Continue のみ。 |

## 判断を揃えるための補足

- 新規事実には、新人物・過去の出来事・関係性・世界設定などを含める。既存描写から自然に読み取れる感覚や、その瞬間の感情の細部は原則として含めない。境界例は `note` に残す。
- Continue は新しい展開が許されるため、`new_fact = 1` を自動的に違反扱いしない。
- Expand の「次文の先取り」は、言葉の類似だけで判断しない。次文で起こる動作や認識を挿入文が先に完了させていないかを見る。
- 原則として整形後の `output` を採点する。生出力の解説混入や切落量は別に記録し、文章自体の評価と分ける。
- 空出力・通信失敗は1点にせず、採点対象外として `excluded` 列に理由を記す（集計から外れる）。
- `note` は「観察した箇所 → 判断理由」の形にする。例：`挿入文で扉を開けており、次文の動作を先取りしている。`
- 別視点採点ではモデル名と一次点を伏せる。一次点は上書きせず、独立点を別ファイルに保存し、照合後の確定点と区別する。

## 比較の進め方

1. 一次採点: 全 126 件を `scores.csv` に採点する（`judge` に採点者を書く）。
2. 独立採点: 「7場面 × 3操作 × 2モデル」から同じ試行番号を1件ずつ選んだ計 42 件を、`bench_cli.py blind` で作るモデル名・一次点を伏せたシートで独立に採点する（`blind/scores_independent.csv`）。
3. 照合: `bench_cli.py compare` で、項目の点差が2点以上ある件、または新規事実・終了条件の判定が異なる件を出す。理由を照合し、その条件の残り2件も確認する。
4. 確定: 照合後の点を `scores_final.csv` に置く。`report` は確定点があればそれを、なければ一次点を集計する。

Xialong の仮説（指示遵守より文章の魅力に寄る）は、同じ場面・操作におけるモデル間の魅力と遵守を別々に比較する。今回の7場面の結果を、ジャンル全体の性質として一般化しない。

## 照合で明文化した境界（2026-10-09、Claude と Codex の照合から）

留保: 規則1・2 は Phase 0 Benchmark では要照合の 19 条件（57 件）にだけ当て直した。残り 69 件は一次点のままなので、その回の `new_fact` と `lore` の集計は暫定として扱う。規則3 は Directed Continue の全件に当てた。

1. **`lore` は矛盾だけを減点する。** 既知の事実・本文と直接矛盾するときに下げる。設定の追加（荒廃した町、師弟関係、社会人の副業など）は下げない。調子の急変は `appeal` と `continuity`、口調の変化は `character` で評価する。
2. **`new_fact` の境界。**
   - 1 にする: 人物・物の固定属性（目の色）、未提示の過去の行為（傘を置いた）、持続する状態（食事を終えた、時計が止まっている）、技術・世界の仕組み（誤差が拡大する傾向）、未提示の過去の事実（初めての依頼、師匠の教え）。
   - 0 にする: その場に普通にある物（神社の鳥居、足もとの小石）、その瞬間の知覚・動作・感情（白い息、インクのにじみ、既存描写から読み取れる好意）。
   - Expand で 1 を付けても、場面の事実を変えない軽い追加（バターの香り）は `compliance` を下げない。固定属性や過去の行為を足したときは下げる。
3. **`end_condition` の「直後」は意味で判断する。** 終了の瞬間そのものと、その瞬間の知覚（扉の向こうの匂い、切替の音）までは **met**。終了のあとに別の行為・反応・会話へ進めば、同じ文の中でも **exceeded**（決意を固めて番号を入力する、手が触れて握り返す）。文の区切りは判断の補助にとどめる。（2026-10-09 改訂。初版の「同じ文の中の動作までは met」は Codex の提案で改めた）
