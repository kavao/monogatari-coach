# 人物プロフィールの圧縮句をほぐす（欄の層分け）

`character.md` の説明文に短く積まれた句（圧縮句）を、別の抽象へ言い換えずに、その句が指している場面へ戻す基準をまとめます。ほぐせるのは、句を長くしたときではありません。句の層を分け、気質だけを **性格** に残し、ほかを正しい欄と設計の項へ戻したときです。

既定では読みません。読むのは次のときだけです。

- `character.md` を作る・直すとき（企画 Gate B の B4 手順5の掘り下げを含む）。
- 「性格欄をほぐして」「圧縮された性格を解釈して」と頼まれたとき。
- 本文・あらすじ・章出来事を書く前に性格欄を読み、意味の取れない短句が残っていたとき。

工程正本ではないので、全件必読にはしません。手順はスキル `novel-character-profile`、章出来事の文の形は `synopsis_presentation.md`、過剰圧縮の一般則は `slop_patterns.md` が受け持ちます。

この検査は、加筆（新しい性格を足す）でも、口語化（あだ名を直す）でも、設定監査（資料どうしの矛盾）でもありません。既にある句がどの層かを判定し、所属を移すだけです。

## 1. 対象の欄

- 主に **性格**。
- 同じ圧縮が寄りやすい **ワンポイント特徴**・**目標**・**倫理観**・**口調** にも同じ検査を通します。
- 外見・外見の個性・服装・ボディーの子項目は対象外です。

## 2. 層分け

句を一つずつ切り、次のどれかに振り分けます。

| 層 | 残す場所 | 判定 |
| --- | --- | --- |
| 気質（いつでもそうする） | **性格** | 場面を選ばず言える |
| この話での決め方 | **目標** または **倫理観** | この作品の中で一度決めた方針 |
| 一度の出来事 | **設計の章項**。性格には戻さない | 特定の章で一度したこと |
| 知らないことの処理 | **倫理観** または **口調** | 理由の分からない体調・出来事を、自分の知っている理由に載せて言う |

一つの句に二つの層が混ざっていることがあります（気質と一度の出来事など）。そのときは句を割り、気質の部分だけを性格に残します。

## 3. 解釈の四つ（意味を確かめる観点）

四つは、圧縮句が何を指しているかを確かめる観点です。性格欄に四つを全部書くための条件ではありません。

1. **いつ**（どんな場面で）
2. **誰に**
3. **何をする／しない**
4. **なぜ**（人物のほかの欄、世界の決まり、設計の項のいずれかで指せる）

- 句が指す場面を、資料（`character.md` のほかの欄・`world.md`・設計・本文）から四つで確かめ、分かった結果で層を選びます。
- 性格に残す句に要るのは、場面を選ばず言えることと、読者が動作として思い浮かべられることだけです。「返事を待たずに先に決める」のように、誰に・なぜを書かなくても動作が浮かぶ気質は、そのまま残します。四つをそろえるために、相手や理由を作り足しません。
- 資料から取れない部分があり、そのせいで句の意味（どの層か、何をするのか）が決まらないときは、推測で埋めずに要確認として作者へ返します。
- 開くことは、言い換えることではありません。「褒め言葉は出し惜しむ」を「評価が厳しい」に替えるのは、抽象を別の抽象へ移しただけなので不合格です。

## 4. 不合格と合格

例の人物は、小さな食堂の店主です。見習いを一人置いています。資料には次のことが書いてあるとします。

```text
character.md 悩み: 若いころ、客の前で師匠に怒鳴られ、しばらく店に立てなくなった。
character.md ワンポイント特徴: 停電の夜に倉庫へ閉じこめられてから、暗い所が苦手。
設計 第3章: 客の帰ったあと、見習いが洗った茶碗を並べて「まだ合格じゃない」と言う。
設計 第8章: 朝の手のしびれは、店の古い換気扇の煙のせいだと分かる（店主は知らない）。
```

```text
不合格（性格）: 先に決める。褒め言葉は出し惜しむ。当番の言葉で見習いを動かす。客が来ると当番は言わない。暗い倉庫には一人で入らない。朝のしびれは寒さのせい。雨の日は店を閉める。

合格（性格）: 返事を待たずに先に決める。見習いの出来を、その場では褒めない。暗い倉庫には一人で入らない。
合格（口調）: 見習いへの頼みごとは「当番」という言葉で言う。
合格（倫理観）: 客の前では、見習いに当番を言いつけない。
合格（倫理観／口調）: 朝に手がしびれても理由を知らないので、寒さのせいだと言う。
合格（設計の章項）: 第3章の既存の項を指すだけにする（書き足さない）。
要確認: 「雨の日は店を閉める」。
要確認: 客の前で当番を言いつけない理由（悩みの欄の経験とつながるかは、資料に書いていない）。
```

- 「先に決める」は、場面を選ばず言える気質です。誰に・なぜが書いてなくても動作が浮かぶので、そのまま性格に残します。
- 「褒め言葉は出し惜しむ」は、気質（その場では褒めない）と一度の出来事（設計の第3章）が混ざっています。気質は性格へ、出来事は第3章の項を指して戻します。
- 「当番の言葉で見習いを動かす」は、言い回しの句です。口調へ移します。「短い命令で言う」のような、資料に無い性質を足しません。
- 「客が来ると当番は言わない」は、この話での決め方です。倫理観へ移します。悩みの欄には客の前で師匠に怒鳴られた経験がありますが、それがこの決め方の理由だとは、どの資料にも書いていません。もっともらしくても、経験と決め方を推測でつながず、なぜは書かずに要確認として作者へ返します。資料が両者を結んでいれば（「だから客の前では叱らない」など）、そのときだけ添えます。
- 「暗い倉庫には一人で入らない」は、ワンポイント特徴の欄が理由を支える気質です。性格に残します。「誰かに明かりを持たせる」のような、資料に無い動作は足しません。
- 「朝のしびれは寒さのせい」は、知らないことの処理です。人物が本当の理由を知らないことを、倫理観か口調に置きます。理由の正体（設計の第8章）は設計の側に残します。
- 「雨の日は店を閉める」は、資料のどこにも根拠が無く、気質か一度の出来事かが決まりません。層を推測せず、性格に置いたまま要確認として作者へ返します。

本文では、設計の第3章の場面を演じます。性格の句を地の文に貼りません。

## 5. 直しの拘束

- 新しい性格・関係・出来事を足しません。句の所属を移すだけです。
- 開いた内容は、正しい欄と設計の既存の項へ移します。性格の横に「解釈」の欄を足しません（同じ句が二つになるため）。
- 出来事の層は、設計の既存の項を指します。新しい章項は足しません。指す項が無ければ要確認にします。
- 「なぜ」の根拠が `character.md` のほかの欄・`world.md`・設計・本文のどこにも無い句は、理由を作らず要確認として作者へ返します。
- 本文がある作品では、本文で確認できる範囲だけを開きます。

## 6. 書くとき／読むとき

- **書くとき**（`character.md` を作る・直す）: 句を切って層を選びます。気質以外は性格から出します。出来事の句は、設計の項を指してから書きます。
- **読むとき**（本文・あらすじ・章項を書く前）: 残った圧縮句があれば、四つで意味を資料から確かめてから書きます。分かった結果は場面で演じ、欄の句を地の文へ写しません。資料から意味が取れない句は、推測して演じず、書く前に作者へ確かめます。分かった結果を性格へ戻して再圧縮しません。

## 7. 出す前の検査

- 性格の各句は、場面を選ばず言えるか。
- 圧縮句の意味を四つで確かめたとき、取れない部分を推測で埋めていないか。
- 開いた先の動作・理由ごとに、根拠の箇所（欄・`world.md`・設計の項・本文）を一つ挙げられるか。
- 章の出来事の要約が性格に混ざっていないか。
- 開いたつもりで、別の抽象（「厳しい」「不器用」「優しい」）へ言い換えただけになっていないか。
- 足した内容に、資料に無い性格・関係・出来事が入っていないか。
