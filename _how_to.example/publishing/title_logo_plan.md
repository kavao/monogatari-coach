## 前提（崩さない）

1. **表紙絵には文字を焼かない**（`illustration_00` の方針を維持）。
2. **横書き・横タイトル主体（既定）**: ライトノベル・現代書籍で一般的な横書き（`writing_direction: horizontal`）タイトルロゴを既定（デフォルト）とする（縦書きの指定がある場合を除く）。
3. 題字テキストは `book.yaml` の `title`（または `cover.front.title_display`）と同文とする。
4. 配置は `cover.yaml` の box／safe_areas に従う（横書き既定のため表紙上部〜中央の横長帯を推奨）。
5. 著者名をロゴに含めるかは作品ごとに決める（多くの作品は著者を別レイヤーの組版のまま）。
6. 生成物は **透明背景のロゴ単体**を原則とし、表紙全体の再生成はしない。

## 生成後チェックリスト

- [ ] 文字が作品タイトルと一致し、読み違えない
- [ ] 意図しない縦書き・不要な英字・著者名（方針外）が混入していない
- [ ] 背景が透過、または単色で容易に抜ける
- [ ] 確定 box に載せても顔・主要モチーフを汚さない（合成プレビュー）
- [ ] サムネイル縮小でも題が識別できる
- [ ] 権利記録（生成日・ツール・利用範囲）を materials に書ける
