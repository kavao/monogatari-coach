# 表現ミックスの種類分けの基準

版: 1（2026-11-24）

表現ミックスの重みを、作者が直した差から決めるための基準である（計画 `_workingspace/plans/20261121_expression-mix-weights.md` §5）。本文を一文ずつ、カタログ（[`catalog.yaml`](catalog.yaml)）の10種類のどれか一つへ振る。同じ稿なら誰が振っても同じ結果になることを目指す。

- **起草・清書では読まない。** 重みを決める作業で、直す前と後の稿を数えるときだけ使う。
- 振り分けの結果と集計は作品の `_work/` か計画の作業用の写しに置く。提示層には書かない。
- 作者の振り分けと食い違ったら、この基準を直して版を上げ、両方の稿を振り直す。版の違う結果どうしを比べない。

## 1. 単位と字数

1. **単位は一文。** 句点（。）・感嘆符・疑問符と改行で切る。台詞の鉤括弧の中の句点では切らない（「行こう。今すぐ」と彼は言った。は一文）。
2. **字数**は、その文の空白と改行を除いたコードポイント数（`novel_char_count.py` と同じ NFC）。鉤括弧も数える。
3. **一文に一種類。** 字数を種類に割らない。複数の種類が入る文は、§3 の判定順で先に当たった種類に振る。
4. 振らない行（数に入れない）:
   - 章見出し・場面区切りの記号・空行
   - 章末ステータスのブロック（`<!-- status:begin -->`〜`end`）と、`status_display.md` で定義した本文内の通知
   - HTML コメント

## 2. 種類

| ID | 名前 | この基準での定義 |
|---|---|---|
| `dialogue` | 会話往復 | 台詞が文の主である文。台詞に付く「と言った」「と返した」までを含む |
| `interiority` | 内面 | 視点人物の考え・感情・判断・動機・記憶・自分への観察 |
| `metaphor` | 比喩 | 比喩が文の主である文（比喩を外すと文の半分以上が消える） |
| `sound` | 現場音 | 場面で鳴っている音が主である文 |
| `sensory` | 五感 | 手元・身近な物の色・手触り・匂い・味・温度・重さ・痛みなど、感覚の中身が主である文 |
| `environment` | 情景 | 場所・空・天気・光・建物・遠景など、場の見え方が主である文 |
| `gesture` | 所作 | 表情・視線・姿勢・間・身振り。人との距離や反応を見せる体の動き |
| `process` | 時間の伸び | 作業・工程・手当て・調べ物などの手順の一段、または手順の途中の物の変わり方 |
| `daily` | 生活行動 | 食べる・作る（食事）・洗う・片づける・身支度・寝起き・通い・買い物 |
| `action` | 動作 | 上のどれにも当たらない体の動き（歩く・取る・走る・打ち合う・運ぶ） |
| `narration` | 叙述（その他） | 説明・要約・設定・時間の経過・出来事の報告。カタログの ID ではない |

`narration` は重みの案に使わないが、集計には残す。直した差で叙述が大きく減ったか増えたかは、作者の好みの材料になる（要約で流すのを嫌う、など）。

## 3. 判定順

上から順に問い、最初に「はい」になった種類に振る。迷ったら §5 の迷う例を見る。

1. **振らない行か**（§1 の4）→ 数えない
2. **鉤括弧の中身が、文の字数の半分以上か** → `dialogue`
3. **視点人物の頭の中が主か**（「〜と思った」「〜気がした」「〜だろうか」「〜はずだった」、地の文に溶けた考え、思い出し）→ `interiority`
4. **比喩を外すと文の半分以上が消えるか**（「〜のような」「まるで〜」「〜みたいに」、隠喩）→ `metaphor`
5. **音が主か**（何が鳴ったか、どう響いたか）→ `sound`
6. **手元・身近な物の感覚の中身が主か** → `sensory`
7. **場の見え方が主か**（場所全体、空、光、遠く）→ `environment`
8. **人に向けた体の動き・表情・間か**（相手がいて、反応や距離を見せる）→ `gesture`
9. **手順の一段か、手順の途中の物の変わり方か** → `process`
10. **暮らしの中の行いか** → `daily`
11. **体の動きか** → `action`
12. どれでもない → `narration`

順番の理由:

- 台詞を先に取るのは、会話往復の増減が文の中身より台詞の有無で決まるからである。
- 内面を比喩と感覚より先に取るのは、見せ方軸（内心をどこまで語るか）で差し引くために、内面の数を濁らせないためである。
- 比喩を感覚と情景より先に取るのは、比喩を足す直しと感覚を足す直しを分けて数えるためである。ただし「半分以上が消える」に当たらない短い比喩は、残りの中身で振る。
- 所作を動作より先に取るのは、カタログで所作が動作の一部を切り出した種類だからである。

## 4. 種類ごとの文例

文例は直しの比べやすさのため、異世界の工房とふつうの暮らしから取る。人物の名前は例のためのもので、作品とは関係がない。

### `dialogue` 会話往復

- 「その鋲、あと三本足りない」
- 「足りないなら打てばいい」とリオは言った。
- 「明日の朝までだ」親方は帳面から顔を上げずに言った。（台詞が半分以上）

### `interiority` 内面

- この値段では誰も買わないだろう、とリオは思った。
- 親方に見せるのが怖かった。
- 前の世界なら、ここで機械に任せていたはずだ。
- 三日前にも同じところで割れている。（視点人物が思い出している文。地の文の事実の報告なら `narration`）

### `metaphor` 比喩

- 炉の口は、眠りかけた獣のように赤く息をしていた。
- 噂は乾いた藁に火が移るように町じゅうへ広がった。
- 鋼は彼の手の中で、まだ答えを言っていない。（隠喩）

### `sound` 現場音

- 槌が鉄を打つたびに、高い音が梁まで響いた。
- 外で荷車の車輪が石畳を噛んでいる。
- ふいごが二度、低く鳴った。

### `sensory` 五感

- 柄の革は汗を吸って、指に吸いつくように湿っていた。
- 焦げた油の匂いが鼻の奥に残る。
- 刃先に指を当てると、皮膚が引っかかるだけの鋭さがあった。
- 鉄はまだ芯に熱を持っていた。

### `environment` 情景

- 工房の窓から、雨に濡れた市場の屋根が見えた。
- 夕方の光が、棚に並んだ瓶を一列に照らしている。
- 坂の上に、石造りの組合の建物がある。

### `gesture` 所作

- 親方は刃を光にかざし、何も言わずに目を細めた。
- リオは一歩下がって、相手の言葉を待った。
- 娘は鍋を抱えたまま、視線だけをこちらへ向けた。
- 二人のあいだで、しばらく誰も口を開かなかった。

### `process` 時間の伸び

- まず割れた縁を削り、新しい鉄の当たる面を平らにする。
- 赤くなったところで炉から出し、角を叩いて落とした。
- 膠は冷えるにつれて白く濁り、やがて指で押しても跡が残らなくなった。
- 三度目の焼き入れで、ようやく刃の反りが止まった。

### `daily` 生活行動

- 朝は井戸で顔を洗い、黒パンを半分だけ食べた。
- 仕事の後、リオは床の鉄屑を掃き集めた。
- 市場で塩と干し肉を買って帰る。

### `action` 動作

- リオは梯子を上がり、棚の上の箱を下ろした。
- 男は戸口から飛び出し、通りを駆けていった。
- 剣を受け流し、そのまま相手の脇へ回り込む。

### `narration` 叙述（その他）

- この町では、鍛冶の値は組合が決めている。
- それから十日、注文は一つも来なかった。
- 噂は三日で隣の村まで届いた。
- 魔石は熱を溜めるが、水に浸けると力を失う。（設定の説明）

## 5. 迷う例

| 文 | 振り先 | 理由 |
|---|---|---|
| 「まだだ」と言いながら、親方は刃を光にかざして目を細め、長いあいだ黙っていた。 | `gesture` | 鉤括弧の中身が半分未満。残りは人に向けた所作 |
| 「三本足りない」 | `dialogue` | 一語でも台詞は台詞 |
| 槌の音が、まるで誰かが戸を叩いているように聞こえた。 | `metaphor` | 比喩を外すと「槌の音が聞こえた」で半分以上が消える |
| 炉の火は蜜のような色で、鉄の肌を照らしていた。 | `sensory` | 比喩（蜜のような）を外しても文の半分以上が残る。手元の鉄の色が主 |
| 鉄の焼ける匂いがして、これでいい、とリオは思った。 | `interiority` | 判定順で内面が五感より先 |
| 熱い。 | `sensory` | 視点人物の感覚の中身。考えではない |
| 熱いのは嫌いではなかった。 | `interiority` | 感覚への好き嫌いは頭の中 |
| 鉄が赤から橙に変わった。 | `process` | 手順の途中の物の変わり方。色そのものを味わう文なら `sensory` |
| 鉄は夕陽と同じ赤に焼けて、表面がわずかに揺らいで見えた。 | `sensory` | 色と見え方が主で、手順の段を進めていない |
| リオは槌を振り下ろした。 | 工程の中なら `process`、そうでなければ `action` | 前後が手順の段の並びなら `process`。喧嘩で振り下ろすなら `action` |
| リオは槌を置き、親方を見た。 | `gesture` | 置く動作より、相手へ向けた視線が主 |
| 親方は黙って頷いた。 | `gesture` | 反応を見せる体の動き |
| 外は雨になっていた。 | `environment` | 場の見え方。時間の経過の報告なら `narration`（「三日、雨が続いた」） |
| 雨が屋根を叩いている。 | `sound` | 音が主 |
| 二人は黙って夕食を食べた。 | `daily` | 食事の行い。黙っていることが反応の主なら `gesture`（「黙って」の後に視線や間が続くとき） |
| 鍋に塩をひとつまみ入れ、弱火で煮詰める。 | `daily` | 食事を作る手順は生活行動。工房の作業・職能の工程だけを `process` にする |
| 薬草を刻んで、湯に落とす順を三度確かめた。 | `process` | 職能（調合）の手順。家の食事なら `daily` |
| その剣は、町で一番の値で売れた。 | `narration` | 出来事の報告 |
| 誰もが、その剣の出来に息を呑んだ。 | `gesture` | 見ている人たちの反応。報告だけで体の反応が無ければ `narration`（「剣は評判になった」） |
| 前の世界の工場では、これを機械が一日に千本作っていた。 | `narration` | 視点人物の説明。比べて何かを感じる文なら `interiority` |
| 彼女の手は、思っていたより冷たかった。 | `sensory` | 手の温度が主。「思っていたより」は感覚の言い方の一部 |

一文に二つの種類が同じくらい入るときは、判定順で先の種類に振る。半分以上かどうかが際どいときは、字数を数えて決める。

## 6. 数えないもの（書き手の崩れ）

直した差のうち、ジャンルの好みではないものは集計から外す。

- `tools/metron/writer_slips.py` の目印に当たる直し: 作業指示の漏れ、Beat の意図の写し、文の二重書き、地の文の敬称、三人称の作品での視点の崩れ
- 体裁の直し（三点リーダー・句読点・段落の字下げ）
- 誤字の直し、用語の表記の直し（`world.md` の用語に揃える直し）
- 設定・筋と食い違う文の直し（その文は直す前も後も振るが、増減の根拠には使わない。§7 の表で「崩れ」と書く）

## 7. 結果の書き方

稿ごとに一つの表を作る。直す前と後の文は並べず、それぞれの稿を独立に振る（文の対応は取らない）。

```text
# 種類分け: <作品> 第<N>章 <直す前|直した後>
基準: classification_guide.md 版 1
振った者: <モデル名 | 作者>

| 番号 | 字数 | 種類 | 文の頭 | 備考 |
|---|---|---|---|---|
| 1 | 24 | environment | 工房の窓から、雨に… |  |
| 2 | 31 | dialogue | 「その鋲、あと三本… |  |
| 3 | 18 | process | まず割れた縁を削り… | 崩れ |
```

集計は種類ごとの字数の和と、稿全体に対する割合を出す。増減は「直した後 − 直す前」の字数と割合の差で見る。`崩れ` と書いた文は集計から除く。

作者が照らし合わせる場面（例: 各章の1場面）は、作者の振り分けを同じ表の形で書き、基準の振り分けと一文ずつ並べる。食い違った文は、どちらが正しいかを作者が決め、基準が違っていたなら §4・§5 に文例を足して版を上げる。

## 8. 読み方の注意

- **2〜3章の合計で見る。** 会話の多い章と作業の多い章で、比率は大きく変わる。
- **見せ方軸の分を差し引く。** 内面の増減は、作品の見せ方軸（内心をどこまで語るか）で決まる分がある。試行の作品の見せ方軸を集計の頭に書く。
- **指示と並べる。** 作者の指示の文（`_work/additions/`）と、その指示で増減した種類を対応させる。指示に出ていない増減は、書き手が勝手に足した・削った分かもしれない。
