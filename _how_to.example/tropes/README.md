# tropes（物語の型とあるある）

葉は **既定では読まない**。各葉の「発動条件」に当たるときだけ選ぶ。新しい葉を足すときは `_how_to.example/_index.md` と、この README の表の両方に1行置く。既存作品の selected は自動では増やさない。作業用 `tropes/README.md` がある環境では、そちらへ追随するまで標準だけの新葉は選定対象外。

ジャンルをまたいで物語でよく見る型（あるある）と、その内側の論理を整理する。対象は二種類ある。

- **人物**: 特定の価値観・美学を持つ人物や集団が、なぜそう振る舞い、どこでずれ、何をきっかけに変わるか。
- **設定**: 作品独自の要素（能力・技術・存在・ルールなど）が、世界・制度・人物をどう変え、その掘り下げがどう物語を進めるか。

| ファイル | 対象 | 主な用途 | 発動条件 |
|---|---|---|---|
| [yankee_aesthetics.md](yankee_aesthetics.md) | 人物 | ヤンキー美学。筋・意地・仲間・地元・過剰装飾、理想と実践のずれ | 「ヤンキー美学」の明示、または不良文化の筋・意地・仲間・地元・過剰装飾が人物・集団の主要な軸のとき（「友情」「義理」「派手」だけでは選ばない） |
| [zero_sum_mindset.md](zero_sum_mindset.md) | 人物 | ゼロサム思考・ハルピュイア型。取り分の奪い合いとして世界を見る人物、略奪者から統治者への転化、改心のきっかけ | 盗賊・山賊・略奪者・ただ乗りする人物や集団が主要な軸のとき、または奪う側と作る側の価値観の衝突を物語の推進力にするとき（「悪役」「強欲」だけでは選ばない） |
| [foreign_element.md](foreign_element.md) | 設定 | 異物導入。一つの独自要素の帰結を追う、知られ方・運用上の性質、掘り下げの層、段階ごとのあるある、制約の設計、失敗例 | 作品独自の要素を既存の世界に持ち込み、その性質・制約・副作用の掘り下げ自体が物語の進行になるとき（魔法や異能が当たり前にある世界を背景にするだけでは選ばない） |

## ほかのカタログとの住み分け

- `tropes/`：人物・集団が信じている論理と、その型の振る舞い。作品独自の要素の掘り下げ方。どちらもジャンルを問わない。
- `genre/`：作品全体へ効くジャンルの約束事と長期構造。ジャンル軸が該当すれば必読。異世界クラフトや闇鍋のように、特定のジャンルで独自要素をどう扱うかはこちら。
- `episode/`：一話・一場面として再利用する展開や装置（敵対者・偽味方・恩義など）。
- [`ethos.md`](../ethos.md)：義務・禁止線・代償による倫理的な選択の設計。tropes の葉で型を決めたあと、個々の人物の選択を具体化するときに併用する。

## 運用

- 型名・軸名・ID は設計の判断材料である。物語案や `proposal.md` のログライン・あらすじ・キャラクター紹介には型名のまま書かず、人物・出来事・選択として書く（`_how_to.example/synopsis_presentation.md`）。
- 一人の人物へ型を丸ごと載せない。作品に要る軸と、崩れる・ずれる点を選ぶ。
- 葉の内容は創作のための整理であり、実在の集団・地域・国籍の性質を説明するものではない。史実や実在の文化として本文へ出す事項は別途資料で確認する。
- 基準本文は `_how_to.example/tropes/`、ユーザー共通の調整は `_how_to/tropes/`、作品固有の決定は `novels/<作品>/` の `character.md`・`world.md`・`design_specification.md` へ置く。
