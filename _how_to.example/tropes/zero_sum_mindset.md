# ゼロサム思考とハルピュイア型

> 原資料（来歴）: `C:/Users/Owner/Downloads/ゼロサム思考_ハルピュイア/zero-sum-tropes.md`

## 発動条件

> 盗賊・山賊・略奪者・ただ乗りする人物や集団が主要な軸となる場合、または奪う側と作る側の価値観の衝突を物語の推進力にする場合に選ぶ（既定では読まない。「悪役」「強欲」「ケチ」だけでは選ばない）。

## まず考える5つの問い

1. この人物は、他人の得を「その人が作った結果」と見るか、「自分に回るはずだった取り分」と見るか。
2. 明日も同じ相手と付き合う前提があるか。無いなら、なぜ無いのか（環境か、本人の見方か）。
3. 奪う相手を、どんな理由で「奪ってよい相手」にしているか。
4. 一人のときと群れの中で、振る舞いはどう変わるか。
5. 何が起きたら「全部は取らない」「作る側に回る」へ動くか。

ここで扱うモデルは人物・集団を設計するための創作レンズであり、実在の集団・地域・国籍の性質を説明するものではない。人物の倫理的な選択とその代償を詳しく設計するときは [ETHOS](../ethos.md) を、主人公を追い詰める敵役として組むときは [敵対者類型設計](../episode/general/episode_antagonist.md) を併用する。

## 中心命題

ゼロサム思考の人物は、世界を「価値を増やす場所」ではなく「すでにある価値の取り分を争う場所」として見る。作る・育てる・維持する・返すよりも、取る・奪う・出し抜くを先にする。

> 他者の利益を「価値を作った結果」ではなく、「本来自分にも回ってくるはずだった取り分」として見る。

物語上の要点は、本当に取り合うしかない場面でそう考えることではない。協力すれば全体が増える場面まで奪い合いに変え、全体を縮めてしまうことにある。

```
協力すれば   A 100 / B 100   合計 200
奪い合うと   A  60 / B  40   合計 100   ← A は「B より多い」ので勝ったと思う
```

この「相対的には勝ったが、全体は減った」構図が、単なる強欲や短期志向との違いになる。

## ハルピュイアという像

ハルピュイアはギリシャ神話の怪鳥で、食卓に舞い降りて食べ物をさらい、残りを汚して去る。本資料では、ゼロサム思考のうち「奪う」と「次を考えない」が重なった型の名前に使う。

| 振る舞い | 内容 |
| --- | --- |
| さらう | 他人が用意したものを、対価なしに持ち去る |
| 汚して去る | 持ち去ったあとの場（村・市場・仲間うち）が続くかを気にしない |
| 次の食卓を考えない | 用意した者が次も用意してくれるかに関心がない |

> 「そこにあるなら取ればいい。明日のことは明日考える。」

## 土台: 有限のパイ

五つの軸すべての前提にある見方。

- 富・楽しみ・資源は最初から決まった量だけあり、誰かの取り分が増えれば自分の分が減る。
- 全体を大きくすることより、今ある分のどこを自分が取るかを考える。

人物に出る振る舞いの例:

- 他人が儲けると、まず「取りすぎだ」と考える。
- 成功した者を見ると「どこから持ってきたのか」を考える。
- 「みんなが得をする」という話を疑う。

## 五つの軸

| 軸 | 名前 | 欠けているもの | 口癖 |
| --- | --- | --- | --- |
| A | 一回きり思考 | 明日という時間 | 「次なんて知らん」 |
| B | 手間が見えない | 作る工程の想像 | 「元からそこにあったもの」 |
| C | 被害者意識による正当化 | 加害の自覚 | 「奪われてるのはこっちだ」 |
| D | 相互不信と同調 | 信頼と個人の責任 | 「みんなやってる」 |
| E | 共有地の食い潰し | 維持に加わる意識 | 「誰かが直すだろ」 |

一人に五つ全部を載せる必要はない。主な軸を一つか二つ決め、ほかは弱く添えるか持たせない。

### A. 一回きり思考

明日も相手と付き合う前提があれば、仕返し・信用・お返しが協力を支える。その前提が消えると協力する理由も消え、「今日 100 取る」が「今日 70、明日も 70」より先に来る。

- 早い者勝ち・抜け駆け・今しか手に入らないものに強く反応する。
- 恩を受けても返さない。次に会うかわからない相手には借りを作ってよいと考える。
- 「まだ残っている」うちは問題にせず、枯れてから初めて気づく。枯れても次の場所へ移るだけ。

**環境への適応として描ける。** 約束が守られない土地、蓄えても奪われる暮らし、譲って報われたことが一度もない経験の中では、今日の確実な得を選ぶのは本人にとって筋が通っている。能力の欠けではなく、そう学んだ結果として書ける。

口癖: 「今しか手に入らないんだから」「どうせ潰れるなら今のうちに」「その時になったら考えればいい」

### B. 手間が見えない

できあがった物の後ろにある工程を思い描けない。作った経験が無いことが主な理由だが、それだけではない。腕のある職人でも、専門の外では「そんなもの簡単だろう」と言う。

工程が見えないと、作られた物は「誰かが作った物」ではなく、川の水や山の木のように「そこにある物」に見える。すると作り手は「価値を生んだ人」ではなく「価値ある物を抱え込んでいる人」に映り、権利は報酬ではなく、取るのを邪魔する門になる。

- 「こんなの誰でも作れる」と言う。自分では作ったことがない。
- 直しや手入れの手間を仕事と思わない。
- 「好きでやってるんだろう」と、作り手の労を値切る。
- 作り手を「作った人」ではなく「握っている人」と見る。

口癖: 「減るもんじゃないし」「金取るほどのもんじゃない」「文句があるなら自分で作れ」（自分が作る側に回るとは考えない）

### C. 被害者意識による正当化

奪うことへのためらいが起きない、または言い訳で打ち消される。内側は人によって違う。

- 後ろめたさはあるが、理屈で押さえ込んでいる。
- 損は小さいと思っている。
- そもそもその決まりに同意していない。
- 奪ったあとに何が起きるかを考えていない。

どの場合も、「自分のほうこそ奪われている」という見方がためらいを外す。相手を強者・搾取する側・敵と位置づければ、奪うことは「取り返し」になる。相手が豊かなほど、相手の損は見えなくなる。

- 「あれだけ持ってるんだから少しくらい」と言う。相手が小さな店でも同じことを言う。
- 咎めた者を「あいつらの手先」「お高くとまった奴」と呼んで黙らせる。
- 自分の取り分が侵されたときだけ、急に権利を言い立てる。
- 「強い奴が根こそぎ奪って何が悪い」。奪うこと自体が強さの証になっている襲撃者の型。

口癖: 「向こうだって儲けてるだろ」「こっちは食えてないんだよ」「嫌ならやめればいい」

背景になりやすい条件:

- 「相手の身になって考えろ」と教わった経験が乏しい。教わっていても、「相手」に作り手や遠くの者が入っていない。
- 過去に奪われた経験、決まりや支配する側への不信。
- 自分は弱い側・やられる側だという自己像が強い。

### D. 相互不信と同調

> 自分が取らなければ、他人が取る。出し抜かなければ、出し抜かれる。

この前提では「取れるのに取らない」は美徳ではなく「取り損ねた」だけになる。善し悪しの基準は「これを続けられるか」ではなく「ほかの者もやっているか」になる。

- 善意を罠だと疑い、ただでくれる物には裏を探す。
- 譲ればもっと要求されると思い、歩み寄りを弱さと取る。
- 決まりを守る者を要領が悪いと笑い、抜け道を見つける者を賢いと褒める。
- 被害が大勢に散ると、後ろめたさも薄くなる。

口癖: 「みんなやってる」「俺だけ守って何になる」「正直者が馬鹿を見る」「俺がやらなくても誰かがやる」

### E. 共有地の食い潰し

一人ひとりが取れるだけ取ると、みんなで使う物が壊れる。根にあるのは、二種類の「共有」の取り違えである。

| 種類 | 意味 | 関わり方 |
| --- | --- | --- |
| 入会（いりあい）の物 | みんなで手入れしながら使う物（井戸・道・森・砦） | 使いながら、手入れにも加わる |
| 戦利品 | 誰かの物を奪って得た物 | 取った者の物になり、手入れの責任は無い |

入会の物は「使ってよい物」であると同時に「手入れしなければ消える物」である。戦利品として見ると、後ろの半分が消える。ゼロサム思考の人物は入会の物を戦利品として扱い、「自由に使える」を「好きなだけ取ってよい」と読む。

- 誰かが手入れするのを当てにして、自分は手を出さない。
- 「全体が崩れなければ、自分一人の抜け駆けはかまわない」と考える。

口癖: 「使えるものは使えばいい」「知らなかった奴が悪い」

## 軸の連鎖

```
A 明日はない
  → 次の収穫・次の作品が視野から消える
B 元からあった物
  → 作り手が「抱え込んでいる者」に見える
C 奪われてるのはこっちだ
  → 奪うことが取り返しに変わる
D みんなやってる
  → 責任が群れに溶ける
E 誰かが直すだろ
  → 作る者・手入れする者が離れ、本当に明日が無くなる
  → A へ戻る（「やっぱり世界は奪い合いだ」と確信が強まる）
```

見方はゼロサムでも、行動の結果は全体を減らす。全体が減ると「世界は奪い合いだ」という見方がさらに強まる。この自己強化が、型としていちばん厄介な点であり、物語の悲劇の芯にもできる。

崩れ方は一気には来ない。物語で時間をかけて見せるなら、次の三段に分けられる。

| 時間 | 起きること | 当人からの見え方 |
| --- | --- | --- |
| 短い（数か月） | 実りや支えが少しずつ減る | ほとんど見えない |
| 中くらい（一〜数年） | 店が畳まれる、職人が去る、村が捨てられる | 「急に終わった」と感じる |
| 長い（数年以上） | その土地・その仕事に新しく来る者がいなくなる | 「昔はよかった」と言う |

ここで示すのは、奪うことが細る原因の一つになりうるという構造である。物語の中でも、崩れた理由を一つに決めつけない人物を置くと厚みが出る。

## 型

| 型 | 主な軸 | 特徴 |
| --- | --- | --- |
| 刹那型 | A | 先を考えないが、作り手への敵意はない。説けば動くことがある |
| ただ乗り型 | A+B | 「ただでいいだろ」。悪気は薄いが、悔いもしない |
| **ハルピュイア型** | A+B+C（しばしば D） | 根こそぎ持ち去り、次を考えず、作り手を敵と見る。咎められるほど言い訳が強まる |
| 群れ型 | C+D | 一人では動かないが、「みんなやってる」場では先頭に立って奪う |
| 共有地荒らし型 | A+E | 悪気なく、みんなの物を使い切る |

## 山賊の経済

この見方を極端に単純にすると、農民ではなく山賊の経済になる。

| 立場 | 考えること |
| --- | --- |
| 農民 | 種を残さなければ、来年は収穫できない |
| 商人 | 信用を失えば、次の取引ができない |
| 職人 | 道具と腕を保たなければ、次の品を作れない |
| **山賊** | 今日通った商人から、取れるだけ取る |

違いは、次の実りを作る側に加わっているか、今ある物を奪う側にいるかである。

### 略奪者から統治者へ

> 山賊は蓄えを奪う。領主は毎年の実りを押さえる。

略奪 → 定期的な取り立て → 年貢 → 統治

頭目が「全部は奪うな。来年も取れるように残せ」と言い出したら、A を抜け出した兆しである。農民が作り続けられることを守る必要が出た時点で、「全部取る」は「来年も取れるだけ取る」に変わり、略奪者は治める者になる。成り上がりの筋、盗賊団の分裂（全部取りたい者と残したい者）、悪役の格上げに使える。

## 人物の段階

| 段階 | 描き方 |
| --- | --- |
| 雑魚の盗賊 | ハルピュイア型そのもの。後ろめたさが無く、奪うことを楽しむ |
| 群れの盗賊 | D が主。一人では何もできないが、群れると残酷になる |
| 知恵のある頭目 | A を半分抜けている。奪い方を「続けられる形」にする |
| 義賊 | C の向きを変えた型。奪う相手を絞ることで、奪うことを正しいものにしている |
| 改心する盗賊 | B を得る（何かを作る・守る経験）ことが転機になる |

## 改心のきっかけ

どの軸が崩れるかで、きっかけの形が変わる。

| 崩れる軸 | きっかけの例 |
| --- | --- |
| A | 帰る場所や、明日を約束される |
| B | 初めて自分で何かを育て、実りを得る |
| C | 奪った相手に助けられる |
| D | 群れから外れ、一人で選ぶことを迫られる |
| E | 頼っていた井戸・道・砦が枯れる、崩れる |

改心を一度で終わらせず、別の軸が残って揺り戻す筋も作れる（育てる喜びは知ったが、群れに戻ると奪う側に立ってしまう、など）。

## 対になる型: 増やす側の人物

主人公や対立役を、ゼロサム思考の人物と並べるときに使う。

| 観点 | ゼロサム（ハルピュイア） | 増やす側（耕す者） |
| --- | --- | --- |
| 世界の見方 | 決まった量を奪い合う | 作れば増える |
| 時間 | 今日だけ | 来年・次の代 |
| 作られた物 | そこにあった物 | 誰かの手間の結果 |
| 作り手 | 抱え込む者・敵 | 次の食卓を用意してくれる人 |
| 他人の得 | 自分の損 | 全体が増えれば自分にも回る |
| 取らない者 | 弱い・要領が悪い | 場を守る者 |
| みんなの物 | 戦利品 | 入会の物 |

増やす側に見られる振る舞いの例:

- 作り手が儲けていると「次が出る」と喜ぶ。
- 「これを作るのは大変だったろう」と工程を思い描く。
- 受けた恩を、別の誰かへの手助けで返す（恩送り）。恩の授受を物語の台帳として扱うときは [恩義設計論](../episode/general/episode_obligation.md) に従う。
- 共同の井戸や道の手入れに、小さくても手を貸す。

## 悪意と決めつけない

この見方は、他人を苦しめたいという悪意から生まれるとは限らない。

- 先への不信、極端に目先しか見られない暮らし
- 作った経験の乏しさ
- 決まりや支配する側への不信
- 過去に奪われた経験
- 生き延びるのがやっとの環境

人物は「世界は奪い合いだ」と信じていて、その世界の中では筋の通った行動をしている場合がある。断罪するだけの悪役にせず、条件が変われば変わりうる人物として描くと、改心や揺り戻しの筋が立つ。

## 深掘り用の問い

必要な問いを選び、答えを `character.md`、`world.md`、`design_specification.md` など作品の適切な正本へ記録する。

1. この人物の主な軸はどれか。弱く添える軸、持たせない軸はどれか。
2. 明日が無いと学んだ出来事は何か。それは本人の外の事情か、思い込みか。
3. 奪う相手をどう呼び、どんな理由で奪ってよい相手にしているか。
4. 群れの中で、誰の目を気にして奪っているか。
5. 奪ったことで何が細り、それを本人はいつ、どう知るか。
6. どの軸が、何をきっかけに崩れるか。崩れたあと、何が残って揺り戻すか。
7. 物語の視点は、この人物を裁くか、理解するか、両方を見せるか。

## 現代劇で使う場合

原資料は、現代の観察（海賊版や無断転載、無料の道具の使い倒し、寄付で回る場への無関心など）と、創作の人物設計を兼ねている。現代劇でこれらを題材にするときも、本資料の軸は使える。ただし、特定の国・地域・集団の性質として書かない。差を生むのは生まれや国ではなく、「作る側に立った経験」と「信頼が報われる環境にいたか」と置くほうが、人物の変化を描きやすい。実在の事件や数値を本文に出すときは、別途資料で確かめる。

## 作業用への導入

標準版を作品で選定する前に、作業用 `_how_to/_index.md` がある場合は、利用者が `_how_to/tropes/zero_sum_mindset.md` へコピーし、作業用索引から参照できる状態にする。作業用の葉がある場合はそちらを実効版として使い、標準版と自動合成しない。既存作品の `_meta.md` の selected は、作品ごとに適用を決めたときだけ更新する。
