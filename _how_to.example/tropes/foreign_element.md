# 異物導入と、その帰結の追い方

> 原資料（来歴）: `C:/Users/Owner/Downloads/異要素の制約/foreign-element-tropes.md`

## 発動条件

> 能力・技術・存在・知識・ルール改変など、作品独自の要素（以下「異物」）を既存の世界に持ち込み、その性質・制約・副作用を掘り下げていくこと自体が物語の進行になる場合に選ぶ（既定では読まない。魔法や異能が当たり前にある世界を背景にするだけでは選ばない）。

## まず考える5つの問い

1. 異物は何か。一つに絞ると、何が幹になるか。
2. 何ができないか。その制約は、登場人物にどんな新しい行動を強いるか。
3. 世界のどこまでが、その異物を知っているか（本人だけ・一部・噂・社会全体）。
4. 誰が最初に悪用し、誰が商売にし、誰が規制しようとするか。
5. 物語の終わりに、異物込みのどんな「新しい普通」が成り立っているか。

一人の人物の価値観を設計するときは [ETHOS](../ethos.md) を、異物を複数混ぜて摩擦を起こす作品では [闇鍋・多題材混交](../genre/yaminabe_hybrid.md) を併用する。持ち込んだ技術・知識が社会へ広がる過程の具体例は [異世界クラフト](../genre/isekai_craft.md) と [異世界現代知識無双](../genre/isekai_modern_knowledge.md) にある。

## 中心命題

> 既存の世界に異物を持ち込み、その異物が世界・人物・制度・倫理・戦い方をどう変えるかを、いくつもの方向から噛みくだいていく。

面白い作品ほど、異物そのものより「異物があった結果、何が変わるか」を何段階も追っている。

| # | 命題 | 効く場所 |
| --- | --- | --- |
| 1 | 異物を増やすのではなく、一つの異物の帰結を追う | 設定 |
| 2 | 良い制約は弱体化ではなく、新しい行動原理を作る | 物語 |
| 3 | 噛みくだいた先にあるのは異物の消滅ではなく、異物込みの新しい普通 | 世界観 |
| 4 | 設定では全方向に噛みくだき、本編では主題に関わる方向だけ描く | 書き方 |

## 0. 適用範囲

能力ものに限らず、「既存の世界への異物の持ち込み」として扱う。

- 超能力・魔法・特殊体質
- SF の技術・道具・新しいエネルギー
- 新しい種族・怪物・神・幽霊・異世界人
- 不老不死・蘇生・複製・人格交換
- AI・新しい社会制度・ルールの改変
- タイムリープ・予知など因果に触れるもの

### 一次の異物は一つに絞る（推奨）

「嘘は一つだけ」は役に立つ指針だが、必須ではない。大事なのは嘘の数ではなく、因果の幹が一本であること。

二つ目以降の特殊な要素を入れるときは、次のどれかを区別する。

- **派生**: 一次の異物から自然に生じたもの
- **適応・対抗**: 一次の異物に応じて生まれたもの
- **独立**: 一次の異物と関係のない、別の異物

派生・適応・対抗なら同じ幹に属する。独立した異物が増えると、掘り下げの軸がぶれる。

```text
一次の異物: 超能力者がいる
├ 派生: 能力は遺伝する → 血統の管理
├ 対抗: 能力を抑える鉱石 → 採掘権の争い
└ 適応: 能力者を嗅ぎ分ける生き物 → 検問に使われる
```

一つの異物でも、帰結を追えば世界は連鎖して変わる。

```text
瞬間移動（一次の異物）
├ 物流: 配送・航空が崩れる
├ 国境: 入国管理が意味を失う → 行き先の監視が生まれる
├ 所有権: 「能力者は国の資産か」が争点になる
└ 建築: 密室が無くなる → 防犯の考え方が変わる
```

## 1. 分類軸

### 1-1. 異物の種類

| 種類 | 例 |
| --- | --- |
| 能力 | 時間停止、読心、瞬間移動、予知 |
| 道具 | 願いを叶えるノート、タイムマシン |
| 存在 | 吸血鬼、宇宙人、神、AI |
| 知識 | 未来の記憶、禁書、前世の記憶 |
| ルール改変 | 死者が蘇る世界、嘘がつけない世界 |

### 1-2. 広がりの大きさ

```text
個人 → 身近な人間関係 → 地域・組織 → 社会・国家 → 世界・歴史
```

### 1-3. 誰が知っているか（ジャンルを分ける大きな分かれ目）

| 知られ方 | 内容 | 吸血鬼を例にしたジャンル | 厚くする層（→2） |
| --- | --- | --- | --- |
| 公知 | 社会全体が存在を知っている | 共存社会もの | 7 経済・8 制度・10 文化・11 歴史 |
| 秘匿 | 一部の組織だけが知っている | 裏社会・伝奇もの | 4 悪用・5 対抗・6 情報、組織の掟 |
| 都市伝説 | 噂だけがある | ホラー・ミステリー | 0 効果・1 制約の不確かさ、6 情報の真偽 |
| 主人公だけ | ほとんど誰も知らない | 日常侵食もの | 2 個人・3 応用、日常と人間関係 |

知られ方は物語の中で移る（主人公だけ → 秘匿 → 公知）。移る瞬間が大きな転換点になり、厚くする層もそこで切り替わる。

### 1-4. 異物の運用上の性質

同じ読心でも、「世界で一人だけ・渡せない・見抜けない」と「訓練すれば誰でも身につく」では、社会の変わり方がまったく違う。

| 性質 | 問い |
| --- | --- |
| 希少性 | 一人だけか、少数か、誰でもか（→3-12） |
| 再現性 | 同じ条件なら同じことが起きるか |
| 移転性 | 他人に渡せるか、奪えるか |
| 複製性 | 増やせるか |
| 遺伝性 | 子孫に伝わるか |
| 習得性 | 訓練で身につくか |
| 検知性 | 持っていること・使ったことを外から見抜けるか（→1-5） |
| 永続性 | 一時的か、一生か |
| 可逆性 | 元に戻せるか |
| 拡散性 | うつるか、広がるか |

- 移転性・複製性が高い → 所有権（3-15）と経済（3-11）が前に出る
- 遺伝性が高い → 血統・婚姻・家の物語になる
- 習得性が高い → 教育・資格・格差の物語になる
- 拡散性が高い → 感染の広がり・隔離・ホラーの物語になる

これらを決めておかないと、渡せるか・遺伝するかが場面ごとにぶれる（→8-1）。決めた性質は用語集の定義に書く（→「用語集への登録」）。

### 1-5. 見抜けるか × 誰が知っているか

見抜けるかどうかは、知られ方とは別の軸である。社会が異物の存在を知っていても、誰が持っているか分からない世界は成り立つ。

| | 見抜ける | 見抜けない |
| --- | --- | --- |
| **公知** | 登録制度・資格・差別・管理 | 疑心暗鬼・身分証明・監視社会 |
| **秘匿** | 秘密組織による狩り・回収 | 潜伏・スパイ・都市伝説 |

見抜く技術の発明や、それを逃れる手段の発見は、それ自体が物語の転換点になる（→3-8）。

## 2. 掘り下げの層

異物を見るためのレンズ。番号は進む順ではなく、全部を通る必要もない。作品の主題に合わせて、厚く掘る層を選ぶ。

| 層 | 問うこと |
| --- | --- |
| 0. 効果 | 何ができるか |
| 1. 制約 | 何ができないか |
| 2. 個人 | 本人はどう使うか |
| 3. 応用 | 別の使い道は |
| 4. 悪用 | 悪人ならどう使うか |
| 5. 対抗 | どう防ぐか |
| 6. 情報 | 正体や仕組みを知ると何が変わるか |
| 7. 経済 | 誰が儲かり、誰が潰れるか |
| 8. 制度 | 法律・軍・警察はどう変わるか |
| 9. 倫理 | 許される使い方はどこまでか |
| 10. 文化 | 常識・礼儀・価値観はどう変わるか |
| 11. 歴史 | 数十年後にどう定着しているか |

### ジャンル別の掘り方

| ジャンル | 中心の層 |
| --- | --- |
| 日常もの | 0・1・2・3・9・10 |
| 能力バトル | 0・1・3・4・5・6 |
| 社会派 SF | 0・1・7・8・9・10・11 |
| 伝奇・裏社会 | 0・1・4・5・6・8 |
| 恋愛・人間ドラマ | 0・1・2・9 |

### 全体の流れ

```text
異物が来る
↓ 混乱（発見・確かめ・制約が分かる）
↓ 利用（個人で使う・応用する・商売にする）
↓ 対抗（悪用・対策・情報戦）
↓ 制度化（分類・法・規制）
↓ 文化化（常識・礼儀・言葉が変わる）
↓ 新しい釣り合い
```

世界はいつまでも「能力者が現れて大騒ぎ」しているわけではない。自動車も電話も、現れたときは社会にとっての異物だったが、いまでは前提になっている。物語の始まりの異物が、作品を通して世界に飲み込まれていく過程そのものを描くこともできる。

## 3. 段階ごとのあるある

20項目は4つの群に分かれる。社会の群は 3-10 を要にし、3-11〜3-16 はその各論にあたる。

```text
個人   3-1 発見 → 3-2 確かめ → 3-3 制約 → 3-4 個人で使う → 3-5 日常 → 3-6 応用
対立   3-7 悪用 → 3-8 対策のいたちごっこ → 3-9 情報戦
社会   3-10 露見と社会への組み込み（要）
        ├ 3-11 経済   ├ 3-12 希少性 ├ 3-13 分類
        ├ 3-14 法律   ├ 3-15 所有権 └ 3-16 倫理
時間   3-17 文化になる → 3-18 積み重なり・戻せない → 3-19 長い目での釣り合い → 3-20 正体・起源
```

### 3-1. 発見と最初の反応

- 最初の発動は偶然。本人が気づかないか、別の原因だと思い込む。
- 「夢かと思って」もう一度試し、同じことが起きてから受け入れる。
- 最初の使い道がくだらない（遅刻を避ける、カンニング、自販機の下の小銭）。
- 誰かに話しても信じてもらえず、証明しようとすると発動しない。

### 3-2. 確かめる段階（実験の場面）

- ノートやメモに条件を書き出した「決まりの一覧」が出てくる。
- 回数・距離・続く時間・対象の大きさを一つずつ変えて測る。
- 協力者（理系の友人、マニア、冷静な幼なじみ）が確かめ役を買って出る。
- 生き物に試すかで一度ためらう（虫 → ネズミ → 人の順に進む）。
- 「書いてある決まり」と「実際の動き」がずれていて、そこが伏線になる。
- 本人にも本質や範囲がつかみきれず、試しながら探ることになる。

### 3-3. 制約が分かる ―「できること」より「できないこと」が決まる

物語を長く持たせるには、早めに「何ができるか」から「何ができないか」へ移る（詳しくは「4. 制約の設計」）。

- 使いすぎると鼻血・頭痛・記憶が抜ける・寿命が減る・人らしさが削れるなどの代償がある。
- 何でもできそうなのに、肝心な場面でだけ使えない条件がある。
- 発動の条件（見る、触る、名前を知る、時刻、気持ちの状態）が後半で詰みどころになる。
- 自分には使えない、または自分にだけ跳ね返る。
- 強すぎて制御できない。精度や範囲を絞れない。

### 3-4. 本人がどう使うか

- 暮らし・仕事・金儲け・恋愛・犯罪・身を守ることにどう使うか考える。
- 隠すべきか、見せたほうが得かで迷う。
- 便利な道具のはずが、人柄を形づくる原因になる。
  - 読心: 「便利」→「いつも聞こえるなら人付き合いがつらい」→「人を信じる力を失う」

### 3-5. 日常での使い道 ― 戦い以外の使い方で世界が立つ

- 念力でリモコンを取る、洗濯物を干す。
- 予知で電車の遅れや混雑を避ける。
- 治す力で肩こり・虫歯・二日酔いを治す。
- 風呂・トイレ・寝ている間に暴発しないか、服はどうなるか。
- 「時間を止めている間、他人の服は動かせるのか」のような細部が、読者の議論を呼ぶ。

作者がその力と一緒に暮らすところを想像している感じが出る。

### 3-6. 応用の発見 ― 強くなるのは出力ではなく理解

```text
火を出せる → 熱を操れる → 熱を奪える → 温度の差を使える
```

- 力の名前が考え方を縛る。「炎を出す力」と思っていたものが、実は「物の中の粒の動きを速める力」だった。
- 本人の思い込み（「これは炎の魔法だ」）が使い方を狭めている。
- つまり、力をどう理解しているか自体が、力の制約になる。

### 3-7. 悪用 ―「敵ならどう使うか」

主人公だけが使うという前提を捨てると、世界が一気に広がる。

- 犯罪者・軍人・詐欺師・政治家・企業・宗教団体ならどう使うか。
- 瞬間移動: 主人公「移動が楽」→ 犯罪者「密室が無くなる」→ 国「国境の警備が崩れる」
- 悪用する者が、主人公の思いつかなかった使い方を最初にやってのける（大きな見せ場の一つ）。

### 3-8. 対策のいたちごっこ

異物の存在が知られれば、それを前提にした対策が生まれる。

| 異物 | 対策 |
| --- | --- |
| 透明になる | 熱を見る道具、粉、音、重さを測る床 |
| 瞬間移動 | 行き先になりそうな場所の監視 |
| 予知 | でたらめさを増やす |
| 読心 | 意味を知らない者に暗号を扱わせる |
| 変身 | 本人確認を何重にもする |
| 蘇生 | 死亡を確かめる制度そのものを変える |

```text
異物 → 使い方 → 悪用 → 対策 → 対策破り → 新しい当たり前
```

### 3-9. 情報戦 ― 力そのものより「力についての情報」

- 「目に入った相手を止める」力も、仕組みがばれれば背後・煙幕・鏡・遠距離・無人の兵器で対処される。
- 力の情報は軍事機密になる。
- 戦力 ＝ 力 ＋ 力についての知識 ＋ 相手に与えた誤った情報

### 3-10. 露見と社会への組み込み（社会の群の要）

露見を境に、異物は経済（3-11）・希少性（3-12）・分類（3-13）・法律（3-14）・所有権（3-15）・倫理（3-16）へ同時に広がる。各論は別々に参照できるが、実際の作品では同時に起きる。

国や企業は、知らないものをいきなり理解せず、次の順で扱おうとする。

```text
露見 → 分類 → 管理 → 商品にする → 規制 → 標準になる
```

- 自分のほかにも同じ異物を持つ者がいたと分かる。
- 組織（国、企業、宗教、研究機関）が嗅ぎつける。
- 異物を前提にした制度・保険・法律・差別が生まれる。
- 持たない者からの妬み・恐れ・利用・研究・排除。
- 公にすれば秩序が崩れるので隠すしかなく、孤立し、人間関係が変わる。
- 同じ異物を持つ者どうしで、効果がぶつかったり強め合ったりする。

### 3-11. 経済 ― 商売人が必ず出てくる

その力で誰が商売をしているかを見ると、社会まで掘り下げられているかが分かる。

- 治す力 → 病院、美容、スポーツ、軍、保険、延命、金持ち向けの医療
- 瞬間移動 → 配送、旅行、通勤、軍の輸送、密輸、救急

「それ、今ある商売が潰れるよね？」問題

| 異物 | 潰れる商売 |
| --- | --- |
| 瞬間移動 | 航空・鉄道・物流 |
| 何でも通じる翻訳 | 通訳・語学教育 |
| 予知 | 保険・金融市場 |
| 何でも治す | 医療 |
| 尽きないエネルギー | 石油・電力・輸送 |
| 複製 | 製造業・著作権・貨幣 |

### 3-12. 希少性で抑えることと、その副作用

運用上の性質（1-4）のうち、世界を壊しすぎないためによく使われるのが「持つ者はごく少ない」。しかし掘り下げると、

- 国や企業が囲い込む。犯罪組織が狙う。さらわれる。
- 崇められる。血統が管理される。

つまり、珍しくて強いほど奪い合いの的になる。珍しいから社会に影響しない、とはならない。

### 3-13. 分類 ―「これは何なのか」問題

法律より前に、異物に今ある世界のどの札を貼るかで争いが起きる。

| 異物 | 札をめぐる争い |
| --- | --- |
| 能力者 | 普通の人か、武器か、災害か |
| AI | 人か、道具か、法人か |
| 複製された人 | 本人か、別人か |
| 幽霊 | 死者か、生き物か |
| 異能が現れること | 病気か、才能か |
| 異世界人 | 移民か、使節か、侵略者か |

```text
異物 → 今ある分類へ押し込む → 収まらない → 例外の決まり → 新しい分類ができる
```

どの札を貼るかで、受け持つ役所・当てはまる法・人々の気持ちがまるごと変わる。

### 3-14. 法律どうするんだ問題

| 異物 | 法の問い |
| --- | --- |
| 読心 | 証拠として使えるか |
| 予知 | 先回りの取引は不正か |
| 蘇生 | 死亡届はどうなるか |
| 複製された人 | 戸籍はどうなるか |
| 人格の入れ替わり | 契約したのは誰か |
| 時間停止 | 止めている間の犯罪をどう証明するか |

今ある法が想定していないものを、今ある法に押し込もうとして破綻する。現実的な順は次のとおり。

```text
今ある法で裁く → 判断が割れる → 特例ができる → 専用の法ができる
```

この順で描くと、世界に歴史が出る。

### 3-15. 所有権 ―「誰のものか」問題

個人・国・企業・人類みんなの財産・特許・軍事機密のどれかで争いになる。移転性・複製性（1-4）が高いほど激しくなる。

尽きないエネルギーを生める一人の人間は、本人にとって「自分の力」、国にとって「安全を守る資産」、企業にとって「巨大な市場」、他国にとって「戦略兵器」になる。同じ異物でも、立場で意味が変わる。

### 3-16. 倫理 ― 便利な力ほど後から問われる

- 記憶を変える力: 犯罪者の記憶を書き換えれば再犯しない → それは人格を殺すことでは？
- 予知: 罪を犯す未来の人を、今逮捕してよいか。
- 蘇生: 誰を先に生き返らせるか。
- 複製された人: 複製にも人権はあるか。
- 洗脳: 目的が良ければ許されるか。
- 使ってよい相手・場面の線引き、同意の問題。

異物は、その世界の価値観を試す装置になる。

### 3-17. 文化になる ― 社会が異物に慣れていく

「その異物があって20年後、50年後、100年後は？」

```text
最初の世代「超能力者だ！」
次の世代「クラスに二人くらいいるよ」
その次の世代「就職に使える資格の一つ」
```

異物は制度だけでなく、常識・礼儀・宗教・言葉まで変える。

- 心が読める社会 → 「心を読まないのが礼儀」
- 化けられる者がいる世界 → 本人を確かめる作法が発達する
- 幽霊が実在する世界 → 葬式の意味が変わる

### 3-18. 積み重なり、戻せなくなる ― 異物が世界に跡を残す

使ったことによる副作用。

```text
力を使う → 反動・代償・汚れ・ゆがみ
```

- 結果が世界の別の場所にゆがみとして溜まる。
- 他人の記憶や因果に辻褄合わせが起き、本人だけがずれを覚えている。
- 一度使ったことで、元に戻せない状態が決まる。
- 積み重なりで体・心・環境が戻らなくなり、後半で「力の本質の捉え直し」として示される。

### 3-19. 長い目での釣り合い ― 世界が新しい状態に落ち着く

あり続けることによる変化。

```text
異物があり続ける → 人口・環境・技術・文化が変わる → 異物込みの普通ができる
```

- 異物を前提にした設備・職業・教育が整う。
- 異物以前を知る世代が「昔は〜だった」と語る側に回る。
- 落ち着いた世界に次の異物が来ると、新しい物語が始まる（続編・後日譚の起点）。
- 落ち着きの陰で、慣れられなかった層・土地・職業が取り残される。

### 3-20. 異物の正体と起源

- 終盤で「なぜ持ち込まれたのか」が明かされ、決まりの意味がひっくり返る。
- 力は贈り物ではなく、試験・実験・罰・誤作動だった。
- 持ち込んだ側にも事情や決まりがあった。

起源を明かすか、明かさないか。

| 方針 | 効果 | 向く作品 |
| --- | --- | --- |
| 明かす | 制約や代償の意味がひっくり返り、伏線の回収になる | ミステリー寄り、セカイ系、伝奇 |
| 明かさない | 異物は自然現象のように世界に飲み込まれる（→3-19） | 社会派 SF、日常もの、群像劇 |

明かさない場合、登場人物の仮説や宗教的な解釈が並び立つこと自体が、文化になる過程（3-17）の描写になる。

## 4. 制約の設計

### 4-1. 縛りの4分類

| 種別 | 意味 | 例 |
| --- | --- | --- |
| LIMIT（制約） | そもそもできない | 一日三回まで、生き物には効かない |
| COST（代償） | できるが、払うものがある | 使うたびに寿命が一年減る |
| CONDITION（条件） | 満たせばできる | 満月の夜だけ、相手の名前を知っている |
| RISK（危険） | 起こるかもしれない | 使うと周りに気づかれる、暴発する |

縛りの材料:

| 系統 | 例 |
| --- | --- |
| 量 | 距離、時間、回数、次に使えるまでの間 |
| 代償 | 体力、魔力、記憶、寿命、人らしさ |
| 条件 | 場所、時刻、気持ちの状態、道具、相手との関係、見る・触る・名前を知る |
| 対象 | 生き物には効かない、自分には効かない、特定の相手だけ |
| 精度・認識 | 精度が低い、情報が足りない、本人にも制御できない、無意識に出る |
| 社会・倫理 | 法や決まりとぶつかり、隠す・規制される対象になる |

### 4-2. 制約は弱体化ではなく「盤の形」を作る

制約の良し悪しは型ではなく、何を生むかで決まる。

| 制約の型 | 生むもの | 例 |
| --- | --- | --- |
| 数の制約 | 手持ちのやりくり（いつ使うか） | 一日三回 → 通勤に使うか、逃げるときのために残すか |
| 条件の制約 | 行動の計画 | 一度行った場所にしか行けない → 下見・潜入・拠点・逃げ道の計画が変わり、旅をした経験が財産になる |
| 関係の制約 | 人間関係 | 信じている相手にしか効かない → 誰を信じるかが戦い方になる |
| 代償の制約 | 倫理の選択 | 使うたびに寿命が減る → 誰のために命を削るか |

- **数だけの制約**（一日三回まで）は、選択を生まなければただの弱体化になる。
- **世界との関わりを生む制約**（一度行った場所だけ）は、行動の仕方そのものを変える。

数の制約でも、「いつ使うか」という選択を生むなら十分に盤を作れる。

> 良い制約は、使える回数を減らすものではなく、新しい行動原理を作るもの。

### 4-3. 制約を見せる時期

- 持ち込んだ直後に見せるか、話が進むにつれて少しずつ見せるか。
- 後半で緩める・変えるときは、それまでの世界の延長として根拠を描く。
- 制約を乗り越える過程そのものを物語の推進力にするのは定石。

### 4-4. 見せ方とテンポ ― 説明せず、体で分からせる

| 段階 | 分からせる手段 | 担い手 |
| --- | --- | --- |
| 発見 | 失敗・勘違い・偶然の発動 | 主人公 |
| 確かめ | 実験は結果だけ短く。決まりの一覧は要約にし、全文は見せない | 確かめ役との会話 |
| 制約 | 危ない場面で初めて効いてくる | 敵・状況 |
| 応用 | 読者がもう知っている決まりの組み合わせで解く | 主人公 |
| 悪用 | 被害から逆にたどって手口が分かる | 悪用する者 |
| 社会 | 知らせ・広告・看板・手続きなど背景の小物で示す | 脇役・世界 |

- 一つの場面で明かす決まりは一つまで。
- 決まりは使う直前ではなく、少し前に別の流れで見せておく（後出しに見えない）。
- 社会の掘り下げは説明せず、主人公が手続きや規制に引っかかる形で体験させる。

## 5. 噛みくだく角度

一つの異物を、別々のレンズで噛み直す。

| 角度 | よくある問い |
| --- | --- |
| 物理 | エネルギーはどこから来るか、重さはどこへ行くか、勢いはどうなるか |
| 経済 | 相場・賭け事・物流で儲けられるか、市場が壊れないか |
| 法・制度 | 証明できるか、罪になるか |
| 軍事・治安 | 兵器にされたら、抑止力になるか |
| 倫理 | 使ってよい相手・場面、同意 |
| 日常の細部 | 風呂・眠り・服・家事 |
| 人間関係 | 恋人・家族に明かすか、関係がゆがまないか |
| 宗教・世界の見方 | 奇跡として崇められるか、悪魔扱いされるか |
| 自分とは何か | 力を失った自分に価値はあるか |

### 視点の切り替え

- **使う者の視点**: 便利さと代償の引き換え。失敗や想定外が成長と葛藤の芯になる。
- **周りの視点**: 持たない者・対抗する者の目。妬み・恐れ・利用・研究・排除。
- **世界の視点**: 一か所の例外が広がり定着していく、または世界の根の決まりが少し書き換わる。
- **時間の視点**: 積み重なりと世代交代による変化。

## 6. 能力ものの定番の型

| 型 | あらまし | 物語での働き |
| --- | --- | --- |
| 強すぎて制御できない | 圧倒的だが、精度・範囲を絞れない | 試行錯誤と成長の軸 |
| 代償の積み重なり | 使うたびに寿命・記憶・人らしさが削れる | 選択の重みと倫理の葛藤 |
| 隠すしかない | 公になれば秩序が崩れるので秘密にする | 孤立と人間関係の変化 |
| 今ある決まりとの衝突 | 物理・魔法の体系・制度の例外として働く | 世界の拡張と組み直し |
| 本質の捉え直し | 起源や本当の効果が後半で分かる | 伏線の回収と主題の深まり |
| 持ち主どうしの影響 | 同じ異物の持ち主どうしでぶつかる・強め合う | 対立や協力の新しい軸 |
| 応用で強くなる | 同じ力の意味を捉え直す | 出力ではなく理解で強くなる |
| 情報戦 | 仕組みを隠すことと見抜くことが勝負を分ける | 頭脳戦の軸 |

## 7. 人物の配置

| 役 | 働き |
| --- | --- |
| 確かめ役 | 決まりを言葉にする、理屈っぽい・慎重な人 |
| 悪用する者 | 主人公の思いつかない使い方を最初にやる |
| 規制する側 | 秩序の立場から分類・管理・排除しようとする |
| 商売人 | 異物を市場につなぐ |
| 同類 | 同じ異物を持ち、違う使い方を選んだ「ありえた主人公」 |
| 持たない相棒 | 持たない目から、倫理や日常へ引き戻す |

## 8. 失敗のあるある

### 8-1. 掘り下げ不足

- 世界を変えるほどの力なのに、学校や社会が以前のまま。
- 国・企業・犯罪組織が反応しない。
- 対策の技術が無い。
- 誰も商売にしていない。
- 応用が強すぎて「それで他の問題も全部解けるのでは」（世界平和問題）が残る。
- 希少性を置いただけで、囲い込みや奪い合いが起きない。
- 運用上の性質（1-4）を決めていないので、渡せるか・遺伝するかが場面ごとにぶれる。

### 8-2. 掘り下げすぎ

- 魔法少女の話だったのに、魔法庁の設立史になる。
- 恋愛ものだったのに、能力者の人権法の話になる。
- デスゲームだったのに、運営会社の財務分析になる。
- 掘り下げたことを全部本編に出そうとして、焦点が散る。
- 辻褄合わせのための設定が、物語の主題を乗っ取る。

> 世界として考えておくことと、作品の中で描くことは別。

### 8-3. 書き手の運用の失敗

- 決まりを後から増やし、ご都合主義に見える。
- 序盤で縛りを細かく決めすぎて、終盤が窮屈になる。
- 説明の場面が長く、物語が止まる。
- 独立した異物が二つ三つと入り、因果の幹が分かれて軸がぶれる。

### 8-4. 対策

- 設定資料では全方向に掘り下げ、本編では主題に関わる方向だけ見せる。
- 「2. 掘り下げの層」のジャンル別の掘り方を参考に、厚く描く層を先に決める。
- 序盤で明かす決まりは少なくし、限界と代償は早めに見せる。
- 応用は、読者が予想できる範囲の外側で見せる。
- 詳しい説明より、行動や失敗を通して制約を体で分からせる（→4-4）。
- 制約を設計するときは、世界のどこに最も効くかを先に決める。

## 用語集への登録

異物の名前と決まりは、作品の `world.md` の `## 用語` に置く（書式は [world_glossary.md](../world_glossary.md)）。

- 異物そのものは、種別を技術・制度・現象など決まりを持つものにし、「定義・適用範囲」に効果と制約（LIMIT / COST / CONDITION / RISK）と、決めた運用上の性質（1-4）を書く。本文はその手順・条件どおりに描き、台詞で条件と食い違うことを言わせない。描き方を変えたいときは、本文より先に定義を直す。
- 派生・対抗・適応で生まれた物（抑える鉱石、検知の生き物、新しい制度・職業）は、別の用語として登録し、備考に一次の異物の用語 ID を書いて幹をたどれるようにする。
- 話が進んで新しい決まりや応用が分かったら、本文に出す前に `## 用語（承認待ち）` へ登録案を書く。後出しの決まり（8-3）を防ぐ手立てにもなる。
- 「2. 掘り下げの層」で考えたが本編に出さない設定は、`world.md` の該当する節や `design_specification.md` に置き、用語集を膨らませない。

## 深掘り用の問い

必要な問いを選び、答えを `world.md`、`character.md`、`design_specification.md` など作品の適切な正本へ記録する。

1. 一次の異物は何か。ほかの特殊な要素は、派生・適応・対抗・独立のどれか。
2. 運用上の性質（1-4）のうち、物語に効くものはどれか。それぞれ決めたか。
3. 物語の始まりで、異物は誰に知られているか。どこで知られ方が移るか。
4. 厚く掘る層はどれか。掘るが本編に出さない層はどれか。
5. 主人公を最も追い詰める制約は何で、それはどんな行動を強いるか。
6. 最初に悪用するのは誰で、その手口は被害からどうたどれるか。
7. 物語の終わりに、異物込みのどんな普通が成り立ち、誰が取り残されるか。
8. 起源を明かすか。明かすなら、それで何の意味がひっくり返るか。

## 作業用への導入

標準版を作品で選定する前に、作業用 `_how_to/_index.md` がある場合は、利用者が `_how_to/tropes/foreign_element.md` へコピーし、作業用索引から参照できる状態にする。作業用の葉がある場合はそちらを実効版として使い、標準版と自動合成しない。既存作品の `_meta.md` の selected は、作品ごとに適用を決めたときだけ更新する。
