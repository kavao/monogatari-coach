# 命名技法 (Naming Techniques)

本ファイルでは、小説のタイトル、キャラクター名、地名などの「命名」に関する技法をまとめます。

タイトルは **型（骨格）× 軸（組み合わせ）× 技法（センス）** の三層で組み立てます。型だけで決めると平凡になり、技法だけで決めると内容が伝わりません。1.1〜1.2 で「何を約束するか」を決め、1.3〜1.4 で「どう言うか」を決め、1.5〜1.7 で役割と並びを分け、1.8 で候補を比較して絞ります。

## 1. 小説のタイトル命名

### 1.1 タイトルの5つの役割

小説のタイトルは、実は「センス」よりも「何を約束するか」で考えると整理しやすいです。

1. **読者を呼ぶ**: 視認性を高め、クリックや手に取る動機を作る。
2. **内容を想像させる**: どのような物語が展開されるか予感させる。
3. **他作品と区別する**: 独自性を出し、埋もれないようにする。
4. **ジャンルを伝える**: 読者が求めているカテゴリーであることを示す。
5. **読後に意味が深まる**: 物語を読み終えたとき、タイトルの真意に気づかせる。

**例:**
* 『吾輩は猫である』 → 主人公を伝える
* 『銀河英雄伝説』 → 世界観を伝える
* 『容疑者Xの献身』 → ミステリー感を伝える
* 『葬送のフリーレン』 → 読後に意味が深まる

一つのタイトルで5つすべてを満たす必要はありません。**どれを題が担い、どれを副題・あらすじ・表紙に任せるか**を決めるのが設計です（1.5）。

---

### 1.2 基本の型（骨格）

大半の小説は、以下のいずれかの型に分類できます。VI〜VIII は I〜V に比べて情報量は少ないものの、声や手触りで印象を残す型です。

#### I. 主人公型
主人公そのもの、あるいは主人公の属性や境遇をタイトルにする。
* **構造**: `主人公` / `主人公＋属性` / `主人公＋出来事`
* **例**: 魔王アリア、鉄槌の騎士レオン、田中課長の異世界転生

#### II. 世界観型
舞台となる場所、世界、組織などの魅力を売る。
* **構造**: `場所` / `世界` / `組織`
* **例**: 蒸気都市ヴァルハイト、魔導王国アルメリア、星海帝国年代記

#### III. 事件型
物語の中で起こる主要な事件や謎、危機を示す。
* **構造**: `事件` / `謎` / `危機`
* **例**: 最後の魔術師殺人事件、王都消失、神殺しの夜

#### IV. テーマ型
作品の核になる感情、思想、概念。文学的な響きになりやすい。
* **構造**: `感情` / `概念` / `哲学`
* **例**: こころ、人間失格、約束、贖罪、祈りの果て

#### V. キャッチコピー型（現代Web小説・ラノベ主流）
「誰が」「どうなったか」という状況を説明的に記述する。
* **構造**: `主人公 + 状況`
* **例**: 異世界でハンバーグ屋を始めたら魔王が常連になった件、妹が聖女だったので兄の俺が家計を支えることになった
* **字数**: 説明そのものが題の役目なので、長くてよい。1.4.1 の字数の目安は、I〜IV と VI〜VIII の本題に使う。

#### VI. 発話型（セリフ・独白）
登場人物の一言や、語り手の独白をそのまま題にする。人物の関係と温度を一文で伝えられる。
* **構造**: `セリフ` / `セリフ＋、と誰々は言った` / `独白の言い差し`
* **例**: よく眠れたね、と父は言った、寝息は上手でしょ、たのしいピクニックには百人必要ですわ！
* **注意**: 誰の声かが題から推測できないと、雰囲気タイトルに落ちる。口調（語尾・敬語・方言）で話者を立てる。

#### VII. 物件型（小道具・具体物）
物語の鍵になる物、場所の一角、繰り返される動作を題にする。抽象的な感情を具体物に預ける。
* **構造**: `物` / `物＋動作` / `場所の一角`
* **例**: 鍵をしまって駅へ、星灯りの修理店、通り名ミオの個室
* **注意**: その物が本文で最低3回（導入・転換・終幕）意味を変えて出ることを確認する。一度しか出ない物を題にしない。

#### VIII. 状態・未完了型
「まだ」「知らない」「しない」などで、途中の状態や欠けを示す。続きを読む動機が題の中に残る。
* **構造**: `対象＋は＋まだ〜ない` / `〜を知らない` / `〜しない主義`
* **例**: うめきの止め方は、まだ載ってない、背中合わせの距離を知らない、ドアは閉めない主義

#### 1.2.1 良いタイトルの公式

型の中で語を組むときの定石です。C と D は §1.4 の技法に対応します。

* **A. 固有名詞 ＋ 役割**: 印象的な固有名詞に役割を添える（例: アリアの聖剣、狩野アイ、ホムラ計画）。
* **B. 名詞 ＋ 名詞**: 強い言葉を組み合わせる（例: 月光の魔女、黄昏の王国、機械仕掛けの聖女）。
* **C. 対比**: §1.4-8 を参照。
* **D. 読後に意味が変わる**: §1.4-6 を参照。

### 1.3 組み合わせの軸（複雑度を上げる）

型は骨格にすぎません。次の軸をそれぞれ一つずつ選ぶと、同じ型でも別のタイトルになります。候補を出すときは、**型を固定して軸を振る**と幅が出ます。

| 軸 | 値の例 | 効き方 |
| --- | --- | --- |
| 声（誰が言っているか） | 地の文 / 主人公 / 相手役 / 第三者・伝聞 / 看板・書類の文言 | 距離感と温度が決まる |
| 時点（物語のどこを切るか） | 導入の状況 / 中盤の転換 / 終幕の着地 | 終幕を切ると読後反転になりやすい（1.4-6） |
| 開示量 | 全部言う / 半分言う / 伏せる | 多いほどWeb向き、少ないほど文学寄り |
| 温度 | 平熱 / 誇張 / 皮肉 / 照れ / 断言 | ジャンルの気配を運ぶ |
| 文の形 | 名詞止め / 動詞止め / 言い差し / 疑問 / 命令 / 呼びかけ | 余韻と勢いが決まる |
| 字種 | 和語 / 漢語 / カタカナ / 混在 | 手触り（柔らかい・硬い・異国）を決める |

**組み合わせの例（型: VII 物件型）**
* 地の文 × 終幕 × 半分 × 平熱 × 動詞止め → 鍵をしまって駅へ
* 主人公 × 導入 × 伏せる × 照れ × 言い差し → 鍵は、まだ渡してないけど
* 看板の文言 × 導入 × 全部 × 平熱 × 名詞止め → 合鍵お作りします　駅前三分

### 1.4 センスの技法（ずらし）

「センスがある」と感じる題は、多くの場合、**予想される言い方から一つだけずらしてある**題です。二つ以上ずらすと意味が崩れます。

1. **具体物で抽象を運ぶ**: 「別れ」ではなく「鍵をしまう」。感情語を題から外し、動作や物に預ける。
2. **一語だけ違和感を置く**: 「たのしいピクニックには**百人**必要」。常識の中に一語だけ数・場所・人物のずれを入れる。違和感の語が作品の核と一致していること。
3. **助詞で意味を立てる**: 「は」は対比（他は違う）、「も」は追加、「の」は所属、「を」は目的、「、」は間。「寝息**は**上手でしょ」の「は」は、上手ではない他のことを匂わせる。
4. **言い差しと未完了**: 「〜は、まだ載ってない」「〜なのに」。題の外に続きがあると、読者はそれを本文に探しに行く。
5. **声を借りる**: 引用と「と誰々は言った」で、題に人物の関係を一つ入れる。誰が誰に言ったかで、読後の意味が変わる。
6. **読後反転を逆算する**: 終幕の一文や最後の出来事を先に決め、その言葉を題に置く。読前はありふれた意味、読後は別の意味に読めるかを確認する（例: 『葬送のフリーレン』、よく眠れたね、と父は言った）。
7. **語彙の格に段差をつける**: 大仰な漢語と日常の和語を一つの題に並べる。「過労魔導士の実家療養日記」は、魔導士（幻想・硬い）と実家（生活・柔らかい）の段差で笑いと温度を出す。
8. **対比を並べる**: 相反する二つを「と」でつなぐ（例: 魔王と聖女、勇者と徴税人）。片方を意外な語にすると、ずらしを兼ねる。
9. **音を整える**: 1.4.1 を参照。

#### 1.4.1 音の点検

題は声に出して確認します。

* **長さ**: 本題は 7〜15 字前後が覚えやすい。20 字を超えるなら副題へ分ける（1.5）。V キャッチコピー型の説明題はこの目安の対象外。
* **リズム**: 五・七・五、七・五などの拍に近いと口に残る（例: よくねむれたね／とちちはいった ＝ 七・七）。
* **読点**: 読点は息継ぎの位置。置く場所で強調が移る。「うめきの止め方は、まだ載ってない」は、読点の後の「まだ」が強くなる。
* **頭と尾の音**: 語頭の音は検索と記憶に効く。語尾の「ね／でしょ／わ／ない」は話者と温度を決める。
* **濁音と清音**: 濁音が多いと重く強く、清音と母音「あ・い」が多いと軽く明るく響く。作品の温度と合わせる。

### 1.5 二段タイトル（本題＋副題）

「読者が最初に知りたいこと」と「余韻」は、一行で両立しないことがあります。そのときは役割を分けます。

* **本題**: 声・物・違和感など、記憶に残る部分（1.4）。
* **副題**: 誰が・どこで・何をする話かを伝える部分（1.7 の三要素）。
* **構造**: `本題_副題` / `本題　〜副題〜`
* **例**: 店行けよ。なのに金曜はソファ席_ツンデレ妹の一次会限定店（本題は発話型で温度、副題でジャンルと人物を約束する。発話の切れ目は読点か「。」で読者に聞こえるようにする）
* **注意**: 副題が本題の言い換えになっていないか確認する。本題と副題が別の情報を運ぶこと。

---

### 1.6 並びの中での差別化

同じ作者、同じシリーズ、同じ投稿棚に並んだとき、題の形が揃いすぎると区別がつきません。

* 近い時期の作品と、**型・語尾・字数・読点の有無**のうち2つ以上を変える。
* 発話型が続いたら、語尾を分ける（「〜ね」「〜でしょ」「〜ない」）か、物件型・状態型へ切り替える。
* シリーズとして揃えたい場合は、揃える要素（例: 語尾、頭の語）を一つだけ決め、残りは変える。

---

### 1.7 命名の極意

タイトルを考えるときは、**「作者が言いたいこと」ではなく「読者が最初に知りたいこと」**を優先してください。

特に商業作品やWeb小説では、以下のうち最低2つが分かるタイトルは非常に強いです。
1. **誰が**
2. **どこで**
3. **何をする話か**

雰囲気だけのタイトル（例: 『蒼き翼』『悠久の彼方』）は、有名作家でない限り内容が伝わらず不利になります。タイトルは「作品の広告コピー」であると意識しましょう。

ただし、発話型・物件型・状態型は、一語の具体性で「誰が・何を」を一つ以上伝えられるなら、雰囲気タイトルにはなりません。「蒼き翼」は何も約束しませんが、「よく眠れたね、と父は言った」は、父と子と眠りを約束します。伝わる要素が一つも無いときだけ、副題で補います（1.5）。

### 1.8 候補の出し方と比較（タイトル命名ゲート連動）

`workflow-specification.md`「タイトル命名ゲート」の **最低5候補** は、同じ型の言い換えを5件並べるのではなく、**型をばらして**出します。

**推奨の5枠**
1. **情報枠**: I〜V のいずれか。誰が・何をするかが確実に伝わる案。
2. **声枠**: VI 発話型。誰かの一言。
3. **物枠**: VII 物件型。鍵になる物か動作。
4. **ずらし枠**: 1.4-2 の違和感、または VIII 状態・未完了型。
5. **反転枠**: 1.4-6 の読後反転。終幕から逆算した案。

**比較観点**（`config.md`「資料上の別名」の採否理由に書く）
* 内容想起・ジャンル伝達・固有性/検索性・読後の意味（ゲート既定の4観点）
* **約束の正しさ**: 題が、本文にない展開・設定・ジャンルを約束していないか。
* **開示の早さ**: 題が、本文より早く結末や正体を明かしていないか。
* **音**: 声に出して覚えられるか（1.4.1）。
* **並び**: 近い作品と形が重なっていないか（1.6）。

**よくある却下理由**
* 説明的で、要約をそのまま題にしている。
* 設定と食い違う連想を呼ぶ（例: 部活のない設定で「日曜のリュック」が部活帰りを連想させる）。
* 題が本文より早く発覚させる。
* 前作の焼き直しに見える。
* ずらしが二つ以上あり、意味が読めない。

### 1.9 企画例への適用

* **『感情のロボティクス』**: 非常に良いタイトル。AI作品であることが一発で分かり、感情とロボットの対比（テーマ）が示されている。
* **『Dear My Sister』**: 海外作品風で雰囲気は良いが、内容が伝わりにくい。商業的には「聖女の妹」「妹を育てる一年」などの副題を検討。
* **『異世界魔術師は500円のハンバーグランチで感動した』**: Web小説型として非常に強力。異世界、魔術師、現代日本、グルメという要素が即座に伝わる。

## 2. キャラクター名・地名・組織名

人物名の候補づくりと抽選は `character-naming` スキル（`_how_to/name_creature.json`、`tools/json_weighted_pick.py`）に従います。ここでは、候補を絞るときの観点だけを示します。

* **呼び分け**: 同じ場面に出る人物の頭音・字数・語尾を重ねない（例: ミオとミナ、ユウとユイを同時に置かない）。
* **呼称の層**: 本名・通称・あだ名・敬称付きの呼び方を分けて持つ。誰がどの呼び方をするかで関係が伝わる。
* **音の体系**: 同じ文化圏の人物・地名は、音の傾向（使う母音、語尾、長さ）を揃える。異なる出自の人物だけ体系を外す。
* **意味の重さ**: 名前に物語の意味を背負わせすぎない。背負わせる場合は、本文で一度だけ明かす。
* **地名**: `地形・産物・由来＋接尾語`（〜坂、〜津、〜ヶ原など）で組むと、世界の手触りが出る。
* **組織名**: 正式名称と、現場で使われる略称・俗称を両方決める。人物は略称で話す。

## 3. ペンネームの命名

Web小説・ライトノベル等の創作活動において、ペンネームは読者との接点および長期的なブランド形成に直結する重要な要素です。安易な選定は発見性の低下や書籍化後の機会損失を招きかねません。

### ペンネーム設定時の避けるべき事項

#### I. 基本的な避けるべき事項
* **発見しにくい名称**: 難解漢字・記号多用・短すぎる名称等によるエゴサーチの弱さ。
* **重複リスク**: 既存の作家名・作品名・商標等と重複し、検索汚染や法的リスクを生じさせる。
* **乖離した名称**: 内容や世界観と乖離した、または無造作に付された名称。
* **呼びにくい名称**: 読者や関係者が人前で呼びにくい、または不快感・誤解を招く名称。

#### II. 具体的な避けるべき名称の特徴
* **エゴサに弱い名前**: 自身の作品や情報が検索上位に表示されにくく、読者獲得の機会を逸する。
* **人前で呼べない名前**: 読者や書店関係者等が人前で発声しにくい、または恥ずかしい印象を与える。
* **誤読を誘う名前**: 読み方が複数存在し、誤解や混乱を招きやすい。
* **長過ぎる名前**: 覚えにくく、タイトル表記や告知・口コミに不向き。
* **とりあえず目の前にある物体の名前**: 周囲の物体や安易な着想から命名した、軽率な印象を与える。

これらの名称は、Web小説プラットフォームにおける露出低下や、書籍化時の売上機会損失（書店での口コミ・陳列に支障を来す事例を含む）を引き起こす可能性が指摘されています。

---

### 改名タイミングに関する重要事項

不適切なペンネームで活動を継続し、一定の読者層やブランドが形成された後では、改名が極めて困難となります。

* **推奨**: 早期の変更、または遅くとも「書籍化のタイミングで必ず改名」すること。
* **リスク**: 機会を逃すと「詰み」（継続的な活動への重大な支障）を招くおそれがあります。

ペンネームは作家の別人格として慎重に選定し、年1回程度の定期的な見直しを行うことが、創作活動全体の基盤を形成する上で肝要です。
