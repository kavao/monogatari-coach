# 礼儀作法から身分関係を読む

> 原資料（来歴）: `C:/Users/Owner/Downloads/etiquette-tropes.md`（なろう系・異世界貴族もの「礼儀作法あるある」集）。2026-11-03 に `literacy/` の2枚目の葉として導入。導入版では、発動条件・本資料の注意（4区分の印とカタログの3区分の対応、実在の礼法への配慮）・Monogatari Coach での使い方と、カタログの共通の5点のうち原資料に節が無かった3節（多層構造と価値の式、作劇の三方向、観察者ごとの解像度）を、原資料の章を指す・材料にする形で足した。0〜23章は章番号のまま残した。原資料の「次に独立させる候補」は別葉にせず、末尾の将来メモに畳んだ。原資料は変更していない。

礼儀作法は単なるマナーではない。**社会関係を宣言・確認・変更するためのプロトコル** であり、身分・教養・親密度・敵意・政治的立場を可視化する装置として使われる。服装が身分を「見せる」のに対し、礼儀は身分関係を「実行する」。対象は、なろう系（異世界転生・転移）、悪役令嬢、貴族学園、王宮もの。史実の再現ではなく、**読者と作者のあいだで共有された礼儀の記号体系** として整理する。

## 発動条件

> 礼儀作法（挨拶・呼称・席次・紹介・エスコート・茶会や舞踏会の作法など）を、身分・親密さ・敵意・政治的立場の表明として設計する場合、または作法の違反や過剰な礼儀で立場や関係が動く場合に選ぶ（既定では読まない。令嬢もの・貴族ものというジャンル指定だけでは選ばない。装いの格は `literacy/dress.md`）。

## 本資料の注意

**凡例**

| 印 | 意味 | カタログの3区分 |
|---|---|---|
| 【史】 | 実在した礼法・社会慣習にかなり近い | ［史実由来］ |
| 【混】 | 史実を単純化・誇張したフィクションの定番 | ［ジャンル慣習］ |
| 【虚】 | なろう・少女漫画・ロマンスなどで成立し、ジャンル内で共有されている約束事 | ［ジャンル慣習］ |
| 【創】 | 作品ごとに値や意味が変わる独自設定（作例） | ［世界設定依存］ |

- 【混】は史実を誇張した定番で、史実の核がある。カタログの3区分ではジャンル慣習に寄せるが、核まで作り話として扱わない。
- 判定は傾向を示す目安。実在の慣習も、時代・国・宮廷によって大きく異なる。同じ印でも、誇張の度合いは作品によって異なる（例：【混】のカーテシーも、作品によっては儀式めいた様式美として描かれる）。
- 【史】【混】の作法を、作中の人物や地の文に「史実ではこうだった」と言わせない（§22-2「史実の断言」）。史実として本文へ出す事項は別途資料で確かめる。
- カーテシー・土下座・箸（§3・§18）などの所作を、特定の宮廷・民族・時代の礼法の性質として書かない。獣人・エルフなど異種族の作法は、作品の世界設定で決める。

## Monogatari Coach での使い方

作法の読み合いで立場や関係が動く作品の Plan Mode で参照する。全項目を採用する一覧ではなく、作品で読み合いが起きる場面と、作法が破られる一点を選ぶための資料である。

| 作品資料 | 主に反映する項目 |
|---|---|
| `world.md` | 礼の深さと身分の対応、呼称の体系、席次と入場順、謁見の手順、ダンスの回数などの数値ルール、違反の重大度と罰、冒険者ギルドの別体系 |
| `character.md` | 礼儀への態度（知っている・知らない・知った上で破る・過剰に守る・省略する）、転生者の類型、礼法教師や上位者の義務を果たすかどうか |
| `design_specification.md` | 作法の違反・過剰な礼儀・呼称の変化で関係が動く章出来事（誰が何を破り、誰が気づき、関係がどう変わったか） |
| `_meta.md` | 誰が誰をどう呼んでいるかの変化、招待と排除の推移、違反と制裁の履歴 |

設計時は、最低限次を決める。

- 作品で読み合いの中心になる作法を一つか二つ選ぶ（呼称・席次・ダンス・茶会など）。全場面の作法を同じ厚さで書かない。
- 作中で数値や記号にするルール（ダンスの回数、贈り物の意味など）は、初出で一度だけ定義し、途中で変えない（§22-1・§22-2）。
- 主人公と主要人物が、礼儀に対してどの態度をとるか（§0-3）と、転生者ならどの類型か（§17）を決める。
- 誰が作法を読めて、誰が読めないか（下の「観察者ごとの解像度」）を決め、その差を場面の推進力にする。
- 上位者の義務（§15）を一度は描くかどうかを決める。
- 作法を破る・逆手に取る・書き換えるのうち、作品の主軸を一つ選ぶ。
- 葉の名前・章の名前・区分の印は設計の語である。物語案・あらすじ・キャラクター紹介には出さず、人物と出来事で書く（`_how_to.example/synopsis_presentation.md`）。

関連する葉: 装いの格・色・宝飾は [服飾の格を読む葉](dress.md)、破滅回避・断罪・ざまぁの話の約束は [悪役令嬢](../genre/akuyaku_reijo.md)、カタログの契約と住み分けは [README](README.md)。

## 多層構造と価値の式

この葉では新しい式を立てない。作法の格がどう決まるかは、次の節を読む。

- 礼儀は「誰に何が許されているか」を可視化する権限管理として読める（§0-1）。
- 作法が伝える情報は「誰が・誰に・どこで・どの程度・どの順で」の層になっている（§0-2）。身分差から呼称、礼、立ち位置・席次、会話の順、場面別の作法へ下り、意図的な作法違反が侮辱・政治的メッセージになる。
- 礼儀への態度そのものが情報になる（§0-3）。礼の度合いは無礼・最低限・丁重・過剰・省略の5段階で設計でき、礼儀正しいほど仲が悪い、という逆転が成り立つ（§0-4）。

## 作劇の三方向

| 方向 | 礼儀作法での現れ | 主な章 |
|---|---|---|
| 規則を **破る** | 知らずに破る（転生者の無知型、平民ヒロイン）、知った上で破る（挑発・権力誇示）。帰結は違反の重大度で変わる | §16・§17・§21 |
| 規則を **逆手に取る** | 形式を守った攻撃、否認できる婉曲表現、違反の指摘、完璧な礼儀で違反の誘発をかわす | §2 |
| 規則を **書き換える** | 現代の常識・前世の職業経験・異文化の所作を持ち込み、慣習そのものを変える（茶会の「欠席という選択肢」も含む） | §10・§17・§18 |

## 観察者ごとの解像度

同じ所作でも、誰が見るかで読み取れる意味が変わる。この節は新しい作法を足さず、既存の章を材料に、読める者と読めない者を並べる。

| 観察者 | 読み取れること | 読み取りにくいこと |
|---|---|---|
| 平民・使用人 | 礼の深さ、起立・入場などの大きな所作（§3・§7）、主人の自分への態度の変化（§13） | 婉曲な罵倒の裏の意味（§2）、紹介順や席次の操作（§6・§7） |
| 転生者（無知型） | 現代のマナー解説に近い作法（§1-1・§11） | 視線・歩き方・席順の意味（§17）。自分が軽い違反（§21 の Lv.1〜2）をしていること |
| 下位の貴族・学園の生徒 | 呼称の変化と名前呼び（§5）、ダンスの回数（§9）、茶会の招待と席（§10） | 否認できる攻撃が攻撃であること（§2）。礼儀正しすぎる態度が断絶の宣言であること（§0-4・§2） |
| 礼法に通じた高位の貴族・礼法教師 | 否認できる攻撃と婉曲な罵倒（§2）、紹介順・席次の意図的な崩し（§6・§7）、違反が侮辱か挑発か（§21 の Lv.3〜4） | — |
| 王族・宮廷の中枢 | 席次の操作や公式行事での排除の政治的な意味（§21 の Lv.4）、上位者が義務を果たしているか（§15） | — |
| 冒険者ギルド | 実績・ランク・強さ（§19） | 宮廷の作法の格。宮廷式の敬語は「貴族のボンボン」の印としてだけ読まれる（§19） |

- 作法を読めないことは、本人だけでなく家の教育の欠如として扱われる（§2「知らなかった」は言い訳にならない）。
- 視点人物が読めない作法は、地の文で意味を言い切らず、周囲の反応（息をのむ、場が凍る、ざわめく）として見せると、読者も一緒に「何かが起きた」と気づける。

## 0. 基本構造

### 0-1. 礼儀＝「誰に何が許されているか」を可視化するルール

礼儀作法の大部分は、社会的な**権限管理**として読める。

```text
上位者
├─ 先に話しかけられる
├─ 先に座れる
├─ 相手を待たせられる
├─ 礼を簡略化できる
└─ 相手との距離を決められる

下位者
├─ 待つ
├─ 許可を得る
├─ 深く礼をする
├─ 呼称を崩せない
└─ 勝手に距離を縮められない
```

アクセス制御で言えば次のようになる。

```text
王族     → privileged user
高位貴族 → elevated role
下位貴族 → normal role
平民     → restricted role

対象となる操作：発言・着席・接近・接触・名前呼び・招待・贈答
```

「王子が平民ヒロインに名前呼びを許した」がイベントになるのは、**権限の付与**だからである。

### 0-2. 礼儀は「誰が・誰に・どこで・どの程度・どの順で」の情報

```text
身分差
  ↓
呼称
  ↓
挨拶・礼
  ↓
立ち位置・着席順・入場順
  ↓
会話の順番
  ↓
場面別作法（食事・舞踏・茶会・訪問・謁見）
  ↓
意図的な作法違反 ＝ 侮辱・政治的メッセージ
```

### 0-3. 礼儀への態度が示すもの

| 態度 | 読者に伝わる意味 |
|---|---|
| 礼儀を知っている | 教養・出自・育ちの良さ |
| 礼儀を知らない | 平民・田舎者・成り上がり・転生者 |
| 知った上で破る | 挑発・権力誇示・敵意 |
| 過剰に守る | 距離を置いている・拒絶 |
| 省略する | 親密・身内扱い・特権 |

### 0-4. 礼儀の5段階（設計用）

| 段階 | 表現 | 意味 |
|---|---|---|
| 無礼 | 礼をしない | 敵意・無知 |
| 最低限 | 規定通り | 他人 |
| 丁重 | 通常以上 | 敬意 |
| 過剰 | 異常に格式張る | 距離・拒絶 |
| 省略 | 礼を省く | 親密・特権 |

**逆転の妙**：礼儀正しいほど仲が悪い、が成立する（→ §2）。

## 1. ナーロッパ礼法の生成原理

### 1-1. 成分の混在

ナーロッパ礼法には、次のような要素が混ざっていると考えられる（仮説）。

```text
中世の世界設定
＋ 近世の宮廷文化（席次・謁見・舞踏会）
＋ ヴィクトリア朝の社交（茶会・訪問・扇）
＋ 現代の「英国式マナー」解説
＋ 少女漫画・ロマンス小説・乙女ゲーム
＋ 日本の上下関係・敬語・武家礼法
＝ 読者が直感的に理解できる架空の西洋貴族社会
```

- 【虚】**時代の混在**：中世の設定なのに作法は近世〜ヴィクトリア朝風で、精神性は武家礼法寄り
- 【混】**アフタヌーンティーの時代錯誤**：アフタヌーンティーは19世紀に成立した習慣。中世風の世界にあれば、それ自体が時代混在の好例になる
- 【虚】**現代英国式マナーの輸入**：カトラリーは外側から、小指を立てない、スコーンの食べ方など、現代のマナー解説がそのまま宮廷作法として描かれる
- 【虚】**土下座の意味が通じる**：西洋風の世界なのに、日本文化を知らないはずの人々が「そこまで頭を下げるとは…！」と即座に理解する

### 1-2. 曖昧な慣習を数値・記号のルールにする傾向

Web小説では「何をしたらどういう意味になるか」を一瞬で伝える必要があるため、ルールが明文化・数値化されやすい。

- 【虚】ダンスの連続回数で関係の深さが決まる（→ §9）
- 【虚】自分の瞳の色の宝石を贈る＝求愛
- 【虚】ファーストダンスの相手＝婚約者、またはそれに相当する相手
- 【創】作例：白い花は拒絶、夜会に3回招かれたら派閥入り、など

### 1-3. その他の生成原理

- 【虚】**作法は破られるために説明される**：丁寧に解説された作法ほど、数話後に誰かが破る
- 【虚】**厳しさは家格に比例する**：ただし最上位の王族はかえって気さく
- 【創】**礼儀がゲームの仕組みになる**：マナー違反で魔力を奪われるなど、礼儀が戦闘や交渉のシステムに組み込まれる
- 【混】**時代差の大きい作法は世界固有のルールにする**：帽子や手袋の扱いなどは史実に寄せるより、作中で統一した方が安全
- **定番化の理由**：異世界の階層構造を効率よく伝えられ、ギャップの爽快感と身分逆転のカタルシスを生む。優れた作品は形式の社会的意味や代償まで描き、単なる権威否定で終わらせない

## 2. 礼儀を武器にする（中心章）

- 【混】**婉曲な罵倒**：「まあ、興味深いご趣味ですこと」「お元気なお嬢様ですこと」。礼儀正しい文章そのものが攻撃になる
- 【混】**礼儀による攻撃は否認できる**：「まあ、そのような服がお好きなのですね」と言われた相手が「馬鹿にしているの！？」と返すと、「いいえ？ 感想を申し上げただけですわ」でかわされる。形式を守った攻撃は、攻撃したこと自体を否認できる。宮廷劇の核になる技術
- 【混】**最大の侮辱は礼儀正しすぎること**：親しかった相手が急に正式呼称へ戻るのは「もう個人的な関係ではない」という宣言
  - 例：夫婦喧嘩のあとの「おやすみなさいませ、旦那様」。普段は名前で呼ばれている夫には、相手の激怒が伝わる
- 【虚】**違反への反応にも格がある**：下品な人物は「無礼者！」、上品な人物は「…ずいぶんと独創的な作法を学ばれたのですね」
- 【虚】**礼法バトル**：相手がわざと紹介順を崩すと、主人公が「こちらでは紹介の順序が随分と自由なのですね」と返して相手が絶句する
- 【虚】**完璧な礼儀が主人公の武器になる**：敵が違反を誘発しようとしても完璧に処理する。礼法が剣や魔法と同じ習得型スキルとして扱われる
- 【混】**作法違反は敵対の意思表明になる**：作法が「味方かどうかの証明書」として機能する
- 【混】**「知らなかった」は言い訳にならない**：無知は家の教育の欠如を意味し、本人だけでなく家門の恥になる

## 3. 挨拶・礼

- 【混】**カーテシー**：令嬢がスカートをつまみ、片足を引いて膝を折る。礼そのものより「動作の完成度＝教育水準」として描かれる。「完璧な角度のカーテシー」は定型句
- 【虚】**男性は胸に手を当てて一礼**：男性の礼は作品ごとの差が大きい。胸に手を当てる一礼は、視覚的に分かりやすいファンタジーの記号
- 【混】**騎士は片膝をつき、剣を捧げる**：騎士道ロマンス・映画・ゲームによって形成された記号
- 【混】**礼の深さで身分差を表す**：下位者ほど深く、上位者は「うむ」と頷くだけ
- 【虚】**王族が礼を返すと大事件**：王子が自ら頭を下げると「殿下が平民に礼を！？」と周囲がざわつく
- 【虚】**定型挨拶**：「ご機嫌麗しゅう」「ごきげんよう」。これが言えるかどうかが階層のしるしになる

## 4. 謁見・王権

- 【混】**謁見の定型手順**：入室 → 規定位置まで進む → 跪く → 頭を下げる → 王が発言 → 許可されて顔を上げる
- 【虚】**「面を上げよ」**：許しが出るまで顔を上げない。勝手に上げる者は小物か大物のどちらか
- 【混】**停止線**：絨毯の端や金糸の線の手前で止まる。超えると近衛騎士が止めに入り、王権が視覚的に示される
- 【混】**王を直視しない**：視線の置き方そのものが作法になっている
- 【史】**王に背を向けない**：数歩後退してから向きを変えて退出する。これを入れるだけで宮廷らしさが増す
- 【混】**違反の代償は段階的**：程度に応じて叱責、退出命令、謹慎、宮廷への出入り禁止、処罰へと進む。王への接近や武器の所持など警護上の違反は、命に関わる（→ §21）

## 5. 呼称・言葉遣い

- 【混】**正式な場では私的な名前呼びを避ける**：爵位・家名・敬称を用いる。具体的な形式は世界の制度によって異なる
  - 史実では、英国の公爵には "Your Grace"、「von」はドイツ語圏の貴族名の要素など、国ごとに違う
  - ナーロッパでよく見る例：「○○公爵閣下」「フォン・○○伯爵」
- 【混】**敬称の取り違えが「不敬」とされる**：「殿下」「閣下」「卿」の取り違えが政治問題や処罰の口実になる。不敬が正式な犯罪かどうかは作品内の法制度による
- 【虚】**呼称は親密度ゲージとして働く**

  ```text
  爵位・家名 → 敬称＋名前（レディ・アリシア）→ 名前 → 愛称
  ```

  「私のことも名前で呼んでくれ」が恋愛イベントになる（呼称権限の付与）
- 【虚】**公衆の前での名前呼びは関係の露呈**：「レティシア嬢」でなく「レティシア」と呼んだ瞬間、周囲が息をのむ
- 【虚】**令嬢口調**：「わたくし」「〜ですわ」「〜ですの」。崩れたら素が出た合図
- 【虚】**平民が貴族にタメ口を使う → 「無礼者！」**：ただし実力で黙らせる、または面白がられる展開に転ぶ

## 6. 紹介・会話の順序

- 【史】**身分の低い者を高い者へ紹介する**：「殿下、こちらが我が娘でございます」であって、その逆ではない。主人公が自然にこなすと「この娘、礼法を知っている」と評価される
- 【混】**下位者から話しかけてはいけない**：上位者が会話を始めるまで待つ。実在の宮廷にも、王族に自分から話しかけない慣習があった
- 【虚】**上位者から話しかけた＝寵愛のしるし**：「殿下の方から！？」というざわめきは恋愛演出に便利
- 【虚】**平民ヒロインがこのルールを破り、場が凍る**

## 7. 空間の作法（着席・入場・通行）

- 【史】**主賓が座るまで座らない**：「皆も楽にせよ」で着席する
- 【混】**席順がそのまま身分表**：席次（order of precedence）は実在の制度。公爵令嬢が末席なら冷遇、男爵令嬢が王太子の隣なら宮廷がざわつく
- 【混】**入場順**：低位から入場し、最後に王族。侍従の「国王陛下ならびに王妃陛下、ご入場！」で全員が会話を止めて起立する
- 【混】**王族の入退場時は全員起立**：知らずに座ったままの転生者というイベントになる
- 【混】**廊下では下位者が道を譲る**：中央を堂々と歩く主人公が「何者だ？」という導入になる
- 【混】**高位者が自分で扉を開ける場面は珍しい**：使用人が扉を扱う生活のため。だから王子が主人公のために扉を開けると、身分差を越えた丁重な扱いとして「殿下が自ら！？」となる

## 8. エスコート・接触

- 【混】**「お手をどうぞ」**：誰が誰を、誰が先に申し出るか、断るか横取りするかがすべて政治になる
- 【混】**許可なく触れない**：勝手に腕を掴めば「無礼者！」。王子が突然手を取るだけで大胆な行為になる（接触権限の侵犯）
- 【混】**手の甲へのキス**：格式重視の作品では唇が触れる寸前で止める。儀礼・求愛・挑発を曖昧にできる
- 【混】**馬車の乗降**：男性が先に降りて手を差し出す

## 9. 舞踏会

- 【虚】**ファーストダンスは特別**：婚約者・配偶者・主催者と踊る。王太子が主人公に「最初の一曲を」と申し込めば公開告白に近い
- 【虚】**同じ相手と連続して踊る回数に意味がある**（値は作品ごとに異なる）

  ```text
  1曲 → 社交辞令
  2曲 → 好意
  3曲（作品によっては4曲以上）→ 求婚の意思／マナー違反
  ```

- 【混】**断るには理由が要る**：「少々疲れておりますので」と言った直後に別の相手と踊れば、最高に分かりやすい侮辱になる
- 【虚】**婚約者の色を身につける**：服飾格付けと連動する

## 10. お茶会

- 【混】**お茶会は女性貴族社会の政治会議**

  ```text
  招待する       → 仲間として扱う
  招待しない     → 派閥から排除する
  招待状が遅れる → 格下扱い
  末席に置く     → 冷遇
  ```

- 【虚】**誰が茶を淹れるか**：主催の令嬢が自ら淹れるのは歓迎のしるし。「あなたには必要ないでしょう」は露骨な排除
- 【虚】**カップの扱い**：小指を立てるのは下品、カップだけを優雅に持つ。現代の英国式マナー解説の輸入（→ §1-1）
- 【虚】**アフタヌーンティーの順序**：下段のサンドウィッチ → スコーン → スイーツ。現代のアフタヌーンティーで一般的に案内される順序が、異世界の茶会にそのまま持ち込まれる
- 【虚】**茶器・茶葉・手土産で教養と家格を測られる**：茶葉の産地を当てさせる教養テストもある
- 【虚】**開始・終了時刻や途中退席の可否が論点になる**：主人公が「欠席という選択肢」を作って慣習を変える展開もある

## 11. 食事

- 【混】**食事の開始は主人から**：王がナイフを取るのが合図
- 【虚】**カトラリーは外側から使う**：現代の西洋料理マナーの輸入。読者に分かりやすいので多用される
- 【虚】**食器の扱いで育ちがバレる**：成り上がりは「フォーク多すぎない？」と戸惑い、平民主人公が完璧にこなすと「どこでその作法を…」という出自の伏線になる
- 【虚】**ナプキン**：膝の上に置き、首から下げず、盛大に口を拭かない

## 12. 訪問・招待・贈答

- 【混】**訪問には事前連絡が要る**：使者 → 書状 → 日時調整 → 訪問。王太子の突然の来訪は重大事件
- 【混】**招待状の格**：紙・封蝋・家紋・筆跡・配達者。王家の封蝋を見ただけで使用人が青ざめる
- 【混】**上位者の招待は断れない**：断るなら体調や先約といった、社会的に通る理由が要る。毎回「体調不良」で断るのは政治的な拒絶
- 【虚】**贈り物の序列**：日用品 → 菓子 → 花 → 装飾品 → 宝石 → 家宝。王子が未婚の令嬢に宝石を贈れば求愛と受け取られる
- 【虚】**瞳の色の宝石を贈る＝求愛**
- 【虚】**花言葉の取り違え**：意味を知らずに贈って勘違いイベントが起きる

## 13. 屋内・使用人

- 【混】**ノック → 許可 → 入室**：「入りなさい」「失礼いたします」。許可なく入ってくれば重大事件の合図
- 【混】**使用人は主人の会話に割り込まない**：「お話中失礼いたします」と前置きして報告するだけで緊急性が伝わる
- 【虚】**使用人への態度で人物を評価させる**：善玉は「ありがとう」、悪役は「使えないわね！」
- 【虚】**お礼の一言に使用人が感涙する**：「私どものような者にお礼を…？」。現代人の最低限の対人マナーが、封建社会では**人格チート**として扱われる（→ §17）
- 【虚】**善行が人的資本に変わる**：使用人に優しい主人公のもとに使用人ネットワークから情報が集まり、政争で有利になる

## 14. 淑女教育・感情の統制

- 【混】**淑女は感情を見せない**：大声で笑わない、怒鳴らない、泣き叫ばない、走らない、足音を立てない
- 【混】**扇は第二の表情**（史実の「扇言語」を誇張したフィクション表現が多い。体系的な扇言語は、19世紀の扇メーカーの販促用冊子によって広まったとする説が有力で、宮廷で実際に通じた暗号体系だったとは言いにくい）

  ```text
  口元を隠す   → 感情を隠す
  扇を閉じる   → 会話を終える
  軽く叩く     → 不満
  扇越しに見る → 警戒
  ```

- 【虚】**礼法教師キャラ**：カーテシー・歩き方・会話・食事・舞踏・手紙・家系・紋章を叩き込む。決め台詞は「お嬢様、もう一度でございます」、訓練は頭に本を載せて歩くこと
- 【虚】**転生令嬢の内心ツッコミ**：完璧な淑女を演じながら、内心では作法の窮屈さを吐露する

## 15. 上位者の礼儀（義務としての礼）

礼儀は服従のルールだけではなく、**上位者にも義務を課す**。これを描くと、単なる身分制の礼賛から離れ、社会に説得力が出る。

- 【混】**客人を保護する**：招いた相手が自邸で害されたら主人の恥になる
- 【混】**招いた相手に恥をかかせない**：主催者は場の秩序と争いの収拾に責任を負う
- 【混】**下位者の礼に応答する**：礼を無視するのは上位者側の無作法
- 【混】**与えた庇護を軽々しく撤回しない**
- 【混】**家臣の失態は主人が責任を負う**
- 【虚】**弱者への公然たる暴力を許さない**
- 物語での使い方：義務を果たす上位者は「器の大きさ」として描かれ、果たさない上位者（庇護を投げ捨てる王子など）は失脚の伏線になる

## 16. 悪役令嬢・婚約破棄・学園

- 【虚】**「学園内では身分は平等」という校則**：制度上の平等と社会的な権力が一致しない。男爵令嬢が「学園では平等でしょう！」と言えば、公爵令嬢は「卒業後も同じことが言えるのかしら」と返す
- 【混】**婚約者をエスコートしない＝公然の侮辱**：王子が男爵令嬢をエスコートして入場する
- 【混】**婚約者以外とべったりする**：浮気にとどまらず、家同士の契約への侮辱という政治問題になる
- 【虚】**公衆の面前での婚約破棄**：作法違反の極みであり、宣言した王子側が自滅するフラグ
- 【虚】**ヒロイン（ゲーム主人公）の距離感がおかしい**：ボディタッチや呼び捨てを連発し、悪役令嬢が注意しただけなのにいじめ扱いされる
- 【虚】**不敬罪を振りかざす小物貴族**：直後に正体を隠した上位者に返り討ちにされる

## 17. 転生者・転移者の類型

| 類型 | 内容 |
|---|---|
| 無知型 | 視線・歩き方・席順で粗相する。前世の知識で対応しても「西洋式とは違う」と指摘される |
| 適応型 | 作法を学んで習得していく。成長の過程そのものが見せ場になる |
| 現代常識型 | 礼を言う、清潔、時間厳守、報連相、女性の尊重、使用人に乱暴しない → 「なんと高潔な…」と言われ、本人は「普通では？」 |
| 逆輸入型 | 現代のマナーや慣習を異世界の標準にしてしまう |
| 専門家型 | 前世の職業経験で礼儀チートを発揮する。【創】作例：元ホテルマン・元CA・元秘書・元百貨店勤務・元マナー講師 |

- 【虚】**無礼が「面白い」と気に入られる**：王族や魔王に敬語を使わず、なぜか好感度が上がる
- 【虚】**丁寧さが平民層に好かれる**：「礼儀正しい子」として村で受け入れられる

## 18. 異文化作法

- 【虚】**土下座**：謝罪・感謝・威圧されたときに出る日本式の所作の持ち込み
  - 【創】ユニークスキル【土下座】で相手の敵意を下げる。前世の社畜経験がスキルとして顕現する
  - 【虚】婚約破棄した王太子が最後に土下座する（身分逆転の象徴）
  - 【虚】令嬢の「美しい土下座」の姿勢まで作法として描かれる
  - 【虚】周囲が主人公に跪くことで実力差を強調する
- 【虚】**箸文化の持ち込み**：転生者が箸を自作して使い、周囲が驚く。転生者が異世界の食卓のルールを変える
- 【虚】**獣人・エルフなど異種族の作法を知らずに失礼を働く**

## 19. 冒険者ギルドの礼儀（別の序列システム）

ギルドは「礼儀がない場所」ではなく、**別の礼儀が存在する場所**。

```text
宮廷：血統 → 礼儀 → 爵位
ギルド：実績 → ランク → 強さ
```

- 【虚】**身分より実力・ランク・経験を重視する**：宮廷式の敬語を使うと「貴族のボンボンか？」と絡まれる
- 【虚】**テンプレの初対面**：「そんな貧弱な装備で冒険者に？」、受付嬢の態度はカジュアルか侮蔑的
- 【創】**ギルドの不文律の例**：他人の獲物を横取りしない、パーティメンバーを見捨てない、依頼内容を外に漏らさない、先輩冒険者に最低限の敬意を払う
- 【虚】**宮廷とギルドの往復**：主人公が両方を行き来することで、世界の階層の多層性が示される

## 20. 決闘

- 【混】**手袋を投げる＝決闘の申し込み**：歴史的慣習を記号化したもので、一目で意味が通じる優秀な記号
- 【混】**正式な手順を設定すると世界観が締まる**：介添人・証人・武器の選択・時刻・場所

## 21. 礼儀違反の重大度

マナー違反と国家犯罪を混同しないための段階表。

```text
Lv.1 ぎこちない
  フォークを間違える／挨拶が少し不自然
  → 失笑・評判の小さな低下

Lv.2 無作法
  話を遮る／呼称を間違える／席順を間違える
  → 叱責・陰口・社交的な評価の低下

Lv.3 侮辱
  礼を返さない／招待を意図的に無視する／婚約者をエスコートしない
  → 関係の断絶・社交的制裁

Lv.4 政治的挑発
  王族への公然たる無礼／席次の操作／公式行事での排除
  → 派閥間の対立・政治問題・処罰の口実

Lv.5 （礼儀の外側との境界）反逆・治安問題
  王への無断接近／謁見の場への武器の持ち込み／王命への公然たる拒絶
  → 警護・法の問題。生命に関わる
```

```text
礼儀違反 ≠ 必ず犯罪
礼儀違反 → 評判の低下 → 社交的制裁 → 政治問題 → 場合によって法的処罰
```

## 22. 創作での使い方と落とし穴

### 22-1. 使い方の原則

- **作法は「破られる瞬間」のために置く**：ルールの説明は、違反や逸脱が起きる直前に最小限で済ませる
- **一つの所作に一つの意味を持たせる**：名前呼び＝権限の付与、末席＝冷遇のように、読者が意味を即座に読める対応関係を作る
- **作中ルールは早めに一度だけ明示する**：【虚】【創】のルール（ダンスの回数など）は初出で定義し、以後は説明なしで使う
- **礼儀の変化で関係の変化を描く**：呼称・距離・礼の深さの推移を、台詞で語らせずに関係の進展や断絶として見せる
- **上位者側の義務も一度は描く**：庇護・応答・責任を果たす（または果たさない）場面を入れると、身分社会に説得力が出る

### 22-2. 落とし穴

- **説明過多**：作法の解説が長くなり、展開が止まる
- **史実の断言**：【混】【虚】の作法を、作中の人物や地の文に「史実ではこうだった」と言わせてしまう
- **無礼の免罪の乱用**：「無礼でも許される主人公」を繰り返すと、作法の重みが消え、場面の緊張がなくなる
- **一方向の身分制**：下位者の服従だけを描き、上位者の義務が欠けると、社会が舞台装置に見える
- **正しさの固定**：作法を守る側が常に正しい、という構図に固定されると、礼儀を武器にした悪役や形式の窮屈さが描けなくなる
- **ルールの不整合**：作中で定義した回数・色・順序が途中で変わる。数値ルールほど矛盾が目立つ

## 用語集への登録

作中独自の作法の名前、数値ルール（ダンスの回数・贈り物の意味など）、敬称の体系、不敬が罪になるかどうかは、作品の `world.md` の `## 用語` に置く（書式は [world_glossary.md](../world_glossary.md)）。

- 数値ルールや違反の罰のように手順・条件を持つ決まりは、種別を制度とし、「定義・適用範囲」に誰が・いつ・何をすると何を意味するかを書く。本文はその条件どおりに描き、台詞で条件と食い違うことを言わせない。
- 新しく決まりや名前が要ったら、本文に出す前に `## 用語（承認待ち）` へ登録案を書く。作法を「破られる瞬間」のために置く（§22-1）ときも、先に決まりを登録しておくと後出しにならない。
- 一般の礼法の語（カーテシー、エスコート、席次など）は用語集に入れない。初めて出すときは、視点人物が見て分かる形で説明を添える。

## 深掘り用の問い

必要な問いを選び、答えを `world.md`、`character.md`、`design_specification.md` など作品の適切な正本へ記録する。

1. この作品で、作法から一番よく読まれる情報は何か（身分・親密さ・敵意・派閥・教養）。
2. 主人公は礼儀に対してどの態度をとり、それは物語のどこで変わるか。
3. 呼称はどの順で変わり、名前で呼ぶことを誰が誰に許すか。
4. 誰が作法を読めて、誰が読めないか。その差はどの場面で効くか。
5. 礼儀を武器にする人物は誰で、その攻撃は誰に否認され、誰に見抜かれるか。
6. 違反の重大度はどこで線を引くか。どこからが法の問題になるか。
7. 上位者の義務を果たす人物と果たさない人物は誰で、それは何の伏線になるか。

## 作業用への導入

標準版を作品で選定する前に、作業用 `_how_to/_index.md` がある場合は、利用者が `_how_to/literacy/etiquette.md` へコピーし、作業用索引の 1.7 と作業用 `_how_to/literacy/README.md` から参照できる状態にする。作業用の葉がある場合はそちらを実効版として使い、標準版と自動合成しない。既存作品の `_meta.md` の selected は、作品ごとに適用を決めたときだけ更新する。
