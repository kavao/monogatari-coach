# ドレス・服飾の格を読む

> 原資料（来歴）: `C:/Users/Owner/Downloads/dress-ranking-tropes.md`（ドレス・服飾格付けあるある集。なろう系・令嬢もの）。2026-11-03 に `literacy/` の初葉として導入。導入版では、原資料の0〜15章を10章へ組み直し、発動条件・使い方・最低限決めること・関連葉・用語集への登録・深掘り用の問いと、いくつかの章末の短い使い方の注記（関連葉への誘導、色の規則を先に見せる、読めない情報の見せ方）を足した。原資料の「発展候補」は別葉にせず、末尾の将来メモに畳んだ。原資料は変更していない。

服飾を「身分・財力・教養・政治力・寵愛の可視化装置」として使うための設計資料。対象は異世界転生、悪役令嬢、婚約破棄、貴族社会ものなど。物語上の面白さは、服そのものよりも **「服を見て何が読み取れるか」** にある。

## 発動条件

> 服飾・ドレス・衣装の格を、身分・財力・教養・政治の可視化として設計する場合、または夜会・茶会で装いを読んで立場や関係が動く場合に選ぶ（既定では読まない。令嬢もの・貴族ものというジャンル指定だけでは選ばない。画像用の配色・衣装は `world_wear.md`）。

## 本資料の注意

本資料は歴史服飾の再現資料ではない。主として「西洋風異世界」「悪役令嬢もの」で頻出する **物語上の記号・慣習** を整理したものである。

実際のヨーロッパ服飾史とは異なる内容を含み、また17〜19世紀の慣習が同じ世界の中で混在することも多い。各項目には必要に応じて次のラベルを付ける。

| ラベル | 意味 |
|---|---|
| **［ジャンル慣習］** | なろう系・令嬢ものの記号として定着しているもの。史実の裏付けは問わない |
| **［史実由来］** | 実際の服飾史に根拠があるもの |
| **［世界設定依存］** | 時代・地域・工業化レベルなど、世界の設定次第で成立が変わるもの |

［史実由来］の項目も、史実として本文へ出すときは別途資料で確かめる。未確認の一般化を事実として言い切らない。

## Monogatari Coach での使い方

装いの読み合いで立場や関係が動く作品の Plan Mode で参照する。全項目を採用する一覧ではなく、作品で読み合いが起きる場面と、格付けの規則が崩れる一点を選ぶための資料である。

| 作品資料 | 主に反映する項目 |
|---|---|
| `world.md` | 禁色・専用色、白など色の意味、家門色、素材と産地の格、仕立て屋の序列、既製服の有無（工業化レベル）、TPO と既婚・未婚の制限、喪の規則 |
| `character.md` | 人物が財力×文化資本の四象限のどこにいるか、誰に何が読めるか（観察者の解像度）、ペアカラーで示す関係 |
| `design_specification.md` | 装いを読む場面の章出来事（誰が何を見抜き、誰が恥をかき、関係がどう動いたか）、嫌がらせとその反証、流行の創出 |
| `_meta.md` | 誰が誰の色をまとっているかの変化、贈られた装飾品の行方、流行の推移 |

設計時は、最低限次を決める。

- 作品の格付けで一番効く層を一つ選ぶ（素材・仕立て・色・来歴・TPO など）。全層を同じ厚さで書かない。
- 色の意味（特に白・黒・禁色）と家門色を、その国の規則として `world.md` に固定する。国ごとに違えるなら、どこで違うかも決める。
- 主人公と主要人物が、財力×文化資本の四象限のどこにいるかを決める。
- 誰に何が読めるか（観察者ごとの解像度）を決め、読める者と読めない者の差を場面の推進力にする。
- 規則を破る・逆手に取る・書き換えるのうち、作品の主軸を一つ選ぶ。
- 服飾の格付けは架空世界向けの記号であり、特定の時代・地域の史実として扱わない。

## 1. 多層構造と価値の式

### 1.1 格付けの多層構造

```
素材 → 職人（手間） → 仕立て → 流行 → TPO → 家格 → 政治的意味
```

服は次の三つを兼ねる。

- **名刺**: 家格・所属・派閥がわかる
- **資産証明**: 素材・職人・宝飾品から財力がわかる
- **政治声明**: 色・贈り物・合わせ方で立場や関係を表明する

### 1.2 服飾の価値の式

```
服飾の価値 ＝ 財力 ＋ 文化資本 ＋ 家格 ＋ 人脈 ＋ 来歴 ＋ 政治的意味
```

この式により「なぜ地味な公爵令嬢が派手な成金令嬢より上なのか」を説明できる。金額だけでは格は決まらない。

> 補足: 来歴は家格・人脈と重なる部分があるが、宝飾品や家宝の格を語るときに独立して効くため、別項として扱う。

## 2. 作劇の三方向

1. 規則を **破る**（僭越、マナー違反、断罪の口実になる）
2. 規則を **逆手に取る**（知識逆転型ざまぁ。→7.2）
3. 規則を **書き換える**（前世知識による流行創出、服飾チート）

これは服飾に限らず、貴族社会ものの作劇原理と対応する。

| 作品類型 | 三方向との対応 |
|---|---|
| 婚約破棄もの | 規則を破ったと糾弾される |
| 悪役令嬢もの | 実は主人公側が正しい規則を知っている |
| 内政・転生もの | 主人公が新しい規則を作る |

### 主人公による逆転・革新（書き換えの型）

- 前世がアパレル関係者だった主人公が、新しいデザインや機能性のある服を作る
- 庶民や下位貴族の娘が、魔法や独自のデザインで上位貴族の豪華なドレスを凌駕する
- **バトルドレス**: 優美な見た目に防具や魔法補助の機能を持たせる
- 「ずいぶん地味なドレスですね」→「……あれ、王室御用達の新作では？」「布だけで屋敷が買えるぞ」という、**真の上流の地味ドレス** 展開

服飾の書き換えが流行・経済・制度へ広がる帰結を追うときは [異物導入](../tropes/foreign_element.md) を併用する。

## 3. 素材・手間・本物の見分け

### 3.1 素材の評価軸

繊維（原料）と織物（組織）は別のカテゴリーなので、軸を分けて考える。

| 評価軸 | 例 |
|---|---|
| 原料 | 絹、羊毛、麻（リネン）、綿、魔獣毛、魔蚕の糸 |
| 織物 | サテン、ベルベット、タフタ、ブロケード |
| 染色 | 深紅、紫、鮮やかな青、玉虫色 |
| 加工 | 刺繍、金糸、レース、ビーズ |
| 産地 | 王都、南部、外国、幻獣領 |
| 職人 | 一般工房、名工、王室工房 |

組み合わせるだけで格の説明になる。

> 「南部産の極細絹を王都の名工がサテンに織り、東方産の染料で染めたもの」

### 3.2 素材の格の目安

| 格 | 例 | 用途・印象 |
|---|---|---|
| 下位 | 粗布、粗い麻布、大量生産された粗い綿布、粗い羊毛 | 庶民・使用人。実用と耐久性が優先 |
| 中位 | 上質な絹のサテン・ベルベット、上質なリネン、薄手のレース | 貴族の日常着、中規模の夜会 |
| 上位 | 「○○産の絹」など産地ブランド品、ブロケード | 「王都でも滅多に手に入らない」最上級品 |
| 幻想級 | 魔蚕の糸、月光蜘蛛（アラクネ）の糸、竜鱗織り、不死鳥の羽の刺繍 | 自己修復、魔力補助、美貌強調、汚れを弾く防汚、季節を問わない体温調節、刃を通さない防護などの機能付き |

### 3.3 素材の注意点

- **麻＝庶民と固定しない**［史実由来］: 上質なリネンは高級品になり得る。下位に置くのは「粗い麻布」
  - 例: 極薄で目の詰んだ高級リネン（カンブリックなど）は、襟、袖口、ひだ襟、下着、ハンカチに使われ、肌に触れる部分の上質さを示す品だった
  - 作劇例: 「表は地味な毛織物でも、袖口から覗く麻が極上」で真の上流を示せる
- **綿＝安物と固定しない**［世界設定依存］: 時代や地域によっては、輸入綿布が高級品になる
- 綿の大量生産は、**産業革命チート** の入口として使える
  - 綿花栽培 → 紡績 → 織機改良 → 綿布の大量生産 → 衣料価格の低下
  - 生産の実装と社会の受容を描くときは [異世界現代知識無双](../genre/isekai_modern_knowledge.md) を併用し、この葉は夜会での見え方だけを扱う

### 3.4 素材のあるある

- 値段の表現は「**屋敷一軒買える**」「**平民一家の一年分の生活費**」が定番［ジャンル慣習］
- 地味に見えたドレスが、鑑定すると **最高級素材** だったと判明する
- 異世界ものでは **素材の魔法化** が特に多用される

### 3.5 職人・手間

**刺繍**

- 刺繍の量は **金と人手の量** を示す［史実由来］
- 金糸・銀糸・宝石を縫い込んだ刺繍は高級品
- 全面刺繍は「何人の職人を何か月拘束したのか」という水準
- 手刺繍か魔法刺繍かで価値が揉める

**レース**

- 手編みのものや極細のものほど高価［史実由来］
- 「この襟だけで平民の年収」系の描写が多い
- 転生者が **大量生産技術を持ち込んで価格破壊** する展開に使いやすい

**染料**

- 紫、深紅、鮮やかな青などの **希少色** は高価［史実由来］
- 安物は色が薄い、くすんでいる、退色している

### 3.6 仕立て（「本物」の見分け方）

- 一見地味でも **体に完璧に合っている**
- 縫い目が見えず、ドレープが美しい
- 「**分かる人には分かる**」上級貴族の装い

これにより、格付けを二段階にできる。

| 単純な格付け | なろう的な格付け |
|---|---|
| 派手なドレス＝高級 | 派手なドレス＝**金持ち（成金）** |
| 地味なドレス＝安物 | 洗練されたドレス＝**本物の上流階級** |

### 3.7 仕立て屋・ブランド力

- 「**王妃御用達のマダム・○○**」
- 「予約は三年待ち」「公爵家でも紹介状が必要」
- 「彼女が直接採寸するのは王族だけ」
- その仕立て屋の予約が取れるかどうかが、社交界での立場を示す
- 主人公が「この人、昔助けたおばさんですよ？」と気づき、**最高峰デザイナーに特別扱いされる** のが王道

### 3.8 衣服の入手経路［世界設定依存］

| 層 | 前近代寄りの世界 | 近代寄りの世界 |
|---|---|---|
| 庶民 | 家庭裁縫、町の仕立て屋、古着 | 既製服 |
| 富裕層 | 専門の仕立て屋 | 高級既製服、仕立て屋 |
| 貴族 | 専属または高級仕立て屋 | オーダーメイド |

**既製服の存在そのものが、世界の工業化レベルを示す**。

## 4. 色と所属・関係の記号

### 4.1 禁色・専用色

- 紫・金・特定の青などが **王族専用** とされる［ジャンル慣習／一部史実由来（奢侈禁止令など）］
- 格下の者が着ると「**僭越**」「不敬」となり、断罪の口実になる

### 4.2 意味を持つ色

| 色 | よくある意味づけ |
|---|---|
| 白 | デビュタントの色、聖女・神殿の色、国によっては王族の婚約者専用［世界設定依存］ |
| 黒 | 喪・不吉。主人公が着こなして「大人の色」として流行させる |
| 赤・黒・濃紫 | 悪役令嬢の色として割り振られがち［ジャンル慣習］ |
| 家門色 | 王家の色、公爵家の色、母方の家の色などで所属を示す |

> ※ **白の意味は国によって大きく異なる** よう設定できる。デビュタントの礼装、花嫁の色、王族の婚約者専用、聖職者の色、喪の色など、どれを採るかで TPO 違反や異文化摩擦の火種になる（→6.1 TPO 違反の型、7.2 知識逆転型ざまぁ）。

### 4.3 ペアカラー／庇護色［ジャンル慣習］

婚約者の髪や瞳の色をまとう表現は、史実一般というより **令嬢もの独特の視覚言語** である。衣装だけで人間関係を説明できる。

| 状態 | 服飾表現 |
|---|---|
| 婚約成立 | 相手の瞳の色の宝石を身につける |
| 円満 | 互いの家門色を一部に取り入れる |
| 陣営表明 | 公爵令嬢が王太子の瞳と同じ蒼をまとう →「私は王太子側です」 |
| 冷却 | 相手の色を使わない、贈られた装飾品を着けない |
| 決裂 | 自家の色だけに戻す |
| 浮気 | 第三者の色をまとう。浮気相手が婚約者の色で現れると修羅場が始まる |
| 庇護 | 王族が自分の色の宝石を与える |

男性側も、婚約者の色のタイやカフスを合わせてペアを示す。冷遇系の夫が **妻とまったく色を合わせない** ことで、不仲が周囲に知れ渡る。

## 5. 宝飾・小物・贈答

### 5.1 宝飾品の本当の格

```
市場価格 ＋ 素材品質 ＋ 職人 ＋ 希少性 ＋ 来歴（プロヴェナンス）
```

- 成金は **巨大な宝石を大量に** つける
- 本物の上流は「**小さいが最高品質**」「由緒ある家宝（パリュール）」
- 主人公が石の **産地やカット** を見抜き、相手の教養不足を暴く

### 5.2 継承品・来歴

新品が最高とは限らない。貴族社会ではむしろ **古いものが強い**。

- 王国建国時のティアラ
- 初代公爵夫人のネックレス
- 王妃から祖母に下賜されたブローチ

成金が高額なダイヤを持ち出しても、「こちらは初代国王が我が家に下賜したものです」で負ける。

### 5.3 扇子（万能小道具）

| 格 | 特徴 |
|---|---|
| 安物 | 印刷模様 |
| 中級 | 手描き |
| 上級 | 象牙、螺鈿、金細工 |
| 最高級 | 名工作、家紋入り |

**扇を使った非言語演技**

- 口元を隠す、笑いを隠す
- 相手を指す、視線を送る
- 閉じることで会話を打ち切る
- 激しく扇いで苛立ちを示す

> ※「この角度は愛の告白」のような体系化された「扇言葉」は、後世の宣伝やロマン化による要素が強い。**その国独自の扇コード** として世界設定に組み込むと扱いやすく、設定の独自性も出せる。
>
> ※この節は扇という小物の格を扱う。扇で感情や意思を示す作法（扇は第二の表情）は [礼儀作法の葉](etiquette.md) §14。

### 5.4 その他の小物

- ティアラ、ネックレス、イヤリング、ブローチ、手袋、靴、バッグで女性同士の格付けが行われる
- 手袋を投げつける＝決闘の申し込み
- 靴はガラスの靴型のシンデレラオマージュが定番

### 5.5 贈答・下賜

服飾社会では、**誰が買ったか、誰から贈られたか** が非常に重要である。贈答は単なるプレゼントではなく、**庇護・承認・政治的所属** の表明になる。

| 贈答 | 意味 |
|---|---|
| 王太子が宝石を贈る | 寵愛、婚約者としての承認 |
| 公爵夫人が仕立て屋を紹介する | 社交界への推薦、派閥への受け入れ |
| 王妃がレースやブローチを下賜する | 王妃の後ろ盾 |

> 「そのブローチは王妃殿下から？」
> 「ええ、先日の茶会で賜りました」
> ――周囲が静まり返る。

この一言で「主人公には王妃の後ろ盾がある」と伝わる。

## 6. 流行・TPO・身分制限

### 6.1 TPO 違反の型

- 昼の茶会に夜会用ドレスを着てくる
- デビュタントなのに既婚女性向けの装い
- 王宮舞踏会で宝石が過剰
- 喪中なのに鮮やかな色

「**高価な服を着ているのにマナー違反**」にすると、成金や田舎貴族を表現できる。

逆に主人公は「去年のドレスを少し仕立て直しただけです」と言いながら、色・時間帯・格式を完璧に合わせ、「あの令嬢は分かっている」と評価される。

### 6.2 身分・立場による制限

- **既婚と未婚** で、露出度、髪型（結い上げるか下ろすか）、色が変わる
- **主催者や王族を意図的に食う装い** は、無作法または **政治的挑発** と受け取られることがある［世界設定依存］
  - 例: 王妃より大きなティアラ → 単なるファッションではなく政治的マウンティング
- **喪服期間** の長さや装いの規則が、家の事情や陰謀の伏線になる
- **一日に何度も着替える文化**（朝用・午後用・夜会用）が、余力のある家の証になる［史実由来（19世紀的）］

### 6.3 着回し

- **同じ組み合わせ** で大舞踏会に何度も出ると、財政難や社交への無関心を疑われる設定がある［ジャンル慣習］
- 史実では、高級衣服は装飾、袖、レース、リボン、宝飾品の交換や仕立て直しで再利用された［史実由来］

**節約型ざまぁ** の型:

> 貧乏令嬢「去年のドレスです」
> ↓ 袖・襟・レース・装飾を交換
> ↓ まったく別のドレスに見える
> 王妃「あの娘、センスがありますね」

### 6.4 流行と時代遅れ

- 継母や義妹に **流行遅れのドレス** を着せられ、夜会で恥をかかされる
- 「今年の流行を押さえていない」という一言でセンスと情報網のなさを示す
- 流行を作るのは **王妃や公爵夫人** で、彼女たちに認められることが格上げの契機になる
- 主人公が前世知識で新しいデザインを持ち込み、大流行させる
  - → 主人公の商会・ブランドが成立し、**服飾チートが経済チートにつながる**

### 6.5 下着・シルエット改革の描き方

> ※エンパイアラインだからといって補正下着が不要になるわけではない［史実由来］。当時も短いステイズなどは使われていた。

説得力のある言い方は次のとおり。

- △「コルセットを廃止します！」
- ○「**締め上げることを前提にしない下着と服の設計にします**」

## 7. 嫌がらせ・知識逆転

### 7.1 嫌がらせの類型

| 類型 | 典型展開 |
|---|---|
| 汚損 | ワインをかけられる、裾を踏まれる → 魔法で修復、または用意された着替えで逆転 |
| 破損・妨害 | ドレスを破られる、切り裂かれる、仕立て屋への妨害で届かない |
| 強奪 | 義妹にドレスや宝飾品を奪われる → 実は呪い付きや偽物だった |
| 偽ドレスコード | 招待状に嘘を書かれる（「仮装舞踏会」と書かれていたのに正装の会） |
| 贈り主の誤認 | 平民ヒロインの豪華なドレスを「下品」と嘲笑 → 贈り主が王族だと知って青ざめる |
| 婚約破棄の連動 | 婚約解消と同時にドレスの注文が一斉キャンセルされ、仕立て屋が困る |

**台詞・反応例: 偽ドレスコード**

> 義妹「招待状には仮装舞踏会とありましたもの。お姉様がそんな格好でいらしたのは、お姉様の勘違いですわ」
> 主人公「では、こちらの招待状の控えを皆様にお見せしても？　主催者の封蝋も残っておりますの」
> 主催者夫人「……私、仮装などと書いた覚えはございませんわね」

反応パターン: 嘲笑していた周囲が黙る → 視線が義妹に移る → 主催者が事実を確認して決着。

**台詞・反応例: 贈り主の誤認**

> 令嬢A「平民があのような宝石を。どこの商人に貢がせたのかしら」
> 侍従「そちらは殿下が先日、宝物庫からお選びになったものでございます」
> 令嬢A「…………」

反応パターン: 周囲が一斉に扇で口元を隠す → 嘲笑した側から人が離れる → 後日その家への招待状が減る。

### 7.2 知識逆転型ざまぁ

- ヒロインが白いドレスで来る → その国では **白は王族の婚約者しか着てはいけない**
- 悪役令嬢の白を「花嫁みたい」と嘲笑 → 周囲「**未婚女性の正式礼装ですが？**」

どちらも、4.2 で決めた色の規則を読者に先に見せておくと、逆転が後出しにならない。

## 9. 観察者ごとの解像度（鑑定眼）

### 9.1 読み取りの描写パターン

上級貴族は一瞬で次のことを読み取る。

- 「そのレースは北部産」
- 「去年流行した型」
- 「王室御用達の仕立て屋の仕事」
- 「その宝石は南方伯爵領のもの」
- 「母方の家の紋章色」

### 9.2 観察者別の情報解像度

同じ服でも、誰が見るかで読み取れる情報が変わる。**服飾を鑑定する能力そのものが身分を示す**。

| 観察者 | 読み取る情報 |
|---|---|
| 庶民 | 派手、高そう |
| 商人 | 素材の価格、産地 |
| 仕立て屋 | 縫製、流行、どの職人の仕事か |
| 貴族令嬢 | 家格、TPO、派閥 |
| 公爵夫人 | 政治的な意図 |
| 王妃 | 誰がこの衣装を用意したのか、その背後関係まで |

読み取れないこと自体が、格下である証として描かれる。

視点人物が読めない情報は、地の文で言い切らず、周囲の反応（黙る、扇で口元を隠す、人が離れる）として見せると、読者も一緒に「何かが読まれた」と気づける。

## 10. 財力×文化資本の四象限

### 10.1 財力 × 文化資本の二軸

|  | 文化資本が低い | 文化資本が高い |
|---|---|---|
| **財力が低い** | 貧乏 | **没落名門** |
| **財力が高い** | **成金** | 真の上流 |

- **没落名門**: 金はないが、配色、TPO、所作、宝飾品の来歴、着回しで圧倒的に強い
- **成金**: 高価、派手、最新だが「昼の茶会にそれを？」となる

**金額＝格ではなく、財力×文化資本で格が決まる**。

### 10.2 階層別早見表

| 格 | 特徴 |
|---|---|
| 庶民 | 粗い布地、家庭裁縫や古着（近代寄りなら既製服）、装飾が少ない |
| 富裕商人 | 高級素材、大きな宝石、派手 |
| 下級貴族 | 流行を追う、仕立ては良い。同じ組み合わせが続くと没落を疑われる |
| 上級貴族 | オーダーメイド、最高級素材 |
| 公爵家級 | 名工、希少素材、来歴のある家宝 |
| 王族 | 禁色、王室工房、歴史的宝飾品 |
| 真の上流 | 一見地味だが全部最高級 |

## 付記: 時代設定の混合

多くの作品は、**中世的な身分制度** を土台にしつつ、**17〜19世紀のドレス文化**（一日に何度も着替える、クリノリンやバッスルによる大きなスカートなど）を取り入れている。

歴史的な正確さよりも、**華やかさと身分の視覚的な強調** が優先される傾向にある。設定を作る際は、どの時代の服飾文化を混ぜているのかを意識すると、世界観の一貫性を保ちやすい。

## 用語集への登録

作品独自の色の規則・家門色・扇コード・仕立て屋の名前・幻想級の素材など、名前のあるものは作品の `world.md` の `## 用語` に置く（書式は [world_glossary.md](../world_glossary.md)）。

- 禁色・白の意味・喪の規則のように手順・条件を持つ決まりは、種別を制度とし、「定義・適用範囲」に誰が・いつ・何を着てはいけないかを書く。本文はその条件どおりに描き、台詞で条件と食い違うことを言わせない。
- 新しく決まりや名前が要ったら、本文に出す前に `## 用語（承認待ち）` へ登録案を書く。知識逆転の種（7.2）を後出しにしない手立てにもなる。
- 一般の服飾語（サテン、ブロケード、パリュールなど）は用語集に入れない。初めて出すときは、視点人物が見て分かる形で説明を添える。

## 深掘り用の問い

必要な問いを選び、答えを `world.md`、`character.md`、`design_specification.md` など作品の適切な正本へ記録する。

1. この作品で、装いから一番よく読まれる情報は何か（財力・家格・派閥・寵愛・教養）。
2. 白・黒・禁色は、この国で何を意味するか。隣国ではどう違うか。
3. 主人公は財力×文化資本の四象限のどこから始まり、どこへ動くか。
4. 主人公には何が読めて、何が読めないか。その差はどの場面で効くか。
5. 誰が流行を作り、誰に認められると格が上がるか。
6. 嫌がらせの反証に使える物証（招待状の控え、封蝋、贈り主の記録）は何か。
7. 服飾の書き換えが、流行・商売・制度のどこまで広がるか（広がりを追うなら異物導入を併用）。
