# literacy（身分を読む知識）

このカタログの「識字」は、文字の読み書き（識字率）のことではない。服・席・手紙などの目に見える装置から、身分・財力・所属・関係を読み取る知識を指す。世界設定で庶民がどれだけ文字を読めるかを決めるときは、このカタログを選ばない。

葉は **既定では読まない**。各葉の「発動条件」に当たるときだけ選ぶ。新しい葉を足すときは `_how_to.example/_index.md` と、この README の表の両方に1行置く。既存作品の selected は自動では増やさない。作業用 `_how_to/_index.md` がある環境では、そちらへ追随するまで標準だけの新葉は選定対象外。

**ジャンル軸では選ばない。** Plan Mode のジャンル軸（`genre/`）とは別のカタログで、`tropes/` と同じく葉ごとの発動条件で任意に選ぶ。令嬢もの・貴族ものというジャンル指定だけでは選ばない。ジャンル軸で選んだ作品（例: 悪役令嬢）で夜会の装いや席次が立場を動かす推進力になるときは、Gate B の選定補助に該当する葉を列挙してよい。selected には作者が採ったときだけ入れる。

カタログの発動条件:

> 身分を読む知識（識字。文字の読み書きではない）。身分・財力・所属・関係を、服や席や手紙などの可視装置から読むときに選ぶ。ジャンル軸では選ばない。既定では読まない。各葉の発動条件に当たるときだけ読む。

| ファイル | 装置 | 主な用途 | 発動条件 |
|---|---|---|---|
| [dress.md](dress.md) | 服飾・ドレス・衣装 | 格付けの多層と価値の式、素材と本物の見分け、色と庇護色、宝飾・贈答、流行・TPO、嫌がらせと知識逆転、観察者ごとの解像度、財力×文化資本 | 服飾・ドレス・衣装の格を、身分・財力・教養・政治の可視化として設計する場合、または夜会・茶会で装いを読んで立場や関係が動く場合に選ぶ（既定では読まない。令嬢もの・貴族ものというジャンル指定だけでは選ばない。画像用の配色・衣装は `world_wear.md`）。 |

## 葉の契約

1葉は、読み取れる身分装置を1つだけ扱う。資料の小ネタ（扇の作法、着回し、成金の服装など）を葉に割らず、装置の葉の中の節に置く。

各葉が必ず持つのは次の5点である。

1. **発動条件**: 索引 `_index.md` とこの README の表と、葉の本文で同じ文にする。
2. **多層構造と価値の式**: その装置の格が何で決まるか（金額だけで決まらない理由）。
3. **作劇の三方向**: 格付けの規則を破る、逆手に取る、書き換える。
4. **観察者ごとの解像度**: 誰に何が読めて、誰には読めないか。鑑定眼の専用葉は作らず、各葉のこの節に置く。
5. **ラベル**: 各項目が［ジャンル慣習］［史実由来］［世界設定依存］のどれかを示す。

ほかの節は装置に合わせて立てる。参考例として `dress.md` は、素材・手間・本物の見分け、色と所属・関係の記号、宝飾・小物・贈答、流行・TPO・身分制限、嫌がらせ・知識逆転、男性側の服飾、財力×文化資本の四象限を持つ。後続の葉がこの節をすべて持つ必要はない。

## ほかのカタログとの住み分け

| 置き場 | 担当 | このカタログとの境界 |
|---|---|---|
| `literacy/` | 可視の装置から身分・関係を読む。1葉＝装置1つ | 話の約束でも、人物の内側の論理でもない |
| [`genre/akuyaku_reijo.md`](../genre/akuyaku_reijo.md) | 破滅回避・断罪・ざまぁの話の約束 | 夜会は舞台として扱う。装いの読み方は `dress.md` |
| [`genre/isekai_modern_knowledge.md`](../genre/isekai_modern_knowledge.md) | 知識を持ち込み、社会が受け入れる話 | 染料などの実装と社会の受容はこちら。夜会での見え方は `dress.md` |
| [`tropes/foreign_element.md`](../tropes/foreign_element.md) | 一つの独自要素の帰結を追う | 服飾の知識や魔法が制度・物流を変える帰結はこちら。装いの読みは `dress.md` |
| [`world_wear.md`](../world_wear.md) | 画像用の配色・衣装 | 見た目の指針。格の読み方は持たない |
| [`world_glossary.md`](../world_glossary.md) | 作品固有の名前の書式と照合 | 用語の登録。身分の読み方の作劇ではない |

`genre/isekai_craft.md` には現状、織物・服飾の節が無い。ものづくりの工程はクラフト、仕上がった服の格の読みは `dress.md` と分ける。

## 運用

- 葉の名前・節の名前・ラベルは設計の判断材料である。物語案や `proposal.md` のログライン・あらすじ・キャラクター紹介には書かず、人物・出来事・選択として書く（`_how_to.example/synopsis_presentation.md`）。
- 全項目を一作へ詰め込まない。作品で読み合いが起きる装置と、規則が崩れる点を選ぶ。
- 葉の内容は創作のための整理であり、史実の再現資料ではない。［史実由来］の項目も、史実として本文へ出すときは別途資料で確かめる。未確認の一般化を事実として言い切らない。
- 作品独自の色・紋・扇の作法などを決めたら、名前のあるものは `world.md` の用語集へ登録する（`world_glossary.md`）。
- 基準本文は `_how_to.example/literacy/`、ユーザー共通の調整は `_how_to/literacy/`、作品固有の決定は `novels/<作品>/` の `world.md`・`character.md`・`design_specification.md` へ置く。
