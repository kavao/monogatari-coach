# novelcore

一般的な小説本文の文法。企画、保存、挿絵、チャットの手順は、それぞれの正本を読む。挿絵計画の雛形は [`illustration_plan.md`](illustration_plan.md) で、候補は作品の `illustrations/plans/chapter_plan.md` に書く。

既定では読まない。選定入口は作業用 `_how_to/_index.md` で、無いときは標準 `_how_to.example/_index.md` を発見用に併読する。Gate B で作品 `_meta.md` の selected に入ったときだけ読む。

## 1. 文体

- トーンは担当の `writer_profile.md` に従う。作家指定が無いときは `writers/000_default/writer_profile.md`。
- 擬音は小説内に独立して書く。
- 三点リーダーは `……`（U+2026 を2つ）を使う。例: 「もっと……」「いいよ……」。半角の `...` や単独の `…` は使わない。
- 地の文の段落は、行頭を全角1文字下げる。セリフ行（`「` / `『` で始まる行）は下げない。
- 句点（。）：地の文は文末に置く。文は主述のそろった完結した単位であり、従属節や読点の切れ目だけで終わらせない。
- 会話文は閉じ括弧の直前に「。」を置かない。会話の内部で文が切れる場合は「。」を置く。「？」「！」はこの制限を受けない。正しい例→「こんにちは」「そうね。私たちならどんな冒険も乗り越えられるわ」。誤った例→「こんにちは。」「そうね。私たちならどんな冒険も乗り越えられるわ。」
- 読点（、）：列挙・条件・長い主語の区切りに使う。「は、」「を、」の直後だけで文を切らない。読点だけで長大に文を接続し続けず、適度な長さで句点（。）を打つ。
- 段落の長さと改行: 1つの段落に情景・五感・内面描写を延々と詰め込まず、150〜250文字（2〜4文程度）を目安として、動作の一区切り、視点や情景の転換、息継ぎのタイミングで改行する（空行のあと、次の地の文は全角1字下げ）。
- 説明的挿入の回避: プロフィール（口調、外見、性格）は、地の文で「述べる」のではなく、セリフ、動作、情景を通じて示す。地の文で口調を説明しない。
- 情景や感情は、断片的な比喩の連打に割らず、流れる文でつなぐ。
- 本文に、作者の感想、工夫の解説、プロットどおりである旨を書かない。それらは本文の外に置く。

体裁の機械検査は `tools/novel_text_rewrite_lint.py`。三点リーダー、セリフ末の句点、段落の字下げは同ツールの規則と揃える。

## 2. 会話

- 会話文は、その人物の性格や背景に合わせた口調にする。
- ゲストで、ノリや口調が特徴的な人物を出してよい。
- 人名、口調、特徴は、識別できるよう互いにかぶせすぎない。
- 独立したセリフを、述語の無い名詞一つ・短句一つ（「鍵」「明日、駅で」）で止めない。同じ発話の中で二文にする（会話内部の「。」で切る）。口調の「短い」、見せ方軸の「短く言い切る」は、名詞一つ・短句一つで終えることではない。
- 述語のある一文のセリフ（「資料を準備しておいて」「しょっぱいな」）は対象外。二文に開かなくてよい。
- 二文目は、その場ですでに決まっている範囲（約束、期限、対象、理由）を言う。一文目の言い換えにしない。新しい出来事、新しい情報の授受、相手の新しい返事は足さない。
- 地の文で「短く言った」「次の文は続かない」「それだけ」と書かない。口調の短さはセリフ自体で見せる。
- 開かない例外: 相づちだけ（おう、うん、ああ）。名前呼び・職場の呼びだけ（悠翔、木村さん）。問い返し・叫び・とっさの命令（「本当に？」「伏せろ！」）。作品で一度だけと決めた決め台詞。設計が沈黙・一言と指定した発話。
- 画面・メール・チャットの文は鍵括弧にせず、地の文で誰の画面に何と出たかを書く。声に見せない。
- 清書での開き方は `rewrite.md`。新しい会話の往復を足すのは加筆。
- 会話が少ない場面でやり取りを所作・物・観察で運ぶ本文化は `episode/general/episode_sparse_dialogue.md`（既定では読まない。口調が短い・沈黙指定・会話を足さずに分量を足すとき）。

## 3. 描写

- 情景と人物は、章で新しく出るときに素性や容姿が追えるように書く。プロフィールの写しにはしない。
- 人物名を地の文で繰り返さない。同じ人物の2度目以降は、指す語を減らす。
- 感情と動作で、読者が人物に寄り添えるようにする。
- 服は、行動に必要な範囲で書く。前の章と同じ外見を書くときは言い回しを変える。
- 身長や体格の数値（cm など）を地の文で繰り返さない。数値は初回の紹介に留め、以降は相手との対比、目線の高さ、骨格、動作と家具の位置で示す。
- 家族を呼び合うときに「きみ」「君」は使わない。相手への呼称は、その関係に合ったものを選ぶ。
- 敵やゲストの名前は、命名資料とスキル `character-naming` を参考にする。種族や特徴は作品の設定に合わせる。

## 4. 章の進め方

- 指定された章や項の範囲まで進める。プロットにある出来事は落とさない。
- 前の章と同じ展開、同じ言い回しを避ける。地の文、感情、セリフ、視点の配分を変える。
- 同じことを言うときも、同じ言葉を繰り返さない。
- 選定したエピソード技法の葉がある場合は、その葉をプロットと本文の参考にする。
