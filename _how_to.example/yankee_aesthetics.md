# ヤンキー美学

> 原資料（来歴）: `C:/Users/Owner/Downloads/ヤンキーの美学/yankee-aesthetics.md`

## 発動条件

> 「ヤンキー美学」の適用を明示された場合、または不良文化の筋・意地・仲間・地元・過剰装飾が人物・集団の主要な軸となる場合に選ぶ（既定では読まない。「友情」「義理」「派手」だけでは選ばない）。

## まず考える5つの問い

1. 誰との約束・関係を引き受け、どの仲間・地元への義理として立つのか。
2. 誰を守り、誰を仲間と認めず、境界を越えると何が起きるか。
3. 仲間の評価と本人の禁止線が衝突するとき、何を失って何を選ぶか。
4. 服装・名前・持ち物の過剰さは、誰への帰属や覚悟を示すのか。
5. 建前と実際の行動がどこでずれ、語り手はそれをどう描くか。

恩の具体的な対象・授受・返報・返済をどう設計し記録するかは、[恩義設計論（ON）](episode/general/episode_obligation.md)に従い、作品内の台帳は人物関係記録に置く。本資料は、その恩義が仲間・地元・意地の内側でどう機能するかを扱う。

ここで扱うモデルは人物・集団・場面を設計するための創作レンズであり、ヤンキー文化の史実を網羅した説明や、すべての人物に当てはまる法則ではない。史実として作品に書く事項は別途確認する。

人物の倫理的な選択を詳しく設計するときは、必要に応じて創作技法 [ETHOS](ethos.md) も参照する。名前や刺繍文言など具体的な当て字を作るときは [漢字エンブレム命名](../.rulesync/skills/kanji-emblem-naming/SKILL.md) を使う。

## 3つの読み取り水準

原資料は、混同しやすい内容を三つの水準に分けている。

| 水準 | 創作で見るもの |
| --- | --- |
| L1: 作品内の理想像 | 作品が格好よいものとして描く規範や人物像 |
| L2: 実践 | 集団内の規律、排除、制裁など、理想像と一致しない行動 |
| L3: 外部からの解釈 | 後世の文化論や、作品・社会を読む視点 |

「弱い者いじめを嫌う」といった理想像を、その集団の実践全体や歴史的事実と同一視しない。物語がどの水準を描いているのか、また理想と行動がずれるのかを決める。

## 三層モデル

このモデルは様式だけで人物を決めず、装い・倫理・関係の働きを結びつけるための道具である。各層は固定のチェックリストではなく、作品に必要な要素を選んで使う。

### 表層: 様式

- **過剰**: 感情や覚悟を、装飾や行動で大きく見せる。
- **脱文脈化**: 異なる文化や時代の記号から、元の背景より「強そう」「目立つ」といった効果を取り出す。
- **自己改造**: 制服、乗り物、持ち物など、与えられたものを自分たちの様式へ作り替える。

脱文脈化と自己改造には両義性がある。新しい意味を与える創造であると同時に、元の意味や出所を消してしまうこともある。人物がそれを美点と見るか、問題と見るかは物語の視点に委ねる。

### 中層: 倫理

- **筋**: 引き受けた関係や約束から簡単には逃げない。
- **意地**: 損得だけでなく、自分が自分を許せるかを判断に含める。
- **仲間**: 選び取った関係に大きな責任を感じる。
- **反卑怯**: 弱者への攻撃、裏切り、言い訳などを嫌う理想を持つ。
- **態度と結果**: 勝敗とは別に、逃げなかった態度を評価する場合がある。

これらを全員に当てはめない。何を「筋」とするか、誰の弱さを守るか、誰の裏切りを許さないかを人物・集団ごとに決める。

### 深層: 社会機能

- **帰属宣言**: 装飾や名前が、個人の飾りだけでなく集団への所属を示す。
- **共同経験**: 血縁でなく、共有した出来事が仲間意識を作る。
- **地元**: 遠くへの上昇より、特定の場所や関係の内部に価値を置く人物もいる。
- **通過儀礼**: 不良的な様式を一時期の生き方として経て、別の生活へ移る人物もいる。

この経路は必然ではない。離脱、別の集団への参加、芸能・音楽活動など、別の進路もあり得る。作品で扱う地域・時代・人物に応じて決める。

## 中心の緊張と境界

原資料の中心命題は「世間から与えられた規範を拒む一方、自分が引き受けた筋には従う」という緊張にある。反抗が規範そのものへの反対ではなく、「誰が規範を決めるか」の争いになることがある。個人の意地と仲間内の同調は同時に存在し得る。

集団内外で保護と制裁の範囲が異なる場合、境界を具体化する。たとえば、集団外の無関係な弱者を守る理想と、集団内の「にわか」や裏切り者を排除する慣行は、同じ集団の中で並存し得る。この矛盾を美談に丸めず、誰がその規則を作り、誰が損失を受けるか描く。

原資料の七原則は設計候補である。

| ID | 原則 | 物語で問うこと |
| --- | --- | --- |
| Y1 | 筋 | 引き受けた関係から逃げないのは誰に対してか |
| Y2 | 意地 | 損得より守る自分なりの線は何か |
| Y3 | 仲間 | 選んだ関係に何を負うか |
| Y4 | 反卑怯 | 誰を守り、誰への制裁を正当化するか |
| Y5 | 過剰 | 何をほどほどにせず表現するか |
| Y6 | 自己改造 | 与えられたものを何に作り替え、何の意味を消すか |
| Y7 | 地元 | どの場所や関係の内側で完結しようとするか |

「負けても格好いい」は物語内の理想や評価の基準になり得る一方、集団内の権威や生活上の結果まで消すものではない。誰がどの基準で評価するかを分ける。

## 整ったモデルを崩す要素

筋や仲間意識だけでは、集団や人物を美化しすぎることがある。原資料が挙げる要素を、必要に応じて人物や環境へ加える。

- **見栄**: 覚悟と虚勢が混ざり、本人も区別できない。
- **性と承認**: 原資料では、集団内の承認や女性の位置づけが不均衡であり、美学を語る言葉も主に男性側から組み立てられている。この注意は原資料の記述範囲を示すもので、美学の普遍条件ではない。レディース、集団を離れた人物、他ジャンルに部分適用する人物へ男性中心の規範を固定条件として課さず、作品ごとの人物と視点を設計する。
- **金**: 乗り物や装いの費用、仕事、違法な収入など、様式を支える経済条件がある。
- **恐怖**: 喧嘩や制裁に恐怖が伴い、参加しない者・逃げる者・離脱する者がいる。
- **地域差**: 地域や時代で様式も規範も異なり、「ヤンキー」を一枚岩にしない。

これらも全作品への必須設定ではない。どの要素を採るかは作品の題材と視点に合わせる。

## 深掘り用の問い

必要な問いを選び、答えを `character.md`、`world.md`、`design_specification.md` など作品の適切な正本へ記録する。

1. 誰との約束や関係を引き受けた人物か。
2. 誰を仲間と認め、誰を保護や配慮の外に置くか。
3. 集団の規律を誰が決め、破ったとき誰がどんな損失を与えるか。
4. 服装・名前・持ち物の過剰さは、誰に何を見せるためのものか。
5. 理想として掲げる倫理と、実際の行動はどこでずれるか。
6. 人物がその規範を選ぶことで何を得て、何を失うか。
7. 物語の視点は集団の理想を肯定するか、距離を置くか、矛盾を見せるか。

ETHOS を併用する場合は、そちらの義務・禁止線・代償の問いで倫理的選択を具体化する。本資料の七原則で置き換えない。

## 史実として扱う場合

本資料の三層モデル・七原則・社会機能は創作のための整理であり、すべての地域や時代を代表する学術的結論ではない。実在の文化、集団、地域、歴史を説明する文章では、創作上のモデルを根拠として断定せず、必要な主張を信頼できる資料で個別に確認する。未確認の出典や学者への帰属を補わない。

## 研究上の未解決事項（参考）

以下は原資料が提示する仮説や研究課題の要約であり、確定した史実でも、創作時の必須調査でもない。

- **反抗の様式が保守的な対人倫理を運ぶ理由**: 原資料は、学校・校則・進学競争などの管理装置への反発と、義理・人情などの対人倫理を分ける仮説を提示する。一方で、それらの倫理が任侠映画や企業社会などからどう供給されたか、また装飾の過剰さがなぜ必要だったかは未解決としている。「前近代的」と断定する説明にも留保がある。
- **帰属単位の比較**: 武士道・任侠・体育会・ヤンキーで、誰や何に属するか、誓約がどのように結ばれるかを比較する課題。
- **装飾過剰の系譜**: 祭りの山車、仏壇、デコトラなどの庶民装飾との関係を調べる課題。類似だけで直接の影響関係を断定しない。
- **文化的な伝播経路**: 任侠映画、暴走族、少年漫画などを通じた義理・人情や表現様式の伝播を、資料に基づいて検証する課題。
