# 会話の少ない場面の本文化

一般エピソード技法のうち、登場人物の会話が少ない場面を、あらすじから本文へ起こすときの設計。索引は [episode_.md](episode_.md)。

会話が少ないことは欠点ではない。言葉以外の媒体でやり取りが成立すればよい。沈黙や余白はそれ自体が演出になる。描写を増やすことが目的ではない。

**既定では読まない。**

**発動条件**（次のいずれかのときだけ読む）:

- 口調が短い、沈黙指定、EXPRESSION が低い、会話の往復を設計していない場面を本文にするとき
- 作者が、会話を足さずに場面の下限へ届かせたい、または喋りが少なく広げるものがない、と言ったとき
- Gate B で真顔・短い言葉・沈黙を採り、会話劇ではないと分かっているとき

## 0. 住み分けと歯止め

| 葉・資料 | 役割 | この葉との違い |
|---|---|---|
| 本葉 | 会話が少ない場面の**演出の層**（ビート・媒体・密度）と、本文の運び方 | 沈黙を話題で埋めない。内心モノローグが快楽の作品用でもない |
| [話題生成・フード理論](episode_dialogue.md) | 沈黙を検知して話題を足し、会話を往復させる | **逆方向**。設計が会話を少なくしている場面では使わない |
| [地の文モノローグ](episode_monolog.md) | 内心の言語化が地の文の主体で、それが快楽である作品 | INTERIORITY が高い語り。本葉は独白で沈黙を埋めない |
| [子エピソードによる増量](episode_sub_episode.md) | 加筆工程で出来事を足して分量を増やす | 本葉は提示の順と媒体を先に組む。新しい CANON は加筆 |
| [文章の伸縮操作規定](../../length_ops.md) | 長さを変える操作の境界。場面の下限は `chars_floor` | 下限に届かないからといって同じ物を測り直さない |
| [novelcore.md](../../novelcore.md)「会話」 | 述語の無い一言のセリフは二文に開く | 台詞が少ないことと、名詞一つで止めることは別 |
| [見せ方軸](../../showing_axes.md) | INTERIORITY・EXPRESSION・LANGUAGE_SYSTEM | 本葉の内面・感覚は、作品の見せ方軸を越えない |

**内面描写は見せ方軸を越えない。** INTERIORITY が `--` / `-` の作品、特定人物の内心を書かない指定、口調の「短い」は、本葉より優先する。沈黙を独白の説明で埋めない。視点人物が相手の沈黙を「読む」（読み違えを含む）のは、その視点の範囲に限る。

**描写の厚さは、構造側の歯止めを先にする。** 「詳細に描く」は、ビートで密度を厚とした箇所にだけ使う。AI 生成では「描写を厚く」が水増しに直結しやすい。

**新しい YAML 方言を作らない。** 媒体と密度は、METRON を使う作品では既存の `beats.yaml`（`type` / `weight` / `dialogue_turns` / `sensory` / `interiority` / `chars_hint`）に載せる。第二のビート表を正本にしない。

**字数の言い方。** 報告では「床○○文字」とだけ書かず、場面の下限か Beat の下限か章の目標かを言う。章の目標と混ぜない。場面の下限は `chars_floor`、Beat の下限は `chars_hint`、章の目標は分量目安である。数値はこの葉に固定しない。作品の契約を正とする。

## 1. 3層モデル

あらすじには通常、物語の層しかない。会話が書きにくい原因の多くは、**演出の層が未設計**であること。

| 層 | 内容 | 執筆時の問い |
|---|---|---|
| 物語の層 | 出来事・因果関係 | 何が起きたか |
| 演出の層 | ビート・情報提示順・緩急 | 読者にどの順番で体験させるか |
| 文章の層 | 地の文・会話・描写・文体 | どういう言葉で表現するか |

構造・工程は演出の層、描写の手札は文章の層である。本文を書く前に演出の層を組む。

---

## 2. やり取りの媒体（7種）

やり取りは人物同士に限らない。人物と環境・情報・自分自身とのあいだにも応答関係を作る。

| 媒体 | 対象 | 例 |
|---|---|---|
| 会話 | 人物↔人物 | 質問、返答、反論、言いかけてやめる |
| 非言語 | 人物↔人物 | 視線、仕草、姿勢、距離、呼吸、表情 |
| 間接交流 | 人物↔人物（時間・空間を隔てて） | 手紙、メモ、回想、第三者の観察、共有された作業 |
| 行動 | 人物↔環境 | 扉を開ける、道を探す、道具を扱う |
| 観察 | 人物↔情報 | 異変に気づく、違和感を覚える |
| 思考 | 人物↔自分 | 判断、推測、葛藤、決意 |
| 反応 | 人物↔出来事 | 驚く、身構える、ためらう |

環境描写（光と影、音、匂い、天候、室内の細部）は独立した媒体ではない。上記を増幅する装置として扱う。場の空気に緊張や時間経過を代弁させる。

画面・メール・チャットは会話媒体に数えず、間接交流として地の文で書く。鍵括弧にしない（`novelcore.md`「会話」）。

## 3. 会話のない場面の基本構造

```text
目的         主人公は遺跡の奥へ進みたい
  ↓
観察・発見   床に不自然な傷がある
  ↓
推測・判断   罠の可能性を考える
  ↓
行動         石を投げて床を調べる
  ↓
結果         仕掛けが作動し、奥から音が響く
  ↓
（新しい状況 → 次の目的へ）
```

この循環を繰り返せば、会話がなくても出来事が連続する。探索、戦闘、調査、作業、移動、内省に応用できる。

余韻の場面は例外である。孤独や静けさを描くときは、刺激と反応を連続させず、変化を意図的に遅らせる。

### 世界からの応答

主人公が働きかけ、世界が予想どおり、または予想外の答えを返すこと自体が物語上の応答になる。

- 探索する → 予想外の物を発見する
- 推測する → 新しい証拠によって否定される
- 助けようとする → 相手が拒絶する
- 隠そうとする → 逆に疑われる
- 決断する → 想定外の代償が発生する

あらすじに無い重大な事件・設定・人物関係の変化を、循環を回すために独断で足さない。循環に載せる観察・判断・行動は、設計にある範囲か、加筆工程で承認された CANON に限る。既にある出来事の提示順と媒体を変えるのは起草の範囲である。

## 4. 工程：あらすじ → 本文

1. あらすじで、何が起き、どう終わるかを確認する。
2. 一つの場面の範囲を決める。
3. **ビートを組む**（最重要）。各ビートで、目的・刺激・反応・判断・行動・結果のどれか、何が変化するか、それを運ぶ**媒体**と**描写密度**（厚 / 標準 / 省略）を決める。
4. 文章の層の技法（§5）を、密度が厚のビートに集中して使う。
5. 推敲では説明を削り、緩急を整える。同じ物の再計測で字数を合わせない。

### METRON の `beats.yaml` への載せ方

媒体と密度は、既存フィールドに載せる。`medium:` や `density:` という第二のキーを正本にしない。

| 演出の割り当て | 既存フィールド |
|---|---|
| 媒体が会話 | `type: dialogue`、`budget.dialogue_turns` に幅を置く |
| 媒体が非言語・行動・観察・反応 | `type: action` など。`dialogue_turns` は 0 または狭い幅 |
| 媒体が思考 | `budget.interiority`。見せ方軸の INTERIORITY と、人物の内心禁止を越えない |
| 媒体が間接交流 | `type` は action か dialogue 以外でもよい。画面文は台詞にしない |
| 環境は増幅 | `budget.sensory`。独立ビートにしない |
| 密度が厚 | `weight: heavy`。`chars_hint` と sensory（必要なら interiority）を上げる |
| 密度が標準 | `weight: normal` |
| 密度が省略 | `chars_hint` を下げ、移動・反復作業を短くする |
| 台詞は山に置く | 転換点の Beat だけ `dialogue_turns` を残し、溜めの Beat は 0 にする |

`intent` は動作だけにする。設計書のただし書き（何ではないか）を写さない。

METRON を使わない作品では、章項または作業メモに「媒体・密度・何が変化するか」を一行ずつ書けば足りる。形は問わない。新しいファイル形式を増やさない。

## 5. 文章の層の技法

密度が厚のビートに集中して使う。標準・省略のビートへは広げない。

### 四つの手札

| 手法 | 内容 | 見せ方軸との関係 |
|---|---|---|
| 内面描写 | 思考、感覚、記憶の断片、感情の揺らぎ | INTERIORITY と内心禁止を越えない。感情語で説明しない |
| 身体言語 | 仕草、姿勢、視線、呼吸、距離、物を介した行動 | EXPRESSION が低いときは叫びや大泣きにしない |
| 環境と雰囲気 | 風景、天候、光と影、音、匂いを人物の状態と連動させる | 役割の無い情景の連打にしない |
| 間接的交流 | 手紙、メモ、回想、第三者の観察、共有された作業 | 画面文は地の文。鍵括弧にしない |

### 技法と向く場面

| 技法 | 主な役割 | 向いている場面 |
|---|---|---|
| 動作の分解 | 行動の手順を見せる | 作業、探索、戦闘 |
| 知覚描写 | 読者を場面に置く | 初訪問、異世界、廃墟 |
| 判断の連続 | 知的な面白さを作る | 推理、調査、交渉前 |
| 心理的抵抗 | 内面の対立を作る | 決断、告白前、後悔（内心を書いてよい視点だけ） |
| 情報の遅延 | 疑問と期待を作る | ミステリー、発見 |
| 非言語的応答 | 関係性を見せる | 恋愛、対立、再会 |
| 環境からの応答 | 行動に結果を返す | 冒険、サバイバル |
| 省略・時間経過 | 不要な部分を圧縮する | 移動、反復作業 |

## 6. 書くときの原則

- **発見の順番で提示する。** 情報を一度に説明しない。読者が視点人物と同じ順で体験できるようにする。
- **内面描写は判断・行動につなげる。** 感情を説明するだけだと停滞する。思考の結果として次の行動が生まれる形にする。内心を書かない指定の人物では、判断は所作と選択で見せる。
- **文章量は変化の大きさで決める。** 行動にかかった時間では決めない。
- **少ない台詞は山に置く。** 無言の応酬で溜め、転換点で発させる。述語の無い一言のセリフは二文に開く。述語のある一文、相づち・名前呼び・沈黙指定は開かない（`novelcore.md`「会話」）。
- **あらすじに無い会話を、文章量を増やす目的で足さない。** 新しい往復は加筆工程である。
- **視点の一貫性を保つ。** 相手の沈黙は視点人物が読むことで意味を持つ。読み違えも演出になる。
- **感情語（嬉しい、悲しいなど）を地の文で直接書かない。**
- **情景は、雰囲気・伏線・状況把握の役割を持つものを優先する。**
- **場面の下限に届かないからといって、同じ物・同じ縁・同じ距離を測り直して埋めない。** 観察→判断→行動の転換が足りないときは、起草の反復計測で埋めず、設計追加または加筆へ振る（`length_ops.md`）。

### 工程の境界

| 工程 | してよいこと | してはならないこと |
|---|---|---|
| 起草 | 設計にある出来事を、媒体と発見の順で書く。密度が厚のビートに手札を集中する | 会話の往復を足して下限を埋める。同一物の再計測。内心禁止の独白 |
| 清書 | 既にある観察・行動・判断の言い回しを寄せる。同じ物の再計測を削る（`rewrite.md` の重複の剪定） | 新しい転換・新しい台詞の往復を足す |
| 加筆 | 承認のあと、観察の結果・判断・行動などの CANON を足す | 清書のつもりで足す |

## 7. 手順（プロンプトのコピーは置かない）

あらすじから本文を起こすときは、次の順で行う。長いプロンプトを how_to に貼らない。

1. あらすじを場面に分ける。
2. 各場面のビートを先に決める。各ビートに、目的・刺激・反応・判断・行動・結果のどれか、媒体（§2）、描写密度（厚 / 標準 / 省略）を割り当て、METRON なら §4 の表で `beats.yaml` に載せる。
3. ビートに従って本文を書く。
4. あらすじに無い会話を、分量のため足さない。
5. 台詞は転換点に絞り、それ以外の応答は所作・物・沈黙で返す。
6. 観察・行動・認識・判断・反応を中心に展開する。
7. 行動には目的を持たせ、状況からの反応で次の行動へつなげる。
8. 心理は感情の説明だけにせず、判断や行動との関係が分かるようにする（書いてよい視点だけ）。
9. 内面・感覚は密度が厚のビートに集中する。見せ方軸を越えない。
10. 展開上重要でない移動や反復作業は省略する。
11. あらすじに無い重大な事件、設定、人物関係の変化を独断で足さない。

## 8. 例

### 例1: 説明型と体験型（廃屋の手紙）

あらすじ:

> 主人公は廃屋を訪れる。かつて友人が住んでいた家だ。部屋を調べているうちに古い手紙を発見し、友人が自分に隠していた事実を知る。

**A. 説明型**（あらすじの詳細化に留まる）

> 主人公は廃屋に入った。そこは以前、友人が住んでいた家だった。部屋の中は長い間放置されており、家具には埃が積もっていた。主人公は机の引き出しを調べ、古い手紙を発見した。その内容から、友人が自分に重大な秘密を隠していたことを知った。

**B. 体験型**（観察・行動・思考を発見の順に出す）

> 玄関の扉は、思いのほか簡単に開いた。蝶番が軋み、湿った空気が流れ出してくる。最後にここを訪れたのは、もう五年も前になる。廊下の奥に見える机は、記憶にある位置から動いていなかった。ただ、天板を覆う埃だけが、流れた年月を物語っている。引き出しに手をかける。鍵はかかっていない。中には古びた封筒が一通、残されていた。取り上げた瞬間、裏面に書かれた名前が目に入る。自分の名前だった。なぜ、ここに。封を切る指先が止まった。

出来事はほとんど増やしていない。提示の順番と媒体だけが違う。

### 例2: 物の受け渡しによる応酬

あらすじ:

> 父と息子が数年ぶりに食卓を囲み、わだかまりが少し解ける。

> 父は息子の皿に、黙って焼き魚の腹の身を移した。昔から、そこは父の取り分だったはずだ。息子は箸を止め、しばらくそれを見ていた。それから自分の皿の漬物を、父の方へ少し押しやった。父は何も言わずにそれを食べた。「……しょっぱいな」「昔からだよ」

物の受け渡しで往復させ、最後に台詞を置く。和解は誰も口にしていない。「しょっぱいな」「昔からだよ」は述語のある一文なので、二文に開く規則の対象ではない。短い台詞を転換点の一往復だけに絞っている。

### 反パターン

| やり方 | 起きること |
|---|---|
| 会話が少ないので話題を足す | `episode_dialogue.md` の沈黙リカバリーになり、設計の寡黙が壊れる |
| 場面の下限に届かないので同一の物・縁・距離を測り直す | 「一度」「残る」「置かない」の連打。情報量は増えない |
| 沈黙を内心の説明で埋める | INTERIORITY が低い作品、内心禁止の人物と衝突する |
| 画面の文を鍵括弧に入れる | 声に見え、誰がしゃべっているか分からなくなる |
| 描写を全体に厚くする | 水増し。転換点以外は圧縮する |

## 9. まとめ

```text
あらすじ → 場面 → ビート（媒体・密度を既存 beats に載せる） → 本文 → 推敲
```

- 構造で組む。表現の手札は密度が厚の箇所にだけ使う。
- 会話の少なさを補正すべき欠点として扱わない。演出上の特徴として使う。
- 下限の不足は再計測で埋めない。転換が足りなければ設計か加筆へ振る。
