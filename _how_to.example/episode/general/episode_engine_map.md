# 第I部 展開エンジン表（燃料10本・燃費層・修飾3軸）

前段の9分類を、**層ごとに分離**して再構成したもの。

- **燃料エンジン（10本）**：話を動かす。何かが変化する。
- **燃費層**：話を動かさないが、動かすためのコストを下げる。
- **修飾軸（3本）**：どのエンジンにも掛かる。単独では何も動かない。

分離の基準は一つ。

> **それ単独で「次が読みたい」または「いま読んでいて面白い」を生むか。**

生むなら燃料。コストを下げているだけなら燃費。他の何かに掛かるだけなら修飾。

## 0. 二本の背骨

エンジンを並べる前に、分類の軸を二本立てる。

### 背骨A：情報の配分

「誰が何を知っているか」の配置が、そのまま快の種類を決める。

| 配置 | 生じる快 |
|---|---|
| 作者 > 読者 > キャラ | サスペンス・露見の緊張 |
| 作者 > 読者 = キャラ | 謎・反転 |
| 読者 = キャラ（ルール公開） | 攻略・フェアプレイ |
| 読者 > 主人公（自分の感情について） | もどかしさ・発見 |
| 読者が事前に持つジャンル知識 | 省略・裏切り |
| 誰も知らない領域へ | 探索・驚異 |

昭和型と現代型の差もこの軸で言える。昭和型は**後から情報を追加して配分を書き換える**。現代型は**配分を最初に固定し、開示順だけを操作する**。技術の優劣ではなく、後出しか先置きかの違い。

### 背骨B：牽引か滞在か

- **牽引**＝先を読ませる（次が読みたい）
- **滞在**＝いまの場面を面白くする（読んでいて楽しい）

> **最低条件：牽引エンジン1本以上 ＋ 滞在エンジン1本以上。**

「ヒット作ほど複数エンジンを持つ」の正体はこれで、**数ではなく種類**の問題。牽引だけだと読者が疲れ、滞在だけだと読み止められる。

## 第1層 燃料エンジン（10本）

### E1. 欲望・欠乏

**牽引** ／ 何が変化するか：**主人公と目標の距離**

主人公が何かを欲しており、障害がある。最も基礎的で、最も見落とされる。

- 読者の問い：**「手に入るのか？」**
- 情報配分：非依存（どの配分でも動く）
- 備考：他の9本が全部止まっても、これだけは動く。逆に「主人公が何も欲しがっていない」状態はどのエンジンでも救えない。

### E2. 格上げ・再定義

**牽引** ／ 何が変化するか：**既存要素の意味と重要度**

既に出ているもの（人物・技・傷・地名）の意味を、後から大きくする。旧①。**運用カードは [第II部 §3 E2](#e2-格上げ再定義運用カード)。定石と許容は [第III部](#第iii部-昭和漫画的勢い展開の技法e2深掘り)。**

- 読者の問い：**「次は何が飛び出す？」**
- 情報配分：作者 > 読者・キャラ（後から追加）
- 消耗：**速い**。3回で「作者が言えば何でもあり」に到達し、以後どんな危機も緊張を生まなくなる。在庫として回数管理する。

### E3. 謎と反転

**牽引** ／ 何が変化するか：**既出の出来事の解釈**

先に情報を置き、後から意味を開示する。旧②。E2と表裏で、**後出しか先置きか**だけが違う。

- 読者の問い：**「あれはどういう意味だったのか？」**
- 情報配分：作者 > 読者 = キャラ
- 備考：先置きの仕込みが必要な分、初速は遅く、寿命は長い。

### E4. ルール攻略

**牽引（短距離）＋滞在** ／ 何が変化するか：**ルールの理解度**

世界に明示的な制約があり、その穴を突いて勝つ。旧③。

- 読者の問い：**「その条件でどう勝つ？」**
- 情報配分：読者 = キャラ（公開が前提）
- 消耗：ルールを後から足すと即座に死ぬ。**ルールの追加ではなく組み合わせ**で延命する。

### E5. 隠蔽と露見

**牽引** ／ 何が変化するか：**誰が何を知っているか**

正体隠し、身分偽装、実力の秘匿。読者は知っていてキャラは知らない、という非対称そのものが燃料。

- 読者の問い：**「いつバレる？ バレたらどうなる？」**
- 情報配分：作者 > 読者 > キャラ
- 備考：バレる瞬間は報酬だが、**バレるまでの区間が本体**。悪役令嬢もの・追放ものが長編を保たせている主力はほぼこれ。

### E6. 関係変化

**滞在** ／ 何が変化するか：**人物間の距離**

知り合う → 近づく → 誤解 → 離れる → 本心を知る。旧④。

- 読者の問い：**「この二人はどうなる？」**（弱い牽引）
- 情報配分：非依存
- 備考：単独では牽引力がほぼゼロ。日常系・関係中心作品が必ず小さな謎か隠し事か締切を併設しているのはこのため。

### E7. 感情発見

**滞在** ／ 何が変化するか：**主人公の自己理解**

「俺は強くなりたかったんじゃなく、認められたかったんだ」。旧⑤。

- 読者の問い：**「この人は本当は何を求めている？」**
- 情報配分：読者 > 主人公
- 備考：E1の変種で、**欲望が本人に見えていない**状態を扱う。クライマックスが勝利ではなく理解になる。

### E8. 職能・手続きの開示

**滞在** ／ 何が変化するか：**読者の知識**

料理、医療、捜査、鍛冶、内政。専門的手順が正確に開示されること自体が報酬。

- 読者の問い：**「どうやるのか？」**
- 情報配分：作者 > 読者（実在知識の移転）
- 備考：異世界クラフト・現代知識無双が機能している中核。ジャンル記号（旧⑥）に吸収されて見えにくいが、独立した燃料。

### E9. 探索・驚異

**滞在** ／ 何が変化するか：**世界の見えている範囲**

謎ではなく風景。見たことのないものを見る快。

- 読者の問い：**問いが立たないのが正常**（答えを要求しない）
- 情報配分：誰も知らない領域へ
- 備考：E3謎と混同されやすいが逆。謎は「答えが来る」快、探索は**「答えが要らない」快**。回収義務がないぶん低コストで、乱発しても壊れない。

### E10. 蓄積・運営

**滞在＋緩い牽引** ／ 何が変化するか：**数値・規模・進捗**

拠点が育つ、仲間が増える、地図が埋まる、ステータスが伸びる。

- 読者の問い：**「次は何が増える？」**
- 情報配分：非依存
- 備考：事件が一つも起きなくても進捗が報酬になる、唯一の滞在エンジン。Web小説の主力。ただし**増加が止まった瞬間に何も残らない**ので、上限設計が要る。

## 第2層 燃費 — 説明コストの削減

**旧⑥「既知フォーマット高速展開型」はここ。エンジンではない。**

既知フォーマットは話を前へ進めない。**進むための説明コストを削っている**だけで、削って浮いた紙幅で結局E1〜E10のどれかを回している。「婚約破棄された悪役令嬢です」で20個の設定を共有した後、何で読ませるかは別途必要になる。

同じ列に並べると「⑥で書く」という存在しない選択肢が見えてしまうため、層を分ける。

### 燃費を上げる手段

- **ジャンル共有語彙**：転生／悪役令嬢／追放／婚約破棄／ダンジョン／回帰
- **テンプレ配役**：説明なしで役割が伝わる配置（婚約者、腹黒宰相、幼馴染）
- **タイトルとあらすじでの前提開示**：本編開始時点で読者が既に知っている状態を作る
- **一人称の速度**：説明を地の文でなく主観の断定で済ませる

### 燃費層の運用則

1. **燃費は差分の予算**。共有語彙で浮いた紙幅を、どのエンジンに投下するかを先に決める。
2. **「普通の◯◯ものだと思ったら△△だった」の△△が燃料**。◯◯は燃費。ここを取り違えると、テンプレをなぞっただけの作品になる。
3. **燃費が良すぎると差分が薄く見える**。共有語彙が強いジャンルほど、投下先エンジンの出力を上げる必要がある。

## 第3層 修飾軸（3本）

単独では何も動かさないが、全エンジンに掛かる。

### M1. 期待応答軸 — 応える ↔ 外す

**旧⑦（期待充足・ご褒美）と旧⑧（期待ずらし）は、同一軸の正負。**

読者の予測に対して、そのとおり与えるか、外すか。

```
外す ←──────────────┼──────────────→ 応える
 反転・裏切り      予測可能         ざまぁ・無双・溺愛
```

- **応える側**：意外性ではなく**タイミングが技術**。「そろそろ報われてほしい」と思った直後に報われる。
- **外す側**：読者のジャンル知識そのものを伏線として使う。追放ものと思わせて追放側が悪人ではない、など。
- **注意**：ずらしは燃費を消費する。共有語彙を裏切ると、以後その語彙で省略できなくなる。

#### 旧⑦の分解

「ざまぁ」「正体バレ」は快感としては強いが、エンジンではなく**組み合わせの結果**である。

> ざまぁ ＝ E1（欠乏＝正当な評価が無い状態）＋ E5（露見）＋ M1応える側の**タイミング**

だからエンジン表からは消えるが、快感が消えるわけではない。**どう作るかが明示される**だけ。

### M2. 粒度軸 — 供給周期

**旧⑨「小さな謎連鎖型」はここ。**

疑問と答えを、どれくらいの間隔で更新するか。

```
話単位 ←────────────────→ 巻単位・シリーズ単位
 スマホ縦読み向き            単行本・長期連載向き
```

謎連鎖（誰？→兄→なぜ敵側に？→守るため→何から？）は、**E3をM2の最小粒度で回した形**。同じことは他のエンジンでもできる。関係変化を話単位で回すことも、ルール攻略を巻単位で回すこともできる。

原則：**常に一つ「先を読みたい理由」を未解決で残す**。粒度が細かいほど離脱率は下がるが、大きい快は作りにくい。

### M3. 圧力軸 — 時間圧

締切、余命、封印の残り、ループの残り回数、次の襲撃まで◯日。

新情報をまったく出さずに緊張だけを維持できるため、**中盤の失速に対して最も即効性がある**。ただし単独では動かない。E1の目標やE5の秘密など、**脅かす対象があって初めて機能する**ので、エンジンではなく修飾。

```
圧力なし（滞在向き） ←────→ 圧力あり（牽引が強制的に発生）
```

# 第II部 運用カード

分類表ではなく、**執筆中に診断・投入するための道具**として使う。カードは7項目に **0. 燃料** を足した8項目。

- **設計・ジャンル診断・旧分類の読み替え** → 第I部
- **執筆中の投入判断・中盤の失速診断** → 第II部（まず §1 早見表、迷ったら §4）
- **E2を実際に撃つときの定石と許容** → 第III部

### 二層構造

| 層 | 用途 | 参照時間 |
|---|---|---|
| **§1 早見表** | 「いま何を入れるか」を数十秒で判断 | 数十秒 |
| **§3 カード10枚** | 投入を決めた後の詳細な運転マニュアル | 数分 |

§0（共通概念）と §2（遷移マップ）は、両者をつなぐ読み方の規則。

---

## 0. 共通概念

10枚を横比較できるようにするための、共通の物差し。

### 0-1. カードの8項目

| 項目 | 役割 |
|---|---|
| **0. 燃料** | 何があればこのエンジンを起動できるか |
| **1. 主変化** | 何が変わることで「進んだ」と感じるか |
| **2. 読者の問い** | 読者の頭に何を保持させるか |
| **3. 供給周期** | 何話・何章ごとに報酬を出すか |
| **4. 寿命・故障条件** | 何回使えるか／何をすると壊れるか |
| **5. 失速サイン** | 作中で何が起きたら停止と判定するか |
| **6. 相性** | 並列運転すると何が強く／弱くなるか |
| **7. 乗り換え** | 出力を何の燃料へ変換できるか |

**項目0が起動チェックを兼ねる。** 燃料が用意できないエンジンは、どれだけ入れたくても回らない。「E3を入れよう」と思った時点で先置きの違和感が一つもないなら、E3は起動できない。

### 0-2. 寿命は「量」ではなく「型」

各カードの寿命を「長い／短い」だけで書くと横比較できないので、**摩耗のしかた**で三類型に分ける。長短より、こちらのほうが運用上効く。

| 型 | 性質 | 対処 | 該当 |
|---|---|---|---|
| **摩耗型** | 使うほど効きが落ちる。回数で死ぬ | 回数を在庫管理する | E2、E7 |
| **在庫型** | 素材が尽きるまで持つ | 素材を補充し続ける | E3、E4、E8、E9、E10 |
| **恒常型** | 条件が維持される限り減らない | 条件の維持を監視する | E1、E5、E6 |

摩耗型は「何回使ったか」を数える。在庫型は「あと何枚残っているか」を数える。恒常型は回数を数えても意味がなく、**前提条件が壊れていないか**だけを見る。

### 0-3. 失速判定は「削除テスト」に統一できる

10枚を並べると、各エンジンの最重要サインがすべて同じ形に還元される。

> **そのエンジンの出力を作中から削除して、話が同じなら、そのエンジンは回っていない。**

| エンジン | 削除するもの | 回っていない状態 |
|---|---|---|
| E1 | 主人公の目標への行動 | 向かわなくても話が成立する |
| E2 | 今回の格上げ | 人物の選択が変わらない |
| E3 | 今回の回収 | 判明しても「だから何？」 |
| E4 | ルールそのもの | 同じ展開が成立する |
| E5 | 秘密 | 明かしても物語がほぼ同じ |
| E6 | その会話場面 | 前後で二人の距離が同じ |
| E7 | 今回の自己理解 | 理解しても選択が変わらない |
| E8 | 解説部分 | ドラマが変わらない |
| E9 | その場所の固有性 | 場所を入れ替えても同じ話 |
| E10 | 増加分 | 選択肢が増えていない |

覚えるのは表ではなく、**削除テスト一つ**でいい。表は適用例。

### 0-4. 乗り換えの原則

乗り換えはおすすめ一覧ではない。

> **前エンジンの出力を、次エンジンの燃料へ変換する。**

「正体がバレました。次は関係変化です」は乗り換えではなく中断。正しくは「E5で蓄積した秘密を決済し、その結果生じた感情差をE6の燃料にする」。

したがって全カードの項目7には、乗り換え先だけでなく**引き継ぐもの**を必ず明記する。引き継ぐものが書けない乗り換えは、実際には乗り換えではない。

### 0-5. 最低条件（再掲）

> **牽引エンジン1本以上 ＋ 滞在エンジン1本以上。**

牽引だけだと読者が疲れ、滞在だけだと読み止められる。複数エンジンは数ではなく**種類**の問題。

## 2. 遷移マップ

10枚の乗り換え先を集計すると、構造的な偏りが出る。これ自体が診断材料になる。

### 2-1. 流入数（何本のエンジンから乗り換えて来られるか）

| 流入数 | エンジン |
|---|---|
| 8 | **E1 欲望・欠乏**、**E6 関係変化** |
| 5 | E5 隠蔽と露見 |
| 4 | E3 謎と反転 |
| 3 | E10 蓄積・運営 |
| 2 | E4、E7、E8、E9 |
| **0** | **E2 格上げ・再定義** |

### 2-2. 二つのハブ

E1（流入8・牽引）とE6（流入8・滞在）が突出している。ほぼすべてのエンジンが、最終的にこの二本のどちらかへ出力を渡せる。

> **失速したら、まずE1かE6へ落とす。**
>
> - 前へ進める力が足りない → **E1**（出力を新しい目標へ変換）
> - 場面が退屈 → **E6**（出力を人物間の距離の変化へ変換）

これは他の乗り換えを検討する前の既定手として使える。ハブが二本あるのは、牽引と滞在それぞれに受け皿があるということで、最低条件（§0-5）と対応している。

### 2-3. E2だけが流入ゼロ

**他のどのエンジンからもE2へは乗り換えられない。** これは表の不備ではなく、E2の性質による。

E2の燃料（意味を使い切っていない既出要素）は、他エンジンの出力ではなく、**物語が進むだけで自動的に溜まる**。したがってE2は常に起動可能だが、決して「前の展開の結果として到達する」ことがない。

運用上の帰結：

- E2は**いつでも使えるが、使う必然性が物語側から供給されない**。だから作者の判断だけで投入され、結果として乱発されやすい。摩耗型・短命であることと合わせると、最も管理が必要なエンジン。
- E2を入れるときは、**同時に出口（E1／E5／E6）を決めてから入れる**。単発で撃つと出力が行き場を失う。

### 2-4. 世界系クラスタの閉塞

E8・E9・E10は互いに強く結ばれ、ほぼ閉じた循環を作る。

```
E9 ⇄ E10        E8 → E9, E10        E9 → E8
```

この三本だけで長期運転できてしまう（探索して持ち帰り、技術で加工し、また探索する）。内政もの・探索もので**進捗はあるのに物語が動いていない感じ**が出るのは、たいていこの閉塞が原因。

対処は、クラスタ外への唯一の出口を意識的に通すこと。

- E10 → **E5**（大きくなったので外部に発見される）
- E10 → **E6**（人が増えたので古参と新参が対立する）
- E9 → **E1**（新天地に欲しいものを発見する）
- E8 → **E6**（師弟・技術継承）

人物系クラスタ（E5・E6・E7）は逆に、E1経由でしか世界系へ出られない。関係中心の作品が中盤で停滞するとき、E1が痩せていることが多い。

### E1. 欲望・欠乏（運用カード）

**牽引｜情報配分：非依存｜主変化：主人公と目標の距離｜寿命：恒常・長**

#### 0. 燃料
**主人公が欲しているものと、それがまだ得られていない状態。**

手に入れたいもの／守りたいもの／取り戻したいもの／到達したい場所／解決したい問題／なりたい状態／避けたい未来。

重要なのは「目的がある」ことではなく、**現在と望む状態の間に距離があること**。その距離が燃料。

#### 1. 主変化
**主人公と目標の距離。** 近づくことだけでなく、遠ざかる／目標そのものが変わる／より大きな欠乏が見つかる／代償が判明する、も前進。読者に**進捗が見えること**が条件。

#### 2. 読者の問い
> **「手に入るのか？」**

具体化すると「間に合うのか」「勝てるのか」「取り戻せるのか」。

#### 3. 供給周期
**長周期。ただし途中成果が必須。** 話単位＝小目標／章単位＝中間目標／巻単位＝到達点／シリーズ＝最終目標、の階層化。最終目標しかないと距離が測れなくなる。

#### 4. 寿命・故障条件
**恒常型・長命。** 目的と障害が存続する限り最も安定して回る。

故障条件：主人公自身が達成を望まなくなる／達成してもしなくても結果が同じ／障害がなくなる／ゴールが曖昧で進捗を測れない／**目的が作者から与えられただけで、主人公自身に理由がない**。

#### 5. 失速サイン
主人公が自分から行動しない／次に何をすべきか本人にも読者にも分からない／事件が起きるまで待っている／失敗しても特に困らない／達成しても人生が変わらない。

> **削除テスト：主人公が目標へ向かわなくても話が成立する。**

#### 6. 相性
◎E3（「知りたい」が目的になる）／◎E4（障害を攻略問題へ変換）／◎E5（守りながら達成する）／◎E10（何のために増やすのかを与える）／○E6（関係そのものの目的化）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E3** | 「なぜこの障害が存在する？」を発生させる | 目標達成を妨げていた異常 |
| **E4** | 大目的を条件付き問題へ落とす | 障害 |
| **E6** | 道中で得た仲間・敵との関係へ | 共同行動で生まれた関係 |
| **E10** | 「達成に何を積み上げる必要があるか」へ | 必要条件 |

#### 運用要約
最も基礎的な牽引エンジン。**主人公は何を欲し、現在どれだけ遠いか。** これが見えないと、他が動いていても物語全体の方向感覚が失われる。

### E2. 格上げ・再定義（運用カード）

**牽引｜情報配分：作者＞読者・キャラ｜主変化：既存要素の重要度｜寿命：摩耗・短**

#### 0. 燃料
**すでに登場しているが、意味を使い切っていない要素。** 人物・技・傷・家系・地名・道具・過去の事件・所属組織。

使いやすいのは、詳細が未説明／妙に印象に残っている／主人公との個人的接点がある／大きな意味を持たせても矛盾しにくい要素。

**新規要素の投入より、既出要素の格上げのほうが効果が高い。**

#### 1. 主変化
**既存要素の重要度。** 普通の傷 → 敵につけられた傷 → 王家の証 → 世界を封印している印。出来事を増やすのではなく、既知のものの意味を拡大して前進させる。

#### 2. 読者の問い
> **「次は何が飛び出す？」／「まだ何か隠されているのでは？」**

問いの対象は真相そのものより、**次の格上げの大きさ**。

#### 3. 供給周期
**中〜長周期。** 小＝章単位の軽い再定義／中＝数章〜1巻の大きな格上げ／大＝シリーズ単位の世界観再定義。短周期の連発は消耗が極端に速い。**小さな格上げ → 間を置く → 大きな格上げ**と強弱をつける。

#### 4. 寿命・故障条件
**摩耗型・短命。** 全エンジン中で最も摩耗が速い。強い再定義を繰り返すほど「どうせ後から何でも足せる」と構造を見抜かれる。

故障条件：危機のたびに新設定が生える／敗北寸前に真の能力が判明する／過去の説明が何度も上書きされる／**前回より大きくし続けなければならなくなる**。

流入ゼロ（§2-3）なので、投入の必然性が物語側から供給されない。**回数を先に決めて在庫管理する**のが唯一の対処。

#### 5. 失速サイン
新しい正体が判明しても驚きより「またか」／窮地でも「どうせ新設定で助かる」と予測できる／世界設定だけ大きくなり目的は変わらない。

> **削除テスト：格上げしても人物の選択が変わらない。**（＝危機が緊張を生まなくなる）

#### 6. 相性
◎E1（格上げで目標そのものを更新）／◎E6（血統・過去の格上げを人間関係へ着地）／○E5（格上げした事実を「誰が知るか」へ変換）

**△E3** — 混ぜすぎ注意。E3は「先に置いた意味を開示する」、E2は「後から意味を大きくする」。境界が曖昧になると、伏線回収のつもりが後付けに見える。

**△E4・△E10** — 攻略不能になった瞬間の格上げはE4の公平感を壊す。積み上げを「実は伝説級でした」で飛び越すとE10の蓄積価値が下がる。

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E1** | 格上げした事実から新しい目的を発生させる | 格上げされた事実 |
| **E5** | 「その事実を誰が知らないか」へ焦点を移す | 新しく確定した秘密 |
| **E6** | 設定の衝撃を人間関係の変化へ決済する | 再定義で変わった人物の意味 |

#### 運用要約
爆発力が高く燃費が悪い。**格上げを連発せず、一度大きく撃ったら結果を別エンジンへ渡す。** 投入前に出口を決めておく。定石カタログと許容四条件は [第III部](#第iii部-昭和漫画的勢い展開の技法e2深掘り)。

### E3. 謎と反転（運用カード）

**牽引｜情報配分：作者＞読者＝キャラ｜主変化：既出情報の解釈｜寿命：在庫・中〜長**

#### 0. 燃料
**先に提示されている違和感・欠落・未説明情報。** 不自然な発言／理由の分からない行動／欠けた記録／名前を伏せられた人物／説明されない傷／辻褄の合わない証言。

重要なのは答えではなく、**答えを要求する形が先に置かれていること**。

#### 1. 主変化
**既出情報の解釈。** 出来事自体は変わらない。「裏切った」が「守るためだった」に変われば、過去全体の意味が変わる。**再読可能性**が報酬。

#### 2. 読者の問い
> **「あれはどういう意味だった？」**

連鎖させるなら「なぜ？」「誰が？」「何のために？」を一つずつ残す。

#### 3. 供給周期
**短〜長すべて対応可。** 短＝誰だ→正体判明→なぜここに／中＝一章で事件の意味／長＝シリーズの根本。M2粒度軸との相性が最良で、**大小の謎を階層化する**と長期運転できる。

#### 4. 寿命・故障条件
**在庫型・中〜長命。** 寿命は先置きした違和感の在庫量で決まる。仕込みが必要なぶん初速は遅く、寿命は長い。

故障条件：答えを後から変更する／読者に判断材料を一切与えない／回収しても状況が変わらない／**謎を解くために新しい謎だけを増やす**／伏線探し自体が目的化する。

#### 5. 失速サイン
読者が答えを知りたがらない／登場人物自身が謎を放置している／新しい謎を足さないと維持できない／「謎だから秘密」なだけの情報が増える／回収より先延ばしの回数が多い。

> **削除テスト：答えが判明しても「だから何？」になる。**

#### 6. 相性
◎E1（「知りたい」が目的になる）／◎E5（E3＝何が真実か、E5＝誰がそれを知るか、と分業）／◎E6（真相で関係が変わると回収が感情的報酬になる）／○E4（ルールの成立理由を謎にできる）／△E2（先置きと後出しの境界管理）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E5** | 「知った人物」と「まだ知らない人物」を分離する | 解明された情報 |
| **E1** | 真相を新しい目標へ変える | 真相によって生まれた目的 |
| **E6** | 「知ってしまった後、二人はどうなる？」へ | 人物について判明した意味 |

#### 運用要約
**謎を増やすより、答えによって次のエンジンを起動する。** 良い回収は終わりではなく、次の問題の原因になる。

### E4. ルール攻略（運用カード）

**牽引（短距離）＋滞在｜情報配分：読者＝キャラ｜主変化：ルール理解度｜寿命：在庫・中〜長**

#### 0. 燃料
**公開された制約と、それによって発生する問題。** 能力条件／勝敗条件／禁止事項／時間制限／資源制限／行動回数／空間的制約／社会的ルール／手順。

重要なのは、**問題の発生前または解決前に、ルールが読者へ共有されていること**。

#### 1. 主変化
**読者とキャラのルール理解度。** 「この条件では無理だ」から、条件の組み合わせ／解釈の変更／相手の使い方の逆利用によって可能性が広がる。

#### 2. 読者の問い
> **「その条件でどう勝つ？」／「どこに穴がある？」**

#### 3. 供給周期
**短〜中周期。** 一戦・一事件・一課題ごとに一つの攻略問題。長編では**基礎ルールを固定し、状況と組み合わせだけを変える**。

#### 4. 寿命・故障条件
**在庫型・中〜長命。** 寿命はルール数ではなく**組み合わせの数**で決まる。

故障条件：解決直前に新ルールを足す／主人公だけ例外になる／以前のルールが都合よく無視される／毎回さらに複雑な条件を追加する。**「そんなルール聞いていない」と思われた瞬間にフェアプレイ性が崩れる。**

#### 5. 失速サイン
主人公がルールを考えず力押しする／勝敗が新能力の有無で決まる／読者に予想材料がない／条件が複雑すぎて記憶する必要がなくなる／制約が実質的に主人公を困らせていない。

> **削除テスト：ルールを削除しても同じ展開が成立する。**

#### 6. 相性
◎E1（攻略する理由）／◎E8（専門知識をルールとして利用）／◎E3（「このルールはなぜ存在する？」へ移行）／○E5（情報を隠したままルール内行動を要求）／**△E2**（攻略不能時の格上げは公平感を破壊）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E3** | 「このルールは誰が何のために作った？」へ | 理解されたルール |
| **E8** | 焦点を勝敗からより高度な手順そのものへ | 身についた技術体系 |
| **E1** | 一つの攻略を終えて大目的へ戻る | 獲得した突破手段 |
| **E6** | 共闘・対戦で相手への評価を変える | 攻略中に見えた人物の能力・価値観 |

#### 運用要約
**ルールを増やすのではなく、既存ルールの組み合わせを増やす。** 読者に考える余地があるほど強い。

### E5. 隠蔽と露見（運用カード）

**牽引｜情報配分：作者＞読者＞キャラ｜主変化：情報の所有者｜寿命：恒常・長**

#### 0. 燃料
**秘密＋それを知らない人物＋知られた場合に起こる変化。** 三点そろって初めて動く。秘密だけでは燃料にならない。

正体／身分／能力／過去／犯罪／好意／裏切り／偽名／本当の目的／隠された関係。

#### 1. 主変化
**情報の所有者。** Aだけが知っている → Bが疑う → Cが知る → Dだけ知らない → 全員に露見、と配置が変化する。

#### 2. 読者の問い
> **「いつバレる？」** そして **「バレたら何が壊れる？」**

#### 3. 供給周期
**中〜長周期。** 完全露見まで長く引っ張れる。ただし途中で、疑われる／一部だけ露見／誤認される／一人だけ知る／証拠が近づく、を短周期で供給する。

#### 4. 寿命・故障条件
**恒常型・長命。** 秘密を維持する理由が自然なら非常に長く回る。回数ではなく**維持理由の自然さ**を監視する。

故障条件：バレても何も困らない／周囲が不自然なほど気付かない／**秘密を守るためだけに登場人物の知能が下がる**／露見しかけても毎回偶然で回避する。とくに**露見時の変化が想像できない秘密**は牽引力を失う。

#### 5. 失速サイン
「なぜまだバレない？」が先に立つ／秘密を知らない人物が話の中心から消える／バレる可能性のある場面を作者が避け始める／読者が露見を待たなくなる。

> **削除テスト：秘密を明かしても物語がほぼ同じ状態。**

#### 6. 相性
◎E6（信頼が深いほど破壊力が上がる）／◎E3（読者が知らない部分をE3、読者だけ知る部分をE5と分業）／◎E1（守りながら達成する構造）／◎E7（本人すら自覚していない感情と組み合わせる）／○E10（成長するほど維持しにくくなる）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E6** | 露見させ「知った後、関係はどうなる？」へ | 秘密によって蓄積した信頼・不信 |
| **E1** | 露見によって新しい目的を発生させる | 露見で変わった状況 |
| **E3** | 秘密は明かすが「なぜ隠していた？」を残す | 公開された事実 |
| **E7** | なぜ隠していたのかを本人に理解させる | 隠蔽行動 |

#### 運用要約
**秘密そのものより、秘密によって壊れうるものが本当の燃料。** 露見は終点ではなく、次エンジンへの決済イベント。

---

### E6. 関係変化（運用カード）

**滞在｜情報配分：非依存｜主変化：人物間の距離｜寿命：恒常・長**

#### 0. 燃料
**距離を変えられる二者以上と、距離を変える出来事。** 共同行動／衝突／秘密の共有／意外な一面／誤解／助ける・助けられる／価値観の不一致／別離／再会／第三者の介入。

単なる会話ではなく、**場面の前後で関係の状態が変わること**が条件。

#### 1. 主変化
**心理的・社会的距離。** 他人→知人→仲間→信頼→依存→対立→決裂→再理解。仲良くなることだけでなく、**離れることも明確な前進**。

#### 2. 読者の問い
> **「この二人はどうなる？」**

ただし牽引力は弱い。E6の本体は**現在の場面そのものを楽しくすること**にある。

#### 3. 供給周期
**短周期向き。** 数場面〜1話で小さな距離変化を作る。ただし告白・決裂・裏切り・和解・別離は章・巻単位で蓄積してから出す。**小さな変化を頻繁に、大きな変化を長周期で。**

#### 4. 寿命・故障条件
**恒常型・長命。** 人物の組み合わせが残る限り運転できる。

故障条件：**関係が固定されること。** 毎回同じ掛け合い／喧嘩しても必ず元通り／好意が永遠に進展しない／誤解を解かないためだけに人物が不自然になる。この状態は「関係」ではなく「キャラクター芸」で、それ自体は悪くないがE6としては停止。

#### 5. 失速サイン
同じ喧嘩を繰り返す／読者だけが分かっている感情を本人が延々と認識しない／関係維持のために事件がリセットされる／新キャラを入れないと変化を作れない／「この二人だから起きる場面」が減る。

> **削除テスト：その場面を削除しても二人の関係が同じ。**

#### 6. 相性
◎E5（「好きだが正体を言えない」は非常に強い）／◎E7（関係変化が自己理解の鏡になる）／◎E1（同じ目標を追う／異なる目標で衝突する）／○E3（相手の過去を知って距離が変わる）／△E10（運営メンバーが増えすぎると個別関係が薄くなる）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E5** | 安定したところで「言えていない事実」を前景化 | 築かれた信頼関係（深いほど露見の衝撃が大きい） |
| **E7** | 「自分はこの人をどう思っているのか」を本人に理解させる | 蓄積した感情 |
| **E1** | 関係そのものを目標化する（取り戻したい／共通目標） | 相手に対する価値 |

#### 運用要約
**会話量ではなく距離の変化量。** 「仲のいい二人を描く」のではなく、**この場面を経て昨日とは違う二人にする**ことが燃焼。

---

### E7. 感情発見（運用カード）

**滞在｜情報配分：読者＞主人公｜主変化：主人公の自己理解｜寿命：摩耗・中**

#### 0. 燃料
**本人がまだ正しく名前を付けられていない感情。** 好意を敵意だと思っている／寂しさを怒りとして表現する／承認欲求を勝利欲だと思う／恐怖を慎重さだと思う／羨望を嫌悪と解釈する／喪失感を使命感へ変換している。

読者にはある程度見えるが、本人には見えていない状態が強い。

#### 1. 主変化
**主人公の自己理解。** 外部状況が一切変わらなくても、認識変化だけで物語を進められる。

#### 2. 読者の問い
> **「この人は本当は何を求めている？」／「いつ気付く？」**

#### 3. 供給周期
**中〜長周期。** 小さな兆候は頻繁に出せるが、大きな自己理解の乱発は軽くなる。基本は蓄積型：

```
行動で兆候 → 他者から指摘 → 否認 → 矛盾が増える → 自覚
```

#### 4. 寿命・故障条件
**摩耗型・中命。** 一つの感情については**発見した時点で終了**する（単発消費）。感情の在庫を持たない人物では長く回せない。

故障条件：読者には明白なのに本人だけ何十話も気付かない／自覚したのに次回から元に戻る／感情を隠すため人物が不自然に鈍感になる／同じ発見を繰り返す。

#### 5. 失速サイン
読者が「もう分かっている」と感じる／周囲が何度も同じことを指摘する／内省場面が増えるが行動が変わらない／気付く寸前で毎回話題が逸れる。

> **削除テスト：理解したのに選択が変わらない。**

#### 6. 相性
◎E6（他者との関係が自己理解の鏡）／◎E1（表面的な欲望から本当の欲望へ目標を更新）／◎E5（本人自身に対する「隠蔽」として機能）／○E3（人物自身を謎として扱う）／△E10（外部進捗ばかり続くと内面変化が埋もれる）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E1** | 本当の願いを実現する行動へ切り替える | 発見された本当の欲望 |
| **E6** | 感情を理解した後、相手にどう接するかへ | 認識された感情 |
| **E5** | 自分では理解したが、まだ相手には言えない状態にする | 自覚済みだが未公開の感情 |

#### 運用要約
**「気付くこと」が終点ではなく、「気付いたため何を選ぶか」が決済。** 自己理解を必ず外部行動へ接続する。

---

### E8. 職能・手続きの開示（運用カード）

**滞在｜情報配分：作者＞読者｜主変化：読者の知識｜寿命：在庫・長**

#### 0. 燃料
**読者が知らない専門的な手順・技術・判断基準。** 料理／医療／捜査／鍛冶／建築／農業／商取引／内政／プログラミング／戦術／職人技。実在知識でも架空技術でもよい。

重要なのは、**結果ではなく過程に見る価値があること**。

#### 1. 主変化
**読者が「どうやるか」を理解する。** 成功することより、どう判断し／何を選び／どの順序で処理したかが報酬。

#### 2. 読者の問い
> **「どうやるのか？」／「なぜその手順なのか？」／「何が素人と違う？」**

#### 3. 供給周期
**短〜中周期。** 一作業・一事件につき一つの知見。長期運転では **基礎 → 応用 → 例外 → 複合問題** と難度を上げる。

#### 4. 寿命・故障条件
**在庫型・長命。** 寿命は作者の知識在庫に直結する。在庫が尽きたら止まる、が最も分かりやすいエンジン。

故障条件：説明が物語から独立する／主人公が講義するだけになる／専門知識が常に万能解決になる／**正確さを示すこと自体が目的になる**。

#### 5. 失速サイン
手順を飛ばしても結果だけで理解できる／説明部分だけ別の記事のように見える／読者が「また解説か」と感じる／問題が毎回知識一発で解決する。

> **削除テスト：説明を削除してもドラマが変わらない。**（＝知識が「選択」に使われていない）

#### 6. 相性
◎E4（知識を攻略の材料に）／◎E10（技術の成果が蓄積される）／◎E1（何のために技術を使うのか）／○E9（未知を専門知識で観察・理解する）／○E6（師弟・同業者・職人同士）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E4** | 覚えた技術を制約条件下で応用する問題へ | 公開した知識 |
| **E10** | 「それを使って何が増えたか」へ | 確立した手順 |
| **E6** | 知識の伝達を師弟・ライバル・世代交代へ | 職能と評価 |
| **E9** | 既存技術でも説明できないものを登場させる | 読者が獲得した基準知識 |

#### 運用要約
**説明するエンジンではなく、理解できるようになるエンジン。** 知識を人物の判断と結果に接続する。

---

### E9. 探索・驚異（運用カード）

**滞在｜情報配分：誰も知らない領域へ｜主変化：世界の可視範囲｜寿命：在庫・長**

#### 0. 燃料
**まだ見たことのない場所・存在・現象。** 未知の土地／奇妙な生物／新しい文化／廃墟／異常現象／巨大構造物／未知文明／異世界の生活様式／深海／秘境。

重要なのは、**答えを要求する謎ではなく、見るだけで価値があること**。

#### 1. 主変化
**世界の可視範囲。** 地図が広がるだけでなく、「この世界にはこんなものまで存在する」という世界認識が更新される。

#### 2. 読者の問い
**原則として、問いを立てなくてよい。** 強いて言えば「次は何がある？」だが、E3のように解答を要求しない。**驚異を味わうこと自体が報酬**で、10本中で唯一、未解決を残さないエンジン。

#### 3. 供給周期
**短〜中周期。** 一場面＝珍しい風景／一話＝新しい土地・生物／一章＝新地域／巻単位＝新大陸。大きな驚異の連発は感覚を麻痺させるので **日常 → 小驚異 → 日常 → 大驚異** とコントラストを作る。

#### 4. 寿命・故障条件
**在庫型・長命。** 未知が残る限り回る。回収義務がないぶん最も低コスト。

故障条件：珍しいものが日常化する／規模を大きくすることだけが驚異になる／新しい土地が既存地域と機能的に同じ／見たものが世界観に影響しない／**主人公が何を見ても驚かなくなる**。

#### 5. 失速サイン
新地域なのに以前と同じことをしている／「大きい」「珍しい」以外の差がない／景色の説明だけが長くなる／新しい土地に行く理由がない／新発見がその後一度も使われない。

> **削除テスト：場所を入れ替えても同じ話が成立する。**

#### 6. 相性
◎E10（探索で得た土地・資源を蓄積へ戻す）／◎E8（未知を観察・分析する楽しみ）／◎E1（「そこへ行きたい」）／○E3（未知に謎を一部だけ混ぜる）／○E6（旅の共同体験）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E10** | 発見したものを持ち帰る／利用する／拠点化する | 新しい土地・資源・知識 |
| **E1** | 探索中に欲しいもの・守るべきものを発見する | 新世界で発見した価値 |
| **E3** | 「これはなぜここにある？」で驚異を謎へ変える | 説明されていない発見 |
| **E8** | 調査・採取・分析・利用の段階へ移す | 未知対象 |

#### 運用要約
**すべてを謎にしないこと。** 「分からないから面白い」のではなく、**存在しているだけで面白い**領域を残す。

---

### E10. 蓄積・運営（運用カード）

**滞在＋弱牽引｜情報配分：非依存｜主変化：規模・選択肢｜寿命：在庫・中〜長**

#### 0. 燃料
**増加を可視化できる対象と尺度。** 人数／拠点／資金／領地／技術／装備／店舗／地図／スキル／信頼度／生産量／コレクション。

重要なのは、**以前と現在を比較できること**。「なんとなく発展した」は燃料にならない。

#### 1. 主変化
**規模・能力・選択肢。** 数字が増えるだけでなく、**増えた結果、以前できなかったことができる**ところまで行くと強い。

> 仲間5人 → 20人 ではなく、
> **20人になったので遠征隊を二つ出せる**

#### 2. 読者の問い
> **「次は何が増える？」** さらに **「増えたことで何ができるようになる？」**

#### 3. 供給周期
**短〜中周期。** 一話＝素材・仲間・設備／数話＝施設完成・ランク上昇／章＝町・組織・領地／長期＝文明規模。**進捗が長期間見えないこと**が直接失速につながる。

#### 4. 寿命・故障条件
**在庫型・中〜長命。ただし上限設計が必要。**

故障条件：数字だけ増えて意味が変わらない／増加量がインフレする／以前の成果が使われない／何を目指しているのか分からなくなる／**上限に達しても次の目的がない**。100→1,000→10,000としても快感は増えない。

#### 5. 失速サイン
新設備が登場回以外で使われない／仲間が増えても名前のある人物が増えない／発展が主人公の問題解決に影響しない／読者が現在値を覚える必要がなくなる／「また増えた」以外の感想がなくなる。

> **削除テスト：数字が増えても選択肢が増えない。**（＝増加が未来の可能性につながらない）

#### 6. 相性
◎E1（進捗の方向を定める）／◎E8（E8＝どう作るか、E10＝作った結果どう育ったか、と分担）／◎E9（探索で資源を発見し運営へ持ち帰る）／○E6（仲間増加を個別関係へ着地）／**△E2**（積み重ねを一発の「実は伝説級でした」で飛び越すと蓄積の価値が下がる）

#### 7. 乗り換え
| 先 | 内容 | 引き継ぐもの |
|---|---|---|
| **E1** | 一定規模に到達したら次の到達目標を設定 | 獲得した能力と資源 |
| **E5** | 成長したことで外部から発見される | 大きくなった存在そのもの |
| **E9** | 未知領域を開いて新資源・土地・文化を投入（E10⇄E9の循環運転が可能） | 探索能力・移動能力・余剰資源 |
| **E6** | 誰が対立するか／誰が責任を持つか／古参と新参 | 増えた人員と役割 |

#### 運用要約
**「増える」ではなく「増えたため世界への働きかけ方が変わる」までを一単位とする。** 低コストで回せるが、上限に着いたら成果を別エンジンへ渡す設計が必要。

### 「いま中盤が退屈」のとき

```
① 現在回っているエンジンは何か
      ↓  §1 早見表で特定
② 削除テストにかける
      ↓  出力を消して話が変わるか（§0-3）
③ そのエンジンの出力として何が残っているか
      ↓  蓄積された秘密／解明された事実／築かれた関係／増えた資産
④ それを燃料にできる次エンジンは何か
      ↓  カードの項目7「引き継ぐもの」で照合
⑤ 迷ったらハブへ落とす
         前へ進まない → E1  ／  場面が退屈 → E6
```

### よくある症状と当たり

| 症状 | 疑う場所 |
|---|---|
| 展開は派手だが緊張しない | E2の摩耗（回数超過）。出口をE1/E5/E6のどれかに決めて撃ち止める |

| 場面は楽しいが読み進めたくならない | 牽引が不足。最低条件（§0-5）違反。E1かE5を立てる |
| 先は気になるが読んでいて疲れる | 滞在が不足。E6かE9を差す |
| 関係は動くが物語が停滞する | 人物系クラスタの閉塞。E1が痩せている |
| 謎はあるが誰も気にしていない | E3の故障（回収しても状況が変わらない）。E1へ変換して目的化する |

# 第III部 昭和漫画的「勢い展開」の技法（E2深掘り）

> 後から考えると強引だが、読んでいる瞬間には「そうだったのか！」と飲み込ませる。
> ——その生成法（A）と、それが通ってしまう条件（B）。

昭和の少年漫画・劇画・特撮的な作劇には、**論理的整合性より、その瞬間の感情的納得を優先する**技法が明確に存在する。単なる行き当たりばったりではなく、再利用可能な方法論として整理できる。

本部では、Aで「どう作るか」（生成）、Bで「なぜ許されるか／どこで許されなくなるか」（検査）を扱う。上位分類は第I部の **E2（格上げ・再定義）**。運用上の燃料・寿命・乗り換えは [第II部 §3 E2](#e2-格上げ再定義運用カード) を先に見る。

---

## A. 定石カタログ — どう作るか

### 1. 「実は○○だった！」型

最も典型的。

- 敵だと思っていた男は実は父親だった
- 死んだと思われた師匠が生きていた
- 主人公の技は実は伝説の流派だった
- ただの傷跡だと思っていたものが王家の証だった
- 昔から持っていた道具が神器だった

重要なのは伏線の緻密さではなく、**過去に存在した情報へ意味を後付けする**こと。

```
新事実を出す
  ↓
過去の情報を再解釈させる
  ↓
「そういうことだったのか」
```

### 2. 既存設定の格上げ

設定を追加するのではなく、既存設定の重要度を突然上げる。

> 主人公は拳法が得意
> → 実はその拳法は三千年の歴史を持つ暗殺拳だった
> → 実はその流派には二千年前に封印された奥義がある
> → その奥義を使える者こそ救世主

これだけで物語が加速する。

### 3. 能力の意味を変更する

能力の強さを上げるのではなく、**能力の定義を変える**。

> 炎を出せる
> → その炎は炎ではなかった
> → 魂を燃焼させる力だった／太陽神の力だった／世界を作った原初の火だった

強化より派手になる。

### 4. 血統・宿命を突然接続する

事件に巻き込まれていただけの主人公が、**物語の中心人物へ変わる**。

```
偶然 → 因縁 → 宿命
```

昭和漫画ではこの「宿命化」が非常に強い推進力になる。（※副作用については B §3 を参照）

### 5. 敵を倒したらもっと大きな敵が出る

単純なインフレとは違う。良い形は「今までの敵が実は下っ端だった」。

> 悪の組織を倒した
> → 実はその組織は世界政府の一部門だった
> → 世界政府の背後に古代文明がいた

重要なのは、**勝利によって世界が狭くなるのではなく、広がる**こと。

### 6. 敵が味方になる

理由は多少強引でいい。「お前との戦いで目が覚めた」だけでも成立する。読者が「このキャラをもっと見たい」と思っているからだ。つまりこれは物語論というより、**キャラクター人気を物語へ再投入する技法**である。

そして次は当然、「元敵だから知っている秘密」を語らせる。それだけで話が進む。

### 7. 奥義にはさらに奥がある

> 主人公「必殺技！」
> 敵「その技は知っている」
> 主人公「ならば——完成形を見せてやる！」

実質は後出しジャンケンだが、演出次第で盛り上がる。ポイントは「新技」ではなく**今までの技の真の姿**にすること。読者は新しいものより、**知っていたものの秘密**のほうを受け入れやすい。

---

### 8. 中心原理：追加ではなく再定義

| 強度 | 展開 |
|---|---|
| 弱 | 新しい剣を手に入れた |
| 中 | 今まで使っていた剣こそ伝説の剣だった |
| 強 | その剣は主人公を選んでいた |
| 最強 | だから主人公は幼い頃からこの剣を持っていた |

ここまで来ると、**過去まで物語に取り込まれる**。

### 9. 三段階格上げ

意味を三段階で増やす。

```
能力 → 歴史 → 個人的因縁
```

- 敵：強敵 → 宿敵 → 実は兄
- 武器：強い武器 → 伝説の武器 → 世界を滅ぼした武器

### 10. 伏線ではなく「伏線用の空き地」

強引な展開を成立させるには、伏線そのものより**接続点**を用意しておく。

- 「主人公の出生は不明」→ 王族／魔族／宇宙人／勇者の子孫／敵の息子、何にでもできる
- 「師匠が昔のことを語らない」→ 実は敵の元幹部だった

つまり、**説明されていない空白を意図的に残す**。これが後付けを強くする。

### 11. 定石の生成式

既存のものを一つ選ぶ（人物／技／アイテム／傷／家族／過去／敵／地名）。そして順に問う。

1. **実は何だった？**
2. **もっと重要だったとしたら？**
3. **主人公と個人的な関係があったら？**
4. **世界規模の意味があったら？**

例：「主人公の腕の傷」

> 実は敵につけられた傷だった
> → 実は魔王の印だった
> → 実は父親が主人公を守るためにつけた封印だった
> → その封印が解けると世界が滅びる

### 12. 前提：読者は設定の因果より感情の因果を見ている

「実は兄弟だった」が設定として強引でも、

> 敵「だから俺は、お前を殺せなかった」
> 主人公「だからあのとき……」

があれば読者は納得する。必要なのは**設定の因果ではなく感情の因果**。

```
新事実
  ↓
キャラクターの過去の行動が理解できる
  ↓
読者が納得する
```

この順番が守られている限り、昭和漫画の強引な展開は案外よくできている。

## B. 許容条件 — なぜ通るか、どこで通らなくなるか

Aは「どう作るか」だった。ここからは「なぜ許されるか」を扱う。問いはこう立て直せる。

> **読者は強引さを許しているのではない。そもそも検算していない。**

許容とは、読者が検算モードに入る前に感情的な決済を終わらせてしまう技術である。

### 1. 「勢い」の正体は、理解速度を情報提示が追い越している状態

新事実 → 過去の再解釈 → 感情の爆発、を読者の処理能力より速く畳みかけると、読者は整合性の検証を「後で考える」フォルダに回す。ところが後で開いたときには、すでに感動として決済済みなので伝票は通ってしまう。

逆に言えば、**強引さが露見するのは退屈な瞬間だけ**である。だから「直後にもっと面白い展開が来る」は演出上の付け足しではなく、許容条件の中核にある。

ここから、作者側の最も危険な行動が導ける。

> **言い訳を始めること。**

「なぜそれが可能なのか」を丁寧に説明した瞬間、読者は説明を読むために立ち止まる。立ち止まった読者は検算を始める。後付けは根拠の量ではなく**断言の強さ**で通る。自信のない後付けだけが疑われる。

### 2. 許容の四条件

一般的な前提三条件（①読者が望んでいる ②キャラの感情に筋が通っている ③直後にもっと面白い展開が来る）を整理・拡張した、実用的な判定四条件。

#### 条件1（①の精密化）：望まれているのは結論ではなく場面（入場券）

読者が望んでいるのは**結論そのものではなく、その結論が発生させる場面**である。「実は兄弟だった」を望んでいる読者はいない。望まれているのは、兄弟だと知った上で殺し合う場面、あるいは殺せなくなる場面のほうだ。

したがって実用的な判定基準はこうなる。

> その後付けは、読者が見たかった**場面への入場券**になっているか。

券になっていない後付け——「そうだったのか」で終わって次の場面を生まない設定変更——は、どれだけ伏線が丁寧でも「作者の都合」として検知される。逆に券になっていれば、根拠が薄くても読者は共犯者になる。

#### 条件2：キャラの感情に筋が通っているか（感情の因果）

新事実によってキャラの過去の行動や選択が読者の中で腑に落ちるか。設定の辻褄合わせではなく、感情の因果が成立していることが必須となる。

#### 条件3：直後により面白い展開・変化が訪れるか

後付けを出した直後に、退屈させず次の興奮を届けること。立ち止まらせないスピード感が検算を防ぐ。

#### 条件4（④追加）：その場で即座に代償（リスク・損失）を支払わせているか

強引な格上げには、その場で何かを失わせる。師匠が実は敵幹部だったなら、その場で主人公が師匠を斬れなくなる、あるいは仲間の信頼を失う。

得るものと失うものが同時に発生していると、読者の中で「ご都合主義」の判定が**「悲劇」の判定に切り替わる**。無償の後付けだけが安っぽい。

### 3. 分水嶺は「加算か減算か」

Aの中心原理が「追加ではなく再定義」なら、許容論の中心原理はその対句になる。

> **意味を増やす再定義は許され、意味を減らす再定義は許されない。**

許されない後付けは、だいたい過去の何かを無効化している。

| 減算のパターン | 何を殺すか |
|---|---|
| 積み上げた努力を無意味にする（実は血統ですべて決まっていた） | 読者が投資した時間 |
| 払った犠牲を取り消す（実は生きていた、の乱発） | 以後すべての犠牲の重み |
| 主人公の選択を運命に回収する（結局そうなる予定だった） | 主人公の主体性 |
| キャラの過去の善意を演技だったことにする | 感情の因果そのもの |

最後の一つが特に致命的なのは、**感情の因果を逆流させる**からだ。昭和的後付けが機能するのは「新事実によって過去の行動が理解できる」ときであって、「新事実によって過去の行動が嘘になる」ときではない。同じ「実は○○だった」でも向きが真逆である。

三つ目も見落とされやすい。A §4 の宿命化は強い推進力である一方、やりすぎると主人公が物語の主体ではなく被害者になる。「偶然→因縁→宿命」の格上げには、**最後に主人公が宿命を拒否するか引き受けるかを選ぶ場面**をセットで置くと、減算が加算に戻る。

### 4. アリバイ一個の原則

昭和にあの荒業が通用した環境要因は、**検算コストの高さ**である。週刊で読み捨て、単行本まで数か月、読み返しは物理的に面倒。現代は全話がアーカイブされ、考察勢が数時間で矛盾を洗い出し、SNSで共有される。検算コストはほぼゼロになった。

したがって現代で同じ勢いをやるなら、

> 伏線の緻密さは要らないが、**アリバイは一個要る**。

セリフ一行、背景の小道具一つ、名前の読み方一つ。緻密である必要はなく、検証されたときに「ここにあった」と言える物証が一点あればいい。むしろ一点だけのほうが、発見した読者に手柄を与えられるぶん強い。

Aの「伏線用の空き地」に対して、**空き地に杭を一本だけ打っておく**イメージである。

### 5. 後付けには利子と在庫がある

一回目の「実はまだ上がある」は熱い。二回目で構造が見え、三回目で世界のルールが「作者が言えば何でもあり」に変わる。そこに到達すると、以後どんな危機も緊張を生まなくなる。

これは個々の展開の質の問題ではなく、**世界の信用が焼かれた**という不可逆の損失である。

運用ルール：

- 作品全体で「格上げ」を何回使うか、先に決めておく
- 同じ型（血統／格上げ／真の姿）を連続で使わない
- 大きい一発の後は、等身大のエピソードを挟んで世界のスケール感を再接地する

長期化して失速した昭和作品は、たいてい在庫管理の失敗に見える。

### 6. 判定用の四問（＋運用一問）

書く手前で使うなら、これくらいに畳める。Aの生成式（①〜④）を通した案を、そのままここへ通す。

1. この後付けは、読者が見たかった**場面**への入場券になっているか
2. 過去の何かを**無効化していないか**（増やしているか、減らしているか）
3. その場で**何を失う**か
4. 検算されたとき差し出せる**物証が一点**あるか
5. （運用）この型を、直前に使っていないか

四問通れば、設定としてどれだけ無茶でも、読者は「そうだったのか」と言ってくれる。通らないものは、伏線をいくら足しても「そんなのありかよ」になる。

## 付録：早見表

### 生成 → 検査の一連の流れ

```
[生成] 既存要素を選ぶ（人物／技／アイテム／傷／家族／過去／敵／地名）
   ↓
   ① 実は何だった？
   ② もっと重要だったとしたら？
   ③ 主人公と個人的な関係があったら？
   ④ 世界規模の意味があったら？
   ↓
[検査] 1. 見たい場面への入場券か
       2. 過去を無効化していないか
       3. その場で何を失うか
       4. 物証が一点あるか
       5. 直前に同じ型を使っていないか
   ↓
[演出] 説明しない。断言する。直後に次の面白い場面を置く。
```

### 二つの中心原理

| | 原理 |
|---|---|
| 生成（A） | 新しいものを持ち込むより、既に出ているものの意味を大きくする |
| 許容（B） | 意味を増やす再定義は許され、意味を減らす再定義は許されない |
