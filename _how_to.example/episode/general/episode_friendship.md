# 友人類型設計（SODALITAS）

一般エピソード・人物関係技法のうち、友人の多面的な造形。索引は [episode_.md](episode_.md)。

友人を単一のラベルではなく、**六軸のプロファイル（F1〜F6）**として置く。
[episode_false_ally.md](episode_false_ally.md)（AMICITIA：偽味方）の対になるが、単純な善玉集ではない。あちらが「一つのエンジンの器別変奏」なら、こちらは「複数の能力の配合違い」。

前提三則:

- **友情は単一特性ではない。** ゆえに定義せず、切り口として使う。合格・不合格の判定表ではない。
- **嫉妬の不在ではなく、嫉妬の処理**が論点。悔しさの発生は普通の感情、悔しさの行使が関係の操作。
- **比較が生じない関係は、試験になっていないだけ。** 軌道が交差しない相手を高く評価しない。

---

## 1. 軸層 — 友人能力 F1–F6

各軸を 0〜3 で置く。人物はこの六桁で書ける。

| ID | 軸 | 内容 | 低いときの兆候 |
|---|---|---|---|
| **F1** | 共喜耐性 | 相手の**上昇**に耐えられる | 祝福に但し書きが付く／温度が下がる |
| **F2** | 共苦耐性 | 相手の**下降**に付き合い続けられる | 短期は熱心、長期で消える |
| **F3** | 実務力 | 夜中に動く、同行する、金と時間を出す | 言葉は厚いが、来ない |
| **F4** | 理解 | 説明せずに通じる | 何度言っても前提から始まる |
| **F5** | 場の非依存 | 環境（職場・学校・趣味）が消えても残る | 場が終わると自然消滅 |
| **F6** | 役割の非固定 | 立場が入れ替わっても関係の条件を書き換えない | 支える側でなくなると不安定になる |

**F1 と F2 は独立している。** ここが設計の要。共苦に強く共喜に弱い人物は大量にいるし、その逆もいる。
**F6 が低いと、善意のまま `AMICITIA`（偽味方）へ滑る。** 悪意は不要。

## 2. 類型層 — C1–C8

`F1/F2/F3/F4/F5/F6` の順で表記。

### C1 共喜の友 — `3/2/2/2/2/3`

- **核**：相手の上昇を、自分の役割喪失として読まない。祝福に何も足さない。**足さないことが祝福。**
- **証明の瞬間**：主人公の回復・成功時にしか起きない。苦しい場面での優しさは、まだ試験前。
- **書き方の注意**：全軸を高くしない。**嫉妬を消さず、処理を描く**（→ 第4節）。悔しさゼロで書くと聖人化して嘘になる。原型でも「悔しさを飲み込む」ことが強調点だった。
- **配置**：一作に一人まで。かつ別方向の欠点（F3 が低い、約束を忘れる等）を必ず持たせる。

### C2 危急の友 — `1/3/3/1/2/2`

- **核**：夜中に動ける。手続きに同行する。実務が出る。
- **強い場面**：事故、病、失職、通夜。ここでは誰より頼りになる。
- **崩れる場面**：主人公の成功報告。悪意なく話題を逸らす。**この人物の限界は、平時に現れる。**
- **物語での使い方**：C1 の対照として置く。「一番助けてくれた人が、一番喜べない人だった」という構造は、どちらも悪くないまま痛い。

### C3 場の友 — `2/1/2/1/0/2`

- **核**：同じ職場・趣味・年代で成立する。環境依存。
- **崩れる場面**：転職、卒業、引っ越し。敵意も裏切りもなく、ただ消える。
- **物語での使い方**：喪失を安く書ける唯一の類型。転機の描写に一人置くと、時間経過の重さが出る。

### C4 理解の友 — `1/2/1/3/2/2`

- **核**：説明せずに通じる。価値観と感覚が近い。
- **固有の弱点**：**近いがゆえに、差が刺さる。** 軌道が同じだから比較が成立してしまう。同期、同業、同人。
- **崩れる場面**：片方だけが評価されたとき。理解の深さが、そのまま傷の深さになる。
- **物語での使い方**：最も痛い決裂を書ける器。憎み合わないまま離れる。

### C5 距離の友 — `3/1/1/2/3/3`

- **核**：数年会わなくても、再会時に**位置の修復を求めない**。
- **強い場面**：主人公が大きく変わったあと。過去を持ち出さない唯一の類型。
- **弱い場面**：日常の共苦。日々の消耗には向かない。
- **物語での使い方**：終盤の解放役。[episode_false_ally.md](episode_false_ally.md) の B1（幼馴染）と正確に対をなす。同じ「昔を知る人」で、P2 を持たない。

### C6 育成の友 — `1/3/3/2/2/0`

- **核**：教える、支える、先に歩く。**善意である。**
- **危険**：F6 がゼロ。援助と支配の境界は、**相手がもう援助を要しなくなったあとに**現れる。
- **分岐点**：主人公の自立時。ここで F6 を上げられれば C1 に、上げられなければ `AMICITIA` の B2／B3 に落ちる。
- **物語での使い方**：**善玉と偽味方を繋ぐ唯一の滑り台。** 読者に「この人は本当に良い人だった」と思わせたまま転落させられる。

### C7 退避型 — `0/2/2/2/1/1`

- **核**：毒は混ぜない。連絡が減り、話題が逸れ、共通の場から消える。
- **動機**：敵意ではなく、**比較の苦痛からの退避**。
- **偽味方との差**：害は小さい。ただし関係としては終わりに近い。引き戻さず、離れる。
- **物語での使い方**：主人公の成功の「代償」を静かに書ける。誰も悪くないので、後味だけ残る。

### C8 勘定型 — `1/2/3/1/2/2`

- **核**：祝福も援助も、貸し借りの残高で動く。互恵契約。
- **評価**：契約としては健全な場合がある。**不誠実ではない。** ただし幸福差試験には弱い。
- **物語での使い方**：主人公が返せなくなったときにだけ牙を出す。感情ではなく帳簿が理由なので、説得が効かない。

## 3. 領域分割 — 同一人物でも位置が変わる

**これが人物を実在させる最重要ルール。** 全領域一律の F1 を持つ人間はいない。

| 領域 | 耐えやすさ | 備考 |
|---|---|---|
| 仕事の成功 | 中 | 同業・同期だと急落する |
| 恋愛の成就 | 低 | 最も耐えにくい。代替不能に見えるため |
| 容姿・健康 | 低 | 努力の帰属が曖昧で、運への変換が起きやすい |
| 経済 | 中 | 差が数値化されるぶん、諦めもつきやすい |
| 家庭・子ども | 低〜中 | 領域外の人には無風、同じ段階の人には直撃 |
| 創作・評価 | 最低 | 主観評価かつ席が有限。C4 と組むと最も鋭い |

**造形レシピ**：一人の友人に「合格する領域」と「落ちる領域」を一つずつ与える。
例）`C1（仕事）／C7（恋愛）` — 昇進は心から祝えるが、結婚報告のあと連絡が減る人物。

## 4. 嫉妬の三段 — 描写素材

原型が最も鋭かった点。**発生と行使を分けて書く。**

1. **発生**（普通の感情。誰にでも起きる）
2. **処理**（ここに人物造形が出る。**尺を割く価値があるのはここ**）
3. **行使**（関係の操作。ここに達して初めて `AMICITIA` の類型になる）

**処理の描写バリエーション**：

- 祝福が一拍遅れる。遅れたことに本人が気づいている。
- 先に事実確認から入る（「いつ受かったの」）。感情を整える時間を稼いでいる。
- 自分の失敗に先に触れてから祝う。自虐ではなく、順序の整理。
- その場では短く、後日あらためて言いに来る。
- 席を外す。戻ってきて普通に話す。
- 相手の努力の具体を挙げる。運への変換の**逆操作**。

**判定の二指標**（観察・作劇どちらでも）:
① 成功を伝えたあと、関係の温度が下がるか。
② 祝福の文に、減点や引き戻しが付くか。
**繰り返されるなら類型。一回の言いかた違いは、まだ類型ではない。**

## 5. 三部作の接続

| | 動機 | 点火点 | 主人公の上昇時 |
|---|---|---|---|
| `MALITIA` D系（[敵対者](episode_antagonist.md)） | 自分の値段の防衛 | 主人公の接近・好意 | 格下げする（敵として） |
| `AMICITIA` P系（[偽味方](episode_false_ally.md)） | 役割込みの自己像の防衛 | 主人公の**回復** | 引き戻す（味方の顔で） |
| `SODALITAS` F系（本書） | ── | 主人公の**回復** | 耐える／退避する／勘定する |

**同じ点火点、逆符号。** 主人公の回復という一つの出来事で、AMICITIA は正体を出し、SODALITAS の C1 は初めて友人として証明される。

**滑り台**：`C6 育成の友` → F6 が上がらないまま主人公が自立 → `AMICITIA B2/B3`。
**逆走**：`AMICITIA B1 幼馴染` から P2 を抜くと `C5 距離の友` になる。改心の道筋として使える。

## 6. 濫用への注意

この軸は鋭いぶん、当てはめが効きすぎる。

- 成功報告に微妙な顔をした一瞬を、直ちに偽味方と読まない。**発生と行使は別。**
- **完全な共喜は常態ではなく理想の極。** 日常の友人の多くは、共苦と場の共有と、時おりの祝福の混合。C1 を基準線に置くと、他の全員が失格者に見える。
- 「幸福差に耐える」は友情の定義ではなく、友情の**試験項目の一つ**。危急に強く共喜に弱い人物を、友人から除外する根拠にはしない。
