# 敵対者類型設計（MALITIA）

一般エピソード・人物関係技法のうち、格下げ装置としての敵対者。索引は [episode_.md](episode_.md)。

主人公を「格下げ」することで機能する敵対者の設計セット。
属性（性別・職業・階層）には紐づけない。**装置**として分解し、任意の人物に一部だけ載せる。
姉妹編として味方の席を保ったまま格下げする [episode_false_ally.md](episode_false_ally.md)（AMICITIA：偽味方）がある。

前提二則:

- 地の文で世界法則として断定しない。**その人物が信じ、運用している論理**として書く。
- 手口の再現は不要。必要なのは結果としての恐怖・痛みだけ。

---

## 1. 部品層 — 格下げ装置 D1–D6

類型はここから組む。単体で使える最小単位。

| ID | 名称 | 定義 | 本人の言い分 | 外から見える形 |
|---|---|---|---|---|
| **D1** | 二重帳簿 | 公的な規範と私的な運用を別勘定にする | 「原則は原則、事情は事情」 | 掲げた基準が自分にだけ適用されない |
| **D2** | 履歴の非対称化 | 自分の過去は「事情」、相手の欲求は「本質」と命名する | 「私には理由があった」 | 同じ行為に別の名前が与えられる |
| **D3** | 代替経路の封鎖 | 主人公が自分以外から承認・接触を得る道を、倫理違反として潰す | 「あなたのためを思って」 | 逃げ道が一本ずつ塞がる |
| **D4** | 後日談の専有 | その場の合意より、後日の説明が勝つ | 「本当はこうだった」 | 記憶の解釈権が一方にしかない |
| **D5** | 献身の減価 | 待つほど、払うほど、主人公の評価が下がる | 「そこまでするなんて」 | 努力が隷属の証明に変換される |
| **D6** | 市場外の自認 | 他者の性・金・労働は商品、自分のそれは尊厳 | 「一緒にしないで」 | 交換の話をした瞬間に侮辱扱いされる |

**台詞の型（一片につき一本あれば足りる）**

- D1「制度としては認められません。私個人の話ではなく」
- D2「あれは若かったから。あなたのは、そういうのとは違う」
- D3「あそこに行く人って、そういう人でしょう」
- D4「あのとき私が黙っていた意味、わからなかったんですか」
- D5「そこまで尽くしてくれる人、正直ちょっと怖い」
- D6「お金の話にするの、やめてもらえます？」

## 2. 類型層 — A1–A4

各カードは部品二片で構成。三片以上は諷刺画かダークファンタジー向き。

### A1 秤の番人 — `D2 + D5`

- **中核**：拒否そのものではなく、**拒否の根拠を相手の価値切り下げに使う**。
- **表の顔**：芯があり、流されない人。周囲の評価は高い。
- **運用**：関係が始まったあとで線を引き、その線の位置を「相手の格」で説明する。
- **主人公の傷**：欲求が下品なものとして命名され、自分だけが例外的に低く見積もられる。
- **底の恐怖**：自分の値段が下がること。
- **破綻条件**：格付けの根拠を第三者に説明させられたとき。線引き自体は正当なので、崩れるのは**理由の部分だけ**。
- **善玉転用**：同じ D2 を「自分の過去を先に開示して非対称を潰す人物」にすると、そのまま好感度の高い脇役になる。

### A2 大義の徴収人 — `D1 + D3`

- **中核**：公的な正義の語彙で、私的な独占を守る。**本人はそれを誠実だと信じている**。
- **表の顔**：倫理的で、弱者の側に立つ発言をする。
- **運用**：主人公が安価に得た充足・癒し・承認を、公衆の前で人格の欠陥として定義する。
- **主人公の傷**：反論すると倫理そのものに逆らう形になり、黙るしかない。
- **底の恐怖**：交渉力の目減り。名分と利害の一致を、一度も疑ったことがない。
- **破綻条件**：同じ基準を本人の利害が絡む場面に適用させる。悪意ではなく**自己認識の破綻**として書くと強い。
- **善玉転用**：D1 を自覚した人物＝「建前と本音のズレを先に申告する交渉役」。

### A3 後日談の書記 — `D4 + D2`

- **中核**：**その場の記録より、後から書かれた物語が勝つ**という恐怖。
- **表の顔**：物静かで、説明が上手く、周囲の言葉を借りるのが巧い。
- **運用**：合意形成の過程を曖昧なまま進め、事後に解釈を確定させる。第三者・機関・共同体の言葉を借りて上書きする。
- **主人公の傷**：善意・遠慮・気遣いといった行為が、そのまま加害の証拠へ反転する。
- **底の恐怖**：被害者の席を他人に取られること。
- **破綻条件**：記録が残っていた、という単純な事実。ただし**記録が出たあとも周囲の空気が戻らない**のが、この類型の後味。
- **注意**：手続きや手口を具体的に書く必要はない。読者が受け取るべきは方法ではなく、**抗弁が最初から無効化されている**という感覚のみ。
- **善玉転用**：D4 を反転させて「後から証言を訂正しに来る人物」にすると、終盤の救済役になる。

### A4 空の聖杯 — `D5 + D6`

- **中核**：渡さないこと自体を課金理由にする。**基準は最後まで開示されない**。
- **表の顔**：気位が高く、誰にでも同じ態度を取っているように見える。
- **運用**：主人公にだけ例外的な条件を課し、その条件を愛や矜持と呼称する。
- **主人公の傷**：誠実・献身・支出が、性的あるいは人間的価値の低さの証として消費される。
- **底の恐怖**：負け組に分類されること。
- **破綻条件**：例外扱いが例外でなかったと露見するか、主人公が支払いをやめて**価格が成立しなくなる**か。後者のほうが主人公の物語になる。
- **善玉転用**：D6 を持ちつつ自分にも適用する人物＝「誰の献身も受け取らない孤高の職人」。

## 3. 動機軸 M1–M3

単純な憎悪より接続性が高い。類型に一つ選んで載せる。

- **M1 値段の防衛**：自分の交渉価値が下がることへの恐怖。→ A1 / A4 と相性良。
- **M2 分類の回避**：負け組・敗者側に置かれることの回避。→ A2 / A4。
- **M3 席の先取り**：被害者の位置を先に確保する。→ A3。

---

## 4. 運用規則

1. **一人二片まで。** 全部を一人に積むと人物が崩れて風刺画になる。
2. **地の文は観察に徹する。** 毒は台詞と内面独白にだけ預ける。地の文が断定を始めると、人物ではなく作者が喋る。
3. **反証人物を必ず一人置く。** 敵対者と同じ属性で、「拒否は正当だが格下げは別問題だ」と切り分ける人物。これがないと、類型が属性への攻撃に読まれる。
4. **主人公の傷の置き場所。** 行為の可否そのものではなく、**「自分だけが例外的に低く見積もられた」感覚**に置く。ここに置けば類型が汎用になり、性別を入れ替えても機能する。
5. **敗北の書き方。** 悪意の露見より、**本人の自己認識の破綻**のほうが後味が長い。「嘘つきだった」より「本気で正しいと思っていた」。

## 5. 組み合わせ早見

| 組 | 生じる人物 |
|---|---|
| D1 + D4 | 制度の言葉で過去を書き換える管理職型 |
| D2 + D3 | 相手の交友関係を一つずつ剥がす独占型 |
| D3 + D5 | 依存を作ってから値札を貼る庇護者型 |
| D1 + D6 | 清潔な立場から他人の生活を採点する批評家型 |
| D4 + D5 | 献身の記録を「執着の証拠」に読み替える告発者型 |
