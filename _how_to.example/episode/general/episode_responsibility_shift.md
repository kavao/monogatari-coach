# 責任移行の人物類型設計（ONUS）

一般エピソード・人物関係・プロット技法のうち、責任移行の設計。索引は [episode_.md](episode_.md)。

批判する側にいた人物を、責任を取る側へ移動させる物語の構成法。  
ID体系：原則 P・固定フィールド F・環境フィールド E・試練手順 S・帰結型 X・検定 T・反パターン A。

---

## 0 適用範囲

この類型は「反権力の人物」を扱うものではない。

扱うのは、**判断の代償が発生しない位置に留まり続ける人物**である。  
したがって左右・保守革新・理想現実の区別とは独立に適用できる。

適用例：野党的立場、社内の評論家、外部顧問、後継を拒む二世、批評家、研究者、在野の理論家、革命前夜の思想家、監視役、助言者、SNS上の言論者、親、教師。

芯となる問いは一つ。

> 意見の正しさではなく、その意見に自分の名前を署名できるか。

したがって ONUS は「責任を取れ」と迫る物語ではない。  
**不作為による代償を可視化したうえで、本人が要求してきた条件を成立させ、その理念を現実に接続し、結果へ署名できるかを問う**物語である。

権限を渡さずに結果責任だけを負わせる構図は、この類型ではなく単なる罰ゲームであり、読者は正しく「権限のないブラック組織」と読む。

---

## P 原則

**P1 位置の原則**  
類型を決めるのは思想の内容ではなく、意思決定に対する位置である。

**P2 非対称性の原則**  
決定は事前・不確実の情報で行われ、批判は事後・確定の情報で行える。この非対称性が、批判者の位置を構造的に有利にする。

**P3 無反証の原則**  
実行されない理念は現実によって反証されない。そのため理念の純粋性は、実践による検証を受けないまま保存されうる。

**P4 無加害幻想の原則**  
意思決定から離れている人物は、自分が誰も切っていないように見える。しかし不作為にも代償はあり、その代償は F4 の人物が負担している。「自分は加害していない」という感覚は、代償を外部化することで成立する。

この類型には二種類の責任がある。
- **作為責任**：自分が決めた結果、誰かが損をした
- **不作為責任**：自分が決めなかった結果、誰かが損をし続けた

**P5 役割保存の原則**  
批判が長期にわたって役割・所属・自己評価と結びつくと、問題の解決よりも「批判可能な状態の維持」が本人にとって有利になることがある。この段階で利益になるのは改善そのものではなく、批判対象が存在すること、評価者の位置にいられること、正しさを更新し続けられることである。  
判定は発言内容では行わない。**解決条件が提示されたとき、それを受け入れるかどうか**で判定する（S2b・T10）。

**P6 署名の原則**  
物語が問うのは主張の当否ではなく、結果責任を主張に接続できるかである。

**P7 可逆性の原則**  
安全席の正体は「不可逆な選択をしない権利」である。この権利を取り上げる装置が、物語そのものになる。

**P8 有用性の原則**  
外部批判を失った組織は、自己修正能力を失いやすい。したがって断罪対象は「批判したこと」ではなく「番が来たのに動かなかったこと」である。この線引きを作品内に明示しない限り、全体が権力擁護の説教に読まれる。

**P9 整合の原則**  
渡す権限は、本人がかつて要求したもの（F9）と一致していなければならない。一致しない権限の付与は試練ではなく懲罰であり、人物の問題が環境の問題にすり替わる。

## F 固定フィールド

人物を立てる時点で埋める欄。F4・F7・F8・F9 が空のまま書き始めると必ず失敗する。X2b を扱うなら F5a–F5c と F10 も先に埋める。

| ID | 欄 | 内容 |
|---|---|---|
| F1 | 批判対象 | 何を、誰を批判しているか |
| F2 | 理念 | 実現すべきと主張している状態 |
| F3 | 安全席の形 | 助言者／監視役／在野／評論／後継拒否／外部委員 など |
| F4 | 代償の所在 | その理念が実現していない代償を、いま誰が払っているか |
| F5a | 事前条件 | 受任前に本人が表明済みの条件 |
| F5b | 追加条件 | 受任を迫られた後に追加された条件 |
| F5c | 後発批判軸 | 問題が解決した後に新設された批判の軸 |
| F6 | 発行者 | 権限を渡し、逃げ道を塞ぐ人物 |
| F7 | 最初の犠牲 | 引き受けた瞬間に切らざるを得なくなるもの |
| F8 | 過去の言葉 | 後で自分に返ってくる、本人がかつて使った台詞 |
| F9 | 要求した権限 | 「これさえあれば自分ならできる」と本人が過去に要求したもの |
| F10 | 批判利益 | 批判者であることで得ているもの。道徳的優位・集団内の役割・注目・支持者・所属感・免責・発言力・商業的利益・敵を持つことによる連帯・決定責任を負わない自由 |

- **F8 と F9 は対になる**：F8 は後から本人に刺さる弾丸（S4 で撃つ）。F9 は逃げ道を塞ぐための鍵（S1 で渡す）。どちらも序盤に本人の口から言わせておく必要がある。
- **F4 と F7 も対になる**：F4 ＝ 安全席にいる間、代償を払い続けていた者。F7 ＝ 責任を引き受けた後、最初に切られる者。責任を取らなければ F4 が傷つき、責任を取れば F7 が傷つく。この対称が成立していると、S3 が単なる二択ではなくなる。
- **F5a／F5b／F5c は帰結型の分離器**：
  - F5a だけで完結 → X6（条件が固定されている）
  - F5b が発生 → X2（条件が責任回避のために移動している）
  - F5c まで発生 → X2b（解決後にも批判軸が生成される）
- F10 が大きいほど、問題の解決そのものが本人の損失になる（T12）。

## E 環境フィールド

ダブルスタンダードは二時点の発言を並べて初めて見えるため、言葉が流れて残らない世界では、X3 は悪徳ではなく最適戦略になる。以下は人物ではなく舞台の設定欄である。

| ID | 欄 | 内容 |
|---|---|---|
| E1 | 記録の永続性 | 過去の発言がどれだけ残り、参照可能か |
| E2 | 参照コスト | 過去の発言を掘り起こす手間を、どちら側が払うか |
| E3 | 忘却速度 | 共同体が矛盾を忘れるまでの時間 |
| E4 | 規模 | この人物の決定が及ぶ範囲 |

- **E1 高・E2 低の世界**：一貫性が資産になる。X3 は自壊し、X2 も長期的には露見する。批判者の位置が有利であり続けるには、本人も一貫性を要求される。
- **E1 低・E2 高・E3 速の世界**：昨日の基準と今日の基準が衝突しない。一貫性を捨てた者が常に有利になる。記憶を保持すること自体にコストが移る。
- **E4 が結末の呼び名を決める**：
  - 小規模：局所支配（物語上の呼称：小悪党）
  - 大規模：制度化された支配
  - 大規模かつ E1 低：忘却依存型支配（物語上の呼称：僭主）

同じ人物を E の異なる二つの環境に置いて対照させると、悪の所在が個人ではなく環境にあることを、説明せずに示せる。

## S 試練手順

「番が来る」の標準六手。順序は入れ替え可だが、S1 と S6 は端に固定する。

- **S1 付与**：本人がこれまで「これさえあればできる」と主張していた権限・資源・裁量（F9）を、実際に付与する。「好きなように変えていい。ただし説明するのもお前だ」。
- **S2 欠乏**：理念どおりに実行できない制約を出す（資源・時間・法・既存制度・利害）。ここで初めて前任者が理想を実現できなかった理由が見える。
- **S2b 解決可能性**：本人が要求していた問題を、現実に解決できる状態を一度作る。正常な批判者は協力的になるが、批判が目的化した人物は逆に不安定になる（X2b）。
- **S3 二者択一**：行動すれば F7 が傷つき、行動しなければ F4 が傷つき続ける局面を作る。「何もしないことも、もう無傷ではない」と本人に理解させる。
- **S4 反転**：自分がかつて使った言葉（F8）とよく似た言葉で批判される。非対称性（P2）を身体で理解する地点。
- **S5 失敗**：一度、明確に失敗させる。予測が外れ、誰かが傷つき、支持者が離れる。逃げれば X2 へ、逃げなければ X1 へ分岐する。
- **S6 署名**：説明の場に立たせる。「これは自分が決めた」と言えるかどうかだけを問う。

## X 帰結型

**X1 継承**  
責任を引き受ける。理想を捨てるのではなく、理想に責任を接続する。到達点は、代案と、その代案が生む犠牲まで併せて語れる批判者になることである。

**X2 帰還**  
引き受けない。条件を増やす、役割を限定する、責任を引き受けた別人を批判する、自己正当化（「私は権力が欲しいわけではない」）。最も安全に存在できる場所へ帰還したという結末。

**X2b 批判維持**  
X2 の強化型。問題そのものが解決しない状態を必要とする。特徴は、要求が満たされるたびに**要求の定義が変わる**こと。

| 型 | 台詞 | 内容 |
|---|---|---|
| 条件追加 | それだけでは不十分だ | 満たせば解決すると言っていた条件が、達成された瞬間に増える |
| 基準移動 | 問題はそこではない | 論点が解決すると、別の論点を本質だったことにする |
| 純粋性退避 | それは本当の解決ではない | 実行可能な改善を、完全解決でないことを理由に否定する |
| 権限否認 | そんな権限を持つこと自体が問題だ | 自分が要求していた権限を、渡された後になって否定する |
| 役割退避 | 私は実行する立場ではない | 実行可能性が生じた瞬間に、自分を批評・監視へ再定義する |
| 責任転送 | まずあちらが責任を取るべきだ | 自分の受任より前に、別人の謝罪や辞任を新条件にする |
| 完全条件化 | すべて解消されなければ意味がない | 部分改善を認めず、達成不能な完全条件を置く |
| 意図攻撃 | その改善は善意からではない | 成果ではなく動機へ論点を移し、改善を評価不能にする |
| 功績否認 | それは当然やるべきことだ | 改善前は重大問題としていたものを、改善後は成果に数えない |
| 問題再生成 | でも別の問題が残っている | 元の問題の解決を認めず、次の問題を同じ深刻度で接続する |

**発覚の標準形**：単に「お前は批判したいだけだ」と言わせるのではなく、周囲が要求を一つずつ満たしていく（人事権→予算→制度…）過程で、逃げ道の移動を観測させる。

**X3 転用**  
引き受けたうえで、責任を特権に変える。「決めたことのない人間に言われたくない」で批判を封殺する。X1 の劣化形であり、P8 の予防線が構造として働く。

**X1 → X3 遷移**  
最も強い経路は、ONUS を正しく通過した人物が落ちる形である。  
- `X1a 継承` → `X1b 摩耗`（「外から言うのは簡単だ」の固定） → `X3 転用`（他者の批判資格を剥奪）  
制動の実例：記録を残す習慣、後継に権限を渡した経験、かつての自分と同じ位置にいる批判者を残すこと。

**X4 集団版**  
X2 の共同体形態。「まだ本物の◯◯が実現していないだけだ」により反証を永久に先送りする。

**X5 免除**  
番が最後まで回ってこない。本人は正しさを保ったまま終わり、読者にのみ判定を委ねる型。

**X6 条件付き受任**  
責任そのものは拒否しないが、責任と権限の対応を要求する（「結果責任を負えというなら、人事権も必要だ」）。条件が満たされた後は新しい条件を追加せずに引き受ける。X2（条件が逃げるために動く）と違い、条件が責任範囲を確定するために固定される。

## T 検定

| ID | 検定 | 問い |
|---|---|---|
| T1 | 署名 | この決定を、誰の名前で説明できるか |
| T2 | 犠牲 | 提示された代案に、その代案が生む犠牲が併記されているか |
| T3 | 条件固定 | 受任条件を事前に列挙できるか。満たされた後に新しい条件が追加されていないか（X2 と X6 の分離） |
| T4 | 解決 | 問題が解決したら、この人物は困らないか |
| T5 | 反転 | かつての自分は、今の自分を何と呼ぶか |
| T6 | 不可逆 | この人物が下した、取り消せない決定が作中に一つでもあるか |
| T7 | 封殺 | 批判の内容ではなく、批判者の資格に応答していないか（X3 検出） |
| T8 | 対照 | X3 を疑うなら、二時点の発言を並べられるか。E1–E3 が低い世界では T7 単独では判定できない |
| T9 | 整合 | 受任条件は、本人がかつて要求したもの（F9）と一致しているか。到達不能な条件が一つだけ新たに足されていないか |
| T10 | 解決受容 | 要求していた条件が満たされたとき、「これは改善した」と明言できるか |
| T11 | 基準固定 | 時点 A と時点 B で、要求・成功条件・評価基準は同じか。対象人物が変わっただけで基準が動いていないか |
| T12 | 損失 | 問題が完全に解決したと仮定したとき、本人は何を失うか（F10 と照合する） |

## A 反パターン

- **A1 説教化**：「責任を取れない者は批判するな」と読める構成（P8 と X3 の欠落）。
- **A2 転向オチ**：権限を得た途端に理念を捨てる（S2〜S5 の省略）。
- **A3 無菌の試練**：制約が甘く、理想がそのまま通ってしまう（S2 欠乏の形式化）。
- **A4 悪意化**：批判者を最初から偽善者として描く（構造の説得力が消える）。
- **A5 犠牲の不在**：切られた側が画面に出てこない（F7 未記入）。
- **A6 事後の全知**：決定時点では持ち得なかった情報を持っているように書かれる（P2 崩壊）。
- **A7 一回性**：番が一度で終わり、繰り返しの選択がない。
- **A8 記録の御都合**：E を設定しないまま、必要な場面でだけ都合よく過去の発言が発掘される。
- **A9 作者による読心**：「本当は批判したいだけだった」と作者が説明して終わる。必ず行動列（要求→充足→新条件追加）で示す。
- **A10 正当な追加条件との混同**：現実に新しい問題が判明しただけなのに「また逃げた」と裁定する。

## 使用手順

```
1. F1–F10 を埋める。F4・F7・F8・F9 が空なら書き始めない
2. E1–E4 を設定する。X3 を扱うならここが本体になる
3. X1–X6 のどれに着地させるかを先に決める
4. S1–S6 を配置する。S1 で F9 を渡し、S4 で F8 を撃つ。X2b を扱うなら S2b を挿入する
5. T1–T12 で通す
6. A1–A10 に触れていないか確認する
```

引き受ければ、その人物は変わる。  
引き受けなければ、その人物が何者だったのかが分かる。  
そして引き受けた後も、試練は終わらない。
