# 部活ラブコメ構成フレームワーク（CLUBROM）

一般エピソード・学園青春ラブコメ技法のうち、部活動を舞台にした恋愛喜劇の設計。索引は [episode_.md](episode_.md)。  
大学サークル版は [episode_circle_romcom.md](episode_circle_romcom.md)（CIRCLEROM）。

ID体系：**原則 P** ／ **設定固定フィールド F** ／ **配役型 R** ／ **場面 S（Scene）** ／ **障害 O** ／ **転換点 X** ／ **検定 T** ／ **反パターン A**

---

## 1. 原則 P — なぜ部活が恋愛装置として強いのか

| ID | 原則 | 内容 |
|----|------|------|
| **P1** | 半強制的接触 | 「会う理由」を毎回作らなくていい。放課後、同じ場所、同じ面子。恋愛小説最大のコスト（再会の口実）が構造的にタダになる。 |
| **P2** | 共同目標の存在 | 大会・公演・作品完成という「二人以外のもの」を並んで見る時間が長い。向かい合う関係より、同じ方向を向く関係のほうが親密化が速い。 |
| **P3** | 期限の内蔵 | 引退・卒業・廃部・最後の大会。作者が用意しなくても、部活には最初からタイマーが付いている。 |
| **P4** | 身体の近接が正当化される | 指導、手当て、道具の受け渡し。触れる理由が競技側から供給される。 |
| **P5** | 私的空間の獲得 | 部室は「学校の中にある、生徒の裁量で回る領域」。教室でも家でもない中間領域が、関係の実験場になる。 |
| **P6** | 部活が先、恋愛が後 | **最重要**。恋愛イベントのために部活を止めない。練習・怪我・レギュラー争い・新入生といった部活側の事件が先に進み、その副作用として関係が動く。これを守るだけで「部室で駄弁るだけのラブコメ」から抜けられる。 |
| **P7** | 温度差が葛藤を生む | 部活への本気度が全員違うこと自体がドラマの燃料。誰が一番真剣かで、誰の恋愛が一番苦しいかが決まる。 |
| **P8** | 認識の非対称 | 親密さ・恋愛感情・その自覚は同時に進まない。本人・相手・周囲で関係の認識がずれるほど、何気ない日常がラブコメになる。「毎日一緒に帰る」は、主人公＝部活仲間だから当然／ヒロイン＝これはほぼデートでは／周囲＝もう付き合っている、と三層のずれを与えて初めて場面になる。 |

### 生成機構（P群の要約）

```
部活が接触を作る            … P1・P4・P5
      ↓
接触が習慣になる            … S-a
      ↓
習慣が親密さを作る          … P2
      ↓
その親密さが「部活だから」なのか
「好きだから」なのか判別できない  … O9
      ↓
大会・怪我・引退で
従来の関係が維持不能になる    … P3・S-d
      ↓
関係を再定義する            … X群
```

**代表原理**：**P1（会う理由がタダ）→ O9（その近さは部活から借りているだけかもしれない）→ X8（会う理由が消えた後でも会うことを選ぶ）**  
この三段が、部活ラブコメを他の学園ラブコメから分ける中核構造。迷ったらここに戻る。

## 2. 設定固定フィールド F — 書き出す前に決める値

| ID | 項目 | 選択肢と効果 |
|----|------|--------------|
| **F1** | 部の種類 | 運動部＝勝敗・身体・序列が自動で付く／文化部＝内面の批評・作品が距離を縮める／珍部（オカルト研・占い部・部活動創設部）＝規則より人間関係が前に出る |
| **F2** | 部員数 | 2〜3人＝密室化、部室＝事実上のデート／10人以上＝嫉妬・派閥・噂が動く／人数は恋愛の「密度」を直接決めるツマミ |
| **F3** | 主軸の学年関係 | 先輩後輩＝卒業という期限が最初から効く／同学年＝三年間まるごと使えるが弛緩しやすい／後輩ヒロイン＝主人公が「見せる側」になる |
| **F4** | 入部動機 | 本命／人数合わせ／付き添い／下心（見抜かれている）／廃部阻止の頭数。動機の不純さは後で回収できる伏線になる |
| **F5** | 期限の位置 | 物語のどこに引退・最終大会を置くか。序盤＝喪失から始まる／中盤＝関係の再定義／終盤＝告白の締切 |
| **F6** | 顧問の存在感 | 不在・放置＝生徒の裁量が増え密度が上がる／厳格＝規律が障害になる／若手で当事者性あり＝大人側のサブプロット |
| **F7** | 部活の危機 | 廃部、予算、人数不足、顧問の異動、事故。危機は「二人で乗り越える」ための最も自然な口実 |
| **F8** | 温度差表 | 各キャラの部活への姿勢を先に一行で決める（P7）。例：主人公＝なんとなく／エース＝全国／マネージャー＝支える／部長＝チーム最優先 |

## 3. 配役型 R — 関係性のパターン

| ID | 型 | 効くところ | 典型の罠 |
|----|-----|-----------|---------|
| **R1** | 先輩 × 後輩 | 卒業＝タイムリミット。教える／教わるの非対称が接触を生む | 「憧れ」で止まり、対等になる場面を書き忘れる |
| **R2** | 部長 × 部員 | 公の顔と素顔のギャップ。責任を負う者の孤独 | ギャップの開示が一回きりで消費される |
| **R3** | 選手 × マネージャー | 世話が愛情に転化する。競技外という疎外感を抱えている | 献身だけのキャラになり、本人の欲望が描かれない |
| **R4** | 同学年ライバル | レギュラー争いと恋愛が同じ土俵に乗る | 競争と好意の切り替えが唐突になる |
| **R5** | 幼馴染 × 新しい関係 | 「昔から知っている」が強みにも弱みにもなる。部活で初めて見る一面 | 幼馴染が負け役の記号で終わる |
| **R6** | 他校のライバル | 大会会場でしか会えない＝希少性。SNSでは既に繋がっている | 敵対と好意の理由づけが薄い |
| **R7** | 極少人数部の二人 | 密室、共犯、生活感 | 外圧がないため物語が停滞する（O群で補う） |
| **R8** | 異種部活の交流 | 合同練習・文化祭で接点。価値観の翻訳が必要になる | 交わる理由が場当たり的 |
| **R9** | 生意気な後輩 | 唯一主人公を「見ている」役。上下関係を逆転させる小気味よさ | 記号的な悪態で終わる |

## 4. 場面 S（Scene） — 関係を進行させる場面の在庫

### S-a 日常（低コスト・反復可能）
- 片付けで最後の二人になる
- 部室の鍵を誰が持つかが妙に重要になる
- 忘れ物（タオル、シューズ、楽譜、原稿）を届けに行く
- 帰りの時刻が同じで、分岐点まで毎日一緒に歩く
- コンビニが準・部室化し、買うものの好みを覚える
- 私物が部室に増え、生活感が滲む
- 寝落ちした相手に上着をかける
- フォーム修正で手が重なる（「力を抜いて」「こう持って」）
- 主人公だけが相手の隠れた努力を知っている

### S-b 天候・偶発
- 雨天中止 → 部室イベントに切り替わる
- 傘が一本しかない／濡れたジャージを貸す
- 電車が止まって帰れない
- 怪我・体調不良の看病。湿布、水、肩を貸す
- 更衣中の遭遇（使うなら結果を後に残す。事故で終わらせない）

### S-c 行事（高濃度・使い所を絞る）
- **合宿**：部屋割り、夜の自由時間、買い出し係、朝の寝起き、風呂上がりの髪
- **文化祭**：制服以外の衣装、出店、後夜祭の告白ジンクス、展示準備で掘り返される過去の品
- **大会前後**：緊張の共有／敗北直後の慰め方／勝利のハイタッチが一拍長い／観客席にいたかどうかを気にしている
- **徹夜の作業**：発表前の作業が明け方に及び、判断力が落ちた時間帯に本音が出る
- **引退・卒業**：「部活が終わったらどうする」が、そのまま告白の導火線になる

### S-d 事件（部活側から供給される）
- 新入生の加入で立ち位置が変わる（既存ヒロインが急に「先輩」になる）
- 怪我でレギュラーを外れる
- 部長交代
- 廃部通告・予算削減
- 顧問の異動

### S-e 役割反転（非対称な関係を対等に移行させる）
- 教える先輩が失敗し、後輩に励まされる
- エースが怪我をして、控えだった主人公に頼る
- いつも世話をするマネージャーが体調を崩し、世話される側になる
- 部長が弱音を吐き、頼りなかった主人公が支える
- 初心者だった主人公が、新入生を教える側になる
- いつもからかってくるヒロインが、本番前だけ緊張している
- ライバル同士が、団体戦では同じ側に立つ

> **告白より前に、一度は上下を入れ替えておく（S-e）。**

## 5. 障害 O — 進行を止めるための装置

| ID | 障害 | 生成される問い |
|----|------|---------------|
| **O1** | 告白がチームを壊す | 恋愛と居場所、どちらを取るか。「引退までは言わない」という自主制約が生まれる |
| **O2** | 部活優先で時間が取れない | 「部活しか見ていない」という誤解。実は最も一緒にいる相手なのに |
| **O3** | 部内恋愛への空気・嫉妬 | 二人だけの問題にならない。第三者の視線が常時ある |
| **O4** | 進路と継続の衝突 | 続けるのか、辞めるのか。恋愛が進路の変数になってしまう罪悪感 |
| **O5** | 実力差・レギュラー争い | 好意と競争心が同じ相手に向く |
| **O6** | 「仲間」と「恋人」の線引き | 現状が心地よすぎて、名前を付けると壊れる予感（勇気の問題） |
| **O7** | 期限の非対称 | 片方だけ来年もいる。残される側／去る側で時間の重みが違う |
| **O8** | 競技外という疎外感 | マネージャー、裏方、故障者。同じ場所にいるのに同じ景色を見ていない |
| **O9** | 借り物の親密さ | 毎日会い、一緒に帰り、体調まで知っている。だがその近さは「同じ部員だから」なのか「好きだから」なのか、本人には判別できない。部活という制度から借りているだけなら、引退した翌日には返さなければならない（認識の問題・最重要） |

## 6. 転換点 X — 関係が動く瞬間

| ID | 出口 | 条件 |
|----|------|------|
| **X1** | 大会・発表の直後 | 感情の防壁が一時的に落ちている。勝敗どちらでも成立する |
| **X2** | 危機を二人で越えた夜 | 廃部阻止、締切突破。共犯関係が言葉を後押しする |
| **X3** | 部活の話が恋愛の話にすり替わる | 「これからも一緒に続けたい」が二重の意味を持つ瞬間。最も上品な告白型 |
| **X4** | 引退・卒業の直前 | 締切による強制。言わなければ永久に言えないと本人が知っている |
| **X5** | 第三者の登場で自覚 | 新入部員、他校の相手。失う可能性が初めて具体化する |
| **X6** | 怪我・不在で欠落を知る | 隣にいたものが消えて、初めて輪郭が見える |
| **X7** | 未遂で終わる | 言いかけて中断。合宿最終夜など。次の山への繰り越しとして有効 |
| **X8** | 部活という接着剤が消える | 引退・退部・卒業により「毎日会う制度的理由」が失われる。そこで初めて、二人は部活ではなく互い自身を選ぶ必要が生じる。P1の逆転であり、O9への唯一の解答 |

## 7. 検定 T — 原稿チェック

- **T1**：部活側の出来事を全部消しても話が成立してしまうなら、それは部活ものではない（P6違反）
- **T2**：ヒロインが部活に対して持つ欲望を、恋愛と無関係に一行で書けるか
- **T3**：期限（引退・大会・卒業）が、登場人物の口から一度でも意識されているか
- **T4**：部室以外の場所が三箇所以上使われているか
- **T5**：脇の部員が、二人の関係を進めるためだけに存在していないか
- **T6**：身体的接触に、競技上の必然が付いているか（P4）
- **T7**：告白後も部活が続く場合、関係の変化がチームに与える影響を書いたか
- **T8**：**主要イベントの前後で、「もう以前の二人には戻れないもの」が最低一つ増えたか**
- **T9**：P8の三層（本人・相手・周囲）の認識のずれを、少なくとも一場面で明示したか

## 8. 反パターン A

- **A1** 部室二人きりの雑談だけで進行する（一場面ごとに「部活側の用件」を付ける）
- **A2** 大会が背景装飾で終わる（勝敗が人間関係の配置を変えるところまで書く）
- **A3** マネージャーが献身のみ（本人の競技経験・断念・嫉妬を一つ持たせる）
- **A4** 合宿で一気に全イベントを消化（一度に一つの機能だけ担わせる）
- **A5** 「部内恋愛禁止」を空気だけで処理（誰が、なぜ、いつからそう言い出したかを具体化）
- **A6** 幼馴染が敗北の記号（部活を通じて「知らなかった一面」を得る側に回す）
- **A7** 告白でジャンルが終わる（X3の型を使い、告白＝部活の継続宣言にする）
- **A8** 顧問が完全に不在（一度だけ介入させ、生徒の裁量が特権であることを可視化）
- **A9** 引退＝エンディングで打ち切る（X8まで書かないとO9借り物の親密さが未解決）
- **A10** 上下関係が最後まで固定（S-eを一度も通さないと対等になった瞬間が見えない）

## 9. 最小構成テンプレート

```
F1 部種       ：
F2 人数       ：
F3 学年関係   ：
F4 入部動機   ：
F5 期限の位置 ：
F8 温度差     ：主人公／ヒロイン／第三者

主軸  R__ ×  障害 O__（O9を副線に必ず一本）
山1  S-a 反復で日常を敷く（P8：三層の認識差を提示）
山2  S-d 部活側の事件が起こる → 関係が揺れる
山3  S-e 役割が反転する → 非対称が崩れる
山4  S-c 行事で密度が上がる → X7（未遂）
山5  期限が迫る → O__ が限界に達する
決着 X__ ／部活の帰結と恋愛の帰結を同じ場面で処理する
余韻 X8 接着剤が消えた後、それでも会うことを選ぶ

※ 各山の後に T8 を当てる（戻れない変化が一つ残ったか）
```
