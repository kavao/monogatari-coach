# 親密さのスロープ（七つの境界軸×越境の四段階）

一般エピソード・人物関係技法のうち、恋愛の親密さが段階的に高まる構造。索引は [episode_.md](episode_.md)。

> 原資料（来歴）: `C:/Users/Owner/Downloads/親密さのスロープ/intimacy-slope-tropes.md`（親密さのスロープあるある集 v0.1。3つの生成元のまとめを統合した資料）。2026-11-04 に `episode/general/` の葉として導入。導入版では、見出し・本文の生成元の名前と版の行を外し、発動条件・本資料の注意・Monogatari Coach での使い方（関連する葉と境界）・深掘り用の問い・作業用への導入を足した。0-3 と 0-4 は「基本の流れ」「基本の流れ（細分版）」として両方残した。0〜10章は章番号のまま残した。原資料は変更していない。

二人の親密さが段階的に高まっていく過程の定番型を、**どの境界を（七つの軸）× どう越えたか（四つの段階）** で整理する。原資料は現代恋愛作品を対象にしている。

## 発動条件

> 二人の恋愛的な親密さが段階的に高まっていく過程（呼び方・距離・接触・自己開示・特別扱いなどの境界がどう解禁されていくか）を設計する場合、または恋愛関係の進み方が単調・唐突で直したい場合に選ぶ（既定では読まない。恋愛が背景にあるだけ、友情や家族の関係の深まりだけでは選ばない。友情の深まりは `episode/general/episode_friendship.md`、ラブコメのジャンルの約束と装置は `genre/romcom.md`、具体的な場面の候補は `episode/common/` の親愛系）。

## 本資料の注意

- 対象は **心理的・状況的なスロープ** に限る。性的行為の直接描写は扱わない。§9「一線の手前」は、直接描かずに打診・確認・暗転・余韻で処理する手順だけを扱う。
- 原資料は現代恋愛を前提にしている。終電・合鍵・委員会などの現代の場面は例示であり、異世界・時代ものでは、その世界で同じ働きをする境界（時間・空間・接触など）に置き換える。現代の場面を、どの世界にも当てはまる型として扱わない。
- 七つの軸の順序やフェーズの並びは固定ではない。作品・人物によって前後・並行する（§8 軸ずれの法則）。

## Monogatari Coach での使い方

恋愛の親密さの進み方が作品の推進力になるときに、Plan Mode で参照する。また、関係の進み方が単調・唐突だと感じたときに、どの軸のどの段階が抜けているかを診断するのに使う。

| 作品資料 | 主に反映する項目 |
|---|---|
| `character.md` | 二人の初期値プロファイル（§7）、軸ずれによる人物の性格（§8 軸ずれの法則） |
| `design_specification.md` | どの軸から開くか（開放順）、各章で越える境界と越え方、触媒と制動の置き場所、自覚の場面の外圧、再演・再階段の場面 |
| `world.md` | その世界で七つの軸にあたる境界（呼称の作法、私室への出入り、接触の規範など） |
| `_meta.md` | 二人が今どの軸のどの段階にいるか、未遂（寸止め）の回数、片方だけ先に進んだ段の時差 |

設計時は、最低限次を決める。

- 二人の初期値プロファイル（§7）を七軸で決め、どの軸から開くかを決める。
- 各場面に、前回からの差分があるかを確かめる（§8 差分の法則）。
- 自覚の場面に外圧を置く（§5）。二人の段階に時差を置く（§8 非対称の法則）。
- 現代の場面を使わない世界では、七つの軸にあたる境界をその世界の言葉で決める。
- 軸の名前・段階の名前・フェーズ記号（P1〜P9）・法則の名前は設計の語である。物語案・あらすじ・キャラクター紹介には出さず、人物と出来事で書く（`_how_to.example/synopsis_presentation.md`）。

関連する葉と境界:

- ラブコメのジャンルの約束と装置の一覧は [ラブコメ](../../genre/romcom.md)。ジャンル軸に当たれば必読で、段階の中身（どの境界をどう越えるか）を設計するときにこの葉を併用する。
- 具体的な場面の候補は `episode/common/` の親愛系（[epsode_common_progression.md](../common/epsode_common_progression.md)・[epsode_common_affection.md](../common/epsode_common_affection.md)・[epsode_common_shyness.md](../common/epsode_common_shyness.md)）。その場面をどの軸・どの段階に置くかはこの葉。
- 友情の深まりは [友人類型設計](episode_friendship.md)、恩義から親密な関係への換算は [恩義設計論](episode_obligation.md)。この葉は恋愛の境界がどう解禁されるかを扱う。

## 0. 定義と構造の核

### 0-1. 基本定義
- 親密さの高まりとは、二人の間にある**複数の境界**が、公的な側から私的な側へ少しずつ**解禁**されていく過程である
- あるあるのほとんどは「**どの境界を**（軸）× **どう越えたか**（主体性）」の組み合わせとして記述できる

### 0-2. 中核の式

```
親密さ ＝ Σ（境界軸 × 越境の主体性）
読者が感じる親密さ ＝ 前回からの差分
```

### 0-3. 基本の流れ
- 偶然 → 習慣 → 信頼 → 身体的近接 → 感情の自覚 → 関係の特別化
- ただし順序は固定ではなく、作品・キャラクターによって前後・並行する（→ §8 軸ずれの法則）

### 0-4. 基本の流れ（細分版）
- 接触頻度が増える → 相手を観察する → 小さな好みを覚える → 日常を共有する → 弱さを共有する → 特別扱いが生まれる → 他者との違いを意識する → 身体距離が縮まる → 不在・嫉妬で感情を自覚する → 将来に相手を含め始める → 「一緒にいたい」が言語化される

## 1. 七つの境界軸

| 軸 | 公的側 → 私的側 | 解禁されるもの |
|---|---|---|
| **A 時間** | たまたま居合わせる → 一緒にいることが目的になる | 共有する時間の量と意味 |
| **B 空間** | 教室・職場 → 帰り道 → 相手の部屋 | 生活領域への立ち入り |
| **C 情報** | 表の顔 → 弱さ・過去・秘密 | 自己開示の深さ |
| **D 身体** | 触れない → 偶然触れる → 触れることを許す | 接触の許容範囲 |
| **E 言語** | 苗字・敬語 → 名前・あだ名・素の口調 | 呼称と話し方の距離 |
| **F 優先** | 大勢の中の一人 → 「自分だけ」 | 相手の中での順位 |
| **G 未来** | 今だけの関係 → 将来に互いがいる前提 | 時間軸上の共有範囲 |

- F 軸はほかの全軸を「この人だけ」という形で束ねる**メタ軸**（→ §8 限定解禁の法則）

---

## 2. 越境の四段階（主体性）

| 段階 | 性質 | 感情的効果 |
|---|---|---|
| **① 口実** | 外的理由があるから越える（雨、仕事、看病） | 好意を認めずに近づける猶予期間になる |
| **② 偶発** | 事故的に越えてしまう（転ぶ、目撃する） | 本人の意思を超えた動揺が生まれる |
| **③ 選択** | 自分の意思で越える（自分から手を取る） | 好意が行動として表に出る |
| **④ 承認** | 越えられたことを拒まず、それが定着する | 関係の不可逆性が確定する |

### 2-1. 軸 × 段階マトリクス（配置図）

| 軸 | ① 口実 | ② 偶発 | ③ 選択 | ④ 承認 |
|---|---|---|---|---|
| **A 時間** | 委員会・担当が同じ、帰り道が同じ | 終電を逃す、閉じ込められる | 用もないのに会いに行く、遠回り | 沈黙が苦にならない、「また明日」が当然 |
| **B 空間** | 看病で部屋に行く、雨宿り | 部屋割りの手違い、家族に鉢合わせ | 自宅に招く | 合鍵、私物が置いてある |
| **C 情報** | 仕事・勉強の相談 | 泣いているところを見られる | 「誰にも言ったことないけど」 | 否定せず聞く、秘密を守り続ける |
| **D 身体** | 人混みで袖をつかむ、手当て | 手が重なる、転んで支えられる | 自分から手を取る | 手を離さない、もたれられても動かない |
| **E 言語** | 周囲がつけたあだ名で呼ぶ | とっさに名前で呼んでしまう | 「名前で呼んでいい？」 | 呼び方が定着し敬語に戻らない |
| **F 優先** | 「ついでに買ってきた」 | 危機で真っ先に名前を呼ぶ | 予定を空ける、ライバルより選ぶ | 「あの人だけ特別」が周囲公認 |
| **G 未来** | 「今度みんなで」 | 来年の話に自然に相手が入る | 「また二人で来よう」 | 将来の計画に互いが前提 |

- 物語の進行は、このマス目が**左上から右下へ**埋まっていく過程として読める

## 3. 軸別あるある

各項目の段階表記：①口実 ②偶発 ③選択 ④承認

### 3-A. 時間軸あるある

| 段階 | あるある | 効果 |
|---|---|---|
| ① | 同じ学校・職場・サークル・委員会になる | 接触を自然に反復できる |
| ① | 席・デスク・担当が近くなる | 日常的な近さを作る |
| ① | 帰る方向が同じで一緒に帰る | 二人きりの時間を自然に作る |
| ① | 二人で買い物に行く（用事つき） | デート未満・デート以上の曖昧さを作る |
| ② | 偶然何度も顔を合わせる | 「縁がある」感を作る |
| ② | 休日に偶然会う | 日常の枠外で会い、関係の格が上がる |
| ② | 終電・交通トラブルで長く一緒にいる | 本来以上の共有時間を作る |
| ② | 閉じ込められる（倉庫・エレベーター・停電） | 強制的な二人きりで本音を引き出す |
| ③ | 用もないのにメッセージが来る／送る | 相手を思い出していることを示す |
| ③ | 「今何してる？」が増える | 日常への侵入＝親密化を示す |
| ③ | 長電話、深夜まで話してしまう | 会話そのものが目的になる |
| ③ | 「もう少し歩こう」と遠回りする | 一緒にいたい気持ちを間接的に示す |
| ③ | 理由を作らず会いに行く | 関係が目的そのものになる |
| ④ | 沈黙が苦にならなくなる | 高度な安心感を示す |
| ④ | 同じ景色を黙って見る | 言語を超えた感情共有 |
| ④ | 一緒に帰るのが「約束しなくても当然」になる | 習慣が関係の定義に変わる |

| ① | 二人だけの「秘密の場所」（屋上・河原・夜景） | 関係の象徴となる場所ができる |
| ② | 旅行・合宿で同室になる／部屋割りの手違い | 寝る前・寝起きの私的時間を共有する |
| ② | 相手の家族に偶然会う | 関係が社会的文脈に入り始める |
| ② | 家族から恋人と誤解される | 関係を外部視点で揺さぶる |
| ③ | 自宅に招く | 公的関係から私的領域へ進む |
| ③ | 友人グループに紹介される | 相手の生活圏へ入ったことを示す |
| ③ | 相手の部屋の本棚・写真・趣味の物を見る | 会話では見えない人格が開示される |
| ④ | 合鍵を渡す | 生活空間の共有を許す象徴 |
| ④ | 相手の部屋に自分の私物が置かれている | 空間の共有が既成事実化する |

### 3-C. 情報軸あるある（自己開示）

| 段階 | あるある | 効果 |
|---|---|---|
| ① | 仕事・勉強の相談をする | 能力への信頼を愛情の土台にする |

| ① | 苦手なものが同じ | 共犯意識・仲間意識を作る |
| ② | 相手の意外な一面を一方的に目撃する | 「本当のあの人」を知り関心が生まれる |

| ② | 他人経由で相手の本心・評判を知る | 認識が書き換わり、興味が増幅する |

| 段階 | あるある | 効果 |
|---|---|---|
| ① | 電車・バスで隣に座る | 身体距離縮小の前段階 |

| ① | 満員電車でかばわれる | 守る構図と密着が同時に成立する |
| ① | 人混みではぐれないよう袖をつかむ | 手を握る一歩手前 |
| ① | 怪我の手当て、額に触れて熱を確認する | 正当な理由つきの接触 |
| ① | 寒さを理由に近づく | 自然な距離縮小の口実 |
| ① | 上着・マフラーを貸す | 「包まれる」感覚と気遣いが結びつく |
| ① | 耳元で話す必要がある | 声と距離の親密さを強調する |
| ② | 同じ物を取ろうとして手が重なる | 最小の接触で最大の動揺を生む |

| ③ | 手をつなぐか一瞬迷う | 接触より「選択」をドラマ化する |
| ③ | 傘を相手側に傾ける | 自己犠牲的な小さな優しさ |
| ④ | 手を離すタイミングが分からない | 相互好意を間接的に示す |
| ④ | もたれられても動かない | 接触の受容を示す |

### 3-G. 未来軸あるある

| 段階 | あるある | 効果 |
|---|---|---|
| ① | 「今度みんなで行こう」 | 未来の約束を集団で薄める |
| ② | 来年の話に自然に相手が入っている | 無意識に未来に相手がいる |
| ② | 自分の将来の話に相手を含めてしまう | 関係の長期化を無意識に示す |
| ③ | 「今度みんなで」が「二人で」に変わる | 集団から個人的関係への移行 |
| ③ | 「また来よう」と言う | 再会を当然視する |
| ③ | 旅行・遠出の計画に相手が入る | 未来の共有を始める |
| ③ | 相手の夢や目標を応援する | 人生への関与を示す |
| ④ | 季節イベントを毎年一緒に過ごす | 暦の共有で関係を特別化する |
| ④ | 将来の計画に互いが前提として含まれる | 関係の不可逆性が確定する |

## 4. 触媒と制動

### 4-1. 触媒（越境のコストを下げる装置）

| 種類 | あるある | 働き |
|---|---|---|
| **非日常** | 祭り・花火・浴衣、旅行、文化祭、イルミネーション、遊園地 | 普段の規範を一時停止させる |
| **閉鎖** | 観覧車、停電、エレベーター、相合傘 | 逃げ場をなくし二人だけの空間にする |
| **弱体化** | 病気、深夜、疲労、雨で濡れる | 防御が下がり本音や接触が出やすい |
| **時間制限** | 転校・転勤・留学、別れ際、終電 | 「今しかない」で選択を迫る |
| **景観** | 夜景、海、川、展望台、夕焼けの教室、雪の夜 | 開放的な景色が感情の転換点になる |
| **感覚刺激** | 香り、体温、耳元の声、鼓動 | 視覚以外の情報で身体性を意識させる |

### 4-2. 制動（越境を止めてエネルギーを溜める装置）

| 種類 | あるある | 働き |
|---|---|---|
| **中断** | 電話、友人の乱入、告白の瞬間に邪魔が入る | 頂点を先送りし期待を蓄積する |
| **誤解** | 異性と歩いているのを見る（実は兄妹） | 一度落とし、解消時の反動を大きくする |
| **自己否定** | 「別に気にしてないし」 | 言葉と行動のズレで好意を逆証明する |
| **撤退** | 近づいた後、慌てて離れる | 好意と恐れの葛藤を可視化する |
| **逆行動** | 「あの人と付き合えば？」と言ってしまう | 本心と逆の行動で葛藤を強める |
| **保留** | 告白の返事を待たせる | 言語化後も緊張を持続させる |
| **喧嘩** | 言いすぎて後悔する、一時的に距離を置く | 失いたくない感情を明確にする |

### 4-3. 喧嘩・すれ違いからの回復あるある
- 仲直りのきっかけを探す → 関係維持への意思を示す
- 謝罪を言えず差し入れをする → 不器用な愛情表現
- 「嫌われたかも」と不安になる → 相手からの評価が重要になったと示す
- 冷たい態度の裏で本当は心配していたと後で判明 → 冷たさが愛情へ反転する
- 衝突を越えた関係は前より強固になる

## 5. 自覚の五つのトリガー

> 好意の自覚は内省ではなく**外からの刺激**で起こることがほとんど。

| トリガー | あるある | 仕組み |
|---|---|---|
| **比較** | ライバルの登場、他人と楽しそうな姿を見てモヤモヤ、元恋人の話に妙に反応 | 「なぜ嫌なのか」を問わされる |
| **外部言語化** | 「それ好きってことでしょ」「それデートじゃん」、家族の誤解 | 他人が先に名前をつける |
| **喪失予期** | 転校の知らせ、恋人がいるかもという噂、相手が誰かと付き合うかもと焦る | 失う可能性で価値が見える |
| **不在** | 会えない日が続く、相手がいないと少しつまらない | いないことで存在の大きさが分かる |
| **身体先行** | 目で追う、鼓動、返信を待つ、通知だけ反応が違う、メッセージを書いては消す | 行動が先に答えを出し、後から気づく |

### 5-1. 自覚の周辺あるある
- 自覚の瞬間の独白：「ああ、この人が好きなんだ」
- 自覚後のぎこちなさ：意識しすぎて普通に話せない
- 会う前に服装を気にする、褒められた服をまた着る
- 好きなタイプを聞く、「恋人いるの？」と遠回しに確認する
- 髪型や服装の変化に気づく
- ふとした表情を綺麗だと思う
- 家に帰ってから今日の会話を思い返す、夢に出てくる
- 失う可能性を想像して怖くなる

## 6. フェーズ構成

| フェーズ | 主に動く軸 | 主な越境段階 | 代表的なあるある |
|---|---|---|---|
| **P1 他者から個人へ** | A・E | ①② | 最悪の出会い、偶然の再会、意外な一面、名前を覚える |
| **P2 習慣化** | A・C | ① | 一緒に帰る、用のないメッセージ、内輪ネタ |
| **P3 内側へ** | C・B | ②→③ | 弱さの目撃、看病、打ち明け、初めて部屋に上がる |
| **P4 特別扱い** | F | 無自覚の③ | 自分にだけ態度が違う、好みを覚えている |
| **P5 自覚** | 外圧 | — | §5 のトリガー |
| **P6 臨界** | D・E | ③の寸前で停止 | 顔が近づいて止まる、言いかけてやめる |
| **P7 言語化** | 全軸 | ④を言葉で確定 | 告白、両片想いの判明 |
| **P8 再階段** | 全軸を再度 | 深度を上げて①→④ | 恋人つなぎ、初デート、家族への紹介、初喧嘩 |
| **P9 一線の手前** | B・D の最終段 | ④の確認 | §9 |

### 6-1. P1 出会いあるある
- 最悪の出会い（ぶつかる、口論、誤解から嫌い合う）→ 後の評価逆転の振れ幅を最大化
- 偶然の再会（さっきの人が転校生・上司・隣人）→ 運命感と継続の理由
- 強制的な接点（席替え、プロジェクト、同居）→ 意思と無関係な言い訳つき接近
- 忘れ物・落とし物を届ける、道案内・手伝い → 小さな善意で印象を更新

### 6-2. P6 臨界あるある
- 顔が近づき双方が止まる → 境界直前の緊張を最大化
- 視線が目 → 口元 → 目へ移る → 言葉にならない意識
- 視線が合ったまま逸らせない → 相互意識を無言で確定
- 「もし〜だったら」の仮定話 → 告白の探り合い
- 「あのさ…やっぱなんでもない」 → 引き延ばしで期待を最大化
- 他愛ない話ばかりして本題に入れない
- 「どうしてそんなに優しいの？」「誰にでもそうなの？」 → 特別扱いの確認
- 「自分だけだと思ってた」と漏らす → 独占欲が恋愛感情へ接続
- 「まだ帰りたくない」「もっと一緒にいたい」 → 告白より一段弱い表出
- 別れ際に何度も振り返る、帰り道だけ急に静かになる
- 名前だけを呼んで沈黙する

### 6-3. P7 言語化あるある
- 「話がある」と呼び出す → 転換点を予告する
- 別れ際に呼び止める、一度離れて振り返って戻る → 理性から感情への転換
- 走って追いかける（空港・駅・去りゆく相手）→ 必死さが感情の強さを示す
- 勢いで言ってしまう告白（口論中の「好きだからだよ！」）→ 計画外の本音の真実味
- 両片想いの判明（「実は俺も前から」）→ 我慢が報われるカタルシス
- 返事の保留 → 告白後も緊張を延長
- 言葉の代わりの初めてのキス → 関係成立の象徴的一線

### 6-4. P8 再階段あるある
- 「付き合ってる」と周囲に言えるか問題 → 関係の公認化
- 初デートの緊張（服選び、何を話すか）
- 恋人になってからの方が照れて話せない → 変化の逆説的表現
- キスの二度目・三度目で意味が変わる → 慣れと高まりの同時進行
- 相手の家族に会う、合鍵を渡す
- 初めての喧嘩と仲直り
- 将来の話をする（「いつか一緒に」）

## 7. 初期値プロファイル（関係類型別）

> 二人の関係の出発点で、七軸それぞれがどの段階にあるかを決めると、物語の開始フェーズが決まる。

| 関係類型 | 高い軸 | 低い軸 | 開始フェーズ |
|---|---|---|---|
| **幼なじみ** | A・C・G（④近く） | D・E（①のまま） | P6 臨界から始まる |
| **最悪の出会い** | ほぼなし（F はマイナス） | 全軸 | P1 から長く登る |
| **上司と部下** | A・B（口実が豊富） | E（敬語が最後まで残る） | P2〜P3 |
| **同居・契約関係** | B・A（強制的に高い） | C・F | P3、ただし空間だけ先行 |
| **ネットで知り合う** | C・A（言葉の上では深い） | B・D（物理的にゼロ） | 対面が P1 の再起動になる |
| **元恋人との再会** | G の残骸、C | A・B（断絶中） | P5 自覚の再演から始まる |

## 8. スロープの法則

1. **差分の法則**
   親密さは絶対距離ではなく**前回からの差**で感じられる。「手をつなぐ」より「前は袖をつかんでいた人が、今回は自分から手を取る」の方が強い。

2. **限定解禁の法則**
   「他人には許さない／見せないものを、その人にだけ許す」ことが特別性の根拠になる。笑顔、弱音、部屋、家族の話、秘密、呼び方、接触、沈黙、失敗した姿を段階的に解禁するだけで自然な恋愛曲線が作れる。

3. **口実剥離の法則**
   口実つきで越えた境界を、**口実なしでもう一度越えたとき**、それは恋になる。雨でもないのに傘に入る、寒くないのに手をつなぐ。①→③の移行の瞬間がもっとも甘い場面になる。

4. **寸止め蓄積の法則**
   未遂の回数だけ、到達時のカタルシスが大きくなる。P6 臨界は長いほど効く。

5. **外圧自覚の法則**
   自覚は内省でなく外圧で起こる。自覚の場面には外部の誰か・何かを配置する（§5）。

6. **非対称の法則**
   二人が同時に同じ段階にいることはまれ。片方が先に一段上がり、もう片方が追いつくまでの**時差**がドラマを生む。両片想いはこの時差が双方向に隠されている状態。

7. **軸ずれの法則**
   軸ごとの進度のズレがキャラクター性を作る。
   - 身体は近いのに情報は閉じている → 遊び人型・ミステリアス型
   - 情報は深いのに身体は遠い → 親友型・幼なじみ型
   - 優先は高いのに言語が遠い → ツンデレ型・不器用型

8. **反復と変奏の法則**
   序盤の場所や行為を終盤で再演し、差分を見せる。秘密の場所の再訪、最初の傘の場面の反転。

9. **再階段の法則**
   交際後も同じ七軸をより深い段階で一周し直す。交際後の物語がだれないのはこのため（P8）。

## 9. 一線の手前（P9）の処理

> 直接描写を避ける場合の定番手順。B 空間と D 身体の最終的な④承認を、言葉と象徴で処理する。

| 段階 | あるある | 働き |
|---|---|---|
| **打診** | 「泊まっていく？」「今日、親いないんだ」 | 言葉の裏を双方が理解している緊張 |
| **準備** | 部屋を片付ける、服を選ぶ、落ち着かない | 期待と不安を行動で示す |
| **確認** | 「いいの？」「うん」 | 同意と信頼の確認で誠実さを担保する |
| **ためらいの受容** | 怖さを吐露する／「待つよ」 | 急がない姿勢が信頼を深める |
| **中断** | 邪魔が入る、片方が泣く、笑ってしまう | 「まだ大事にしたい」を描く寸止め |
| **沈黙** | 言葉が減る、照明を消す、カーテンを閉める | 空気の変化を象徴で示す |
| **暗転** | 場面転換、翌朝へ飛ぶ | 越えたことを直接描かずに伝える |
| **余韻** | 翌朝の照れ、呼び方・距離感の変化 | 差分の法則で関係の変質を示す |

## 深掘り用の問い

必要な問いを選び、答えを `character.md`、`design_specification.md`、`_meta.md` など作品の適切な正本へ記録する。

1. 二人は物語の始まりで、七つの軸のそれぞれどの段階にいるか。どの軸から開くか。
2. 口実つきで越えた境界を、どの場面で口実なしにもう一度越えるか。
3. 自覚の場面に置く外圧は何か（比較・外部言語化・喪失予期・不在・身体先行のどれか）。
4. どちらが先に一段上がり、もう片方が追いつくまでの時差はどれくらいか。
5. 寸止め（臨界での停止）を何回置き、何がそれを止めるか。
6. 序盤のどの場所・行為を、終盤でどう変えて再演するか。
7. 交際後に、どの軸をより深い段階でもう一周させるか。
