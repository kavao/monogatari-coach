# リアリティの設計

一般エピソード技法のうち、説得力の配分。索引は [episode_.md](episode_.md)。

読者が「本当らしい」と感じる状態を、情報の総量ではなく説得力の配分として扱う。
（関連文書：[多人数物語のテンポ設計](episode_tempo_ensemble.md#第iv部多人数物語のテンポ設計)／[物語序盤の設計](episode_tempo_ensemble.md#第i部物語序盤の設計)／[足を引っ張るキャラクターの設計](episode_hindrance.md)）

---

## 0. 前提を置き換える

リアリティとは、現実と一致していることではない。

読者は作中の記述を現実と照合していない。照合しているのは**作中の他の記述との整合**である。現実に反していても整合していれば通り、正確でも整合していなければ落ちる。取材が十分なのに嘘くさい原稿は、事実の不足ではなく、事実同士の接続が示されていないことに由来する。

> **リアリティ ＝ 得られた説得力 ÷ 読者に要求した認知コスト**

この式から二つの帰結が出る。分子を増やす手だけでなく、分母を減らす手も同じ効果を持つこと。そして「情報を足したのに嘘くさくなる」現象は、分子が伸びずに分母だけが増えた状態として説明できることである。

### 主変数は情報量ではない

「情報が多すぎる／少なすぎる」という言い方は、量を測る基準がないため判断が書き手の主観に戻ってしまう。実際に効いている変数は、**新規スキーマの導入コスト**である。

読者が既に持っている枠組みに乗る情報は、ほぼゼロコストで通る。コストが発生するのは、読者の中にまだ存在しない枠組みを新設するときだけである。

| 種別 | 例 | コスト |
| --- | --- | --- |
| 既知への接続 | 駅、剣、担任、上司 | ほぼ無 |
| 既知の変形 | 空を走る鉄道、女性だけの騎士団 | 小（差分のみ提示） |
| 新設 | 独自の魔法体系、架空の身分制度、特殊業界の慣行 | 大（用語＋規則＋例外） |

同じ文字数でも、既知への接続なら軽く、新設なら重い。**総量ではなく内訳を見る。**

目安として、一つの章で新設できるスキーマは1〜2個である。3個以上を並行して立ち上げると、読者はどれも定着させられないまま先へ進むことになる。

## 1. 「リアルに感じない」の原因分解

同じ症状に対して、必要な処置は四通りある。ここを取り違えると、書けば書くほど悪化する。

| 原因 | 症状の出方 | 処置 |
| --- | --- | --- |
| 情報の不足 | 何が起きているか像を結ばない | 既知への接続を一つ置く |
| 内的不整合 | 細部は書かれているのに信用できない | 既出記述との噛み合わせを直す |
| 視点の漏れ | 妙に説明くさい、語りが浮く | 誰が見ているかを固定する |
| 密度のずれ | 退屈、または情報が頭に入らない | 場面ごとの解像度を配分し直す |

「足りないから足す」で解けるのは一行目だけである。二行目以降に足すと、不整合の分量が増え、視点の漏れが広がり、密度がさらにずれる。

---

## 2. 説得力は説明ではなく帰結で払う

設定の説得力は、その設定が引き起こす**不便・コスト・選択の制約**を一度見せると成立する。制度の説明を千字書くより、その制度のせいで人物が一度困る場面のほうが安い。

> **リアリティは名詞ではなく動詞で払う。**

**適用例**

> 「この国では魔法の使用に登録が要る」（説明）
> ↓
> 主人公が急場で魔法を使い、翌日、届出の遅延で罰金の通知が届く（帰結）

後者は説明を一切していないが、登録制の存在・運用の厳格さ・主人公の階層までが同時に伝わる。

この原則は削る作業の可否判定にも使える。**説明を削れるのは、帰結が別の場面で代払いしているときだけ**である。代払いの当てがないまま削ると、単に薄くなる。削る勇気の問題ではなく、支払い先の有無の問題として扱う。

---

## 3. 省略を正当化するのは視点

誰の目で見ているかを固定すると、省略に理由が生まれる。専門家は専門用語で世界を見るので説明しない。素人は誤認したまま通り過ぎる。**視点人物が知らない情報・興味を持たない情報が書かれていないことを、読者は欠落として処理しない。**

視点を決めていない原稿では、あらゆる情報が「書ける」ため、書かない理由を作者が自力で調達しなければならない。力みが生じるのはたいていこの状態である。

逆に、視点を固定すると次が自動的に決まる。

- どの用語に説明が要り、どれが要らないか
- 誰の内心が書けて、誰が書けないか
- 何を誤認したまま進めるか（＝後で反転させられる余地）

三つめは伏線の在庫になる。視点の制限は表現力の制約ではなく、**省略と反転の両方を生む生産設備**である。

---

## 4. 閾値は作品単位ではなく場面単位

説得力の線は作品全体に一本引かれるのではなく、感情の勾配に沿って上下する。

| 場面の位置 | 適正な解像度 |
| --- | --- |
| 世界や状況の導入 | 高め（ただし新設は絞る） |
| 感情が動く直前 | 低め |
| 感情の頂点 | 最低（一点に絞る） |
| 直後の余韻 | 中（喪失の実感は細部で出る） |
| 移動・準備・待機 | 低め |

感情が動く直前に解像度を上げると、読者の注意が細部に吸われて勾配が鈍る。「過度に詳しい」がノイズになるのは絶対量の問題ではなく、**密度の山と感情の山がずれている**からだと見たほうが、判定が具体的になる。

前掲の[多人数物語のテンポ設計](episode_tempo_ensemble.md#第iv部多人数物語のテンポ設計)で扱った変化密度と同じ構造で、ここでも問題は総量ではなく配分にある。

---

## 5. 削除ではなく移送

愛着の問題は、作中から消すことを「破棄」と定義しているかぎり解けない。

作者が保持する層と、読者へ出力する層を最初から分けておく。設定資料・年表・人物ノートへ移送する運用にすれば、作中から外しても作者の中では失われない。削除の心理コストはこの分離だけでかなり下がる。

副次的な効果として、移送された情報は**後で問われたときに答えられる状態**で残る。裏付けは提示しなくてよいが、存在はしていなければならない、という要求はこの層で満たす。

---

## 6. 力みの検出

心理として自己申告させると精度が出ない。文面の特徴として列挙したほうが、他人にも機械にも判定できる。

### 段落単位（書いた直後）

- [ ] 同じ主張が言い換えで二度書かれていないか
- [ ] 比喩の直後に、その比喩の解説が続いていないか
- [ ] 段落冒頭の主語が、人物ではなく設定・世界になっていないか
- [ ] 視点人物が知り得ない情報が地の文に混ざっていないか

### 場面単位

- [ ] 会話が、双方の既知情報の交換になっていないか
- [ ] 固有名詞の初出が短い範囲に集中していないか（目安：一度に定着するのは3〜5個）
- [ ] この場面の解像度は、感情の位置と合っているか
- [ ] 本筋に無関係な挿話が、思いついた順に投入されていないか

### 原稿全体

- [ ] 尺の長い情報が、実際に重要な情報と一致しているか
- [ ] 新設スキーマの数が、章あたり2個を超えていないか
- [ ] 説明だけで存在し、帰結を持たない設定が残っていないか

尺は重要度の信号として読まれる。重要でない事柄に文量を割くと、読者は重要度の判別を誤り、その迷いは退屈として処理される。

## 7. 診断

各設定・各展開に対して置く問い。

| 観点 | 問い |
| --- | --- |
| 寄与 | 読者の理解か感情のどちらかに寄与するか |
| 論理 | 理屈は通るか |
| 尺 | 現在の文量は重要度に見合っているか |
| **帰結** | この設定は、どこかの場面で帰結として払われているか |
| **視点** | 視点人物はこれを知っているか、口に出す動機があるか |
| **密度** | この解像度は、この場面の感情の位置と合っているか |
| **契約** | この作品は、読者にこの解像度を約束していたか |

太字の四つが、量の議論から抜け出すための追加項目である。とくに最後の「契約」は次節につながる。

---

## 8. 削りすぎたときの副作用

ここまでの原則は、突き詰めると逆方向に壊れる。

**情報そのものが娯楽の本体であるジャンルがある。** 考証もの、ハードSF、専門職もの、内政・鍛冶・料理・経営を売りにした作品では、詳細は読者が対価を払って読みに来ているものである。ここで「削れ」は端的に誤りになる。過度な精緻さがノイズになるのは、**それを目当てに来ていない読者に対してだけ**である。

> 閾値を決めているのは普遍的な美学ではなく、作品が序盤で読者と結んだ契約である。

したがって削る判断の前に、その作品が何を約束したかを確認する。序盤で精緻さを実演した作品は、以後それを供給し続ける義務を負う。逆に軽さを約束した作品が中盤で考証を始めると、同じ理由で契約違反になる。

**既知への接続だけで組むと、世界が既視感で埋まる。** コスト最小化を徹底すると、どこかで見た学校・どこかで見た王国になる。新設スキーマの予算は節約するものではなく、**どこに使うかを決めるもの**である。1〜2個という制限は、その1〜2個を作品の中心に置くための制限である。

**省略は、動機がないと不親切に落ちる。** 隠すことと書かないことは違う。驚きは情報を欠落させれば生まれるのではなく、**読者に別の妥当な解釈を保持させ続ける**ことで生まれる。誤誘導が機能していた期間の長さが、反転したときの効き目になる。単に書かなかっただけの情報は、明かされても驚きではなく事後説明として読まれる。

**抽象化しすぎると、感情の足場が消える。** 帰結で払う原則を徹底しても、帰結が抽象的な損得の記述になっていては同じことである。払いは具体物で行う。失った腕、空いたままの椅子、届いた罰金通知。

## まとめ

書くときに見るべきなのは、

> この情報は正しいか

ではなく、

> **この情報は、いま読者のどの判断を助けているか**

である。リアリティは情報の総量ではなく、読者がその場で納得できる説得力の設計である。力みとは、その設計を厚く見せようとして設計そのものを壊す動きを指す。

増やすか削るかは好みの問題ではない。説得力の線に届いていないのか、線の上で冗長になっているのか、そもそも線がどこに引かれる契約だったのか、という三段の判断である。
