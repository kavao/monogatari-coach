# 婚約からの離脱（二つの帳簿・旧配置・Phase 1〜10）

一般エピソード・物語構成技法のうち、家や周囲が決めた婚約から主人公が離れる、または婚約の中身を組み直す物語の流れと部品。索引は [episode_.md](episode_.md)。

> 原資料（来歴）: `C:/Users/Owner/Downloads/婚約から逃げる/engagement-departure-flow.md`（婚約から離れ、自由を勝ち取る若い女性の物語：流れと部品）。2026-11-04 に `episode/general/` の葉として導入。導入版では、発動条件・本資料の注意・Monogatari Coach での使い方（関連する葉と境界）・深掘り用の問い・作業用への導入を足した。0〜5節と Phase 1〜10 は番号のまま残し、新しい Phase・組み合わせ例は足していない。原資料は変更していない。

家や領地の都合で決まった婚約から、主人公が何かしらの理由で離れる、あるいは関係を組み直し、自分の意思と能力で立ち位置を取り戻す物語の型を、**フェーズごとに選べる部品**として整理したものです。

本文では、この型をより正確に次のように定義します。

> **決められた婚約から、自分で選ぶ立場へ移る女性主人公の物語**

善悪の判定は行いません。娯楽の型として、どの部品を選ぶとどんな読み味になるか、なぜその部品が効くのかを記述します。

## 発動条件

> 家や周囲が決めた婚約から主人公が離れる、または婚約の中身を組み直して自分で選ぶ立場へ移る物語（婚約破棄・婚約解消・許嫁や政略結婚からの離脱・契約婚の組み直し・選び直し・非婚・別の家や土地への移籍）の流れを設計する場合に選ぶ（既定では読まない。婚約が背景の設定にあるだけでは選ばない。悪役令嬢の破滅回避・断罪・ざまぁのジャンルの約束は `genre/akuyaku_reijo.md`）。

## 本資料の注意

- 原資料は女性主人公を想定して整理している。発動条件は主人公の性別を問わない。男性主人公や性別を問わない主人公で使うときは、部品を読み替えて使う。
- 婚約・家・爵位・領地の制度は、架空世界の物語向けの定型として扱う。史実の制度として扱わず、実在の家や爵位の性質として書かない。
- Phase 1〜4 と 9〜10 が骨格で、5〜8 は挿入・省略・順序交換ができる（§2）。一本道のプロットテンプレートとして全 Phase を順に埋めない。
- 上昇・下降の数値（§1-4、§3）は読み味の目安であり、計算の規則ではない。

## Monogatari Coach での使い方

家や周囲が決めた婚約から主人公が離れる（または組み直す）流れが作品の骨格になるときに、Plan Mode で参照する。また、離脱のあとの展開が平板・目的不明になったときに、どの Phase の部品が抜けているか、帳簿をどこまで開いているかを診断するのに使う。

| 作品資料 | 主に反映する項目 |
|---|---|
| `character.md` | 主人公の帳簿（自由・尊重・能力など何を求めるか）、個人と役割のずれ（Phase 2）、元の相手の人物像と着地（Phase 8） |
| `design_specification.md` | 骨格の Phase の置き場所、選択式の Phase（5〜8）の採否と順序、第一の山（Phase 4）と第二の山（Phase 9）の章、確証の組み方（内的・外的） |
| `world.md` | 婚約が家の帳簿で必要とされる事情（領地・家格・同盟など。Phase 1）、閉じたままにする帳簿の項目（§5） |
| `_meta.md` | 主人公の上昇と旧側の下降の目安、帳簿の開き方（Phase 7）、閉じたままの帳簿の項目 |

設計時は、最低限次を決める。

- 婚約の事情（Phase 1）と、主人公個人と役割のずれ（Phase 2）を決める。
- 離れるのは婚約そのものか、婚約の中身か（Phase 4、§1-2）を決める。
- 選択式の Phase（5〜8）のうち、どれを入れ、どれを省き、7 と 8 をどちらの順にするかを決める。
- 選択を何で確かめるか（内的確証・外的確証。Phase 9、§1-3）と、旧側をどこまで下げるか（§1-4）を決める。
- 家の帳簿をどこまで開くか（Phase 7）と、閉じたまま終える項目（§5）を決める。
- 帳簿・旧配置・Phase 番号・確証・上昇と下降・組み合わせ例の名前は設計の語である。物語案・あらすじ・キャラクター紹介には出さず、人物と出来事で書く（`_how_to.example/synopsis_presentation.md`）。

## 0. この型の芯

> 家の帳簿で決まった婚約を、主人公個人の帳簿で読み直し、旧配置から離れる（または組み直す）。
> そのあと、新しい配置でも主人公の価値や生活が成り立つと示され、選択が確かめられる。

- 快楽の頂点は**離脱そのもの**ではなく、**離脱・再編のあとに選択が確かめられる瞬間**にある
- 見かけの分岐は多いが、着地は「主人公の自己評価が下がらなかった位置」に集まる
- 年上の婚約者という設定は必須ではない。「決定権の非対称」を短く伝える記号として使いやすい

## 1. 四つの基本概念

各フェーズの部品が「なぜ効くのか」を説明するための概念です。

### 1-1. 二つの帳簿

| 家の帳簿 | 主人公の帳簿 |
|---|---|
| 領地・爵位・財政 | 自由・自己決定 |
| 外交・同盟・信用 | 尊重・愛情 |
| 後継・家臣 | 能力発揮・自己実現・将来 |

この型では、**婚約の成立は家の帳簿で説明され、婚約から離れる判断は主人公の帳簿で行われます**。途中で会計の主体が切り替わるのが、この型のもっとも大きな特徴です。

- **Phase 7（家の事情の決着）**は、いったん閉じた家の帳簿を、必要な範囲だけもう一度開く工程
- **閉じられた帳簿**（第4節）は、家の帳簿のうち物語が開かないまま終える項目

**「普通の善良な義務者」が扱いにくい理由**
責任感があり、家臣や領民のために婚約を受け入れた元の相手を最後まで置くと、家の帳簿を大きく開かざるを得ません。その結果、Phase 7 が巨大化し、物語は個人の物語から制度や共同体の物語へ移っていきます。

### 1-2. 旧配置

主人公が離れるのは、必ずしも「相手」ではありません。離れるのは、**他人によって決められた配置（旧条件）**です。

```text
旧配置から離れる
│
├─ 婚約そのものを手放す
│    ├─ 婚約解消
│    ├─ 家からの離脱
│    └─ 別の家・土地への移籍
│
└─ 婚約の中身を組み直す
     ├─ 契約条件を書き換える
     ├─ 権限や決定権を取り戻す
     └─ 同じ相手を自分の意思で選び直す
```

こう捉えると、婚約破棄、契約婚、選び直し、非婚、新しい恋愛、スローライフ、女領主化までを同じ骨格で説明できます。

### 1-3. 内的確証と外的確証

主人公の選択が正しかったことを、何によって示すかの違いです。

- **内的確証**：主人公自身が「これでよかった」と思う
- **外的確証**：世界が「その判断は正しかった」と応える（事業成功、領地繁栄、周囲の称賛、高位者からの求愛、家族の謝罪、元の相手の後悔、元の相手の問題の発覚など）

確証の組み方によって、同じ離脱でも物語の性格が変わります。

```text
【自由物語】
離れる → 自分が納得する

【再評価物語】
離れる → 能力を示す → 周囲が評価する → 以前の配置が過小評価だったと示される

【ざまぁ物語】
離れる → 主人公が上昇 ＋ 旧側が下降 → 相対的な評価まで逆転する
```

### 1-4. 主人公の上昇と旧側の下降

スカッとの強さは、主人公の上昇量だけでなく、**旧側（元の相手・家）の下降量**でも調整できます。

```text
                     旧側の下降：強
                           ↑
      没落見届け型         │         ざまぁ型
  （旧側の自滅を遠くで知る）│   （主人公上昇＋旧側下降）
                           │
主人公の上昇：弱 ──────────┼────────── 主人公の上昇：強
                           │
      静かな自由型         │       祝福・成功型
    （スローライフなど）   │   （誰も下げずに主人公が上がる）
                           ↓
                     旧側の下降：弱
```

目安の例です。

| 主人公 | 旧側 | 読み味 |
|---|---|---|
| ＋10 | −10 | 強いざまぁ |
| ＋10 | ±0 | 優しい成功譚 |
| ＋3 | ±0 | スローライフ |
| ＋5 | ＋5 | 円満分離 |

**「優しい世界」は、雰囲気ではなく「旧側を下降させない設計」として定義できます。**

## 2. 全体の流れ

**Phase 1〜4 と 9〜10 が骨格です。5〜8 は作品の読み味に応じて挿入・省略・順序交換ができます。** 一本道のプロットテンプレートではなく、部品の体系として使ってください。

```text
【設定】
  Phase 1  婚約の事情
     ↓
  Phase 2  個人と役割のずれ

【転換】
  Phase 3  きっかけ
     ↓
  Phase 4  旧配置からの離脱・再編（第一の山）

【再構築：選択式】
  Phase 5  揺らぎ ………… 省略可
  Phase 6  立ち上がり …… Phase 9 と融合可
  Phase 7  家の事情の決着 … 省略可、8 と順序交換可
  Phase 8  元の相手の着地 … 省略可、7 と順序交換可

【報酬】
  Phase 9  選択の確かめ（第二の山）
     ↓
  Phase 10 新しい均衡
```

## Phase 1｜婚約の事情

婚約が「恋愛ではなく家同士の契約」として置かれる段階です。家の帳簿がもっとも大きく開いている状態です。

| 型 | 内容 |
|---|---|
| 領地維持 | 財政・防衛・交易・水利のため |
| 家格維持 | 爵位・家名・血統の都合 |
| 同盟 | 家同士、国同士の安定 |
| 救済 | 没落・借金・戦災からの立て直し |
| 約定 | 親世代の約束・恩義 |
| 後継 | 家の継承・養子縁組の要請 |

**書き方のメモ**
- 事情を具体的に書くほど、後の Phase 7 で帳簿を開き直す作業が重くなる
- 優しい世界寄りにするなら、事情は「誰も悪くない必要」として置くと、全員を悪役にせずに済む

---

## Phase 2｜個人と役割のずれ

中心にあるのは、**主人公個人の価値・希望と、割り当てられた役割が一致していない**という状態です。

- **人格を見られていない**：妻、領主夫人、後継の母としてのみ期待される
- **才能を使わせてもらえない**：経営、魔法、薬学、学問などの力が婚約の枠内では生かされない
- **意思決定権がない**：本人の意見を聞く場がない
- **評価はされているが、家の事情が優先される**：能力も人格も認められたうえで、家のために役割を引き受けてほしいと求められる
- **適性が合っていない**：本人の資質と、求められる役割の性質が噛み合わない
- **感情の温度差**：相手に悪意はないが、主人公に関心が向いていない
- **直接の冷遇**：無視・軽視（強めのスカッと寄り）

**優しい世界寄りの選び方**
- 「冷遇」より「温度差」「適性が合わない」「評価されているが家が優先」を選ぶと、誰も悪人にしなくても離れる動機が立つ

## Phase 3｜きっかけ

旧配置から離れる、あるいは変えることが可能になる段階です。

| 型 | 内容 | 読み味 |
|---|---|---|
| 自覚 | 「この形でなくてもいい」と気づく | 静か、内省的 |
| 能力の発見 | 自分で生きていける力に気づく | 前向き |
| 第三者の言葉 | 誰かに「あなたには別の道がある」と言われる | 背中を押される |
| 事情の変化 | 事業成功・相続などで婚約の必要が薄れる | 円満に進めやすい |
| 相手からの申し出 | 相手側が婚約解消や見直しを切り出す | 受動だが傷は浅い |
| やり直し | 前の人生で結末を知っている | 決断の迷いが少ない |
| 相手の問題の発覚 | 不誠実・不正が明らかになる | スカッと強め |

---

## Phase 4｜旧配置からの離脱・再編（第一の山）

主人公が手放すのは「相手」ではなく、**自分に割り当てられていた旧条件**です（→ 1-2）。

### 婚約そのものを手放す

| 形式 | 内容 | 次の展開 |
|---|---|---|
| 話し合い | 両家や本人同士で解消を合意する | 円満分離へ |
| 静かな旅立ち | 置き手紙を残して新天地へ | 辺境再起・スローライフへ |
| 公の場での表明 | 夜会・式典で意思を示す | 評価の逆転が同じ場で起きやすい |
| 移籍 | 別の家・別の土地の役目に就く | 新しい居場所の物語へ |

### 婚約の中身を組み直す

| 形式 | 内容 | 次の展開 |
|---|---|---|
| 条件の書き換え | 期限付き・契約婚・形式だけの婚姻に変える | 関係を保ったまま自由を得る |
| 権限の回復 | 決定権や仕事の裁量を取り戻す | 領地経営・女主人としての物語へ |
| 選び直し | 同じ相手を、今度は自分の意思で選ぶ | 選び直しロマンスへ |

**優しい世界寄りの選び方**
- 「話し合い」や「組み直す」側の形式は、家の帳簿を完全に閉じずに済むので、後で無理が出にくい

---

## Phase 5｜揺らぎ（省略可）

離れた直後、あるいは組み直した直後の小さな試練です。多くは Phase 6 への前振りになります。

- 慣れない土地・仕事での苦労
- 家族の心配や反対
- 「本当にこれでよかったのか」という迷い
- 立場を失ったことによる不便

**書き方のメモ**
- ここを短くするとテンポ重視、長くすると成長物語寄りになる
- 迷いを一度きちんと書くと、Phase 9 の内的確証が「ご褒美」ではなく「実感」として読める

---

## Phase 6｜立ち上がり（Phase 9 と融合可）

新しい配置でも主人公の価値や生活が成り立つことを示す、**実証**の段階です。

**能力で立つ**
- 領地経営・商売・薬学・料理・魔法・技術知識
- 前世知識や学んできたことが生きる

**居場所で立つ**
- 新しい土地・職場・工房・領地
- 主人公を必要とする人々（領民、仲間、弟子）

**理解者と出会う**
- 仕事の相棒（商人、学者、騎士、職人）
- 主人公の力を言葉にして認めてくれる人

> 注：才能を言葉にする人は、恋愛対象でもよく、仕事の相棒でもよい。称賛の速さが読み味を決める。
> （出会ってすぐ認めるほどスカッと寄り、時間をかけて認めるほど成長物語寄りになる）

**書き方のメモ**
- 「能力の実証」と「それを認める理解者」を組み合わせると安定する
- 能力を Phase 1〜2 のうちに少し見せておくと、後付け感が減る

---

## Phase 7｜家の事情の決着（省略可、Phase 8 と順序交換可）

いったん閉じた**家の帳簿を、必要な範囲だけもう一度開く**工程です。「そもそもその婚約は、何の問題を解決するための契約だったのか」を回収します。

| 型 | 内容 | 読み味 |
|---|---|---|
| 主人公が別の形で解決 | 能力や事業で家の問題を助ける | 家族とも和解しやすい、もっとも優しい |
| 関係者の協力で解決 | 元の相手・新しい仲間と協力して別の手段を探す | 全員が報われる |
| 事情の変化 | 情勢が変わり、婚約の必要自体が薄れる | 自然な決着 |
| 誤解の解消 | 必要だと思われていた事情が、実は違っていた | 軽やか |
| 家が別の道を選ぶ | 家族が主人公の選択を受けて方針を変える | 家族の成長も描ける |
| 物語の外に置く | 主人公が新天地に移り、元の事情は描かない | テンポ重視 |

### 帳簿の開き方による調整幅

| 開き方 | 作品の性格 |
|---|---|
| 閉じたまま | 軽い作品。テンポ重視 |
| 事情の変化で処理 | 少し丁寧な作品 |
| 全員で代替案を作る | 優しい作品 |
| Phase 7 自体を第二幕にする | 制度劇・領地経営劇 |

## Phase 8｜元の相手の着地（省略可、Phase 7 と順序交換可）

旧側の変化の列は、1-4 の「旧側の下降」との対応です。

| 型 | 内容 | 旧側の変化 | 読み味 |
|---|---|---|---|
| 別の幸せへ | 元の相手にも別の縁や役目が見つかる | 上昇 | もっとも角が立たない |
| 協力者になる | 婚約は解消し、仕事や政治の仲間として残る | 上昇 | 大人の関係 |
| 誤解が解ける | 冷たさには理由があったと判明し、関係を選び直す | 上昇 | 選び直しロマンス |
| 理解して見送る | 主人公の選択を認め、身を引く | 維持 | 優しい。後見人になることも |
| 静かに退場 | 物語から自然に離れる | 維持 | シンプル |
| 後悔する | 手放したあとで価値に気づく | 下降 | スカッと強め |
| 問題が明らかになる | 不誠実・不正が露呈する | 大きく下降 | スカッと最強 |

**優しい世界寄りの選び方**
- 旧側が「上昇」か「維持」の型を選ぶと、誰かを下げずに主人公を上げられる
- 善良で責任感のある元の相手を最後まで置く場合は、Phase 7 を「関係者の協力で解決」にすると、開いた帳簿を無理なく閉じられる

---

## Phase 9｜選択の確かめ（第二の山）

選択が正しかったと示す**確証**の段階です（→ 1-3）。

### 内的確証
- 主人公自身が「これでよかった」と思える
- 迷い（Phase 5）を越えた実感として描かれる

### 外的確証
- **成果**：領地が豊かになる、事業が成功する、人を助ける
- **承認**：領民・仲間・家族から認められる
- **関係**：理解ある相手と心を通わせる
- **元の側の変化**：家族や元の相手が主人公の選択を尊重する、謝罪する
- **相対的な逆転**：元の相手の後悔、問題の発覚

**書き方のメモ**
- 内的確証だけで閉じると自由物語、外的確証を重ねると再評価物語、旧側の下降まで入れるとざまぁ物語になる
- 「他人の評価は気にしない」主人公でも、物語は外的確証を置きがち。優しい世界寄りなら、外的確証を「ざまぁ」ではなく「祝福」として描くとよい

---

## Phase 10｜新しい均衡

```text
                 周囲からの承認が強い
                       ↑
     自立成功型        │       新しい縁・溺愛型
                       │
結婚しない ←─────────┼────────→ 結婚する（新たな縁・選び直し）
                       │
     気ままな自由型    │       条件を組み直した関係型
                       ↓
                 周囲からの承認が控えめ
```

| 着地 | 内容 |
|---|---|
| 自立成功型 | 仕事・領地・研究で身を立て、結婚は選ばない |
| 新しい縁・溺愛型 | 理解ある相手と結ばれる |
| 気ままな自由型 | 旅・スローライフ。大きな成功より日々の自由 |
| 条件を組み直した関係型 | 元の相手や家と、対等な形で関係を結び直す |

## 4. 最小構成

どの変種でも、次の六つがあれば型として成立します。

1. **旧配置** ― 家・制度・他者によって役割が決まっている（Phase 1）
2. **不一致** ― 主人公個人の希望・価値・能力と旧配置が合わない（Phase 2）
3. **転換理由** ― 旧配置から離れる、または変えることが可能になる（Phase 3）
4. **再選択** ― 主人公自身が新しい配置を選ぶ（Phase 4）
5. **実証** ― 新しい配置でも主人公の価値や生活が成り立つ（Phase 6）
6. **確証** ― 旧配置が唯一の答えではなかったと、本人または世界が示す（Phase 9）

この骨格で、婚約破棄、契約婚、選び直し、非婚、新しい恋愛、スローライフ、女領主化をすべて説明できます。

---

## 5. 閉じられた帳簿

家の帳簿のうち、物語が開かないまま終えやすい項目です。

- 家同士の信用・約束の重み
- 家臣や使用人、領民の暮らしへの影響
- 相続・後継の計画
- 次の縁談や外交への影響

これらを閉じるのは欠陥ではなく、個人の物語として成立させるための視野の選び方です。一部を開くと、制度や共同体の物語としての厚みが加わります。

優しい世界寄りの作品では、**一度だけ開いて、主人公や周囲の工夫で丁寧に閉じる**と、読後感を損なわずに奥行きが出ます。開く量を大きくするほど Phase 7 が膨らみ、作品は制度劇に近づきます。

## 深掘り用の問い

必要な問いを選び、答えを `character.md`、`design_specification.md`、`world.md`、`_meta.md` など作品の適切な正本へ記録する。

1. 婚約は家の帳簿のどの項目（領地・家格・同盟・救済・約定・後継）で説明されるか。
2. 主人公の帳簿で、婚約と合わないのは何か（人格・才能・意思決定権・適性・感情の温度差など）。
3. 主人公が手放すのは婚約そのものか、婚約の中身か。
4. 選択式の Phase（5〜8）のうち、どれを入れ、どれを省くか。7 と 8 はどちらを先にするか。
5. 新しい配置で主人公が立つ根拠（能力・居場所・理解者）は、Phase 1〜2 のうちにどこで少し見せておくか。
6. 選択を内的確証だけで閉じるか、外的確証を重ねるか。旧側をどこまで下げるか。
7. 家の帳簿のうち、どの項目を一度だけ開いて閉じ、どの項目を閉じたまま終えるか。
