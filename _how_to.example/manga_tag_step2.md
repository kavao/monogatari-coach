# Step2（ページ生成・抽象レイアウト）用の必読コンテキスト

**いつ開くか**: 互換 Markdown の **`### Step2`** を書く・改稿する、またはページ YAML の **`panels[].step2_summary`** を詰めるとき。**コマ単体生成向けの Step1 だけ**なら不要。

## Step1（`manga_tag.md`）との役割分担

| 項目 | Step1（コマ生成・精密ページのコマ素材） | Step2（ページ生成＝1ページ1枚） |
|------|------------------------------------------|----------------------------------|
| 主な参照 | **`manga_tag.md`**（語彙・`prompt_tags`・ネガの語） | **本ファイル** ＋ 長文テンプレは **`docs/image-generation/manga-tag-generation.md`** の「互換出力: step2」 |
| IR 上の主フィールド | `panels[].summary`、**`panels[].prompt_tags`**（英語トークン列） | **`panels[].step2_summary`**（無ければ `summary` を流用）、**`manga.panel_layout`**、**`panels[].composition.layout`** |
| 抽象度 | コマごとに具体的な作画・タグを優先 | **構図・位置関係・アングル・配置**に言い換え。強い行為名は**直接は前面に出さない**（モデレーション配慮とページ設計の両立） |

- **`manga_tag.md` の置き換え表・体位タグ**は Step1 の `prompt_tags` に効かせる。**Step2 の日本語要約**では、同じ語をそのまま英語タグ列にするのではなく、**「誰がどこにいてどう見えるか」**に落とす（下記チェックリスト）。

## 編集前チェックリスト（必ず満たす）

1. **誰が主役のコマか**、**誰と誰の関係か**、**そのコマの役割**が読める。
2. **セリフがある場合は話者**が分かる（モノローグか台詞かも曖昧にしない）。
3. **`接触` `対峙` `緊張` など抽象名詞だけで終わらない**。**外から見える構図**（位置・距離・視線・段・大小）で書く。
4. Step2 は **行為を消す**のではなく **行為を構図に言い換える**（例: 「殴る」→振りかぶった腕と受ける側の緊張が見える構図）。
5. **安全寄りにぼかすこと**と **何が画面に見えるかを空にすること**は別。**誰がどこに立ち誰を見ているか**まで残す。
6. **部分アップ**なら、**誰のどの部位か**、**何のためのコマか**を一言添える。
7. **ページ内位置**（上段／中段／下段・左右・大小）は、ページ生成で省略しにくい。**均等カットだけ**なら `均等Nコマ・上から読む` の一行でもよい。
8. 細かい髪色・目の色は **`step2_summary` 本文に毎回書かなくてもよい**。IR の **`character_snapshots`** / **`tag/characters/*.yaml`** がエクスポート時に【固定見た目】へ載る（詳細は [manga-tag-generation.md の Step2 節](../docs/image-generation/manga-tag-generation.md#互換出力-step2)）。

## 言い換えの目安（Step2 用・本ファイルが正本）

刺激の強い語や直球の行為名は、**配置・視線・距離・主従・表情・手元**に分解して書く。次表は**方向の例**であり、作品に合わせて `_how_to/manga_tag_step2.md` へ行を足してよい。

`novel_prompt_ir_validate.py` は**言い換え内容を検証しない**（上の表どおりかは見ない）。日本語の意味づけ・品質の正本は、引き続き **`panels[].step2_summary`**（無ければ `summary`）や手で整えた互換 Markdown の本文に**人が書き込む**こととする。

一方、**表に列挙した語の機械置換**だけは、ルール YAML（本表と同期）を **`forge_novel_manga_batch.py`**（`--source step2-pages`）および **`novel_prompt_ir_export_md.py`** が、環境変数 **`MONOCRI_STEP2_PARAPHRASE=1`** または **`--step2-paraphrase`** で**生成・エクスポート直前の文字列**へ適用できる（**`--no-step2-paraphrase`** で無効化。YAML IR ファイル自体は書き換えない）。

**ルール YAML の場所（優先順）**: （1）環境変数 **`MONOCRI_STEP2_PARAPHRASE_RULES`**（絶対パス、またはリポジトリルートからの相対パス）、（2）リポジトリ直下 **`_how_to/step2_paraphrase_rules.yaml`** があればそれ（ユーザー設計・プロジェクトごとの差し替えに向く）、（3）なければツール同梱の **`tools/manga_prompt_ir/data/step2_paraphrase_rules.yaml`**。表を増やしたら、運用で使っている YAML に `avoid` / `use` を追記し、長い `avoid` を先に並べる。

| 避けたい直球表現（例） | 構図・状態への言い換えの方向 |
|------------------------|--------------------------------|
| 抱きつく | 距離が近い二人。片方が相手の胸元へ寄り、もう片方がそれを見下ろす構図 |
| 殴りかかる | 大きく振りかぶった腕と、それを正面から受ける相手の緊張した構図 |
| 押し倒す | 上下の位置差が強い二人の配置。上側の人物が画面手前を占め、下側の人物が見上げる |
| 流血した負傷 | 乱れた衣服、苦痛の表情、体勢の崩れでダメージを示す |
| 胸が腹部に押し当てられて | 胸が当てられて |
| 腰に跨っている | 上に乗っている |

### 抽象語だけで終わらせない（補足例）

Step2 は **行為を消す**のではなく、**画面に見える配置・画角**へ言い換える。

- **言い換えの型（日本語要約のイメージ）**: 「接触」の代わりに → `右手を差し出す人物と、それを正面から見る相手の bust shot`。「忍耐」の代わりに → `うつむき気味で口を結び、肩に力が入った人物の close up`。
- **悪い例（これだけでコマ説明を閉じない）**: `接触`, `忍耐`, `信頼の揺らぎ`, `不穏`
- **良い例**: `机越しに向かい合う二人。左の人物が身を乗り出し、右の人物は椅子に浅く座って視線を受け止める` ／ `俯いた人物の目元と強く結ばれた口元の close up。背景を抜いて感情の硬さを見せる`
- **ページ生成の意図**: モデレーションに触れやすい語を**前面に出さず**、**配置・視線・距離・主従・表情・手元**で伝える。ただし **誰がどこに立ち誰を見ているか**は空にしない。

**経緯メモ**: 上の表と補足例は、もともと **`docs/image-generation/manga-tag-generation.md`** の Step2 節にあった語を、創作技法の正本として **`manga_tag_step2.md` に集約**したものです。**`_how_to/manga.md` に「言い換えの目安」の原文があったわけではありません**（`manga.md` から docs へ移したのは **ページ YAML の最小例**などで、[manga-prompt-ir.md の該当節](../docs/image-generation/manga-prompt-ir.md#yaml-minimal-step1) を参照）。

## 正本・ツール・詳細ドキュメント

- **ページ YAML の正本**: `novels/<作品>/manga/pages/manga_XX_pYY.yaml`
- **Step2 だけ弱めたいとき**: 同じコマに **`step2_summary`** を足し、Step1 用の **`summary`** は具体的なまま残す。
- **検証**: `python tools/novel_prompt_ir_validate.py`（文言の言い換え内容までは見ない）
- **長文テンプレ・エクスポート仕様・固定見た目の合成**: [`docs/image-generation/manga-tag-generation.md`](../docs/image-generation/manga-tag-generation.md)（「互換出力: step2」）
- **IR のフィールド関係**: [`docs/image-generation/manga-prompt-ir.md`](../docs/image-generation/manga-prompt-ir.md)
- **品質ゲート**（主語・レイアウト）: スキル **`manga-tag-quality-gate`**
