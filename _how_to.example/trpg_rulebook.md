# ルールブック: 例作品（恋愛・青春）

## 世界ルール
- 現代日本の高校が舞台。魔法・超常現象はない。
- 主人公が告白するか引き下がるかが毎章のゲート。
- GM は「主人公の内面（葛藤・決意）」を必ず描写する。

## パラメータ定義

### 好感度 ← 主人公（0〜10 数値）

- **範囲**: 0〜10
- **初期値**: 4
- **意味**: 0〜3: 無関心または敵意 / 4〜6: 気になる程度 / 7〜10: 意識している
- **更新条件**: 共同作業・助けのシーンで +1〜2。誤解・失言で −1〜2。GM が裁量。
- **表記例**: `好感度 ← 主人公: 4 → 6`

### 誤解度（0〜10 数値）

- **範囲**: 0〜10（高いほど「わかってもらえていない」感が強い）
- **初期値**: 5
- **更新条件**: 秘密を隠すシーンで +1〜2。打ち明けるシーンで −2〜3。
- **表記例**: `誤解度: 5 → 3`

### 自己肯定感段階（段階型）

- **段階リスト**: 低迷 / 模索 / 受容
- **初期値**: 低迷
- **昇格条件**: 章クライマックスで「自分を認める」選択をした場合。
- **表記例**: `自己肯定感: 低迷 → 模索`

### 緊張度（カテゴリ型）

- **カテゴリ**: 低 / 中 / 高 / 臨界
- **初期値**: 低
- **上昇トリガー**: 告白機会・二人きりのシーン・ライバル登場。
- **低下トリガー**: 会話が弾む・日常シーンへの帰還。
- **表記例**: `緊張度: 中 → 高`
