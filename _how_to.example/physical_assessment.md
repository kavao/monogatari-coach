# physical_assessment.md — フィジカルアセスメント・身体観察執筆参照資料

小説・脚本などで看護・医療・ケア・看病場面を描写する際の創作技法リファレンス。
臨床判断に用いるものではない。数値・手順は一般的な目安であり、施設や作品世界観の設定により調整してよい。

- **正本**: `_how_to.example/physical_assessment.md`（作業用は `_how_to/physical_assessment.md` にコピーして調整）
- **発動条件**: **既定では読まない**。看護師・医師・衛生兵・施療師などが登場する医療・病棟場面、または家庭や戦地での看病・検温・身体観察を緻密に描写する作品で選定する。

---

## 0. 基本思想・創作上の要点

- **フィジカルアセスメントの本質**: 視る（視診）・触る（触診）・聴く（聴診）・叩く（打診）・会話する（問診）を通じて、身体の状態を推定・評価すること。機器測定（体温・血圧・SpO₂）だけに依存しない。
- **診断とアセスメントの境界**: 看護師やケア側は原則として**病名を断定しない**。「〜の可能性がある」「兆候がある」と評価し、医師へ**報告**する。患者へ病名を断定して告げる描写は不自然になりやすい。
- **変化の重視**: 観察は「単発の絶対値」よりも**前回との比較・変化**（「昨日より」「さっきの検温のときより」）が物語の推進力になる。
- **ケアと観察の二重性**: 優しさ（安楽・スキンシップ）と観察は対立せず、同時に進行する（例：手を握って安心させながら、同時に皮膚温・冷汗・脈・握力の左右差を探る）。ただし、すべての接触を観察目的にしない（安楽そのものが主目的の接触もある）。

## 1. 基本の観察技法

| 技法 | 主な観察内容 | 描写における頻度・使いどころ |
|---|---|---|
| **視診** | 顔色、表情、呼吸の様態（肩呼吸・浅さ）、皮膚、姿勢、歩行動作 | 常時（部屋に入った瞬間から目線で語る） |
| **触診** | 皮膚温、湿り（冷汗）、脈拍、浮腫（むくみ）、圧痛、筋の緊張 | 高い（触れ合い・スキンシップと不可分） |
| **聴診** | 呼吸音、腸蠕動音（腹部の音）、心音 | 医療機器・聴診器を素肌に当てる緊張感 |
| **打診** | 指で叩いて音の響きを確かめる（腹部ガス、胸水など） | 日常観察ではやや低め、専門的な診察描写 |
| **問診** | 会話による主観情報 ＋ 応答速度・ろれつ・見当識 | 常時（自然な雑談の中に確認を織り込む） |

## 2. 観察の場面展開とワークフロー

### 2-1. 訪室直後の第一印象（数秒の初動）
ベッドや部屋に近づくまでのわずかな時間に全体を走査する。
- 呼びかけへの反応、視線が合うか。
- 顔色（蒼白・チアノーゼ・紅潮）。
- 呼吸の異変（速い、浅い、肩で息をしている、前かがみの起座呼吸）。
- 異常を感じた際は、詳細観察より先に応援要請やバイタル測定へ移る。急変時の基本軸は **A（気道）→ B（呼吸）→ C（循環）→ D（意識）→ E（体温・外表）**。

### 2-2. 定時のラウンド・検温
定時の見回りでは、単に体温計を挟むだけでなく、以下の要素を束ねて確認する。
- 意識レベル、痛みの程度、食事・水分摂取、排泄状況。
- **全員に全項目を見るのではなく、相手の病態・弱点部位に合わせて絞る**のがリアリティの鍵。

### 2-3. 日常ケアに組み込まれた観察（Show, don't tell）
何気ない世話の動作の中に、観察の目線が重なる。

| ケア動作 | 同時に観察・感知していること |
|---|---|
| **清拭・更衣** | 皮膚の乾燥・発赤、褥瘡の兆候（仙骨・踵）、浮腫、関節の可動域 |
| **体位変換** | 自力で動ける範囲、痛みの表情、皮膚の圧迫痕・赤み |
| **手浴・足浴** | 末梢の冷感、むくみ、爪の色、皮膚の細かな傷 |
| **食事介助** | むせ、嚥下（飲み込み）の音、手の震え、口腔内の汚れ |
| **排泄介助** | 尿や便の量・色・性状、下腹部の張り |
| **移乗・歩行介助** | ふらつき、歩幅、筋力の左右差、息切れの速さ |
| **布団を掛け直す** | 表情、呼吸の深さ、寝汗の有無 |
| **コップを渡す** | 指先の震え、確実に把持できるか、一口で飲める量 |

### 2-4. 報告と記録の作法
観察した内容は、判断と報告・記録で完結する。
- **SBAR（報告の型）**:
  - **Situation（状況）**: 「〇号室の患者です。呼吸数が28回に上がり、息苦しさを訴えています」
  - **Background（背景）**: 「心不全で入院中で、今朝から体重が1.5kg増加しています」
  - **Assessment（評価）**: 「肺で水泡音が聴こえ、心不全の悪化が疑われます」
  - **Recommendation（提案・要請）**: 「至急、診察と利尿薬の指示をお願いできますか」
- **申し送り**: 交代時や引き継ぎでは、「何事もなかったこと」ではなく**「前回からの変化・違和感」**を中心に伝える。

## 3. 部位・行為別の具体的観察

### 3-1. 手に触れる・手を握る
- 皮膚温（温かさ、冷感、左右差）。
- 湿り（冷汗はショックや循環不全の兆候）。
- 握る力、左右差（「右手をぎゅっと握ってください。今度は左手」＝麻痺や認知の確認）。
- 手首の内側に触れれば、そのまま橈骨動脈の脈拍（リズム・強弱・速さ）を探れる。

### 3-2. 脈拍の触診
- 示指・中指・薬指の3本を手首の親指側に当てる。**親指では測らない**（自らの脈を拾ってしまうため）。
- 通常は15秒〜30秒数えて換算。リズムが乱れている（不整脈）ときは1分間通して静かに数える。

### 3-3. 末梢循環と浮腫（むくみ）
- **CRT（毛細血管再充満時間）**: 爪を数秒白くなるまで圧迫し、離して元のピンク色に戻るまでの時間を見る（目安2秒以内）。
- **圧痕性浮腫**: すね（脛骨前面）や足の甲、手の甲を指の腹で5〜10秒ほど押し込み、指を離したあとに窪みが残るかを見る。
- **左右差の着目**: 片側だけの浮腫は局所（静脈血栓など）、両側の浮腫は全身性（心臓・腎臓・栄養状態など）を疑う材料となる。

### 3-4. 呼吸と聴診
- 聴診器は原則として**素肌に直接当てる**（衣類越しだと擦れ音で雑音が混ざる）。左右を交互に比べながら上から下へ進める。
- **副雑音の聴き分け**:
  - パチパチ、ブツブツという音（断続性副雑音・水泡音・捻髪音）：水分貯留、肺炎、肺水腫。
  - ヒューヒュー、笛のような音（連続性副雑音・喘鳴）：気道の狭窄、喘息、分泌物の詰まり。
- ひとつの音で決めつけず、呼吸数、肩の動き、表情と組み合わせて判断する。

### 3-5. 会話・見当識の確認
- 「今日は何月何日でしたっけ」「ここはどこか分かりますか」
- 質問に正しく答えられるかだけでなく、**返答までの間、声の張り、話の辻褄、視線の焦点**から、脱水・感染・せん妄・脳循環の変調を察知する。

## 4. 評価スケールと数値の目安（成人）

作中でカルテや報告、セリフに織り込むための標準値。

| 項目 | 正常・目安値 | 描写の着眼点 |
|---|---|---|
| **体温** | 36.0〜37.0℃ 前後 | 個人差があるため「平熱」との差が鍵 |
| **脈拍** | 60〜100回 / 分 | 頻脈（100超）は緊張・脱水・発熱、徐脈（50未満）はショック・薬の影響など |
| **呼吸数** | 12〜20回 / 分 | 呼吸数の増加（24超など）は悪化の最も早いサイン |
| **SpO₂** | 96〜99% | 90%を割り込むと明らかな低酸素状態 |
| **血圧** | 120/80 mmHg 未満が理想 | 急激な低下はショック、過度の上昇は疼痛や脳圧亢進 |

- **JCS（ジャパン・コーマ・スケール）**: 意識障害の深度（3-3-9度方式）。
  - Ⅰ（覚醒している）：Ⅰ-1（だいたい清明だが今ひとつ）、Ⅰ-2（日付や場所が不確か）、Ⅰ-3（名前が言えない）。
  - Ⅱ（刺激で覚醒する）：Ⅱ-10（呼びかけで開眼）、Ⅱ-20（大きな声・揺すぶりで開眼）、Ⅱ-30（痛み刺激でかろうじて開眼）。
  - Ⅲ（刺激しても覚醒しない）：Ⅲ-100（払いのける）、Ⅲ-200（手足を動かす）、Ⅲ-300（無反応）。
- **NRS（数値的評価スケール）**: 痛みの度合いを0〜10で客観化（「全く痛くないのを0、想像できる最大の痛みを10とすると、今はいくつですか」）。

## 5. 小説・脚本描写のチェックリスト

### リアリティを高めるポイント
1. **動作と観察の重ね合わせ**: 単に「脈を測った」と書くのではなく、布団の端を直しながら胸元の上下を見つめ、何気なく手首に指を添える。
2. **「いつもと違う」という直感の言語化**: バイタル数値そのものが正常範囲内であっても、肌の湿り気、返答のわずかな遅れ、瞳の光り方からベテランが違和感を抱く描写。
3. **視点の二重性**:
   - 受け手側（患者・被介護者）：「手を温かく握ってくれた、優しい言葉をかけてくれた」と安らぎを感じる。
   - 施術側（看護師・施療者）：「指先が異常に冷たい、脈がかすかに飛んでいる」と警戒を強めている。

### 避けるべき不自然な描写
- 看護師が医師のように病名を断定する（「これは心筋梗塞ですね」→「血圧が下がって胸の痛みを訴えています、心電図を取りましょう」など状況・所見を伝えるのが自然）。
- 親指で脈を測ってしまう（親指の動脈と混同するため厳禁）。
- 厚手の衣服やセーターの上から聴診器を当てる。
- 単一の所見だけで即座に確定的な判断を下す。
- すべての患者に対して機械的に頭から爪先までの全身検査を毎ラウンド行う（実際は疾患に合わせて絞る）。

### 会話・台詞の例
- 「ちょっとお手を失礼しますね。……少し冷たいかな」
- 「右手、ぎゅっと握ってもらえますか。はい、今度は左」
- 「靴下、少しずらしますね。足、むくんでないか見せてください」
- 「大きく吸って……はい、吐いて。もう一回お願いします」
- 「今日って何日でしたっけ？」（さりげない見当識確認）
- 「お話ししながら、廊下の端まで歩いてみましょうか」
- 「痛みは0から10でいうと、今どのくらいですか」
