# 現代日常・家族・ヒューマンドラマ 執筆リファレンス

家族再生、共同生活、介護、喪失、居場所づくり、仕事と人生を扱う、**非事件型の物語**（殺人も陰謀も戦争も起きない話）の定番型をまとめた作劇用資料。
出来事ではなく、関係と日常の差分を設計するための足場とする。

---

## Monogatari Coach での使い方

「家族もの」「ヒューマンドラマ」「日常もの」「家族再生」「共同生活・シェアハウス」「介護」「喪失・死別」「居場所」「定年・継承」など、外部事件に頼らない作品の Plan Mode で参照する。
定番を全部採用するための一覧ではなく、作品を動かす圧力、反復する場面、最後に変わって見えるものを選ぶためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 中心原理のどれを約束するか、物語の中心にある不在、結末の型（元には戻らない／折り合えない並走など） |
| `config.md` | 扱う分野（家族・共同生活・介護・喪失・居場所・仕事）、時間スパン、トーン、喪失や介護の描写の重さ |
| `design_specification.md` | 物語圧と駆動パターン、装置 A〜G の配置、反復場面、時間の区切り（期限・季節・法要・最後の○○）、冒頭と終盤の対応 |
| `world.md` | 舞台となる家・店・地域、生活の制度（相続・施設・学校・会社）、小道具と舞台、連絡手段 |
| `character.md` | 家族ホメオスタシス上の役割、役を降りる人物、介護者の年代、喪失への反応、言えなかった一言 |
| `_meta.md` | 反復場面ごとの差分、変わった生活行動（するようになった／やめた）、未解決のまま残す問題、法要や季節の進行 |

設計時は、最低限次を決める。

- 事件の代わりに時間を区切るもの（期限・季節・法要・最後の○○）を一つ以上置く。
- 物語の中心にある不在と、それを埋めようとする役割の組み替えを決める。
- 冒頭と終盤で再利用する場面・物・行動を一つ選び、意味の変化を先に設計する。
- 人物の感情を確定させる選択（残す／捨てる、帰る／残る、かける／かけない）を少なくとも一つ置く。
- 結末は「元通り」ではなく「どう折り合ったか」で書く。問題が未解決のまま関係の形だけ決まる着地も選択肢に入れる。
- 介護・病・死別・相続・制度の記述は創作上の定型であり、具体的な手続きや医療・福祉の実務を本文で確定させるときは別途資料を確認する。
- 一話・一場面単位のフックや親愛描写は `episode/` の葉（親愛・関係・責任移行など）を使い、本資料は作品全体の構造に使う。

## 0. 中心原理

### 原理1：変わった日常に新しい形を与える

> **壊れた日常を元に戻すのではなく、変わってしまった日常に新しい形を与える**

外部事件がなくても、次の流れだけで一本の物語になる。

```text
日常のズレ
↓
放置できない小さな不都合
↓
一緒に何かをする
↓
相手について知らなかったことが見える
↓
役割・距離・認識が変わる
↓
以前とは少し違う日常になる
```

成功条件は「問題の解決」ではなく **人と人の距離が少し変わること**。世界も社会も変わらず、問題も完全には片付いていなくてよい。

### 原理2：出来事ではなく差分を設計する

> **同じ食卓、同じ人物、同じ味噌汁、同じ「いただきます」。なのに第1話と最終話では意味が違う**

この差分がクライマックスになる。設計すべきは「何が起こるか」ではなく **「何が以前と違って見えるようになったか」**。

### 原理3：感情は台詞ではなく生活行動で見せる

> **感情の変化は、台詞より生活行動の変化で可視化する**

「ちゃんと話し合おう」で解決させず、「何をするようになったか／何をやめたか」で関係の変化を示す。言葉による理解より、行動による適応。

## 1. 物語圧 ― 悪役の代わりになるもの

**圧力は「なぜ変わらざるを得ないか」**を担う（「どう人物を動かすか」は2章の装置が担う）。以下、個々の要素は単に「圧力」と呼ぶ。

| 圧力 | 例 |
|---|---|
| **時間** | 老化、卒業、閉店、退職、季節の一巡 |
| **期限** | 引っ越し日、取り壊し、退院、法要、相続手続き |
| **距離** | 引っ越し、転勤、独立、遠距離介護 |
| **生活** | 家事、仕事、介護、育児の同時進行 |
| **役割** | 親、子、兄、姉、店主、稼ぎ手、仲裁役。役割の空白・押しつけ合い |
| **記憶** | 思い出の食い違い、何十年前の一言 |
| **不在** | 死別、離婚、家出、退職 |
| **制度** | 相続、施設入所、学校、会社 |
| **お金** | 家・店の維持費、介護費、修繕費の負担割合、立て替え・仕送り・外食など生活の中の小さな金（3章「お金の日常」） |
| **身体** | 老い、病後、怪我、障害、妊娠・産後、更年期、慢性的な疲労、視力・聴力の変化。**以前と同じように動けないことが役割変更を引き起こす** |
| **習慣** | 続ける／やめる／途切れる |

### 駆動パターンの定番

圧力と装置を組み合わせた、よく使われる動かし方。

- **同居の強制** — 事情があって一つ屋根の下に住まざるを得なくなる。距離の近さ自体が葛藤を生む
- **不在の中心** — 故人・失踪者・出ていった親など、画面にいない人物をめぐって全員が動く
- **遺品・遺言・手紙** — 過去からの「宿題」が届き、それを片付ける過程が物語になる（詳細は6章「遺品整理」）
- **役割の空白** — 要だった人がいなくなり、空いた役割を誰が埋めるか、押しつけ合うか
- **反復する日常＋小さなズレ** — 毎日同じ朝食。その一回だけ何かが違うことが事件の代わりになる
- **秘密の小出し** — 大事件ではなく「実は通院していた」程度の秘密が段階的に明かされる
- **言えなかった一言** — 物語全体が「その一言を言うまで」の助走になっている
- **一人増える／一人減る** — 誰かが生活圏に入る、または出る。それだけで全員の役割が組み替わる

## 2. 装置レイヤー（A〜G）

あるある本文とは別に、機能で分類したレイヤー。

| 層 | 機能 | 例 |
|---|---|---|
| **A. 接近装置** | 人を一緒にする | 同居、帰省、介護、共同作業、店、趣味、食事 |
| **B. 反復装置** | 関係を育てる | 毎日の食事、通勤、散歩、店番、通院、電話 |
| **C. 開示装置** | 知らなかった面を見せる | 遺品、写真、他人の証言、昔の場所、手紙 |
| **D. 摩擦装置** | 関係を揺らす | 価値観差、役割差、記憶差、負担差、世代差 |
| **E. 不在装置** | 相手の重要性を見せる | 来ない、帰らない、辞める、引っ越す、死ぬ |
| **F. 再定義装置** | 関係を更新する | 親子→大人同士、他人→家族的関係、客→仲間、世話する側／される側→相互扶助 |
| **G. 選択装置** | 感情を行動として確定する | 捨てる／残す、帰る／残る、施設／在宅、店を閉める／続ける、会いに行く／行かない、手紙を読む／読まない、電話をかける／かけない、部屋を片付ける／そのままにする、頼る／拒む |

**G. 選択装置**は摩擦とは別物。何を選んだかがそのまま人物の感情表現になる（「父の工具を残す」は「父を愛していた」という台詞の代わりになる）。

**B. 反復装置**の具体的な展開は8章「時間・反復」にまとめている。

### 0章フローとの対応

0章の流れの各段を、主にどの装置が担うかの目安。

| 0章の段 | 記号 | 主な装置 |
|---|---|---|
| 日常のズレ／小さな不都合 | ① | 圧力、D. 摩擦、E. 不在 |
| 一緒に何かをする | ② | A. 接近、B. 反復 |
| 知らなかったことが見える | ③ | C. 開示 |
| 役割・距離・認識が変わる | ④ | F. 再定義、G. 選択 |
| 少し違う日常になる | ⑤ | B. 反復（差分の可視化） |

### 家族まわりの用語

- **仮の家族** — 期間や事情が限定された同居の単位（4章）
- **選択された家族** — 血縁から距離を置いた人が、自分で選んで結ぶ継続的な関係（7章）
- **家族的関係** — 家族ではないが家族のように機能している状態一般。F. 再定義の到達点として使う

## 3. 家族再生

### 集合のきっかけ
- **疎遠だった兄弟姉妹が親の件で集まる** — 葬儀・入院・実家の処分・法事が口実になる
- **成人した子が実家に戻る** — 離婚・失業・休職がきっかけ。親は「いつまでいるのか」を聞かず、子は「邪魔になっていないか」を気にする
- **親が子の家へ転がり込んでくる** — 逆方向の同居
- **離婚した親と子が久しぶりに暮らす**
- **祖父母の家の売却・解体話** — 孫世代が初めて「この家の記憶」を言葉にする

### 家族ホメオスタシス（役割の均衡）

家族は個人の集合ではなく、暗黙の役割分担で均衡しているシステムとして扱える。

```text
A：怒る
B：なだめる
C：黙る
D：笑わせる
```

このうち一人が **「今回はなだめない」** だけで構造が崩れる。

- **家族の中の「いつもの役」** — しっかり者、問題児、仲裁役、ムードメーカー、我慢する人、世話する人、稼ぐ人
- **役を降りる** — いつも仲裁する母が今回は仲裁しない。それだけで家族全体が揺れる
- **役割逆転** — 昔「頼れる兄」だった兄が失業中、「問題児」だった弟が家庭を持った堅実な社会人。昔の役割が今の本人と合わなくなっている

### 人物配置
- **都会に出た子と地元に残った子** — 「残った方が損をしている」という不公平感が火種
- **不器用な父** — 愛情表現が下手で、送迎・修理など行動でしか示せない
- **家を仕切る母／仕切れなくなった母** — 要だった人が弱ることで均衡が崩れる
- **親の再婚相手** — 最初は侵入者、最後は家族。距離の縮め方がそのまま筋になる
- **血のつながらない兄弟姉妹・連れ子・養子・里親** — 反抗は派手な衝突ではなく、ドアの閉め方や洗濯物の分け方に出る

### 定番の展開
- **「言わなくても分かる」が通じなくなる** — 誰も悪くないが、前提が違っていたと判明する
- **兄弟姉妹で記憶が違う** — 「父さん優しかったよな」「私には全然優しくなかった」。同じ過去を共有していても解釈は共有していない
- **喧嘩の原因が何十年も前の出来事** — 言った側は忘れ、言われた側はずっと覚えている
- **一人だけ時間が止まっている** — 亡くなった子の部屋、離婚相手の食器、外せない廃業店の看板。過去を保存することで今への移行を拒んでいる
- **実家の片付け** — 物を一つ処分するたびに記憶が出てくる。エピソードを量産しやすい
- **物が会話を仲介する** — 昔の家族写真、父の手帳、母のレシピノート
- **同じ料理を再現しようとして失敗する** — 母の味は再現できない。レシピにない「目分量」
- **親を一人の人間として知る** — 父にも夢が、母にも恋愛が、親にも失敗があった。「父」が「父という役を演じていた一人の男性」に見えてくる
- **子を一人の大人として知る** — 就職・結婚・離婚・転職を機に、親が子を「自分とは別の人生を持つ人」として認める
- **完全には分かり合えない** — 再生とは元通りではなく「このくらいで折り合う」こと

### 子どもの視点と適応行動

非事件型では、子どもの大事件より **静かな適応行動** の方が効く。

- **親の不和を察知する子** — 食事の味、声の大きさ、ドアの閉め方の変化で気づいている。大人は子どもが知らないと思っている
- **自分が家の空気を左右すると感じる** — 思春期の子が、自分の成績・進路で家の雰囲気が決まると思い込む
- **反抗ではなく過度な礼儀正しさ** — 親の再婚相手に敬語を崩さない。反抗より距離が深い
- **席順を変えない／荷物を最小限にする** — いつ出ていくことになってもいいように暮らす
- **いい子を演じる** — 家族の「問題児」の反対側で、手のかからない役を引き受ける（家族ホメオスタシス）

### お金の日常

相続や維持費のような制度的な金だけでなく、生活の中の小さな金が摩擦にも愛情表現にもなる。

- **立て替えの精算を言い出せない** — 金額より「言うこと」自体が関係を揺らす
- **仕送りの減額を報告できない** — 送る側の事情の変化を隠す
- **「今日は外食しない」** — 家計の温度が食卓に出る
- **誰の口座から公共料金が出ているか** — 家の実質的な責任者が誰かを示す
- **金を渡すことでしか心配を示せない** — 世話を焼く愛情表現の歪んだ形（12章）

## 4. 共同生活（血縁を超えた仮の家族）

### 導入の型
- **シェアハウス／下宿／寮／ルームシェア** — 年齢も職業もバラバラな住人の群像劇
- **商店兼住居・親戚宅への居候**
- **期間限定の同居** — 家が見つかるまで、治療が終わるまで、夏休みの間だけ
- **祖父母と孫の二人暮らし** — 世代差と、中間世代（親）の不在
- **近所の単身高齢者と子育て世帯** — 鍵の預かりや買い物代行から始まる。契約ではなく「カレーが余ったから」という物のやり取りが続く
- **兄弟姉妹で親の家を共同維持** — 修繕費の負担割合と「誰が年に何回帰るか」が争点
- **離婚後の共同養育**

### 関係が深まる流れ
```text
一緒に住んでいるだけ
↓
生活習慣を知る
↓
弱っている時を見る
↓
頼まれていないことをする
↓
帰宅を待つようになる
```

### あるある
- **生活リズムの衝突** — 起床、風呂の順番、ゴミ出し、電気代。小さいほどリアル。解決は話し合いより「相手の習慣を覚えて先回りする」形で進む（原理3）
- **冷蔵庫の張り紙ルール** — だんだん書き足されていく／剥がされる
- **冷蔵庫が人間関係を表す** — 名前を書いた食べ物、勝手に食べられたプリン、いつの間にか買ってある好物、一人分が二人分になる食材、誰も食べなくなって残る食品
- **合鍵を渡す** — 受け入れの儀式
- **一緒に食べる／別々に食べる** — 食事を共にするかどうかが関係の温度計
- **住人の一人が出ていく回** — 中盤〜終盤に必ず来る別れのエピソード
- **最初に来た人が最後に去る** — 共同体の始まりと終わりを一人の視点で閉じる
- **「ただいま」「おかえり」が言えるようになる** — 居場所の完成を示す定番

## 5. 介護・老い

### 始まりと兆候
- **介護には「介護と呼ばれる前」がある** — 買い物代行、病院への送迎、薬の確認が少しずつ増え、転倒や入院を境に家族が初めて「介護が始まった」と認識する。気づいたら介護者になっていた
- **急に始まる介護** — 転倒・脳卒中・入院で準備なく始まる型もある
- **衰えは日常のズレとして現れる** — 名前を忘れるより先に、同じ話を繰り返す、財布の置き場所が変わる

### 負担の構造
- **誰が看るか問題** — 近くに住む子、独身の子、女性に負担が寄る
- **遠方の兄弟は電話で「大丈夫」と聞くだけ** — 服薬の飲み忘れや転倒の頻度といった実際の記録は共有されない
- **介護する側にも生活がある** — 仕事との両立、配偶者との関係、「親孝行なんだから当然」という周囲の期待
- **老老介護** — 双方が「迷惑をかけている」と思い、互いに症状を隠す

### ライフステージ別の介護者

介護者の年代で、ぶつかる圧力が変わる。

| 介護者 | 主にぶつかるもの |
|---|---|
| **ヤングケアラー**（子ども・若年者） | 学校、友人関係、進学。本人は「家族の事情」としか言わず、周囲が気づきにくい |
| **20〜30代の成人介護者** | 就職、キャリア形成、恋愛、結婚、独立 |
| **40〜50代（ダブルケア）** | 仕事の責任、自分の子育て、親の介護が同時に来る |
| **老老介護** | 介護者自身の体力・健康の衰え |

### 関係の摩擦
- **善意同士の衝突** — 姉は「家で看たい」、弟は「施設の方が安全」。どちらも親を心配している
- **「迷惑をかけたくない」親と「頼ってほしい」子**
- **親子の立場逆転** — かつて世話をした側が世話をされる。親は指示されることに反発し、子は親を子ども扱いしてしまう
- **過剰補正** — 親が支配していた関係が、子が親を管理する関係に振れすぎる。そこから相互尊重へ戻る過程がドラマになる
- **着地は「完全介護」でなく「二人の大人として関係を作り直す」でもよい**

### 介護される側を「介護対象」にしない
- **介護される側の秘密の生活** — 行きつけの喫茶店、趣味仲間、昔の仕事仲間、毎週買う雑誌、誰かへの仕送り、毎日の散歩コース。親にも自分の知らない人生があった
- **ケアマネ・ヘルパー・デイサービスの人** — 家族の外の第三者が、家族に言えないことを言う役

### 情緒の型
- **同じ話を何度もする** — 最初は苛立ち、やがてその話の意味に気づく
- **記憶が戻る一瞬** — 一瞬だけ昔の顔に戻る。泣かせどころの定番（使いすぎ注意）
- **介護者の限界と罪悪感** — ふと「早く楽になれば」と思ってしまう自分
- **施設入所を決めた夜、眠れない** — 楽になるはずなのに
- **介護が終わった後の空白** — 生活の中心が突然消え、自分が何者か分からなくなる

---

## 6. 喪失（死・別離・役割の消失）

### 直後
- **葬儀は忙しすぎて泣く暇がない** — 悲しみが来るのは全部終わった後
- **日常のルーティンは止まらない** — 誰かが死んでも腹は減るし洗濯物は溜まる
- **故人のスマホ・SNS・留守電** — 解約するかどうか（デジタル遺品は11章）
- **故人宛ての郵便物が届き続ける** — 世界がまだ故人の死を知らない

### 生活習慣が不在を理解するまで

喪失を「認知」ではなく **身体化された習慣** として描く。

- 二人分の食事を作ってしまう
- 名前を呼びかけそうになる、電話しかけて気づく
- スーパーで好物を手に取ってしまう
- テレビの音量を相手に合わせたまま、番組を録画してしまう
- 玄関に靴が残っている

### 遺品整理（万能の開示装置）
- **物を一つ処分するたびに過去が出てくる** — 写真、手紙、レシート、日記、VHS、子どもの工作、名前の分からない鍵
- **目的は秘密暴露ではなく「持ち主を別の角度から知る」こと** — 誰も知らなかった趣味・借金・手紙が静かに出てくる
- **「捨てる／残す」が人物関係になる** — 亡父の工具を、兄は処分したい、妹は残したい、母は実はもう見たくない。一つの物が三人に違う意味を持つ（G. 選択装置）

### 受容の過程
- **故人の部屋をそのままにしておく** — 片付けられないことが悲しみの表現
- **故人の習慣を真似し始める** — 同じ椅子、同じ銘柄のコーヒー
- **故人を知らない場で知る人に会う** — 同僚、常連客、趣味仲間、昔の友人から「自分の知らない故人」を知る
- **故人への怒り** — 「勝手に死んで」「どうして何も言わなかった」。愛情と怒りが同時に存在する
- **一周忌・三回忌で時間経過を示す** — 法要が章区切りとして機能する
- **悲しくない瞬間に罪悪感を覚える** — 初めて笑った日。終盤で「忘れることと生き続けることは違う」へ移行
- **ペットの死** — 家族の中で一番「泣いてよい対象」になる。人の死では出せなかった感情が先に出る

### 死別以外の喪失
- **子の独立（空の巣）** — 子ども部屋が空く、食事量と洗濯物が減る、夫婦の会話が急に減り休日の予定が立たない。**幸福な出来事なのに喪失でもある**
- **役割の喪失** — 聞き役・調整役だった人がいなくなり、残った誰もその穴を埋められない（仕事上の役割喪失は10章）
- **「代わり」はいないが「次」はいる** — 新しい人は故人の代替品ではないが、別の関係を新しく作ることはできる

## 7. 居場所づくり

### 出発点
- **居場所のない主人公** — 家に帰りたくない、職場しか居場所がない、住居はあるが「家」ではない
- **地域との接点が切れる** — 転勤・離婚・退職で、スーパーのレジや同じ時間帯の公園だけが顔なじみになる
- **「この家にいていいのか」が引っ越し後も数年残る**

### 居場所の成立条件

```text
場所 ＋ 反復 ＋ 役割 ＋ 他者からの予期 ＝ 居場所
```

1. **繰り返し訪れる**
2. **名前・習慣を覚えられる** — 「いつもの」が通じる
3. **小さな役割を持つ** — 「ちょっと手伝って」
4. **不在が認識される** — 「今日は遅かったね」「昨日来なかったね」

「いつも来る」だけではまだ居場所ではない。**来ることを誰かが期待している**ところまで行って成立する。

### あるある
- **偶然入った店・場所が居場所になる** — 喫茶店、定食屋、古本屋、銭湯、駄菓子屋、商店街
- **店主は多くを聞かない** — 詮索しない大人の存在が救い
- **常連たちのゆるいコミュニティ** — 名前も職業もよく知らないが顔は知っている関係
- **「必要とされる側」になる** — 子ども食堂、学習支援、清掃ボランティアなど
- **外に出る最初の理由が家族ではない** — 引きこもり・休職後、趣味のオンラインコミュニティのオフ会が最初の外出になる
- **選択された家族** — 血縁から距離を置いた人同士が作る関係。年末年始の過ごし方で深さが測られる
- **大人になると友達の作り方が分からない** — 顔見知り → 雑談相手 → 一緒に食事 → 個人的相談 → 友人。友情の成立そのものが物語になる

### 転換と終盤
- **「助ける側」が助けられる** — 助けるつもりで関わったのに、自分の生活にリズムや意味が戻っていた
- **「頼る」ことが成長になる** — 何でも自分でやる → 限界 → 助けを求める → 任せる。自立から相互依存へ
- **その場所がなくなる危機** — 閉店、取り壊し、店主の引退。非事件型の最大の山場
- **愛されていても終わるものは終わる** — 「みんなの力で存続」より、終わりを受け入れる方がヒューマンドラマになる
- **場所は失われても関係は残る** — 閉店した店の常連が別の店で毎月集まり続ける
- **主人公が次の誰かの居場所になる** — 受け取った側が与える側に回ってループが閉じる

## 8. 時間・反復

- **小さな約束が関係を作る** — 毎週水曜の夕食、朝の散歩、月一の墓参り、毎晩の電話、犬の散歩。恋愛のデートにあたるのが**習慣**
- **習慣が一度途切れる** — 毎朝いる老人がいない、毎晩の母の電話がない。大事件ではないのに、その人の重要さが分かる
- **季節が一周する** — 春に出会い、夏に慣れ、秋に変わり、冬に別れ、翌春に新しい日常
- **「去年と同じ」なのに違う** — 桜、花火、誕生日、正月、命日、夏祭り。同じ行事の反復で人物の変化を見せる
- **同じ場面の反復** — 同じ食卓、同じ道、同じ電話。意味だけが変わっていく（原理2）

---

## 9. 人生の転機・終わり

9章は **時間と私的な役割の区切り**（卒業・独立・最後の日）、10章は **社会的な役割の区切り**（退職・継承・肩書き）を扱う。

- **最後の○○** — 最後の営業日、最後の登校日、最後の出勤、最後の正月。これが最後だと知っているだけで場面に意味が生まれる
- **最後だと思っていたら続く** — 場所が関係を作ったが、関係は場所を超えた
- **喜ぶべきことを喜べない** — 子の結婚・昇進・転勤・進学・親の再婚。本人には良いことが、別の人には「自分から離れていく出来事」になる。善悪なしでドラマが成立する
- **独立・結婚・転勤で生活圏が組み替わる** — 残る側と出ていく側で同じ出来事の意味が違う
- **身体の変化による転機** — 病後・怪我・妊娠・産後などで、以前の役割や働き方を続けられなくなる

## 10. 仕事と人生

非事件型ヒューマンドラマの大きな領域。**役割喪失**と特に相性が良い。独立した領域であると同時に、3〜7章の圧力源にもなる。

### 他章との接点
- **家族（3章）** — 稼ぎ手の役割が失われると家族ホメオスタシスが崩れる
- **共同生活（4章）** — 在宅勤務・休職で、同じ家にいる時間が急に増える
- **介護（5章）** — 介護離職、時短勤務、キャリアとの両立
- **喪失（6章）** — 肩書きの喪失は死別と同じ受容過程をたどることがある
- **居場所（7章）** — 職場しか居場所がなかった人が、退職で居場所を失う

### 肩書きと役割の喪失
- **定年退職して肩書きがなくなる** — 名刺のない自己紹介ができない
- **家では肩書きで呼ばれないことへの違和** — 職場で「部長」だった人が、家では誰の何者でもない
- **名刺・社員証・制服・定期券の処分** — 役割喪失の物的な可視化。捨てられずに引き出しに残る（G. 選択装置）
- **退職後に「昼間の街」を初めて見る** — 平日の昼のスーパー、公園、図書館にいる人たち
- **仕事しかなかった人が退職後に時間を持て余す** — 家に居場所がないことに気づく
- **長年いた職場を辞める** — 最終日の机の片付け
- **転職して「前の会社の人」でなくなる**
- **長年続けた仕事が社会的に不要になっていく** — 技術・業界の変化で自分の熟練が価値を失う

### 働き方の変化が家庭を変える
- **在宅化・配置転換・時短** — 家庭内にいる時間が急に増え、家族の既存のリズムとぶつかる（A. 接近装置）
- **単身赴任の終わり** — 帰ってきた人の居場所が家の中にもうない
- **仕事の愚痴を言える相手が変わる** — 配偶者から同僚へ、同僚から配偶者へ

### 引き継ぎ・継承
- **後輩に仕事を引き継ぐ** — 教えることで自分が何をしてきたかが見えてくる
- **引き継ぎ資料が書けない** — 自分の仕事を言語化しようとして失敗し、それが勘と関係性で成り立っていたと気づく
- **店を継ぐ／継がない** — 家業と子の人生の衝突（G. 選択装置）
- **家業を畳む** — 愛されていても終わるものは終わる
- **職人が後継者を取る** — 血縁でない弟子が「家族」になる

### 職場の関係変化
- **自分より若い上司が来る**
- **昔の部下と逆の立場で再会する**
- **同僚が退職すると急に私的な関係になる** — 仕事という接点が消えて初めて友人になる

## 11. 日常描写の小道具・舞台

- **食卓・台所** — ヒューマンドラマの主戦場
- **食卓の人数が変わる** — 4人→3人→2人、または1人→2人→3人。家族構成の可視化装置
- **食卓の席順・空席の扱い** — 誰がどこに座るかで関係性を見せる
- **冷蔵庫** — 共同生活の関係表（4章参照）
- **縁側・ベランダ・屋上** — 横並びで座ると本音が出る
- **車の中** — 目を合わせずに済むので核心的な会話が起きる
- **病院の待合室** — 隣に座る時間が自然になっていく
- **玄関** — 送り出し、出迎え、残された靴
- **駅・バス停** — 見送りと再会
- **仏壇・位牌・遺影** — 故人に話しかける独白の装置
- **古いアルバム・家計簿・日記・レシピノート** — 過去を自然に開示する媒体
- **天気と季節の食べ物** — 桜、梅雨、スイカ、おでん。時間経過をセリフなしで伝える
- **家電の故障** — 洗濯機や給湯器が壊れる程度の「小事件」が会話のきっかけになる
- **家事の途中の会話** — 洗濯物をたたみながら、皿を洗いながら短い会話が続く

### 現代の連絡手段・デジタル遺品

2020年代の日常では、手紙や写真と同等以上に効く。多くは C. 開示・E. 不在・G. 選択を同時に担う。

- **家族LINEの既読／未読** — 既読がつかない、グループで一人だけ既読無視、スタンプだけの返事
- **見守りアプリ・位置共有のオン／オフ** — 安心のための道具が監視にも見える。切ることが自立の宣言になる
- **親のスマホを代わりに操作する** — 介護の手伝いとプライバシー侵犯の境界。見てはいけないものが見えてしまう
- **故人のサブスク・クラウド写真** — 解約しないと課金が続く。解約すると写真が消える（G. 選択装置）
- **スマートスピーカーが故人の声に応える** — 登録された名前、設定されたままのアラーム
- **故人のアカウントに届く誕生日通知** — 世界がまだ故人の死を知らない（6章）

## 12. 台詞・感情表現

- **核心を話さない会話** — 天気や夕飯の話をしながら本当は別のことを話している
- **「別に」「いいよ」「大丈夫」** — 全然大丈夫じゃない時に使われる
- **世話を焼くことでしか愛情表現できない** — 食べ物を渡す、荷物を持つ、送迎する、修理する、金を渡す。「心配している」とは言わない
- **謝れないので別のことをする** — 喧嘩の翌日、食事が作ってある、壊れた物が直っている、傘が置いてある。感情を行動に翻訳する
- **言葉にすると壊れそうなので言わない** — 感謝・後悔・寂しさ・尊敬は日常行動の変化で表す
- **「好きだ」より「あんたこれ好きだったでしょ」**
- **電話を切った後の沈黙** — 言えなかったことの重さ
- **方言が出る瞬間** — 地元に帰った時、感情が高ぶった時に標準語が崩れる
- **呼び方の変化** — 「お父さん」→「親父」、苗字→名前。関係の変化を一語で示す
- **微小変化の台詞** — Before「飯はいらない」→ After「今日は三人分でいいの？」
- **最後の最後に一言だけ本音** — それまでの全部がその一言のためにある

---

## 13. 結末の型

- **元には戻らないが、前には進む** — 最も多い着地
- **冒頭と同じ場面の反復で終わる** — 同じ朝食、同じ道。でも意味が変わっている
- **蓄積の可視化で終わる** — 何年かぶりに同じ味噌汁を一緒に飲む、待合室で並んで座るのが自然になっている
- **誰かが去り、誰かが残る** — 共同生活・居場所ものの定番
- **食事のシーンで終わる** — 「いただきます」だけで再生が伝わる
- **季節が一巡して終わる** — 始まりと同じ季節で円環を閉じる
- **関係の再定義で終わる** — 親子が大人同士に、客が仲間に、他人が家族的関係に
- **選択で終わる** — 残す、帰る、電話をかける。一つの選択が感情の答えになる
- **小さな約束で終わる** — 「来年もまた」「今度は一緒に」。未来を開いたまま閉じる

### 折り合えない並走（未解決のままの定着）

原理1の「問題は完全に片付いていなくてよい」を最も厳密に守る型。解決ではなく、未解決のまま関係の形だけが決まる。

- **分かり合えないまま、同じ食卓には戻る**
- **施設か在宅かの結論は出ないが、通院の分担だけ決まる**
- **会いには行かないが、年賀状や歳暮だけは続く**
- **謝罪はないが、次の法事の日程だけは連絡が来る**

---

## 14. 陳腐化・地雷注意

- **泣かせのための病気・死** — 喪失を感動装置として消費すると読者が引く
- **大喧嘩一回で全部解決する** — 蓄積していた関係問題が一度の感情爆発と謝罪ですべて解消すると、日常の積み重ねを描いてきた意味が薄れる（大喧嘩そのものは禁止ではない）
- **理解のある第三者が全部解決する** — 外部の善人の説教で家族が和解する流れは安易
- **親を便利な悪役にする** — 対立の原因をすべて人格的悪意へ還元すると、家族システム・世代差・依存関係などの複雑さが消える（虐待・支配・ネグレクトを扱うこと自体は否定しない）
- **対立を善悪で描く** — 「負担の見え方の違い」「時間の使い方の違い」「記憶の優先順位の違い」に落とす
- **すぐ「ちゃんと話し合おう」で解決させる** — 言葉による理解より行動による適応の方が日常ドラマとして自然
- **介護の美談化** — 負担や怒りを描かないと、現実を知る読者から反発を受ける
- **田舎＝温かい、都会＝冷たい** — 便利だが古い二項対立
- **全員が最後に抱き合う** — 「小さな着地」を壊してしまう
- **記憶が戻る一瞬の多用** — 一作に一度が限度

---

## 15. 設計チェックポイント

- 事件の代わりに **何が時間を区切っているか**（期限・季節・法要・最後の○○）
- 物語の中心に **誰の不在** があるか
- **食事・家事・通院・移動** などの反復場面をいくつ持っているか
- 季節・食事・家事・ゴミの日を **関係変化のマーカー** にしているか
- 物語の **時間スパン** は何か（数週間／一季／一年／数年）。短いほど反復装置の密度が必要になる
- 同じ食卓・同じ廊下を **何視点で** 描くか。1視点だけだと差分が独白の説明に戻りやすい
- 感情（怒り・寂しさ・許し・心配）を台詞で説明せず、**何をするようになったか／何をやめたか** で可視化しているか
- **冒頭と終盤で同じ行動・場所・物を再利用し、意味の変化を見せているか**（例：母の電話を面倒そうに切る → 電話が来ないので自分からかける）
- 人物の感情を確定させる **選択** が置かれているか
- 主人公が最後に **言う／言わない一言** は何か
- 結末は **元通り** ではなく **どう折り合ったか** になっているか
- **何が起こったか** より **何が以前と違って見えるようになったか** が書けているか
