# genre（ジャンル別・横断創作リファレンス）

葉は **既定では読まない**。新しい葉を足すときは `_how_to.example/_index.md` と、この README のように存在するサブカタログ入口の両方に置く。条件は行ごとでも、索引または README の冒頭注記でもよい。既存作品の selected は自動では増やさない。ジャンル葉は、Plan Mode の **ジャンル軸**（作品プロファイルとは別の分類軸。依頼文・`config.md` のジャンル・キーワードから判定する）が該当するときに必読として selected にする。該当するのに読まずに案を出したり、`genre/*` をグループごと not_applicable にしたりしない。作業用 `genre/README.md` がある環境では、そちらへ追随するまで標準だけの新葉は選定対象外。

特定ジャンルの読者期待、世界設定、人物ロール、プロット骨格、語彙、失速対策、企画チェックを横断して扱う。
一場面の作り方だけを集める `episode/` とは役割を分け、作品全体の設計図として Plan Mode で参照する。

## `episode/` との住み分け

- `genre/`：作品全体へ効くジャンル契約、世界設定、長期構造、配慮、完成度チェック。
- `episode/`：一話・一場面として再利用する来訪、製作、茶会、断罪、逃走などのフックと進行。
- ジャンル資料から場面パターンを抽出するときは、総合版を移動せず、`episode/general/episode_<topic>.md` に分冊する。

## 運用

- 全項目を一作へ詰め込まず、作品の主軸と反転点を選ぶ。
- 基準本文は `_how_to.example/genre/`、ユーザー共通の調整は `_how_to/genre/`、作品固有情報は `novels/<作品>/` の各資料へ置く。
- 技術・歴史・制度の記述を史実または実用知識として本文へ出す場合は、ジャンル上の定型だけで確定せず別途資料確認する。
