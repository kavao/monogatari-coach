# 因習村・閉鎖的村落 設定リファレンス（創作用）

> フィクションにおける「因習村」を組み立てるための構成要素カタログ。
> 民俗学的な実在要素と、創作上の誇張・定型を意図的に区別して記載する。
> 用途：ホラー／ミステリ／サスペンス／伝奇の舞台設定、プロット設計、用語生成。

---

## Monogatari Coach での使い方

「因習村」「閉鎖集落」「村落ホラー」「共同体による排除」を扱う作品の Plan Mode で参照する。
全項目を一作へ詰め込むためのテンプレートではなく、作品の主題に合う要素を選び、因習が成立する因果関係を組み立てるためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 因習村を使う必然、主人公と共同体の価値観の衝突、作品の魅力 |
| `design_specification.md` | 来訪から決着までのフェーズ、禁忌の侵犯、排除のエスカレーション、秘密と結末 |
| `world.md` | 地理的閉鎖、家格・組織、相互扶助、信仰・儀礼、現代社会との接続 |
| `character.md` | 外部者／帰郷者／内部の異端者、温厚な代弁者、強硬派、内通者などの役割 |
| `_meta.md` | 伏線、偽の秘密、真相開示の順序、配慮事項、次回確認項目 |

設計時は、最低限次を決める。

- 出られない理由を、物理・制度・心理の三層で用意する。
- 禁忌は三〜五個に絞り、「明示された掟」「暗黙の掟」「失伝した本来の理由」に分ける。
- 「村の秘密」は核を一〜二個に絞り、必要に応じて囮となる秘密を置く。
- 因習の元来の合理性と、現在それが加害へ変質した理由を分ける。
- 実在に関する記述は創作上の目安であり、史実として作品へ書く場合は一次資料・自治体史などで再確認する。

## 0. 前提：因習村とは何か

| 区分 | 内容 |
|---|---|
| ジャンル上の定義 | 閉鎖的な村落共同体が、前近代的な掟・禁忌を現代まで維持し、外部者に敵意または超自然的脅威を示す舞台類型 |
| 実在性 | **創作上の複合概念**。個々の要素（村八分、土葬、若者組、共有地管理）には実在の裏付けがあるが、それらを一箇所に凝縮した「因習村」は現実には確認されていない |
| 機能 | 「近代的な主人公」と「前近代的な論理」を衝突させ、価値観の断絶そのものを恐怖の源にする装置 |
| 代表作 | 『八つ墓村』『犬神家の一族』（横溝正史）、『鬼太郎誕生 ゲゲゲの謎』（哭倉村）、『ひぐらしのなく頃に』（雛見沢）、『サイレン』（羽生蛇村）、『屍鬼』（外場村） |

**創作上の要点**：怖いのは超自然ではなく「多数決で理不尽が正当化される構造」。祟りより先に、まず人間の合意形成を描く。

## 1. 地理・立地

閉鎖性を物理的に担保する装置。「出られない理由」が弱いと物語が崩れる。

### 1.1 地形パターン

- **袋小路型**：一本道の行き止まり。峠越え／隧道（トンネル）／吊り橋が唯一の接続点
- **盆地・すり鉢型**：四方を山に囲まれ、上空からしか全容が見えない
- **半島・離島型**：定期船が日に一往復、または欠航で数日孤立
- **ダム湖畔型**：旧集落は水没済み、移転先で旧習だけが継続（近代化と因習の同居）
- **鉱山跡・炭鉱跡型**：閉山後に取り残された企業城下町。坑道が地下迷宮になる

### 1.2 遮断イベント（外部と切る口実）

| 手段 | 使いどころ |
|---|---|
| 台風・豪雨による土砂崩れ | 定番。復旧見込み「三日後」が制限時間になる |
| 大雪・雪崩 | 冬季限定。足跡・雪の密室が使える |
| 橋の流失／落石 | 一瞬で成立し、破壊工作との区別がつかない |
| 電波の圏外・唯一の公衆電話 | 現代作品では**必須処理**。ここを雑にすると全部壊れる |
| 祭礼期間中の「物忌み」 | 村側の論理で出入りを禁じる。超自然に頼らない遮断 |

> **現代化への対処**：スマホ・SNS・宅配・行政の介入をどう封じるかが、現代舞台の因習村における最大の技術的課題。
> 案：①山間部の圏外＋衛星回線を村が管理／②村ぐるみの偽装（「彼は帰った」と証言を揃える）／③警察・役場に村の人間が入っている／④そもそも数日で解決する事件にする。

## 2. 社会構造

### 2.1 家格のヒエラルキー

```text
本家（旧庄屋・網元・山主）
 ├ 分家（複数）
 │   └ 孫分家
 ├ 譜代の百姓（古くからの構成員）
 └ 新参・寄留者（数十年住んでも「よそ者」）
外部者（旅人・調査者・移住者） ← 主人公はここ
```

- **決定権**は本家当主と長老衆の寄合に集約。多数決に見えて、実質は根回し済みの追認
- **屋号**で呼び合う（「上（かみ）の家」「川向こう」「新宅」）。名字が同じ家が多いための実用でもある
- **入婿・養子縁組**が血の濃さを調整する装置。系図が物語の伏線になる

### 2.2 役職・組織

| 名称 | 役割 | 創作上の使い方 |
|---|---|---|
| 区長・総代 | 行政との窓口 | 表向きの穏健派、内実は隠蔽の実務担当 |
| 宮司・神主・別当 | 祭祀の管掌 | 教義の解釈権を握る。真相を知る人物 |
| 長老衆・年寄 | 最終決定 | 沈黙が最も雄弁なキャラクター群 |
| 若者組・青年団 | 実力行使・祭礼の担い手 | 追跡者・実働部隊。上の命令に忠実 |
| 婦人会・講中 | 情報網 | 監視と噂の伝播。最速の情報インフラ |
| 巫女・イタコ役 | 託宣 | 少女が担うと「制度に搾取される個人」を描ける |

### 2.3 相互扶助と排他性の表裏

> 実在の村落共同体は、**排他的であることと相互扶助的であることが同じ仕組みから生じる**。
> ここを描き分けると作品の格が上がる。「村人は全員悪」より、「善良な人々が善良なまま加担する」ほうが遥かに怖い。

- 共有林・水利の共同管理 → 不参加者への「出不足金」などの罰則（実在）
- 総出の労働（道普請、屋根替え）→ 参加できない者の可視化
- 冠婚葬祭の相互負担 → 抜けると生活が回らない構造的拘束

## 3. 掟・禁忌（タブー）

### 3.1 空間の禁忌

- 入ってはならない山（禁足地）・社叢・洞窟・蔵・離れ
- 特定の道を夜に通ってはならない／振り返ってはならない
- 村内の特定の家の敷居を跨いではならない

### 3.2 時間の禁忌

- 祭礼の夜は外出禁止・雨戸を閉め切る（物忌み）
- 特定の日に生まれた子／死んだ者への扱い
- 何十年に一度の周期行事（起点と次回を明示すると緊張が生まれる）

### 3.3 言葉・名の禁忌

- 真名を呼ばない、隠語で言い換える（「あれ」「山のもの」「お山」）
- 死者・失踪者の名を口にしない
- 方言そのものが暗号として機能する

### 3.4 婚姻・血の禁忌

- 村外との婚姻禁止（族内婚）／逆に特定の家同士のみの通婚
- 特定家系との縁組の禁止
- 双子・異形の子への処遇

> **設計のコツ**：禁忌は3〜5個に絞り、①明示される掟 ②誰も口にしない暗黙の掟 ③掟の本来の理由（既に失伝）——の三層にする。
> 「なぜそうするのか、もう誰も知らない」が最も不気味に効く。

## 4. 信仰・儀礼のモチーフ

| モチーフ | 内容 | 実在性 |
|---|---|---|
| 人柱 | 堤防・橋・城の建造時に人を埋める | 伝承としては全国に多数。史実確認は困難 |
| 生贄・供犠 | 定期的に人・動物を捧げる | 動物供犠は実在。人身供犠は伝承の域 |
| 祟り神・御霊信仰 | 非業の死者を祀り上げて鎮める | **実在。日本の神観念の中核**（菅原道真等） |
| 荒神・地主神 | 土地に憑く恐ろしい神 | 実在 |
| 山の神・田の神の去来 | 季節ごとに神が移動する | 実在 |
| 隠し念仏・隠れ信仰 | 表の宗派と裏の信仰の二重構造 | 実在（東北の隠し念仏など） |
| 落人伝説 | 平家・南朝の落人が開いた村 | 全国に多数。系譜の正統性の主張 |
| 憑き物筋 | 特定の家系が霊的な何かを持つとされる | 実在した差別観念（**取扱注意**：§8参照） |
| 土葬・野辺送り | 火葬せず埋葬する | 実在。2000年代まで一部地域で継続 |
| 若者宿・娘宿 | 未婚男女が集団生活する慣習 | 実在。ただし性的側面は誇張が多い |

### 4.1 儀礼の描き方テンプレート

1. **準備**（何日前から、誰が、何を潔斎するか）
2. **役の選定**（籤／家柄／年齢／身体的特徴 ← ここに理不尽を仕込む）
3. **禁足と物忌み**（村人が屋内に籠る＝主人公が孤立する時間）
4. **本祭**（面・装束・唄・道具立て。視覚的な見せ場）
5. **直会（なおらい）**（後片付けと沈黙。ここで日常に戻る不気味さ）

## 5. 排除メカニズム（村八分）

現実の事例が最も豊富な領域。超自然抜きでも十分に成立する恐怖。

### 5.1 段階的エスカレーション

```text
第1段階：噂の流通     … 事実の有無に関わらず全戸へ数時間で到達
第2段階：微細な冷遇   … 挨拶の省略、寄合での発言の黙殺
第3段階：機能的排除   … 回覧板の停止、行事から除外、共有地の使用拒否
第4段階：生活の遮断   … 農業用水・道路・購買・通学路への妨害
第5段階：物理的圧力   … 器物損壊、投石、家屋への侵入
第6段階：合意された暴力 … 「村のため」という名目での実力行使
```

- 「八分」＝十のうち八つを絶ち、**葬儀と火事の二つだけは付き合う**という語源。この「情け」の残し方が逆に生々しい
- 現代の裁判では違法と認定されうる（民事賠償の判例あり）。**法が届く**という事実は、現代舞台では制約であり同時に希望の糸口

### 5.2 排除の口実になりやすいもの

不正の告発／行事の欠席／移住者の生活様式／補助金・交付金の配分／土地の売却／外部メディアの取材受け入れ／子どもの進学・都会志向

## 6. 「村の秘密」の類型

物語の核。以下から1〜2個を選び、複数の偽の秘密（囮）を配置する。

| 類型 | 概要 | 相性のよいジャンル |
|---|---|---|
| **経済型** | 隠し金山・密造・密輸・不法投棄の受け入れ | ミステリ／社会派 |
| **血統型** | 近親婚の反復による遺伝的問題、私生児の系譜 | 伝奇／ミステリ |
| **過去の犯罪型** | 数十年前の集団リンチ・大量殺人・隠蔽された事故 | ホラー／サスペンス |
| **超自然型** | 封印された何か、感染するもの、祟りの実在 | ホラー／伝奇 |
| **制度型** | 戸籍・住民票の操作、存在しないことにされた人間 | 社会派／サスペンス |
| **医学型** | 風土病、地下水の汚染、集団的な生理現象の民俗的解釈 | SF／ミステリ |
| **外部共犯型** | 村単独ではなく、企業・行政・宗教団体が背後にいる | 社会派／サスペンス |

> **最も強い構造**：超自然に見えた現象に合理的説明がつき、なお「それでも村人はそう信じて人を殺した」という事実が残る形。合理と不条理の二段構え。

## 7. 物語構造のテンプレート

### 7.1 基本フェーズ

| Phase | 内容 | 描写の焦点 |
|---|---|---|
| ① 来訪 | 主人公が村に入る動機（相続、取材、赴任、帰郷、遭難） | 過剰な歓待、または露骨な無視 |
| ② 違和感 | 些細なズレの蓄積 | 会話の断絶、視線、地図にない道 |
| ③ 掟の提示 | 明示的な禁止事項を告げられる | 理由は語られない |
| ④ 侵犯 | 主人公が禁忌を破る／破らされる | 破る動機を必然にする |
| ⑤ 転落 | 歓待が敵意に反転、退路の消失 | 味方だと思った人物の離反 |
| ⑥ 露見 | 秘密の判明、共同体の論理の全貌 | 加害者側にも筋が通っていること |
| ⑦ 決着 | 脱出／破壊／同化／継承 | **どの結末を選ぶかがテーマの表明** |

### 7.2 結末の四類型

- **脱出**：外へ出る。ただし何かを失う／持ち出してしまう（続編の余地）
- **破壊**：因習を断ち切る。カタルシス型。誰が代償を払うかを明示すること
- **同化**：主人公が村の一員になる。最も後味が悪く、最も文学的
- **継承**：因習の意味を理解し、形を変えて引き継ぐ。ビターな肯定

### 7.3 主人公の配置

| 型 | 立場 | 効果 |
|---|---|---|
| 完全な外部者 | 記者・研究者・刑事・旅行者 | 読者の視点と一致。説明が自然 |
| 帰郷者 | かつて出て行った者 | 内と外の両方を知る。最も葛藤が濃い |
| 内部の異端者 | 村に生まれ、疑問を持つ若者 | 逃げられない緊張。青春譚と接続可能 |
| 無自覚な当事者 | 自分が儀礼の中心だと知らない者 | 叙述トリックと相性がよい |

### 7.4 村側のキャラクター配置（最低限）

- **温厚な代弁者**：親切で、しかし決して掟には触れない人物（最も怖い）
- **強硬派**：わかりやすい敵。読者の憎悪を引き受ける
- **内通者**：助けてくれるが動機が不純、または途中で裏切る
- **子ども**：まだ染まりきっていない。希望と残酷さの両方を担う
- **狂言回しの老人**：断片的に真相を漏らす。信頼性は不明

## 8. リアリティと配慮（重要）

創作上の「因習」は実在の差別と地続きになりやすいため、以下を意識する。

### 8.1 やらないほうがよいこと

- 実在の地名・実在の集落を、そのまま加害者集団として名指しすること
- 特定の被差別的出自・血筋を「怪異の原因」として描くこと（憑き物筋・部落差別・ハンセン病等）
- 地方＝野蛮／都市＝理性、という単純な二項対立
- 障害・遺伝疾患を「近親婚の報い」として恐怖の記号に使うこと
- 特定の実在宗教・宗派を邪教として描くこと

### 8.2 代替の作法

- 地名は**架空**にする（実在の郡名＋架空の村名、が最も安全で座りがよい）
- 因習の担い手を「無知な田舎者」ではなく、**合理的判断の積み重ねの結果として間違えた人々**として描く
- 恐怖の源を「異質さ」ではなく「同調と手続き」に置く
- 都市部の職場・学校・オンラインコミュニティにも同じ力学があると示す（村を他人事にしない）

### 8.3 事実と創作の境界（参考）

| 要素 | 実在 | 備考 |
|---|---|---|
| 村八分 | ○ | 戦後〜現代まで事例あり。訴訟例も |
| 土葬の継続 | ○ | 2000年代まで一部地域で高率。現在はほぼ消滅 |
| 共有地の罰則制度 | ○ | 出不足金などは合理的側面をもつ |
| 若者組・娘宿 | ○ | 明治期まで。性的側面の記述は史料が限定的で誇張されがち |
| 祟り神・御霊信仰 | ○ | 日本の宗教史の中核 |
| 人柱・生贄の実施 | △ | 伝承としては豊富、実施の史実確認は困難 |
| 現代まで続く人身供犠 | ✕ | 確認例なし。**完全に創作** |
| 外部者の組織的殺害と隠蔽 | ✕ | 確認例なし。**完全に創作** |

## 9. 語彙・命名リソース

### 9.1 村名の作り方

- **地形＋語尾**：〜倉／〜窪／〜迫／〜谷（たに・や）／〜峡／〜淵／〜瀬／〜鼻／〜岫
- **不吉な字面**：哭／喪／贄／忌／禍／骸／髑／隠／閉／堕
- **一見すると穏やかな名**（反転させると効く）：日和村、和合村、豊穣村、常世村、安寧村
- **音の型**：三音（ひなみ／おぐら／しずり）は据わりがよい。四音は伝奇寄り

### 9.2 使いやすい単語

```text
【空間】禁足地・社叢・注連縄・鳥居・祠・辻・境木・隧道・墓所・洞・淵・堰
【制度】寄合・講・結・惣・出不足・座・宮座・当番・触れ・回覧
【儀礼】潔斎・物忌み・斎戒・直会・神迎え・神送り・湯立・柱立て・年籠り
【役】当屋・頭人・宮守・巫・巫女・別当・大工（儀礼職）・鍵取
【状態】穢れ・障り・祟り・憑き・忌み・詫び・和解・勘当
【時間】朔日・晦日・小正月・盆・彼岸・夏越・寒の入り
```

### 9.3 村人の台詞パターン

- 質問に答えず別の話をする：「……お茶、冷めますよ」
- 主語のない断定：「ここじゃ、そういうことになっとる」
- 好意の形をした警告：「悪いことは言わん、明日の朝の便で帰りんさい」
- 集団の意思への責任転嫁：「わしが決めたことじゃない」
- 時制の混濁（過去の事件を現在形で語る）：「あの子は今も山におる」

## 10. チェックリスト（設定完成度）

- [ ] 村から出られない理由が、物理・制度・心理の**3層**で説明できるか

- [ ] 因習村を「他人事の田舎」で終わらせていないか
