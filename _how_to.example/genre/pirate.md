# 海賊もの 執筆リファレンス

> 原資料（来歴）: `C:/Users/Owner/Downloads/pirate-tropes.md`（海賊あるある集。3つの生成元の案を統合した資料）。2026-11-03 に `genre/` の葉として導入。導入版では、各項目の統合元の印を外し、発動条件・本資料の注意（実在の集団・人物への配慮を含む）・Monogatari Coach での使い方・派生への転用・用語集への登録・深掘り用の問いを足した。原資料の9章（使い方メモ）は「Monogatari Coach での使い方」へ移し、0〜8章は章番号のまま残した。原資料の TODO は、派生への転用を初回の節で扱い、残りを末尾の将来メモに畳んだ。原資料は変更していない。

海賊を単なる悪党ではなく、**国家・商業・戦争の境界で活動する武装集団** として描くための設計資料。対象は大航海時代〜海賊黄金時代、地中海、東アジア、およびそれを下敷きにした海洋ファンタジー、空賊・宇宙海賊などの派生。

## 発動条件

> 海賊・私掠船、または空賊・宇宙海賊など、国家に対する合法と非合法の境界にいる武装した船乗り集団が作品の主軸となる場合に選ぶ（ジャンル軸が該当すれば必読。海賊が敵役や脇役として出るだけの作品では必読にせず、選定補助に挙げるにとどめる。略奪する人物の価値観だけを設計するときは `tropes/zero_sum_mindset.md`）。

海の冒険一般（正規の海軍もの、商船の冒険など）は、それだけではこの葉の対象にしない。海賊が筋に絡むときに選定補助に挙げる。

## 本資料の注意

**凡例**

| 印 | 意味 |
|---|---|
| **【史】** | 史実に根拠がある |
| **【虚】** | フィクション由来の定番 |
| **【混】** | 史実を誇張・変形したもの |
| **《》** | 適用圏（地域・時代）。**表示のない項目は地域・時代を問わない汎用型**。8章は章見出しで地域を示す |

- 最大の注意点は、**カリブ海賊の特徴を「世界の海賊一般」にしてしまうこと**。船長の選挙や掟は大西洋黄金時代に目立つ特徴で、私掠船や東アジアの水軍には当てはまらない（3-2）。
- 8章の地域（バルバリア海賊・倭寇・清代の海賊連合など）と、7-2 の実在人名（アン・ボニー、メアリー・リード、鄭一嫂など）は、型を説明するための例示に留める。実在の人物・民族・宗教・地域の性質として書かない。
- 【史】の項目も創作のための整理である。史実として本文へ出す事項（年代、人物の経歴、制度の細部）は別途資料で確かめ、未確認の一般化を事実として言い切らない。

## Monogatari Coach での使い方

「海賊もの」「私掠船」「空賊」「宇宙海賊」を扱う作品の Plan Mode で参照する。定番を全部採用するための一覧ではなく、作品の主軸にする章と、合法と非合法の境界をどこで動かすかを選ぶためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 主人公の船が国家に対して何者か（私掠・海賊・恩赦待ち）、それがどこで変わるか、作品の主軸 |
| `config.md` | 時代・地域（または派生の世界）、政治劇・経済劇・群像劇・冒険活劇の比重、史実寄りか空想寄りか |
| `design_specification.md` | 免状・恩赦・講和・政権交代など境界が動く出来事、拿捕と降伏交渉、反乱・選挙、末路と裁判 |
| `world.md` | 国家・総督・出資者・港の関係、拿捕審判所などの制度、海賊の掟、旗、航路と補給港、病気と自然 |
| `character.md` | 船長・クォーターマスター・専門職の配置、各人が「なぜこの船にいるか」、転職歴、出資者と庇護者 |
| `_meta.md` | 誰がどの国から何と見なされているかの変化、免状・恩赦の状態、分け前と負債、未回収の裏切り |

### 主軸の選び方

- **1章（正統性）を主軸にすると政治劇**: 免状・恩赦・編入を巡って、同じ人物が英雄、海賊、提督と転がる。
- **2章（国家と陸）を主軸にすると経済・陰謀劇**: 出資者、港、総督のネットワークで「陸と海の共犯」を描く。
- **3章（船内社会）を主軸にすると群像劇**: 掟、選挙、専門職、反乱で、小さな民主国家の興亡として描ける。
- **4〜5章は冒険活劇の骨格**: 戦闘は接舷と降伏交渉、危機は自然と病気。
- **7章はコメディ・パロディ用**: 史実との落差をネタにするなら【虚】の印のものを意図的に使う。
- **ゼロサム型の価値観との対比**: 黄金時代の海賊は刹那的だが、掟や分配では長い目で見た仕組みを持っていた。この矛盾が人物造形の種になる（価値観そのものの設計は [ゼロサム思考とハルピュイア型](../tropes/zero_sum_mindset.md)）。

設計時は、最低限次を決める。

- 主人公の船が、物語の始まりで国家に対して何者か（正規海軍・私掠船・半公認・海賊・無国籍）と、どの出来事でその立場が動くかを決める。
- 主軸にする章を一つ選び、他は補助に置く。全章を同じ厚さで書かない。
- 時代・地域（派生なら世界）を決め、その適用圏に合わない型（例: 東アジアの水軍に船長の選挙）を持ち込まない。持ち込むなら理由を世界設定に書く。
- 略奪品をどこで現金化し、誰が情報を流しているか（港・商人・総督）を決める。陸の協力者がいない海賊は一日も回らない。
- 主要な乗組員ごとに「なぜこの船にいるか」（志願・強制・脱走・恩赦待ち）を一つずつ与える。
- 主軸の呼び名（政治劇・群像劇など）や区分の印【史】【虚】【混】は設計の語である。物語案・あらすじ・キャラクター紹介には出さず、人物と出来事で書く（`_how_to.example/synopsis_presentation.md`）。

関連する葉: 略奪する人物の価値観は [ゼロサム思考とハルピュイア型](../tropes/zero_sum_mindset.md)、宇宙海賊・空賊で作品独自の技術の帰結が主軸なら [異物導入](../tropes/foreign_element.md)、海賊が敵役として出るだけの作品は [敵対者類型設計](../episode/general/episode_antagonist.md)。

## 派生への転用（空賊・宇宙海賊など）

空賊・宇宙海賊などの派生では、次のように移す。派生だけの新しいあるあるは、この葉では作らない。

| 章 | 移し方 |
|---|---|
| 0・1章（合法と非合法の境界、正統性） | そのまま移せる。免状・恩赦・講和・政権交代で立場が動く構造は、船が空や宇宙を行っても同じ |
| 2章（国家と陸） | 「港」を補給基地・ステーション・浮島などに置き換える。陸の協力者と情報網が要るのは同じ |
| 3章（船内社会） | そのまま移せる。掟・選挙・専門職（航海士・船大工にあたる職）・分け前は派生でも効く。適用圏の注意（黄金時代に目立つ型）は、作品の世界で採るかどうかを決める |
| 4章（稼業と戦闘） | 「沈めたくない」「接舷」「評判経済」「偽旗」は移せる。弾種・帆などの細部は世界の技術で置き換える |
| 5章（航海の敵） | 嵐・壊血病・疫病を、その世界の自然の脅威・故障・補給切れで置き換える |
| 6章（末路と裁判） | そのまま移せる |
| 7章（記号） | 旗・眼帯などの記号は、パロディとして意図的に使うときだけ持ち込む |
| 8章（地域） | 移さない。派生の世界の勢力と地域は世界設定で作る |

作品独自の技術（航法・動力・通信など）の帰結そのものが物語の進行になるときは、[異物導入](../tropes/foreign_element.md) を併用する。

## 0. 基本構造

### 0-1. 中心テーマ：合法と非合法の境界
海賊ものの面白さの多くは「**国家に対して自分は何者か**」の揺らぎから生まれる。善人／悪人の二分ではなく、次の連続体で考える。

```text
正規海軍
  ↕
私掠船（国家公認の拿捕）
  ↕
半公認の武装商船・密輸船
  ↕
海賊
  ↕
反乱者・無国籍犯罪者
```

**政治情勢ひとつで、同じ人間が同じ行為のままこの線を行き来する。**

| | 正規海軍 | 私掠船 | 海賊 |
|---|---|---|---|
| 根拠 | 国家の軍隊 | 免状による民間委託 | なし（自称の掟のみ） |
| 収入 | 給与＋拿捕賞金 | 拿捕品の分配 | 略奪品の分配 |
| 標的 | 敵国艦船 | 免状記載の敵国船 | 儲かる船すべて |
| 捕まったとき | 捕虜交換 | 原則として戦争捕虜扱い（ただし免状や発行主体の正統性を争われることがある） | 縛り首 |
| 立場が変わる契機 | 脱走・反乱 | 講和・発行者の失脚 | 恩赦・編入 |

> 海賊「私は合法です」
> 国家「昨日まではな」

### 0-2. 分類の軸
1. **正統性** ― 免状・恩赦・海軍との関係
2. **国家と陸** ― 出資者・港・総督・外交
3. **船内社会** ― 掟・選挙・専門職・懲罰
4. **稼業と戦闘** ― 拿捕・威嚇・換金
5. **航海の敵** ― 自然・病気・火災
6. **末路と裁判**
7. **記号とフィクション**
8. **地域別バリエーション**

## 1. 正統性あるある（「俺たちは海賊じゃない」）

### 1-1. 私掠免状があるので海賊ではない【史】
- 国王の名で発行された拿捕免許（Letter of Marque）を盾に、略奪を「合法な戦争行為」と主張する。
- 名乗りがやたら長く仰々しい（国王の称号を全部唱えてから本題に入る）。
- やっていることは商船襲撃・積荷奪取・拿捕・捕虜取り・港の襲撃で、見た目は海賊と同じ。違いは「国家が許可しているか」だけ。
- **効き**：言葉の格式と中身の落差でコメディにも風刺にもなる。

### 1-2. 「敵国船しか襲ってません」【混】
- 船長「スペイン船しか襲っておりません」→ 役人「今月からスペインとは和平した」→ 船長「……聞いておりませんでした」
- 通信の遅い時代、和平の報が届く前の拿捕は実際に揉め事の種になった。
- **効き**：情報の遅延が罪を生む。

### 1-3. 国庫に上納しているので善良【混】
- 略奪品の一部を国家・出資者に納めることで「公認の商売」を自称する。
- 英仏の私掠では、**拿捕品はまず拿捕審判所（Prize Court）で合法な拿捕かどうか審査され、認められて初めて競売・分配された**。これが分配の中心で、審判所を通さずに売った時点で海賊行為に近づく（1-11）。
- 「五分の一を国王に」は、スペインのキント・レアル（王室五分の一税）を連想させる便利なフィクション的言い回し。**ただし私掠船の拿捕品分配とは別の制度**で、実際の王室・出資者・船主・船員の取り分は国・時代・契約によって異なる。
- **効き**：無法者が意外と書類と税に縛られている。

### 1-4. 本人基準の「善良」【混】
- 「無抵抗の船員は殺さない」「降伏した船は沈めない」「教会は襲わない」「仲間を裏切らない」と独自の倫理を語る。
- 「女子供は殺したことがない」→「ではどうした？」→「もちろん売った」。
- そもそも略奪している、という前提を本人だけ見ていない。
- **効き**：当時の倫理と読者の倫理のズレを、笑いにも怖さにも転じられる。

### 1-5. 大義は神と国王、標的は利益次第【混】
- 「常に神と国王の敵と戦ってきた」と宗教・愛国を前面に出すが、実際の標的は儲かるかどうかで柔軟に変わる。
- **効き**：建前と本音の二重帳簿。

### 1-6. 戦争が終わると梯子を外される【史】《大西洋・18世紀初頭》
- 戦時「勇敢なる海の英雄！」→ 戦後「武装した無職が数千人海をうろついている……」。
- 国家は海軍編入・商船乗組員・植民地警備・恩赦・武装解除などを提示し、拒否すれば普通の海賊扱い。
- 「海軍に入るか、海賊として縛り首か。選ぶのは君達の自由だ」という**自由意思の体裁をとった強制**。
- 史実でもスペイン継承戦争後に失業した私掠船員が大量に海賊化し、海賊黄金時代につながった。
- **効き**：主人公は何も変わっていないのに、世界の側がラベルを貼り替える理不尽。

### 1-7. 海軍は甘い顔、裁断権は常に国家【混】
- 「編入すれば正規兵として扱ってやる」と寛大さを見せつつ、最終判断はいつでも覆せる立場にいる。
- **効き**：選択肢を与えられていること自体が支配の表現になる。

### 1-8. 免状が後から「偽物だったことになる」【混】
- 戦争終了、国王交代、発行者の失脚、政権交代、総督交代、条約締結などで、合法だった免状が紙切れになる。
- 「それを発行した総督は処刑された」「しかし当時は総督でした！」「政府見解では最初から無効だったことになった」。
- 本物かどうかより、**本物として扱う権力が残っているか**が問題。
- 史実の近似例はキャプテン・キッド。ただしキッドの委任状そのものが偽物扱いされたわけではない。クェダー・マーチャント号の拿捕を正当化する決め手だったフランスの通行証が、総督ベロモントの手元に留め置かれ、裁判で提出されなかった。その通行証の存在は後世に確認されている。
- **「権利を証明する紙を持っていても、法廷に出なければ存在しないのと同じ」**という派生型。1-11と直結する。
- **効き**：紙一枚に命を預けている危うさ。政治劇への接続点。

### 1-9. 一斉恩赦（Act of Grace）【史】《英国・1717〜18年》
- 期限内に投降すれば罪を許すという布告。
- 恩赦を受けた直後にまた海に出るやつが必ずいる。
- **効き**：恩赦を受けるか、受けて裏切るか、拒むかで船内が割れる。

### 1-10. 相手国から見れば全員ただの海賊【史】
- 自国では英雄、敵国では賞金首。同一人物の評価が国境で反転する。
- **効き**：視点人物を変えるだけで善悪が入れ替わる。

### 1-11. 拿捕審判所で合法性を争う【史】
- 拿捕が合法だったかを、審判所で書類と証言をもとに争う。中立国の船か、積荷は誰の物か、免状の期限内か、といった点が争点になる。
- 書類の不備や手続きの遅れで、正当なはずの拿捕が無効とされ、船も積荷も返還、ということがある。
- 審判所が遠い・判決が遅い・費用がかかるので、待ちきれずに勝手に売り払う者が出る。
- **効き**：海の戦果が陸の書類仕事で覆る。法廷劇・手続きコメディの種。

### 1-12. 誰の国の船か、実は簡単ではない【史】
- 船主はオランダ人、船長は英国人、船籍はポルトガル、積荷はフランス商人の物、荷主はスペイン植民地、保険はロンドン、乗員は多国籍。私掠船長「……これ敵船か？」
- 船籍、荷主、積荷、通行証、中立国かどうか、禁制品かどうか。どれを基準に「敵」と判定するかで拿捕の合法性が変わり、拿捕法は複雑になっていった。
- **効き**：1-11の審判所争いの火種。襲う前に悩む私掠船長、という型。

## 2. 国家と陸あるある（本当の海賊は陸にいる）

### 2-1. 国家にとって便利な否認可能性【史】
- 敵国の貿易は妨害したいが、海軍を正式に動かせば戦争になる。だから民間武装船にやらせる。
- 成功すれば「勇敢なる民間人の活動です」、失敗すれば「我が国とは無関係の海賊です」。
- **効き**：国家が使い捨ての道具として海賊を扱う構図。

### 2-2. 海賊船はほぼ共同出資事業【史】
- 船を買う者、大砲を出す者、食料を出す商人、人を集める船長がいて、略奪品を分配する。いわば海賊スタートアップ。
- スポンサーには貴族・商人・政治家が多く、表に出ず、失敗すると知らん顔をする。
- **効き**：出資者と実行者の責任の非対称。

### 2-3. 港町と海賊はズブズブ【史】《カリブ》
- 略奪品は現金化できなければ意味がない。商人、酒場、娼館、造船所、武器商人、闇市場、賄賂の効く役人が必須。
- 法の届かない自由港に海賊が集まり、稼ぎを溶かす（ナッソー、トルトゥーガ、ポート・ロイヤル型）。
- 海賊港の最期にも型がある。自然災害で一夜にして沈む**ポート・ロイヤル型**（1692年の地震）と、新総督の着任・恩赦・海軍の圧力で政治的に解体される**ナッソー型**（ウッズ・ロジャーズの着任、2-7と連動）。
- **効き**：群像劇の舞台装置、巨大な地下経済圏。

### 2-4. 総督が取り締まらない理由【混】
- 海賊は金を落とし、商人は儲かり、港は栄え、総督には税が入る。
- 本国「海賊を取り締まれ！」 総督「現在調査中です」。
- **効き**：現地と本国の利害のずれ。

### 2-5. 政権が変わると全員売られる【混】
- 新総督「本国との関係改善のため海賊を処刑する」。昨日まで酒を酌み交わしていた相手が翌日は絞首台に上がる。
- **効き**：庇護者の交代イコール死亡フラグ。

### 2-6. 海賊から提督・総督へ【史】
- 敵国を荒らした功で叙勲される（ドレイク型）、元海賊が植民地の副総督になる（ヘンリー・モーガン型）。
- 「海賊として成功したら国家に潰される」とは限らない。**国家側に取り込まれて統治者になる出世ルート**もある。
- ※モーガンは「ジャマイカ総督」と書かれがちだが、正しくは副総督。
- **効き**：成功した略奪者は、歴史上は英雄と呼ばれる。

### 2-7. 元私掠が海賊狩りに転職【史】
- 恩赦を受けた者や元私掠船長が、海賊討伐の側に回る（バハマ総督ウッズ・ロジャーズ型）。
- 手口を知り尽くしているので強く、かつての仲間を吊るす立場になる。
- **効き**：同業者を一番よく知るのは同業者。

### 2-8. 文明から逃げたはずが文明に依存【混】
- 「自由な海で生きる！」と言いながら、補給港・商人・市場・修理施設・情報網がないと一日も回らない。
- **効き**：海賊もののテーマとして強い自己矛盾。

### 2-9. 最強の武器は大砲ではなく情報【混】
- 商船がいつ出港し、どこを通り、何を積み、護衛がいるか。知らなければ襲えない。
- 情報源は港湾労働者、商人、酒場、船員、税関、港役人、密輸商。
- **港の商人こそ海賊団の情報部**。
- **効き**：2章「本当の海賊は陸にいる」を象徴する型。スパイ物・諜報劇への接続点。

## 3. 船内社会あるある（実は妙に民主的）

### 3-1. 海賊の掟（Articles）に署名する【史】《大西洋黄金時代》
- 加入時に契約書へ署名する。分け前、罰則、負傷補償まで条文化されている。字が書けない者は×印。
- **効き**：無法者の集団が、国家より細かい法を持っている皮肉。

### 3-2. 船長は選挙で選ばれ、選挙で降ろされる【史】《大西洋黄金時代》
- 戦闘中は船長の命令が絶対、平時は船員会議。
- 船長「私は船長だぞ！」 船員「だから？」。臆病や強欲がバレると即解任で、海軍より民主的だったりする。
- ※適用範囲：これは**黄金時代（17世紀後半〜18世紀前半）のカリブ・大西洋の海賊**に目立つ特徴。出資者が船長を任命する私掠船や、大名・領主に仕える東アジアの水軍には当てはまらない。
- **効き**：カリスマ船長の失墜劇。

### 3-3. 本当に怖いのはクォーターマスター【史】《大西洋黄金時代》
- 分配・規律・揉め事の裁定を担う船内の文官で、船長の権力を牽制する。
- **効き**：実権を握るNo.2、陰の主役ポジション。

### 3-4. 分け前の比率が細かい【史】《大西洋黄金時代》
- 船長2口、士官1.5口、平水夫1口など。腕や脚を失うと定額の補償がある。
- **効き**：金勘定の生々しさがリアリティを出す。

### 3-5. 替えの利かない専門職が一番偉い【混】
- **航海士**：死ぬと「俺たち今どこにいる？」になる。
- **船大工**：穴・マスト・舵・浸水、全部「船大工！」。死ぬと全員死ぬので、荒くれ者も「親方だけは怒らせるな」となる。
- **船医**：「脚を切る」「他の治療は？」「ラム酒を飲ませる」「麻酔は？」「私が飲む」（キャラ類型としての誇張）。
- **火薬庫担当**：「煙草吸っていい？」「殺すぞ」。神経質なのが合理的。
- 専門職は拿捕した船から強制徴用されがちで、本人は裁判で「無理やり乗せられた」と証言して助かろうとする。
- **効き**：巻き込まれ型主人公の入口。腕っぷし以外の序列が描ける。

### 3-6. 船上の懲罰は特殊【史】《大西洋黄金時代》
- 牢屋がないので、鞭打ち、配給減、取り分没収、追放、海へ落とす、などになる。
- 代表が**孤島への置き去り（marooning）**で、水と弾一発の銃だけ渡して放置する。
- **効き**：復讐劇の起点として鉄板。

### 3-7. 多国籍・多民族の寄せ集め【史】
- 脱走水兵、元奴隷、失業した私掠船員など、出自がバラバラ。
- **効き**：陸の身分制から逃げてきた者たちの「ここだけの平等」。

### 3-8. 転職歴がおかしい【混】
- 漁師 → 商船員 → 海軍水兵 → 脱走 → 私掠船 → 海賊 → 恩赦 → 海軍。
- 本人「ずっと船乗りですが？」
- **効き**：1-6の境界移動を一人の経歴で見せる。

### 3-9. 海賊同士も仲良くない【混】
- 縄張り争い、略奪品争い、裏切り、船員の引き抜き。特に航海士と船大工は争奪戦になる。
- **効き**：「海賊共和国」の理想と現実。

### 3-10. 強制乗船と脱走が日常【史】
- 海軍は強制徴募隊（プレスギャング）で港の男を連れていき、海賊は拿捕した船の乗組員に「加わるか置いていかれるか」を迫る。専門職に限らず、本人の意思で乗っていない者が一定数いる。
- 逆方向も多い。待遇の悪い海軍や商船から脱走して海賊に加わる者、上陸のたびに逃げ出す者。人員の目減りは常に船長の悩みの種。
- **効き**：乗組員一人ひとりの「なぜこの船にいるか」が違う。3-5・3-8・6-1（「無理やり乗せられました」）と連動。

### 3-11. 船員が増えすぎても困る【混】
- 略奪品100を10人で分ければ一人10、100人なら一人1。**強くなるほど一人当たりの配当が減る**。
- 大船団は常に強いわけではなく、補給・統率・分配の問題が爆発する。
- **効き**：海賊連合の崩壊イベント。拡大と分裂のサイクル。

## 4. 稼業と戦闘あるある（戦うより脅す方が多い）

### 4-1. 船は沈めたくない【史】
- 目的は船と積荷を奪うこと。沈めたら損になる。
- 理想の流れは「威嚇 → 降伏 → 拿捕 → 積荷回収 → 船も売る」。
- **効き**：映画的な撃沈シーンとの対比。

### 4-2. 戦闘の本命は接舷【史】
- 帆・舵・マストを壊して足を止め、甲板を制圧する。艦隊戦というより強盗。
- 弾種で狙いを変える：丸弾は船体、鎖弾は帆やマスト、散弾は甲板の人員。
- **効き**：戦闘描写に目的の違いを持たせられる。

### 4-3. 降伏させるための評判経済【史】
- 商船長は「戦えば10人死ぬ、渡せば全員助かる」と計算して降伏する。
- 海賊側も「抵抗しなければ殺さない」評判を作った方が得。虐殺癖があると商船は死ぬまで抵抗する。
- **残虐性にも経済合理性がある**。恐ろしい噂を意図的に流しつつ実は温厚、という型も作れる。

### 4-4. 海賊旗はブランドロゴ兼心理兵器【混】
- 旗そのものが降伏勧告。有名な旗ほど「あいつには逆らわない方がいい」が効く。
- **効き**：名前と旗が武器になる。

### 4-5. 偽旗で近づく【史】
- 友好国の旗で接近し、射程に入ったら本当の旗を上げる。
- **効き**：正体を明かす瞬間の演出。

### 4-6. 宝の大半は日用品【史】
- 実際の獲物は布、砂糖、酒、薬、帆、ロープ、そして船そのもの。
- 黒髭は薬箱を要求してチャールストン港を封鎖した。
- **効き**：ロマンと現実の落差。

### 4-7. 身代金と人質交渉【史】
- 人そのものが最大の商品で、高貴な捕虜は丁重に扱われる。
- **効き**：捕虜と海賊の奇妙な関係。ロマンスの定番入口でもある。

### 4-8. 通行料を取る海の関所【史】《東アジア》
- 航路を押さえ、払った船は守り、払わない船は襲う（村上水軍の帆別銭型）。
- **効き**：海賊が実質的な地方政権として振る舞う。

### 4-9. 拿捕した船に乗り換える【史】
- 小船で出航 → より強い商船を拿捕 → 乗り換える → さらに大きな船を拿捕 → 旗艦化。
- 船は固定資産であると同時に、**敵から現地調達できる装備**。
- **効き**：成り上がりの段階を船で見せられる。ゲームの成長システムにも転用しやすい。

---

## 5. 航海の敵あるある（最大の敵は海軍ではない）

### 5-1. 自然と病気の方が怖い【史】
- 嵐、座礁、腐った水、壊血病、感染症、食料不足、船体の腐食。
- 「敵艦だ！」「まだ何とかなる」 「樽の水が腐った！」「終わった」。
- **効き**：敵のいない危機、サバイバル展開。

### 5-2. 船は巨大な可燃物【史】
- 火薬、木材、帆、ロープ、油、酒を満載している。火の扱いが生死を分ける。
- **効き**：火災イベント、火薬庫ネタ（3-5と連動）。

### 5-3. 疫病が港と船団を壊滅させる【史】《カリブ》
- カリブの港町では黄熱やマラリアが繰り返し流行した。持ち込まれた病気で船内が一気に倒れることもある。
- 大艦隊の遠征が戦闘より病気で兵力を失う例は珍しくない（1741年の英軍カルタヘナ遠征など）。
- **効き**：寄港が安全とは限らない。疫病の港への入港判断、検疫、船を捨てるかどうかの決断。

## 6. 末路と裁判あるある

### 6-1. 捕まったときの言い訳大会【混】
- 「私掠船です」「免状は？」「沈没時に失いました」
- 「私は料理人なので略奪には参加していません」
- 「無理やり乗せられました」
- 「海賊だとは知りませんでした」「三年乗ってただろ」
- **効き**：法廷コメディ、群像の締めくくり。

### 6-2. 海賊裁判は政治【混】
- 同じ人物が、戦争中は英雄、講和後は犯罪者、外交が悪化すると再び英雄になる。
- **法より外交が海賊の運命を決める**。
- **効き**：1章の正統性テーマの帰着点。

### 6-3. 縛り首と晒し（ギベット）【史】
- 処刑後、遺体を鉄の籠に入れて港の入口に晒す。見せしめ。
- **効き**：冒頭の不吉な情景として鉄板。

### 6-4. 処刑台での最後の演説【混】
- 悔悟する者、開き直る者、出資者を告発する者。
- **効き**：最後の一言で人物を締める。

### 6-5. 足を洗って陸の商人・農園主に【史】
- 成功者ほど静かに引退する。
- **効き**：「元海賊の老人」が過去を語る額縁構造。

### 6-6. 誰にも知られず海に消える【史】
- 嵐、反乱、病気。大半の海賊の最期は記録に残らない。
- **効き**：英雄譚の裏にある無名の死。

## 7. 記号とフィクションあるある

### 7-1. 宝は埋めない、すぐ売る【混】
- 埋めるには、売れる財産を運び、穴を掘り、隠し、また取りに来る必要がある。手間がかかりすぎる。
- 実例はごく少数だが伝説だけが増殖した。宝島伝説は**フィクション的あるある**として分離して扱う。

### 7-2. 見た目と小道具

| 眼帯・義足・鉤爪の手 | 【混】 | 負傷は職業病。義足の補償規定は掟に実在 |
| 肩にオウム | 【虚】 | 『宝島』の影響が大きい |
| 板歩きの刑 | 【虚】 | 史実の記録はほぼない。後世の創作が定着 |
| 宝の地図と×印 | 【虚】 | 『宝島』由来 |
| ドクロ旗（ジョリー・ロジャー） | 【史】 | デザインは船ごとにバラバラ。砂時計・槍・心臓なども |
| 赤旗＝容赦なし | 【混】 | 皆殺しの合図とされる |
| ラム酒と「ヨーホー」 | 【虚】 | 歌は後世の創作 |

### 7-3. フィクション専用の類型
- 海賊王、義賊、呪われた海賊、幽霊船。史実の制約から切り離して使う。

## 8. 地域別バリエーション

> ※この章の地域・集団は、型を説明するための例示である。実在の民族・宗教・地域の性質として書かない。史実として本文へ出す事項は別途資料で確かめる。

### 8-1. カリブ海（バッカニア／黄金時代）
- スペインの財宝船団が獲物。英仏蘭の私掠と海賊の境界が曖昧。

### 8-2. 地中海（バルバリア海賊／マルタ騎士団）
- イスラム側・キリスト教側の双方が、聖戦を名目に船と人を襲う。
- 人質・奴隷の身代金ビジネスが中心で、捕虜を買い戻す修道会まで存在した。
- **効き**：宗教が私掠免状の役割を果たす型。

### 8-3. 東アジア（倭寇／水軍）
- 前期倭寇と後期倭寇。実態は多国籍の密貿易集団。
- 日本の水軍は大名に仕える正規戦力であり、通行料を取る海の領主でもある。
- 秀吉の海賊停止令で「海賊」という生き方そのものが禁じられる。1-6の東洋版。

### 8-4. 南シナ海（清代の大海賊連合）
- 数万規模の船団を女性首領の鄭一嫂が率い、最後は清朝と交渉して投降・恩赦を得た。
- **効き**：国家と対等に交渉できる規模まで育った海賊。

## 用語集への登録

作品独自の制度・組織・船・港・旗の名前は、作品の `world.md` の `## 用語` に置く（書式は [world_glossary.md](../world_glossary.md)）。

- 免状・恩赦・拿捕審判所・海賊の掟のように手順・条件を持つ制度は、種別を制度とし、「定義・適用範囲」に誰が発行し、何を許し、何で無効になるかを書く。本文はその条件どおりに描き、台詞で条件と食い違うことを言わせない。
- 新しく制度や名前が要ったら、本文に出す前に `## 用語（承認待ち）` へ登録案を書く。免状が後から無効になる型（1-8）を使うときは、無効になる条件を先に決めておくと後出しにならない。
- 一般の海事用語（私掠、拿捕、接舷、クォーターマスターなど）は用語集に入れない。初めて出すときは、視点人物が見て分かる形で説明を添える。

## 深掘り用の問い

必要な問いを選び、答えを `world.md`、`character.md`、`design_specification.md` など作品の適切な正本へ記録する。

1. 主人公の船は、物語の始まりで国家から何と見なされているか。終わりには何と見なされているか。
2. その立場を動かす出来事（講和・恩赦・政権交代・免状の失効）は何で、主人公は選べるのか、押しつけられるのか。
3. 出資者は誰で、失敗したとき誰が切り捨てられるか。
4. 略奪品はどこで現金化され、誰が情報を流しているか。その協力者が裏切る条件は何か。
5. 船内で実権を握るのは船長か、クォーターマスターか、替えの利かない専門職か。
6. 乗組員はそれぞれなぜこの船にいるか。恩赦が出たら誰が残り、誰が去るか。
7. 残虐の評判と実際の振る舞いは一致しているか。ずれているなら、それを誰が知っているか。
8. 物語の終わりに、主人公は提督・総督になるか、縛り首か、陸の商人か、海に消えるか。
