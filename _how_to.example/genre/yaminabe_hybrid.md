# 闇鍋・多題材混交（トンチキ闇鍋）創作リファレンス

> 一行で言うと──**「局所は狂ってよい。大域の因果は狂わせない。そして納得とは、読者の予測更新が成功した状態である」**

---

## Monogatari Coach での使い方

「多題材混交」「闇鍋型」「トンチキ×超真面目」「異文化・異制度衝突」「コメディ風味だが骨太な推進軸を持つ作品」の Plan Mode および評価（下読み・整合性監査）で参照する。
奇抜な設定や一発ネタの見本市に堕ちるのを防ぎ、**「出汁（推進軸）による消化」**と**「鍋の運用（摩擦・因果・代償）による納得」**を両立させて物語を着地させるためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | F1 世界法則（一文）、F2 出汁（全員が巻き込まれる具体的面倒事）、ログライン、読後の美点（「馬鹿なのに綺麗」） |
| `config.md` | ジャンル（闇鍋・多題材混交）、投入世界（3つ以内）、作品の規模とトーン |
| `design_specification.md` | F4 争奪構造、F5 進行条件と最小刻み、F6 不可逆な残り猶予、出汁の型（X1〜X7）、一話ごとの接続規則（C1〜C5）、遅効再利用（X8） |
| `world.md` | F3 常識の階層（三層分類）、F6 不可侵リスト（壊してよいもの／いけないもの）、制度・手続き・現場の癖 |
| `character.md` | 人物の切実な欲求（本気度）、語りの水位・ツッコミ役（F4）、紐づく欲望の露出 |
| `_meta.md` | 出汁の現在値／終端値（F3）、進行条件の残余、F7 代償台帳のトラッキング、伏線と遅効再利用の管理 |

設計時は、最低限次を決める。

- **出汁（IUS）を先に決める**：出汁（推進軸）が決まっていない状態で具材（要素）を選ばない（A9 設定見本市への転落防止）。
- **基底テスト（G）を通す**：それまでの積み上げ（獲得物・知識・関係・代償・判断材料）が次の攻略に引き継がれる不可逆な局面変化を維持する。
- **摩擦は「欲求 × 手続き」で置く（C1）**：侍が宇宙船に乗ること自体ではなく、侍の切実な欲求と宇宙船の運用規則が衝突することで笑いとドラマを生む。
- **地の文は世界の常識側に立つ（F4）**：作者や地の文がツッコまない。人物は本気で悩み、温度差で納得させる。

# 第1部：出汁（推進軸）設計フレームワーク（IUS）

多題材混交の物語において、**具材を許可するのではなく消化させる**ための軸を設計する。
対象は「異質な題材が次々出てくるが、読み進める理由が切れない」状態の維持。

**適用範囲**：進行に締切または残り猶予のある物語。滞在型・関係鑑賞型には F6 が過剰な制約になりうる（§1.9）。

---

## 1.0 中心命題と基底テスト

> **出汁とは目的ではない。目的＋計測単位＋不可逆性の三点セットである。**

「金塊を探す」は目的にすぎない。「刺青人皮を◯枚集める／局面は元に戻らない」まで含めて初めて出汁になる。
計測単位のない目的は、具材を消化できず、話数を消費するだけになる。

### 基底テスト（G）

本フレームワークの判定は、最終的に次の一問に還元される。

> **G：それまでの積み上げ（獲得物・知識・関係・代償・読者の判断材料）は、この出来事のあとも次の攻略に引き継がれるか。**

- 引き継がれる → C2（妨害）／C3（変質）として正常
- 引き継がれない → A1（差し替え）／A3（リセット）／A8（免除）のいずれか

A1・A3・A8 は別々の欠陥ではなく、G の違反が現れる三つの位置（目的・進行・結果）である。

---

## 1.1 原則（P）

| ID | 原則 | 内容 |
|---|---|---|
| P1 | 一文性 | 出汁は「誰が・何を・どうなれば終わるか」を一文で言える |
| P2 | 非置換 | 禁ずるのは**推進軸の無接続な差し替え**。人物の隠された動機が明かされることや、目的の意味が深まることは妨げない。判定は G による |
| P3 | 可計測 | 進捗を数える単位を持つ（枚数・段階・距離・残日数・返済額） |
| P4 | 不可逆 | 計測値は往復してよいが、局面は往復しない |
| P5 | 消化器官性 | 出汁は具材を許可する装置ではなく、具材を進行へ接続させる装置 |
| P6 | 外在性 | 出汁は世界の側にある。作者の都合ではなく、複数の人物が本気で欲している |
| P7 | 単数性 | **主たる達成判定は一つ。**補助指標を併用してよいが、役割を明示する（§1.3） |

**P4 補足**：不可逆なのは、以後の選択・戦略・関係の解釈に影響する状態変化である。
情報が一つ増えただけでは足りない。**その情報を無視して、以前と同じ局面を再演できないこと**を要する。
（例：盗難の犯人が不明でも、内部犯行と判明して仲間を同じようには信用できなくなれば、局面は変わっている）

---

## 1.2 固定フィールド（F）— 書く前に埋めて凍結する

| ID | 項目 | 記入例 |
|---|---|---|
| F1 | 目的文 | 「散逸した◯◯を集め、隠された△△に到達する」 |
| F2 | 計測単位 | 刺青◯枚 / 試験◯段階 / 航海◯日 / 借金残高 |
| F3 | 現在値と終端値 | 3 / 24 |
| F4 | 争奪構造 | 同じものを欲する勢力を最低二つ。各勢力について「先に達成したら何を壊すか／何を守るか」を必須で書く |
| F5 | 進行条件と最小刻み | 現在値を進めるために事前に必要なもの（通行許可、案内人の信用、解読器具、季節）を列挙。および一話あたり最低限動く量 |
| F6 | 回復不能な残り猶予 | 冬の到来までの日数、契約終了までの日数、共同体の解散期限、救援物資が尽きるまでの残量、同行できる期間 |
| F7 | 完了と残余 | 達成条件と、達成しても残る負債・関係・傷 |

- **F5 は C1・C2 の判定台帳**である。ここに登録されていない事柄を、事後的に「進行条件だった」と主張しない。書き進める中で新条件が生じたら、その時点で F5 に追記してから使う。
- **F6 に置くのは回復しないものだけ**。体力・所持金・信用・装備は回復・増減するため F6 ではなく、C2 と残留欄が扱う。
- F4 が空欄のまま書き始めると、出汁は主人公の私的な用事に縮む。

---

## 1.3 出汁の型（X）

| ID | 型 | 計測単位 | 向いている題材幅 |
|---|---|---|---|
| X1 | 収集 | 個数 | 最大。土地・人物・文化を無限に足せる |
| X2 | 到達 | 距離・階層 | 大。移動が話数を生む |
| X3 | 資格 | 段階 | 中。試験・組織・昇級で章立てが自動化 |
| X4 | 生還 | 残量（減算） | 中。緊張は強いが横道が入れにくい |
| X5 | 契約 | 履行率 | 大。依頼ごとに題材を替えられる |
| X6 | 追跡／逃走 | 距離差 | 中。追う側・追われる側の視点交代が効く |
| X7 | 保全 | 露見リスク（減算） | 小〜中。単独では推進力が弱く、X1 か X5 との併用が前提 |

**併用規則**：主たる達成判定は一つに定める。補助指標を併用する場合は、それが
**①主軸の進行条件／②残り猶予／③危険度** のどれに当たるかを明示する。
**補助指標の変動だけで F3 の現在値が進んだことにしない。**

---

## 1.4 接続規則（C）— 具材の入れ方

具材（奇習・珍技能・変態・料理・政治）は、次のいずれかで出汁に触れること。

| ID | 接続 | 動くもの | 内容 |
|---|---|---|---|
| C1 | 加速 | 現在値／進行条件 | 現在値を進める、または **F5 に登録済みの進行条件**を獲得・改善する |
| C2 | 減速 | 現在値／進行条件 | 現在値を後退させる、または進行条件を喪失・悪化させる。**次の判断に影響する状態変化が残ること**（G） |
| C3 | 変質 | 計測の意味 | 計測対象の真偽・価値・達成への寄与が変わる |
| C4 | 装飾 | なし | どれにも触れない純粋な余興 |

**境界**
- **C1 と C4**：C1 を主張できるのは、その進行条件が F5 に事前登録されている場合のみ。
- **C2 と A3**：奪われた／失われたあと、以後の判断が変わるなら C2。何も変わらないなら A3（リセット）。
- **C3 と A1**：真相によって解釈が変わっても、獲得物・知識・関係・代償が次の攻略に引き継がれるなら C3。従来の進行と達成への期待が一括して放棄されるなら A1（出汁の差し替え・G 違反）。
- **C3 実施時は T2 を同時に走らせる。**直後に出汁を一文で言い直せないなら、それは C3 ではなく出汁の侵食が起きている。

---

## 1.5 検定（T）

1. **T1**：今話で、**現在値・進行条件・計測の意味**のいずれかが動いたか。どれも動いていないなら C4 のみの回。
2. **T2**：出汁を今も一文で言えるか。言い直しに但し書きが要るなら、具材が出汁を侵食している。
3. **T3**：三話前の局面を、そのまま再演できてしまわないか（P4）。
4. **T4**：敵が先に達成したら何が起きるか答えられるか。答えられなければ F4 が機能していない。
5. **T5**：この具材は C1〜C3 のどれか。C1 を主張するなら、その進行条件は F5 にあるか。
6. **T6**：読者は「何がどこまで進み、次に何が必要か」を言えるか。
7. **T7**：F6 は減り続けているか。直近三章で一度も可視化していないなら、猶予が機能していない。
8. **T8**：今話で発生した利得・損失・関係変化は、次話以降も有効か（G）。

---

## 1.6 反パターン（A）

| ID | 反パターン | 症状 |
|---|---|---|
| A1 | 出汁の差し替え | 新しい目的により、従来の進行と達成への期待が一括して放棄される |
| A2 | 計測不能な出汁 | 「成長する」「真実を知る」など内面語。外形（数えられる物）へ翻訳せよ |
| A3 | リセット | 損失が誰の利得にもならず、以後の判断も変わらない。緊張ではなく徒労を生む |
| A4 | 出汁の並列 | 同格の達成判定が三本走り、どれが本筋か読者が選べない |
| A5 | 浮遊する具材 | 奇妙な回が C1〜C3 のいずれにも触れず、外伝として浮く |
| A6 | 私物化 | 出汁を主人公しか欲していない。争奪が発生しない |
| A7 | 終端の遠さ | 24枚のうち3枚では体感が動かない。中間締切を刻む |
| A8 | 結果の免除 | 笑い・様式・場面転換を理由に、発生した結果を無効化すること。損だけでなく得も持続させる |

A1・A3・A8 はいずれも基底テスト G の違反である。

---

## 1.7 運用（一話分の記入シート）

```
出汁進行 : 現在値 / 進行条件 / 計測の意味 のどれが動いたか（T1）
投入具材 : 目安として二つまで
接続     : 各具材を C1 / C2 / C3 / C4 で明示。C1 なら F5 の該当条件を書く
制約     : 使用条件・使用後の傷・違反時の罰
残留     : 次話で無視できない変化（利得・損失・関係・情報・回復可能資源の増減）
紐づく欲望: 誰の、どの飢えが、この回で一段むき出しになったか
換気     : 食／説明／観察／冗談 から一つ。笑いを理由に残留欄を消さない（A8）
```

- 記入順は**残留を欲望より先**に置く（G 判定を高速化）。
- **回収の判定は二軸で行う**：
  - **構造への接続**：その具材が、進行と以後の選択をどう変えたか。
  - **人物への寄与**：その具材が、誰の欲望をどう一段むき出しにしたか。

---

## 1.8 運用目安

| 対象 | 初期値 |
|---|---|
| 一話あたりの投入具材 | 二つまで |
| C4 の連続 | 二話未満 |
| C3 の総数 | 全体で二〜三回 |
| 中間締切の間隔 | 一章に一つ（A7 対策） |

> **一行要約**：欲望は一貫、手段は異様、**局面は不可逆**、結果は持続。

---

## 1.9 適用外・派生

- **F6 を設定できない物語**（滞在型、日常型、関係鑑賞型）：外形化できる終端（共同体の解散期限、季節、人物が同行できる期間）を一つ立てる。立てられない場合は関係の不可逆を「消えた選択肢の累計」として外形化し、減算の計測単位とする。
- **笑い（ユーモア）**：笑いは C1〜C4 のいずれとも組み合わさる演出であり出汁とは階層が異なる。本体へは「換気」以外の役割（露出・推進・増圧）を接続する。

# 第2部：鍋の運用・品質管理フレームワーク（OLLA）

多題材混交（闇鍋型）の物語において、**混ぜた結果が「破綻」ではなく「納得」に着地する**ための設計・検定資料。

出汁が決まっていない状態で本書を使わないこと。出汁が空欄のまま具材を選ぶと、A9（設定見本市）に必ず落ちる。

---

## 2.0 中心命題

> **局所は狂ってよい。大域の因果は狂わせない。**
>
> そして納得とは、整合していることではなく、**読者の予測更新が成功した状態**である。

---

## 2.1 原則（P）

**P1 納得は整合性ではなく予測更新の成功から生じる**
読者は読みながら世界モデルを組み立てている。トンチキは意図的な予測誤差の注入である。誤差が過大なら破綻、過小なら凡庸。快感が発生するのは、誤差を説明する規則を**読者が自力で見つけたとき**に限る。

**P2 結果を先に、理由を後に、全部は出さない**
作者が規則を説明すると、P1 の快感は作者に横取りされる。理由を先に置くと誤差がゼロになり、笑いも納得も消える。設定説明が退屈なのは長いからではなく、予測誤差を先に潰しているからである。

**P3 あるあるは、読者側に既にインストール済みの推論エンジンである**
稟議・確定申告・シフト表・学級会・町内会は、説明ゼロで読者が自力で先を推測できる。だから説明コストを払わずに誤差だけを注入できる。これがあるあるを使う唯一の理由であり、「知名度」は理由にならない。

**P4 混ぜるのは意匠ではなく運用**
衣装・固有名詞・必殺技を混ぜても「知っている」以上の快感は出ない。混ぜるべきは制度・人間関係・現場の癖といった運用の部品。

**P5 設定は狂わせてよいが、原因と結果は狂わせない**
壊してよいのは設定の細部と固有名詞の正確さ。壊してはいけないのは人物の欲求・因果の前後・感情の向き。

**P6 世界法則は一つだけ真剣に決める**
世界全体を合理化しない。「超常的存在も社会制度から逃げられない」「神も契約に拘束される」など、強い地盤を一本だけ置く。重要なのは「竜と確定申告が同居してよい理由」ではなく、「**竜ですら確定申告から逃げられない理由**」である。

**P7 人物は本気、作者は笑わない**
作者が笑っている世界ほど弱い。竜は住宅ローンに本気で悩み、魔王は離職率を本気で気にする。この温度差が笑いを生む。

**P8 新しい便利さには必ず代償を付ける**
何でもアリの世界が壊れる最大の原因は「何を出しても問題が解決する」こと。新要素を出すたびに新しい面倒を増やす。

**P9 新規は1、再利用は無制限**
一場面で導入する未知の規則は1つまで。既出規則の再利用に制限はない。この非対称が「ちゃんと考えてあった感」の正体である。

**P10 最後だけ論理的に着地させる**
展開は狂ってよいが「だからこうなった」は明快にする。読後に「おかしいんだけど、そうなるわ」と言えれば成功。

---

## 2.2 固定フィールド（F）

**F1 世界法則**（一文で書く）
例：「異世界人も行政手続きから逃げられない」「魔法は便利だが市場経済を壊さない程度に希少」

**F2 出汁**（第1部 `IUS` から転記）
テーマ（家族愛・自由）ではなく、**全員が巻き込まれる具体的な面倒事**を置く。
例：「魔王城を三か月以内に立ち退かねばならない」
以後、投入するあらゆる要素に「で、この要素は立ち退き問題にどう関係するのか」を問える状態を維持する。

**F3 常識の階層**

| 層 | 内容 | 例 |
|---|---|---|
| 我々の常識 | 読者が持つ現実感覚 | 竜は会社員ではない |
| 世界の常識 | 作中では当然。誰も驚かない | 竜も就職する |
| 個別の異常 | 作中人物も変だと思う。ここだけ驚かせる | 竜が火気取扱責任者資格を持っていない |

**F4 語りの水位**
地の文は常に**世界の常識側**に立つ。地の文がツッコむ作品は必ず弱くなる。ツッコミは人物の職掌であり、しかも F3 の第三層にだけ反応させる。

**F5 投入世界**（3つ以内）
4つ目からは T4（密度検定）が通らなくなる。増やしたい場合は世界を増やさず X5（掛け算）で状況を増やす。

**F6 不可侵リスト**
壊してよいもの／壊してはいけないものを事前に列挙。P5 の運用欄。

**F7 代償台帳**
新要素とその代償を対で記録する。P8 の運用欄。台帳が片側だけ伸びている作品は A5（尻すぼみ）に向かっている。

**F8 鮮度区分**
骨格には制度（稟議・相続・労基・住宅ローン）を使い、時事・流行語は香り付けにとどめる。腐る素材を構造に組み込むと作品ごと腐る。

---

## 2.3 混交の型（X）

**X1 同型置換** — 同じ手続きを別世界の名で行う
会社の稟議／ギルドの討伐申請、生徒会選挙／王位継承、炎上対応／魔王討伐の事後報告

**X2 対比強調** — 格の高い営みを低い運用で回す
聖なる儀式がパートタイムのシフト制、英雄譚の本体が経費精算

**X3 因果のねじれ** — 片方が他方の原因、あるいは劣化コピーである

**X4 三段変換** — 現実あるある → 異世界化 → 二次影響
例：人手不足 → 勇者不足 → 勇者派遣会社 → 未経験歓迎求人 → 資格試験の簡略化 → 低レベル勇者の事故増 → 勇者保険の値上げ → 魔王軍が「最近の勇者は弱い」と困る → 魔王軍が勇者育成事業に参入
二次影響まで作って初めて、ギャグが世界を動かす構造になる。

**X5 掛け算** — 足さずに掛ける
「異世界×ブラック企業」は既視感が強い。「異世界×ブラック企業×高齢化社会」にすると、四天王全員が70歳超、若手魔族が管理職を忌避、勇者側より事業承継問題が深刻、といった**既存ネタから発生する新状況**が取れる。

**X6 常識の不在** — あって当然の資格・手続き・前提が欠けている
「竜なのに火気取扱責任者資格を持っていない」。F3 第三層を作る最短の型。

**X7 まともな具材が戦犯になる** — 異常な鍋の中では常識的判断が最大の異物になる
認識の快感と皮肉が同時に取れる強い型。投入順としては後半に置く。

**X8 遅効再利用** — 序盤のくだらない設定を終盤の解決手段に転用する
P9 の実装形。T7 の対象。

## 2.4 接続（摩擦の置き場）（C）

闇鍋の本体は異物ではなく**摩擦**である。侍が宇宙船に乗っていることは面白くない。侍の価値観と宇宙船の運用規則が衝突することが面白い。

**C1 欲求 × 手続き**（基本形）
片方は人物の切実な欲求、もう片方は別世界から来た外部の手続き。
> 「拙者、敵艦へ単騎乗り込む」
> 「駄目です。船外活動申請が72時間前までなので」

**C2 人間の慣性**（界面活性剤）
世界が違っても残る層でつなぐ。面子／前例踏襲／責任の押し付け／場の空気／手続きへの依存。物理法則を統一する必要はない。**人間が世界を運用する癖**を統一するほうが納得感は高い。

**C3 翻訳接続**
現実の対象をそのまま置かず、世界固有の対象へ写像する。役所仕事 → 死者蘇生許可申請／魔王討伐補助金／ダンジョン建築確認。

**C4 二次影響の連鎖**
X4 の出力を次の要素の入力にする。

**C5 自己増殖**
トンチキが別のトンチキを因果的に生んでいる状態。ここに入れば設定同士が化学反応しており、単なるパロディを脱している。

**禁止接続**
制度 × 制度は議事録にしかならない。欲求 × 欲求は普通の人間ドラマになる。摩擦は必ず C1 の非対称で置く。

## 2.5 品質検定（T）

- **T1 推測継続検定**（採否の第一関門）：その要素を入れたあと、読者は自力で次の一手を推測できるか。
  - 推測できる → 採用（労基法、住宅ローン、事業承継）
  - 認識できるだけで推測が続かない → 却下（特定作品の必殺技名、固有名詞の引用）
- **T2 元ネタ独立性検定**：固有名詞を全部伏せ字にして、状況がまだ面白いか。面白くなければ闇鍋ではなく内輪ウケである。
- **T3 摩擦一行検定**：「〈人物の欲求〉÷〈別世界の手続き〉」の形で一行に書けるか。書けないネタはまだネタになっていない。
- **T4 密度検定**：読者が「今何と何が混ざっているか」を指差せる状態か。指差せなくなった時点で闇鍋ではなく濁り水である。併せて、その場面の新規規則が1つに収まっているか（P9）。
- **T5 説明可能性検定**：第三者に「何と何が混ざっているか」を説明させる。説明できなければ要素過多、説明しきれてしまえば驚き不足。その中間が適温。
- **T6 鮮度検定**：骨格に置いた要素は2年後も生きているか（F8）。
- **T7 回収検定**：終盤の解決に、序盤に出したくだらない要素が使われているか（X8）。
- **T8 温度検定**：人物は本気で困っているか。地の文は驚いていないか（P7・F4）。

## 2.7 設計式・実務手順・リズム

### 設計式

> **満足度 ＝ 異物感 × 因果接続 × 本気度 × 再利用 ÷ ご都合主義**
>
> **納得感 ＝ 世界法則の一貫性 ＋ 人物の反応の妥当性 ＋ 過去設定からの帰結**

### 実務手順

1. 出汁を一文で書く（第1部 `IUS` / F2）。例：「異世界でも稟議は死なない」
2. 世界法則を一つだけ決める（F1）
3. 投入する世界を3つ以内に絞る（F5）
4. 各世界から「制度・人間関係・現場の癖」を5つずつ抜き出す
5. T1 を通らないものを捨てる（意匠だけのものはここで落ちる）
6. 残った要素を C1 の形に一行で書き直す（T3）
7. X4 で三段目（二次影響）まで伸ばす
8. 常識の階層を三層に割り、驚く役を第三層だけに割り当てる（F3）
9. 一番まともな要素を、場を壊すか救う位置（後半）へ置く（X7）
10. 人物が混交世界を「異常」ではなく「いつもの現場」として扱う稿を書く（F4・P7）
11. 代償台帳を埋める（F7）
12. T2・T4・T5・T7 を通す

### 投入順の標準リズム

1. 誰もが知るあるあるを、まず素直に出す
2. 別世界の同型項を重ね、まだ笑える範囲で歪める
3. 一番まっとうな要素を後から入れ、場を壊すか救う（X7）
4. 壊れた結果が、最初の出汁へ戻る

### 到達目標

読者の読後推移が次の順に動けば成功である。

1. 序盤：「なんだこの世界」
2. 中盤：「まあ、この世界ならそうなるか」
3. 終盤：「いや待て、確かに第2話でそれ言ってたわ」
4. 結末：「なんでこんな馬鹿な話がこんな綺麗に着地するんだ」

この最後の**「馬鹿なのに綺麗」**が、満足度の高いトンチキ闇鍋の本質である。
