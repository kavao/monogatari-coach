# ラブコメ 執筆リファレンス（恋愛・ロマンス主軸）

現代恋愛、異世界恋愛、身分差、両片思い、恋愛群像を対象に、「恋愛そのもの」を物語の駆動力にする定番を、物語を動かす装置として整理した作劇用資料。
悪役令嬢ものとは軸を分け、関係の実態と本人たちの認識のずれを設計するための足場とする。

---

## Monogatari Coach での使い方

「ラブコメ」「恋愛もの」「ロマンス」「両片思い」「幼なじみ」「偽装恋人・契約結婚」「身分差恋愛」「異世界恋愛」「恋愛群像」など、恋愛を主軸に据える作品の Plan Mode で参照する。
定番を全部採用するための一覧ではなく、関係類型、主戦場にする進行段階、ずれを作り・保ち・解消する装置を選ぶためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 誰と誰が、本当の気持ちと相手の思い込みのどこですれ違うか、付き合う前の話か付き合ってからの話か、二人がどこで顔を合わせ続けるか、読者に約束する甘さと笑いの比重、最後に二人の何が変わるか。関係類型や反転させる定番の名前は `design_specification.md` 側で使う |
| `config.md` | サブジャンル（学園／社会人／異世界／身分差／群像）、恋愛とコメディの比重、トーン |
| `design_specification.md` | 進行段階ごとの装置の配置（CON → DST → CMP → AWR → … → UPD）、両片思いの維持期間、行事の配置、告白・関係更新の位置 |
| `world.md` | 舞台（学校・職場・異世界の社交界など）、身分・婚約・種族などの外的障害の制度、行事の暦 |
| `character.md` | 反応様式（ツンデレ・鈍感・からかい上手など）、自分の気持ちの認知段階、相手の気持ちの認知段階、当て馬・キューピッド役 |
| `_meta.md` | 実関係と認知関係の現在地、使用済みの装置 ID、進展阻止の残弾、周囲が知っていて本人が知らないこと |

設計時は、最低限次を決める。

- 関係類型を一つ主軸に選び、反応様式（キャラクター類型）とは別に掛け合わせる。
- 主戦場を交際前（両片思いを長く取る）か交際後（恋人になって生まれる意識）かに決める。
- 主要な二人について、自分の気持ちと相手の気持ちの認知段階を章ごとに追えるようにしておく。
- 外的な障害（家・身分・種族・寿命）を使う場合も、二人の認知・選択・すれ違いにどう作用するかへ置き換える。
- 定番の反転は原則一箇所に絞り、残りの定番を読者との共通言語として使う。
- 悪役令嬢・婚約破棄から始まる作品は `genre/akuyaku_reijo.md` を併読し、その後の恋愛を主題にする部分で本資料を使う。
- 一話・一場面単位のフックは `episode/` の葉（部活・大学サークルのラブコメ構成、親愛、恥じらい、関係の進行など）を使い、本資料は作品全体の構造に使う。

## 0. この文書の構造

あるあるを場面ネタではなく、**物語を動かす装置**として分類する。三つの軸を別々に持ち、掛け算して使う。

| 軸 | 内容 | 例 |
|---|---|---|
| **装置**（何が起きるか） | 関係を動かす出来事や状態の機能 | 接触・距離圧縮・自覚・誤認・進展阻止・比較・関係認定・関係更新 |
| **関係類型**（誰と誰か） | 二人の関係の初期設定 | 幼なじみ、身分差、偽装恋人、上司部下 |
| **進行段階**（どこまで来たか） | 関係の現在地 | 出会い → 特別扱い → 自覚 → 両片思い → 告白 → 交際初期 |

これとは別に、次の二つの層を持つ。

- **キャラクター類型**（§2）：反応の仕方。関係類型とは同じ階層に置かない。「ツンデレ幼なじみ」「クーデレ上司」「からかい上手な政略結婚相手」は、どれも「反応様式 × 関係類型」の組み合わせとして表す。
- **演出層**（§7）：媒体に依存する見せ方。状態遷移の部品ではない。

掛け算の例：

- **幼なじみ × 嫉妬**：近すぎて意識していなかった相手を、他人に取られそうになって初めて意識する
- **身分差 × 進展阻止**：「釣り合わない」という自己評価が告白を止める
- **偽装恋人 × 関係認定**：周囲からは恋人と認定されているのに、本人たちだけが本物だと認めていない

### 中心原理：実関係と認知関係のずれ

ラブコメでは、関係を次の二層に分けて扱う。

- **実関係（actual relation）**：二人が実際にどれだけ親密か
- **認知関係（recognized relation）**：それぞれの本人が、自分の気持ちと相手の気持ちをどう認識しているか。認知は**二人それぞれが別々に持つ**

```text
実関係：毎日一緒に登校する／昼食も一緒／休日も二人で出かける／互いの家族とも顔見知り
認知関係：A「ただの友達」／B「ただの友達」
```

`実関係 > 認知関係` の差が大きいほど、読者は「いやもう付き合ってるだろ」という快感を覚える。
各装置は、このずれを**作る**（CON・DST・AWR）、**広げる／固定する**（MIS・BLK）、**指摘する**（REC）、**解消する**（UPD）のいずれかとして働く。比較（CMP）は、ずれに外から圧力をかける。

例（ずれが生まれて指摘されるまで）：

```text
一緒に帰る
 → 毎日帰る
 → 相手を待つようになる                … 実関係が進む
 → 他人に「付き合ってるの？」と言われる   … REC：ずれを指摘される
 → 二人で全力否定する                  … 認知関係は据え置き
 → その日の帰り道だけ妙に気まずい         … ずれを本人が意識する
```

### 基本循環（ラブコメエンジン）

```text
接近
 → 感情変化（実関係が動く）
 → 認知との不一致
 → 圧力（障害・誤認・比較・周囲の指摘）
 → 確認／回避
 → 関係更新（または更新の阻止）
 → 新しい距離へ
```

誤認を使わない例：看病 → 意識する → 距離を取る → 寂しくなる → 自覚する

### 認知の段階

認知は、対象によって二つの系列に分かれる。進行段階（§4）とは別の軸として、キャラクターごとに持たせる。

**自分の気持ちについて**

```text
無自覚 → 兆し → 否認（「いや違うし！」） → 自覚
```

**相手の気持ちや二人の関係について**

```text
知らない → 誤解している → 薄々分かっている → 分かっているが確認しない → 確認する
```

「否認」と「分かっているが確認しない」は、どちらもラブコメに特有の強い停滞状態である。前者は自分の気持ちから、後者は相手の気持ちや関係の変化から目をそらしている。

## 1. 装置別あるある

ID は `RC-<装置>-<番号>` の形式。項目を後から追記するときは、この ID に紐づける。移動・削除した番号は欠番とし、再利用しない。

**型**の列：
- **E**（単発イベント）：一度起きて終わる
- **S**（継続状態）：設定として続き、繰り返し効く

**装置間の因果**：比較（CMP）は多くの場合きっかけとなり、その結果として自覚（AWR）が起きる。一つの場面に二つの ID が付くときは、`CMP → AWR` のように因果の順で書く。

### 1-1. 接触装置（CON）：接点を作り、継続させる

| ID | 型 | あるある | 物語上の機能 |
|---|---|---|---|
| RC-CON-01 | E | 最悪の第一印象（失態の目撃、口論、誤解） | 後の評価逆転を仕込む |
| RC-CON-02 | E | 曲がり角で衝突（パンをくわえて走ってくる派生を含む） | 強制的に接点を作る |
| RC-CON-03 | E | 落とし物・拾い物を届ける | 自然に再会させる |
| RC-CON-04 | S | 席替えで隣の席になる／窓際最後列 | 継続的な接触を自然にする |
| RC-CON-05 | S | 同じ委員・係・バイト・プロジェクトになる | 二人きりになる理由を作る |
| RC-CON-06 | E | 転校生が実は知り合い（「あ、あのときの！」） | 教室全体を巻き込んで関係を公にする |
| RC-CON-07 | E | 幼なじみと再会する | 最初から親密度を持たせる |
| RC-CON-08 | S | 弱みを握る／握られる（隠れた趣味・バイト・正体） | 主従めいた関係と秘密の共有を作る |
| RC-CON-09 | S | 親の再婚・居候・ルームシェアで同居する | 日常生活に相手を入り込ませる |

| RC-CON-11 | S | 偽の恋人・契約結婚・お見合いの代役 | 装置としての機能は「恋人らしい行動の先取り」。関係類型としての「契約恋愛」（§3）とは役割を分ける |

| RC-DST-02 | E | 雨宿り | 足止めして二人きりの時間を作る |
| RC-DST-03 | E | 停電・倉庫・エレベーターに閉じ込められる | 密室で逃げ場をなくす |
| RC-DST-04 | E | 終電を逃す | 二人きりの時間を長く取る |
| RC-DST-05 | E | 看病イベント（おかゆを「あーん」） | 弱っている姿を見せる |
| RC-DST-06 | E | 熱や酒で理性が薄れ、本音が出る | 心理的な距離が縮んで本音が漏れる。本人には言い逃れの余地が残る |
| RC-DST-07 | S | 勉強を教える／勉強会 | 顔や体が近くなる。家族に目撃される |
| RC-DST-08 | E | 親が出張で家が空く | 二人きりを意識させ、生活音が急に大きく聞こえる |
| RC-DST-09 | S | 手料理・お弁当（腕前は極端にうまいか壊滅的か） | 恋人らしい行為を半分先取りする |
| RC-DST-10 | E | ラッキースケベ（押し倒す構図を最悪のタイミングで目撃される） | 身体を意識させ、同時に誤解も生む |

| RC-BLK-02 | E | 告白が花火・鐘・放送の音にかき消される | 決着を延期しつつ、言った側には既成事実が残る |
| RC-BLK-03 | S | 好きだから避ける | 好意が嫌悪のように見える |
| RC-BLK-04 | S | 相手の幸せのために身を引く（大抵は誤解がもと） | 両片思いを長引かせる |
| RC-BLK-05 | S | 「自分なんか釣り合わない」と思い込む | 自己評価そのものを障害にする |
| RC-BLK-06 | E | 冗談めかして告白してしまう | 本音をなかったことにする |
| RC-BLK-07 | S | 告白した方が負け（プライドを賭けた頭脳戦） | 恋愛を勝負に変える |
| RC-BLK-08 | S | 鈍感・難聴系の主人公が好意に気づかない | 決着を構造的に延ばし続ける |
| RC-BLK-09 | S | 寝言や酔った勢いで本音を聞いてしまい、「聞かなかったこと」にする | 認知段階「分かっているが確認しない」を、本人の選択によって固定する |

| RC-UPD-08 | S | 付き合った途端にぎこちなくなる | 次の問題へ移る |
| RC-UPD-09 | S | 友達のときにできたことが、恋人になるとできない | 意識しすぎをコメディにする |
| RC-UPD-10 | E | 初デートで張り切りすぎる | 恋愛初心者ぶりをコメディにする |

## 3. 関係類型（初期設定）

§3 は二人の関係の**初期設定**だけを扱う。舞台ごとの傾向は §5 で扱う。

| 幼なじみB：過去の約束 | 幼い頃の約束（相手が誰かは曖昧）→ 片方だけが覚えている → 再会 → 約束の意味が変わる | CON-07 → UPD で約束を回収 |

| 上司部下／先輩後輩 | 公私の切り替えが甘い。社内恋愛を隠す | REC-03 |
| 師弟 | 尊敬と恋愛の境界が曖昧になる | AWR |

## 4. 進行段階

```text
出会い → 仲良くなる → 特別扱い → 自覚 → 両片思い → 告白 → 交際初期 → 安定期 → 結婚を意識
```

「否認」は段階としては扱わず、認知の段階（§0、自分の気持ちの系列）で表す。そのため、どの進行段階にいても否認は起こりうる。

| 段階 | 主に使う装置 |
|---|---|
| 出会い | CON |
| 仲良くなる・特別扱い | DST, AWR-03 |
| 自覚 | CMP → AWR |
| 両片思い | MIS, BLK, REC（下の定義を参照） |
| 告白 | BLK → UPD |
| 交際初期 | UPD-06〜10, BLK-10 |
| 安定期・結婚を意識 | CMP-05（元恋人）、新たな外圧 |

### 両片思いの定義

次の三つがそろった状態を「両片思い」（内部名 `mutual_unrecognized_love`）と呼ぶ。

1. **実関係**：両者とも相手を恋愛的に好いている
2. **認知**：両者とも自分の気持ちを自覚しているが、相手の気持ちは「知らない」または「誤解している」か、「分かっているが確認しない」段階にある
3. **読者**：両想いであることを知っている

この状態を作ったり保ったりする装置：MIS-05、MIS-06（誤解を作る）、BLK-04、BLK-05、BLK-09（確認を避ける）、REC-03（周囲だけが知っている）。

## 5. サブジャンル別あるある

§5 は舞台ごとに、**よく使う装置**とその舞台に固有のあるあるを扱う。関係の初期設定は §3 を参照する。

### 5-1. 現代恋愛（学園）
- よく使う装置：CON-04、CON-05、CON-06、DST-07、REC-01、§6 の行事
- 定番の舞台：屋上、放課後の教室、下駄箱のラブレター
- 家族やクラスメイトに目撃されることで、話が転がる

### 5-2. 現代恋愛（社会人）
- よく使う装置：CON-05、DST-04、DST-06、REC-03
- 上司と部下、取引先、同期
- 仕事での有能さと、恋愛での不器用さの落差（AWR-06）

### 5-3. 異世界恋愛
- よく使う装置：CON-11（政略・契約）、AWR-06（溺愛の落差）、BLK-04、UPD-05
- 婚約破棄から始まっても、主題は「その後の新しい相手との恋」（悪役令嬢の復讐劇とは別系統）
- 冷徹な公爵・氷の騎士が主人公にだけ甘い
- 召喚された側が現代知識（料理・薬）を通じて「他の誰とも違う存在」と認識され、それが恋愛上の特別視につながる
- 護衛と主、冒険者と依頼主。任務で密着するのが日常になり、任務が終わった後どうするかで悩む
- 異文化による誤解：求愛の作法の違い、番（つがい）の認定（MIS の舞台版）
- 魔法や契約で心が読めてしまう／読めない。認知のずれを、設定で強制したり解消したりする
- 異世界の行事（祭り・月見）に現代側が戸惑い、相手が優しく教える

### 5-4. 身分差
- よく使う装置：CON-01、AWR-06、BLK-04、BLK-05
- 第一印象は最悪だが、意外な生活力や優しさで見直す
- 素性を隠して出会う（お忍び）。正体が明かされる場面が山場になる
- 家の重みを背負って自分から距離を置き、相手には「嫌われた」と誤解される（BLK-04 → MIS）
- 身分差は障害であると同時に、相手の「素」を見せる装置でもある

### 5-5. 両片思い
- よく使う装置：§4「両片思いの定義」を参照
- 相手を試す駆け引きが空回りし、互いに自爆を繰り返す
- 「もし〇〇が誰かと付き合ったら」と想像して勝手に落ち込む
- 告白した方が負けという頭脳戦（BLK-07）

### 5-6. 恋愛群像
- よく使う装置：CMP-07、CMP-08、REC-04
- 合コン、実行委員、部活、旅行の部屋割りで組み合わせが入れ替わる
- 成立するカップルと成立しないカップルを対比する
- 全員に均等に恋をさせず、視点キャラクターの揺れを中心に据える

## 7. 演出層（presentation）

媒体に依存する見せ方。状態遷移の部品（device）ではなく、`presentation` として別の層で扱う。

- 赤面すると頭から湯気が出る。心臓の音が効果音で鳴る
- 「な、なんでもない！」で会話を打ち切る
- 夢オチ・妄想オチ
- 翌朝、お互いに気まずい
- 視点の交互切り替え：読者だけが両想いを知っている状態を作る
- 同じイベントを複数のカップルの視点で描く（群像）
- 最終話まで付き合わない（引き延ばしの極致）
- 最終回は結婚式か、数年後のエピローグで締める

## 8. 設計指針（恋愛そのものを主軸にする場合）

以下は絶対の原則ではなく、ラブコメで有効な傾向である。

- ラブコメの軽さを保つなら、障害の中心は「伝えられない」「タイミング」「プライド」「自己評価」といった関係の内側に置く。家・政治・種族・寿命・婚約などの外的な障害を使う場合も、それが二人の認知・選択・すれ違いにどう作用するかに置き換えて描く
- コメディは恥ずかしさと密着で、恋愛は小さな特権（看病、傘、夜の会話）で進める
- 告白を唯一のゴールにしない。交際前を主戦場にする型では、両片思いを長く取れる。交際後を主戦場にする型では、「恋人になったことで新たに生まれる意識」を使う
- 実関係が進んでいることと、本人たちがそれを認めることの間にずれを作り、そのずれ自体を笑いと甘さの源にする

## 9. 状態遷移部品としての記述（参考・未実装）

> この YAML は設計メモの書き方の一例である。Monogatari Coach のツール・検証はこの形式を読まず、作品資料に必須の形式でもない。作品の `design_specification.md` や `_meta.md` で認知の推移を整理する助けにするときだけ使う。

あるあるを単なるイベント集ではなく、状態遷移の部品として記述する。認知はキャラクターごとに持たせる。

```yaml
romcom_device:
  id: RC-AWR-01
  device: awareness
  form: event                     # event（E）| state（S）
  caused_by: RC-CMP-01            # 装置間の因果
  relation_type: childhood_friend_close   # 幼なじみA
  stage_before: friends
  actual_relation: mutual_love    # 実関係（読者は知っている）
  perception_before:
    A: { own_feeling: denial,    belief_about_other: friend_only }
    B: { own_feeling: aware,     belief_about_other: friend_only }
  obstacle: low_self_esteem
  result:
    visible: A_denies_feelings
    perception_after:
      A: { own_feeling: aware,   belief_about_other: friend_only }
      B: { own_feeling: aware,   belief_about_other: friend_only }
  stage_after: mutual_unrecognized_love   # 両片思い
```

語彙：

```yaml
device:
  CON: contact
  DST: distance_compression
  AWR: awareness
  MIS: misrecognition
  BLK: progression_block
  CMP: comparison
  REC: relation_recognition
  UPD: relation_update
own_feeling:          # 自分の気持ちの認知
  [unaware, sign, denial, aware]
belief_about_other:   # 相手の気持ち・関係の認知
  [unknown, misread, suspect, known_unconfirmed, confirmed]
flags:
  [emphasis]          # 段階を進めずに強調する
layer:
  [device, presentation]
```
