# 異世界クラフトもの ネタ帳

> 一行で言うと──**「快適に暮らしたかっただけなのに、文明革命の主犯になってしまった」**

---

## Monogatari Coach での使い方

「異世界クラフト」「ものづくり」「生産職」「辺境開拓」「技術・内政チート」を扱う作品の Plan Mode で参照する。
発明一覧を順番に消化する資料ではなく、読者へ供給する快感、技術ツリーの因果、主人公の限界、現地社会への波及を一体で設計するためのリファレンスである。
知識の出所・解説の演出・現地社会に受容される段階を主に設計するときは、関連資料 [isekai_modern_knowledge.md](isekai_modern_knowledge.md) も併読する。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 解決・称賛・積み上げのうち主軸となる快感、クラフトを行う私的な欲、差別化のレバー |
| `config.md` | ジャンル、技術到達点、魔法と工学の関係、作品の規模とトーン |
| `design_specification.md` | 一話の解決サイクル、文明ツリー、試作と失敗、社会が追いつく章、技術由来の障害 |
| `world.md` | 素材・資源・物流、現地技術、ギルドと既得権益、「なぜ誰もやらなかったか」の理由 |
| `character.md` | 主人公の前世技能、作れないもの、共同製作する仲間、反発・協力・利用を選ぶ人物 |
| `_meta.md` | 現在の技術段階、解禁済み設備、未解決の制約、社会的副作用、次に扱う不便 |

設計時は、最低限次を決める。

- 主人公の私的な欲と、どうしても作れないものを一つずつ置く。
- 技術ツリーの開始点と終了点を決め、飛躍の間に素材・設備・技能・時間の制約を置く。
- 「現地人が未発明だった理由」を固定し、現地固有の優れた技術も用意する。
- 発明の恩恵だけでなく、量産、資源枯渇、失業、軍事転用、依存などの反作用を少なくとも一度描く。
- 技術・化学・農業の記述は作劇上の略図である。工程を本文で具体化する場合は、安全性と技術的妥当性を別資料で確認する。

## 0. ジャンルの骨格

読者が金を払っているのは、大きく分けて次の三つ。

| 快感の種類 | 中身 | 供給が切れると |
|---|---|---|
| **解決の快感** | 不便 → 工夫 → 解決、の小さいサイクル | 話が停滞して読まれなくなる |
| **称賛の快感** | 現地人が驚く／認める | 主人公が偉くなりすぎて驚き役が枯渇する |
| **積み上げの快感** | 拠点・技術・仲間が目に見えて増える | 「今どこまで進んだか」が見えなくなる |

**この三つを1話に最低1つは入れる。**
理想は「不便を提示 → 作る → 誰かが驚く → 次の不便が見える」で1話を閉じる形。引きが自動的に生まれる。

## 1. 主人公の型

| 型 | 前世 | 強み | 弱み（＝ドラマの種） |
|---|---|---|---|
| **DIY／ホームセンター型** | 趣味人・職人 | 代用品発想が無限に出る | 学術的裏付けがなく、規模拡大で詰まる |
| **技術者型** | 機械・化学・土木 | 精度と再現性、規格化 | 現地の人心を軽視しがち |
| **ゲーマー型** | 廃人プレイヤー | クラフトUI・効率厨・数値管理 | 世界を「システム」として見るので情が薄い |
| **社畜型** | 会社員 | 生産管理・原価・交渉 | 断れない性格が事業を暴走させる |
| **農家・料理人型** | 一次産業 | 食と農で一気に人心を掌握 | 戦闘・政治に無力 |

> **ワンポイント：** 万能型にしない。「作れないもの」を最初に一つ決めると、仲間を入れる理由と敗北の余地が同時に手に入る。

## 2. スキル設計の定番

### 名前の定番

《クラフト》《錬金》《加工》《創造》《建築》《鍛冶》《分解》《合成》《修復》《複製》《鑑定》《収納》

### お約束の流れ

1. 授与される
2. 「戦闘スキルじゃないのか……」と落胆される
3. 現地の常識では**外れスキル**扱い
4. 数話後「このスキル、とんでもないのでは？」
5. 最終的に世界の技術基盤になる

### 三種の神器（と、その毒）

| スキル | 効能 | 制限を入れないと壊れる点 |
|---|---|---|
| **鑑定** | 素材名・用途・毒性が分かる。試行錯誤を全部スキップできる | 「調べる話」が全部消える → *情報の粒度を段階的に解禁する* |
| **アイテムボックス** | 無限収納＋時間停止。物流・保存・輸送問題が消滅 | 経済の話が死ぬ → *容量・重量・生物不可などの枷を* |
| **分解／複製** | リバースエンジニアリングし放題 | 技術習得のドラマが消える → *素材ロスや回数制限を* |

> **原則：** 強いスキルほど「物語を殺す」。**弱くするのではなく、条件を付ける。**
> 例：鑑定は「一度食べた／触れたものしか詳細が出ない」、複製は「原本が消える」など。

## 3. 文明ツリー（段階と、それぞれの見せ場）

### フェーズ0：サバイバル（第1〜3話）

水 → 火 → 寝床 → 食料 → 屋根

- 最初の道具は**石斧・木の棒・ナイフ**
- 飲用可否の判断で知識チートを最初に見せる
- 火起こしに苦労させる（ここで苦労させないと以降の万能感が説得力を失う）
- 雨で屋根の、夜で壁の重要性を知る
- 「文明ってありがたかったんだな……」

### フェーズ1：石器〜土器

石斧／かまど／石臼／**粘土**発見 → 陶器 → 保存・調理・運搬が一気に解決

> 粘土は**生活水準を数千年ジャンプさせる魔法の土**。発見シーンを大きめに書いてよい。

### フェーズ2：木炭と鉄

**木炭 → 高温 → 製鉄 → 良い道具 → もっと採れる**

このループが技術ツリー全体の起点。ここを丁寧に描くと以降の飛躍が許される。

- 主人公「まず木炭を作ろう」
- 現地人「木を……焼く？」

### フェーズ3：生活革命（読者人気が最も出る帯）

石鹸／ガラス／紙／風呂／トイレ・下水／ポンプ／井戸／保存食

- **石鹸**：灰＋油。清潔→疫病減→人口増、まで繋げると重みが出る
- **ガラス**：窓 → 瓶 → 保存 → 薬品 → 実験器具、と派生が広い
- **紙**：教育・行政・出版が変わる。**主人公が情報革命の父になる**
- **風呂／温泉**：日本人主人公なら高確率。関係性を進める便利な舞台装置

### フェーズ4：農業・インフラ

輪作／堆肥／品種改良／畝／灌漑／水車／温室／接ぎ木／測量／道路

- 「畑に腐った草を入れるだと！？」→「堆肥です」→数か月後「収穫が倍だ！」
- **水車**は製粉から始まって、木材加工・鍛冶・工場へと際限なく育つ
- 測量と地図は、民生の顔をした**軍事技術**。政治編への橋になる

### フェーズ5：機械

ネジ／ベアリング／旋盤／歯車／蒸留／活版印刷／規格統一

- **ネジ**は地味だが分岐点。ここを超えると「機械」が作れる
- **規格化**を言い出したら、主人公はもう職人ではなく**異世界ISO**
- 活版印刷は必ず**宗教・国家の警戒**を呼ぶ。ここから話が重くなる

### フェーズ6：魔法工学

魔石電池 → 魔導モーター → 魔道具 → 魔導炉 → 魔導車 → 飛行船 → 巨大兵器

> 石斧から始まった主人公が、最終巻でロボットを作っている。
> ジャンルの到達点だが、**どこで止めるかを最初に決めておく**とラストが締まる。

## 4. 「なぜ現地人は誰もやらなかったのか」問題

クラフトものの**最大の破綻ポイント**。作品開始前に理由を一つ選んで、最後まで一貫させる。

| 言い訳 | 相性のいい話 |
|---|---|
| 魔法で間に合うので工学が育たなかった | 魔法工学もの全般。最も使いやすい |
| 職人ギルドが技術を秘匿している | ギルドとの対立編が自動生成される |
| 貴族が知識を独占し、平民に教育がない | 教育・内政もの |
| 文字と紙が高価で、知識が世代を越えない | 印刷・出版もの |
| 魔物のせいで物流が寸断され、地域間で知識が共有されない | 辺境開拓・交易もの |
| かつて高度文明があり、失われた（＝退化した世界） | ダンジョン・遺跡もの |

> **裏技：** 「実は現地にも同じ技術はあったが、別の形で実装されていた」を一度やると、
> 世界に厚みが出て、現地人が急に賢く見える。

## 5. 定番発明カタログ（ツボ押さえ用）

反応がテンプレ化しているものほど、読者の期待に応えている＝安全牌。

| 発明 | 現地人の反応 | 波及先 |
|---|---|---|
| 石鹸 | 「肌がすべすべです！」→貴族が買い占める | 衛生・商業・貴族社会 |
| マヨネーズ | 「なんだこれは！！」 | 食文化・行列・店舗経営 |
| カレー／味噌／醤油 | 「う、うまい……！」翌日行列 | 香辛料交易・農業 |
| 手押しポンプ | 「水が勝手に上がってくる！」 | 村の日常・信頼獲得 |
| 下水・トイレ | 「下水……？」 | 都市計画・疫病・政治 |
| ガラス窓／鏡 | 貴族が殺到 | 建築・美容・資金源 |
| 冷蔵（氷魔法応用） | 魔法使い「そんな使い方が……」 | 食品流通・遠隔交易 |
| ゴーレム労働力 | 最初は荷運び、最後は工場 | 産業革命・労働問題 |

**貴族が欲しがるものリスト：** 石鹸／ガラス／鏡／香水／砂糖／時計／蒸留酒
主人公「庶民向けのつもりだったんだけどな……」

## 6. 人間関係のテンプレ

### 反発 → 心服の型（最頻出）

```text
村人／職人：「素人が口を出すな！」
    ↓ 実演
成果が出る
    ↓
「……弟子にしてください」
```

**使いすぎ注意。**3回目からは読者が飽きる。以降は「**認めるが従わない**」「**認めた上で利用しようとする**」に変える。

### 商人の登場

- 恰幅のいい人の良さそうな商人
- やり手の女性商人
- 商業ギルド長

「これを私に売らせてください！」→ 別室 → 紅茶 → 独占契約の話。

### 組織の階段

工房 → 弟子 → 孤児・行き場のない者を雇用 → 待遇改善 → 慕われる → 巨大組織 → 王城から召喚状

主人公「なんで？」／読者「そりゃ呼ばれる」

## 7. 敵と障害の作り方（このジャンル最大の弱点）

クラフトものは**主人公が強すぎて敵が作りにくい**。魔王を出すと途端に別ジャンルになる。
そこで、**技術そのものから生まれる障害**を使う。

| 障害 | 内容 |
|---|---|
| **量産問題** | 試作は成功。商人「一万個ください」→ 主人公「え？」→ 生産管理もの化 |
| **原料枯渇** | 木を切りすぎて禿山に。持続可能性という現代的テーマが入る |
| **模倣と特許** | コピーされる。異世界に知財概念がない → 制度を作る話へ |
| **既得権益** | 水車が製粉業者を、印刷が写字生を失業させる。**善意の技術が人を殺す** |
| **技術流出** | 敵国が同じ武器を持つ。主人公の発明が戦争を長引かせる |
| **依存** | 主人公が倒れたら全部止まる組織。属人化の恐怖 |
| **倫理** | 蒸留酒 → 中毒。火薬 → 兵器。「作れる」と「作っていい」は違う |

> **強い一手：** 主人公の発明が原因で誰かが死ぬ回を、中盤に一度置く。
> ここを通した作品と通していない作品で、後半の重量が決定的に変わる。

## 8. 差別化のレバー

ツボを押さえた上で「それらしいのに新しい」を出すための操作点。

1. **止める位置を決める** — 蒸気機関まで／魔法工学まで／あえて中世で止める
2. **不得意分野を作る** — 火が扱えない、金属が苦手、生物は無理
3. **失敗を残す** — 一発で成功させない。試作3回目で通る、くらいが読み味が良い
4. **現地の技術に敬意を払う** — 主人公が現地の職人から学ぶ回を入れる
5. **一次産業を主軸に** — 鍛冶ではなく、製塩・養蜂・製紙・林業など地味な職を中心に
6. **測る／記録する** — 度量衡、帳簿、実験ノート。「科学の作法」自体を持ち込む話は珍しい
7. **共同作業にする** — 主人公が設計し、他人が作る。組織の物語になり、群像劇に開ける
8. **時間をかける** — 「三年後」を挟む。積み上げの実感が跳ね上がる

## 9. 失速パターンと処方箋

| 症状 | 原因 | 処方 |
|---|---|---|
| 中盤で飽きられる | 驚き役が全員心服済み | 新しい土地・新しい階層（王都、他国、敵対勢力）に移す |
| 説明が長い | 技術解説が本編を圧迫 | 作る過程ではなく**使った人の反応**で描く |
| 主人公が動かない | 拠点が完成し、不便が消えた | 拠点を壊す／規模を一段上げる／外から依頼が来る |
| 技術ツリーが暴走 | 石斧→コンピュータまで一直線 | フェーズごとに「社会が追いつく話」を1本挟む |
| 誰の話か分からない | 発明カタログ化 | 主人公の**私的な欲**（風呂に入りたい等）を常に一つ持たせる |

## 10. 1話の雛形

```text
1. 不便が起きる（できれば他人が困っている）
2. 主人公が原因を見抜く（知識チートの見せ場）
3. 材料が足りない／障害が一つある
4. 工夫・代用・試行錯誤
5. 完成
6. 現地人が驚く（称賛の快感）
7. 「ということは、次はこれも作れるのでは？」（引き）
```

## 付録：語彙メモ

**素材** 木材／石材／粘土／砂／鉄鉱石／石灰／灰／獣脂／麻／樹脂／魔石／魔物素材

**工程** 採取・選別・粉砕・焼成・精錬・鍛造・鋳造・研磨・蒸留・発酵・乾燥・組立

**設備** かまど／炉／ふいご／水車／轆轤／旋盤／坩堝／窯／井戸／水路

**単位・制度** 度量衡／規格／品質等級／型番／帳簿／契約書／専売権／組合

*用途：フィクション執筆用の発想支援メモ。項目は「入れるべき正解」ではなく「読者が既に知っている型」であり、意図的に外すための地図としても使える。*
