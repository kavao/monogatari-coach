# 異世界現代知識無双 ― トロープ集 & 実作ガイド

> 現代的・科学的知識を持つ主人公が、それを持たない世界で「当たり前のこと」を語り、
> 結果として世界を動かしてしまう ― その類型を、書く側の道具として整理したもの。

---

## Monogatari Coach での使い方

「異世界現代知識無双」「知識チート」「内政・国家再建」「異世界探偵」を扱う作品の Plan Mode で参照する。
知識カタログを主人公へ丸ごと与える資料ではなく、情報の非対称性、知識の穴、説明の場面化、現地社会が受容・拒絶する過程を設計するためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 無双・再建・探偵の型、地位逆転・万能感・共犯感の主軸、知識で新たに困る主題 |
| `config.md` | 知識の出所、中核分野、作品の技術水準、知識無双と政治・事件・生活改善の比重 |
| `design_specification.md` | 反応の階梯、六つの壁、失敗と副作用、知識が政治的危険へ変わる転換点 |
| `world.md` | 現地固有の知識体系、語彙・度量衡・道具・材料・権威、「なぜ未普及か」の理由 |
| `character.md` | 主人公の中核・周辺・うろ覚え・空白、翻訳役、現地の専門家、模倣者・先行者・反対者 |
| `_meta.md` | 公開済みの知識、受容段階、誤解・模倣・副作用、危険視の伏線、未使用の失敗候補 |

設計時は、最低限次を決める。

- 主人公の知識を「中核一分野・周辺二分野・うろ覚え・空白」に分け、必要時に都合よく増やさない。
- 解説には、話す相手・話さねばならない理由・世界語へ引き受け直す翻訳役を用意する。
- 「知っている」と「現地で作れる・制度化できる」を分け、材料・道具・人手・時間・権威・言葉の壁を通す。
- 現地側にも一貫した知の体系と経験知を与え、主人公が学ぶ・負ける場面を置く。
- 成功後に、模倣、利権、依存、軍事転用、誤伝、危険視などの代償を描く。
- 医療・薬学・化学・農業・軍事などの記述は作劇上の整理であり、本文へ具体的な処置・工程・史実を書く場合は、信頼できる専門資料で安全性と妥当性を別途確認する。

関連資料：ものづくり、量産、技術ツリー、文明段階を主軸にする場合は [isekai_craft.md](isekai_craft.md) も併読する。

## 0. この文書の使い方

- **2〜3章** はキャラクター設計時に読む（誰が、何を、どこまで知っているか）
- **4〜6章** は場面を書く直前に読む（解説をどう演出するか）
- **7〜10章** が本丸。**知識は「答え」ではなく「制約」として使うと物語になる**
- **12〜13章** はプロット組み立てと最終チェック

## 1. ジャンルの定義と快感原理

### 1.1 定義

作中世界の技術水準・常識体系から**乖離した知識体系**を主人公だけが保有し、
それを**当然の事柄として**運用・解説することで、周囲との落差が物語的価値を生む類型。

転生・転移は必須条件ではない。重要なのは**情報の非対称性**そのもの。

### 1.2 快感の正体

読者が気持ちよくなっているのは、知識それ自体ではない。

| 表層 | 実際に効いているもの |
|---|---|
| 「すごい知識だ」 | 軽んじられていた者が、一瞬で価値を認められる**地位の逆転** |
| 「なるほど勉強になる」 | 学校で習った程度の知識が**通貨として通用する**という万能感 |
| 「主人公が賢い」 | 読者が主人公と**同じ側に立っている**という共犯感（読者は答えを知っている） |

→ **設計上の帰結**：主人公の初期身分は低く、知識の内容は難解すぎない方が効く。
量子力学より、手洗いと煮沸の方が強い。

### 1.3 三つの下位ジャンル

| 型 | 代表的な形 | 知識の役割 | 物語の駆動 |
|---|---|---|---|
| **無双型** | なろう系知識チート全般 | 問題の即時解決手段 | 成り上がり・承認 |
| **再建型** | 内政・国家再建・ものづくり | 社会構造の書き換え | 制度と産業の成長 |
| **探偵型** | 『薬屋のひとりごと』的 | 観察と推論の道具 | 事件・謎・宮廷政治 |

**探偵型は転生を必要としない**。世界内部で正当化された知識（変人の師、異国の書物、
特殊な生育環境）で成立するため、世界観の一貫性を壊さない。長編では最も破綻しにくい。

## 2. 主人公の設計

### 2.1 知識の出所（五類型）

| 出所 | 説明の楽さ | 世界観との整合 | 向く話 |
|---|---|---|---|
| 転生（記憶保持） | ◎ | △ 前世描写が必要 | 幼少期からの積み上げ |
| 転移（身一つで来訪） | ◎ | ○ 異物として扱える | 序盤のサバイバル |
| 異界の文献・遺物 | ○ | ◎ | 学者もの、探索もの |
| 独学の異才（猫猫型） | △ 仕込みが要る | ◎ | 宮廷、密室、長期連載 |
| 神託・夢・前世の断片 | ○ | ○ 便利だが逃げにも | 幻想寄り、ホラー寄り |

**混合が最も使いやすい**：転生記憶は「方向」だけを与え、実務は現地で学び直させる。
これだけで「思い出すだけで全部できる」という白けを回避できる。

### 2.2 知識レンジの決め方 ― 中核1・周辺2・空白多数

キャラの知識を**均一に強くしない**。以下の四層で切る。

```text
[中核]   完全に語れる         … 1分野だけ。ここが人格になる
[周辺]   要点は分かるが手は動かない … 2分野程度
[うろ覚え] 結論は知るが原理を知らない … 大量。最良の物語燃料
[空白]   まったく知らない      … 明示しておく。弱点＝人間味
```

**「うろ覚え」層こそが最重要**。

- 「たしか青カビが効くはず」→ 精製できず失敗する
- 「輪作すればいいんだったか」→ 作物の組み合わせを間違える
- 「消毒には酒」→ 度数が足りず効かない

正しい知識より、**半分正しい知識**の方がドラマになる。

### 2.3 身分と動機

- 落差を作るため、**初期身分は低い**（下女、平民、幼児、奴隷、流れ者）
- 「目立ちたくない」は定番だが、**毎回解決するなら早めに動機を上書きする**
  （借金、家族、故郷、単なる知的好奇心、退屈が嫌い、等）
- 承認欲求を否定しているキャラほど、承認された瞬間が効く

## 3. 知識ジャンル別カタログ

| 分野 | 定番ネタ | 必要な前提 | 作中インパクト | 実装難度 |
|---|---|---|---|---|
| **衛生** | 手洗い、煮沸、消毒、上下水道、便所の位置 | ほぼ不要 | 極大（死亡率が動く） | 低 |
| **医療** | 感染症、脱水、栄養失調、止血、隔離、産褥熱 | 権威との衝突 | 極大 | 低〜中 |
| **薬学** | 毒の同定、用量、抽出、鎮痛、解毒 | 薬草知識、器具 | 大 | 中 |
| **食品** | 発酵、保存食、塩蔵、温度管理、調味料 | 塩・容器・時間 | 中（掴みが良い） | 低 |
| **農業** | 輪作、堆肥、接ぎ木、選抜育種、灌漑 | 土地と権限、数年 | 極大だが遅効 | 中 |
| **化学** | 蒸留、石鹸、灰汁、酸・アルカリ、染料 | 器具・耐熱・燃料 | 中〜大 | 中〜高 |
| **数学** | 位取り、筆算、割合、測量、確率 | 記数法の導入 | 地味だが基盤的 | 低 |
| **商業** | 複式簿記、原価計算、在庫、信用、価格戦略 | 識字と数字 | 大（静かに効く） | 低 |
| **工学** | 滑車、水車、歯車、ふいご、規格化 | 素材と職人 | 中〜大 | 高 |
| **行政** | 戸籍、統計、検地、防疫体制、法の整備 | 権力へのアクセス | 極大 | 中 |
| **軍事** | 兵站、衛生、陣形、狼煙、暗号 | 立場 | 大 | 中 |
| **心理・話術** | 誘導尋問、認知の偏り、群集心理、交渉 | なし | 中（低コストで映える） | 低 |

### 分野選択の指針

- **序盤**：衛生・食品・心理（元手がいらない、即効性、読者に分かりやすい）
- **中盤**：医療・薬学・商業（社会的地位が上がる）
- **終盤**：行政・農業・工学（世界の構造が変わる。ここは数年単位で描く）

**基礎的なものほど無双しやすい**。石鹸・蒸留・消毒・発酵・統計。
逆に、火薬・蒸気機関・電気は前提技術が深すぎて、書けば書くほど嘘が増える。

## 4. 「解説」の演出

### 4.1 誰が・誰に・何のために話すか（四類型）

| 型 | 話す動機 | 相性 |
|---|---|---|
| **独白型** | 自分の思考整理。読者だけが聞いている | 探偵型、寡黙なキャラ |
| **教導型** | 相手を動かす必要がある | 実務、危機の現場 |
| **尋問型** | 問い詰められて仕方なく答える | 宮廷、法廷、権力者相手 |
| **論破型** | 反対者を黙らせる | 会議、学者、迷信との対決 |

**独白型以外は必ず「話さねばならない理由」を先に置く**。
理由なしに解説が始まると、そこで小説がテキストに戻る。

### 4.2 翻訳役（ワトソン役）を必ず置く

主人公の言葉を、その世界の語彙に**引き受け直す**キャラ。

> 主人公「脱水症状ですね」
> 側近 「……つまり、身の内の水が足りぬということか」
> 主人公「まあ、そうです」

この一往復があるだけで、解説が会話になる。翻訳役は同時に、
**読者の理解速度の代理**でもある。分からないときに分からないと言ってくれる人。

### 4.3 語彙の壁 ― 存在しない言葉をどう扱うか

| 方針 | 効果 | 注意 |
|---|---|---|
| うっかり口を滑らせて訂正する | 定番。異物感が出る | 多用すると芸がなくなる |
| その場で造語・命名する | 世界に痕跡が残る。強い | 命名は権力行為。誰が許すか |
| 徹底して言い換える | 世界観が濁らない | 説明が長くなる |
| 地の文だけ現代語、台詞は世界語 | 読みやすい | 視点の統一が要る |

> 「ビタミンが……」
> 「びたみん？」
> 「……食い物の、目に効く成分です」

### 4.4 長さの管理

- **一度の解説は、原則3〜4文で切る**。それ以上は相手に質問させて分割する
- 解説の途中で**手を動かさせる**（湯を沸かす、布を裂く、匂いを嗅ぐ）
- 説明の直後に**必ず結果を見せる**。理屈→実演→変化、の三点セット
- 会話で処理できないほど長い説明は、**そもそも読者が読みたがっていない**

## 5. あるある集（場面テンプレ）

そのまま使える定型。順序は使用頻度順ではなく、場面の流れ順。

### 導入 ― 認知の落差

1. **みんなが迷信で片付けている現象を、主人公だけが原因まで理解している**
   > 「呪いではありません。中毒です」／「祟りじゃない。感染です」
2. **主人公にとっては常識、世界にとっては革命**
   > 手洗い、煮沸、便所の位置、休ませる、水を飲ませる
3. **「別に大したことじゃない」と本人だけが思っている**
   > 「こんなの誰でも分かるでしょう」／周囲「分からん」
4. **周囲がちょうどよく無知**
   > 「煮沸すれば」「しゃふつ？」「湯を沸かすんです」「そんな方法が……！」

### 観察 ― 感覚と推論

5. **匂いだけで成分を推測する** ― 甘い杏仁の香り、微かな金属臭
6. **一口で毒を特定し、本人だけ嬉しそう** ― 舌の痺れ、後を引く苦味
7. **爪・唇・肌・瞳孔・歩き方・食べ残しから生活習慣まで当てる**
8. **他人が見落とす「量」を見ている** ― 何人が、何日で、何度目か
9. **本人は結論を先に言い、根拠を後から並べる** ― 周囲は順序に混乱する

### 解説 ― 語りの型

10. **専門分野になると急に饒舌になる** ― 普段「別に」／毒の話「まず急性毒性と慢性毒性が」
11. **突然の先生モード** ― 「そもそも毒というものは――」
12. **妙に分かりやすい比喩を出す** ― 「身体を城だと」「血管は水路です」「病は侵入者です」
13. **世界にない言葉をうっかり使い、言い直す**
14. **専門用語を誰かが翻訳してくれる**
15. **権力者相手でも専門知識だけは譲らない**
    > 皇帝「余に毒を盛った者は誰だ」／主人公「その前に食生活を改めてください」

### 実践 ― 手を動かす

16. **「確かめれば分かります」で実験が始まる** ― 身分社会なのに方法論だけ近代的
17. **なぜか道具がそこそこ揃う** ― 火、水、布、酒、灰、薬草。この五つで大抵やる
18. **再現実験で犯人だけ顔色が変わる**
19. **一度失敗して、条件を変えて二度目で成る** ― 一発成功は読者が信じない
20. **成果より先に、副作用が出る**

### 反応 ― 周囲

21. **偉い人が主人公の説明を面白がる** ― 「続けよ」「面白い娘だ」／主人公は帰りたい
22. **職人・古老が最初に反発し、最後に味方になる**
23. **知識を披露するたび評価が一段上がる** ― 変人 → 役に立つ変人 → 手放せない変人 → 国家的重要人物
24. **本人は出世したくない。なお毎回解決する**
25. **味方が増えるのと同じ速度で、危険視する者も増える**

### 変奏（使い減りしにくい）

26. **知識が通用しない** ― 前提が違う、素材が違う、魔法がある
27. **正しいのに採用されない** ― 慣習、利権、面子
28. **知識が誤解されて広まる** ― 「煮沸が効く」→「湯に神が宿る」
29. **誰かが主人公の知識を模倣し、中途半端に運用して被害を出す**
30. **主人公が世界の側の知恵に負ける** ― 経験則が近代知識を上回る瞬間

## 6. 周囲の反応の階梯（七段）

主人公の社会的位置は、この階段を昇る。**飛ばすと安っぽくなる**。

| 段 | 状態 | 代表的な台詞 |
|---|---|---|
| 1 | 黙殺 | （誰も聞いていない） |
| 2 | 嘲笑 | 「下女が何を言う」 |
| 3 | 困惑 | 「言っている意味が分からぬ」 |
| 4 | 検証 | 「では、試してみよ」 |
| 5 | 驚愕・称賛 | 「魔法か」「神の御業か」 |
| 6 | 依存・囲い込み | 「あれを手放すな」 |
| 7 | 畏怖・危険視 | 「あの娘は、知りすぎている」 |

**7段目を用意しているかどうかが、短編と長編を分ける。**
知識は力であり、力を持つ者は必ず政治の対象になる。

## 7. 障害の作り方 ― 「六つの壁」

現代知識は、そのままでは実装できない。**壁の一つ一つが、そのままエピソードになる。**

| 壁 | 内容 | 物語への転換例 |
|---|---|---|
| **材料** | 原料が手に入らない・高価・産地が遠い | 交易、採掘、代替品の探索、盗み |
| **道具** | 耐熱・気密・精度・透明度が足りない | 職人との交渉、試作の連続、破損 |
| **人手** | 技能者がいない、分業が成立しない | 弟子の育成、ギルドとの対立 |
| **時間** | 発酵・乾燥・育種は季節と年を要する | 待つ間に政変が起きる、間に合わない |
| **権威** | 許可・慣習・利権・宗教が阻む | 論争、根回し、実演、断罪 |
| **言葉** | 概念そのものが世界に存在しない | 命名、教育、誤解の拡散 |

### ゼンメルワイス反射

**正しさは、受容の理由にならない。**
むしろ「これまでの死者は我々の落ち度だった」と認めさせる知識ほど、激しく拒絶される。

医者に手洗いを説くとき、主人公が敵に回すのは無知ではなく**professionの誇り**である。
ここを書けると、知識ものが一段深くなる。

## 8. 失敗と副作用のカタログ

無双を成立させるには、**負け方の在庫**が要る。

- **原理は合っているが精度が足りない**（度数の低い酒では消毒しきれない）
- **前提が違う**（水質、気候、土壌、そもそも人体の作りが違う世界）
- **副作用**（下剤が効きすぎる、堆肥で寄生虫が広がる、保存食で塩害）
- **社会的副作用**（効率化で職人が失業、識字で身分秩序が揺らぐ）
- **知識が敵に渡る**（毒の作り方、兵站の要点）
- **依存**（主人公がいないと回らない体制ができてしまう）
- **時期尚早**（成功しすぎて、周囲がついて来られない）
- **記録が残らない**（口伝で歪み、次代には迷信に戻る）

最後の一つは終盤の主題になりうる。**知識を残すことは、知識を使うことより難しい。**

## 9. 考証の地雷原

「それらしさ」を壊しやすい定番。異世界なら設定で回避できるが、**回避したと分かるように書く**こと。

| やりがちな描写 | 実際に必要なもの | 回避策 |
|---|---|---|
| 透明な耐熱ガラス器具がある | 平滑・透明・耐熱ガラスは相当に高度 | 陶器、金属、竹筒、厚手の土鍋で代用 |
| すぐ高純度の蒸留酒 | 冷却器と反復蒸留 | 度数が上がらず失敗、から始める |
| 「摂氏◯度で」 | 目盛りのある温度計 | 湯気、泡、色、指、経験則で語らせる |
| 砂糖を気軽に使う | 精糖は高価な奢侈品 | 蜂蜜、水飴、干果、麦芽 |
| 酵母を「培養」する | 単離の概念と器具 | 酒母、種継ぎ、前回の生地 |
| 規格の揃ったネジ・歯車 | 旋盤とゲージ、標準化された計測 | 木製、楔、縄、個体差込みで描く |
| 分単位の時間指定 | 機械時計 | 砂時計、水時計、線香、脈拍、詠唱 |
| ペニシリンを作る | 工業的な精製と力価管理 | 「効かなかった」で終わらせるのが誠実 |
| 全身麻酔 | 近代化学 | 酒、阿片、失神、痛みを描く覚悟 |
| 抗生物質的な万能薬 | 同上 | 対症療法と看護に寄せる |
| メートル・グラムで語る | 度量衡の統一 | 身体尺、地域単位、統一自体を物語に |
| アラビア数字と筆算が通じる | 位取り記法の普及 | 「ゼロ」の導入をイベント化できる |
| 火薬をすぐ作る | 硝石の安定確保 | 硝石丘、糞尿の管理、数年かかる |
| ジャガイモ・トマト・唐辛子 | 新大陸原産 | 異世界なら自由。歴史ものでは厳禁 |
| 活版印刷で即量産 | 鋳造技術、紙、インク、文字数 | 表音文字なら有利、表意文字は不利 |

**原則**：主人公が「知っている」ことと、その世界が「作れる」ことは別。
両者の距離が、そのまま物語の長さになる。

## 10. 「なぜ今まで誰もやらなかったのか」問題

読者が最も冷める瞬間は、**世界の側が馬鹿に見えたとき**。
必ず答えを用意しておく。用意できない知識は使わない。

| 理由づけ | 例 |
|---|---|
| **禁忌**である | 死体に触れてはならない、火を扱えるのは特定身分のみ |
| **コスト**が合わない | 分かっていても燃料・人手が足りない |
| **分業**で断絶している | 作る者と使う者が口をきかない |
| **記録**が失われた | かつては知られていた。廃墟に痕跡がある |
| **必要がなかった** | 魔法・気候・地形が代替していた |
| **実は知られている** | 一部の者は知っていて、隠している ← 最も強い |

最後の選択肢は特に有効。**「誰が、なぜ隠していたのか」がそのまま長編の背骨になる。**

## 11. 陳腐化を避ける差別化

1. **知識の分野を絞り、深く掘る** ― 万能より偏執
2. **世界の側にも知の体系を持たせる** ― 占星術・医方・錬金術に内的整合を与える
3. **主人公が学ぶ側に回る場面を必ず作る** ― 現地の経験知に一度負ける
4. **知識を持つ第二の人物を出す** ― 敵でも、先行者でも、模倣者でも
5. **成功の代償を描く** ― 誰が損をしたのか
6. **時間を飛ばす** ― 育種・制度・教育は、年単位の経過が効く
7. **知識で解けない問題を主題に据える** ― 感情、身分、信仰、死
8. **語り口で差をつける** ― 淡々／皮肉／過剰に親切／面倒くさがり

## 12. エピソード骨格テンプレ

### A. 疫病型（衛生・医療）

異常な死 → 迷信による誤対応 → 主人公の観察 → 原因の特定 → **反対される** →
限定的な実演 → 効果の証明 → 制度化の要求 → 政治的抵抗 → 部分的勝利

### B. 毒殺・事件型（探偵型の基本）

不可解な症状 → 呪い・祟りとして処理されかける → 症状の分解 → 毒物の同定 →
入手経路の逆算 → 再現実験 → 動機の露見 → 権力者の裁定 → 主人公は褒賞を嫌がる

### C. 産業立ち上げ型（ものづくり）

不足の発見 → 原理の想起 → 試作①失敗（材料の壁） → 職人との出会い →
試作②失敗（道具の壁） → 成功 → 需要の爆発 → 利権との衝突 → 標準化・継承

### D. 内政・再建型

統計を取る（ここが最初の異常事）→ 実態の判明 → 優先順位の決定 →
小さな成功 → 抵抗勢力 → 制度化 → 数年後の風景の変化

### E. 論争型（会議・法廷）

権威者の主張 → 主人公の反論（証拠なし）→ 嘲笑 → 検証条件の合意 →
実演 → 沈黙 → 「では、なぜお前がそれを知っている」← **次の謎へ**

E型は短く、緊張が高く、シリーズの繋ぎに使いやすい。
