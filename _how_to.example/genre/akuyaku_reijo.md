# 悪役令嬢もの 執筆リファレンス

乙女ゲーム／小説世界の「悪役令嬢」に転生・憑依した主人公が、破滅を回避しようとするジャンルの構造・道具立て・語彙をまとめた作劇用資料。
定番の網羅と、それを外すための足場づくりを目的とする。

---

## Monogatari Coach での使い方

「悪役令嬢」「乙女ゲーム転生」「破滅回避」「婚約破棄」「断罪・ざまぁ」を扱う作品の Plan Mode で参照する。
定番を全部採用するための一覧ではなく、作品が約束する快感、原作知識の限界、現実の人物との乖離、反転させる一点を選ぶためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 情報優位・評価のズレ・逆転の主軸、読者とのジャンル契約、反転させる定番 |
| `config.md` | 転生／憑依／ループ等の型、恋愛と政治の比重、ざまぁの強度、作品のトーン |
| `design_specification.md` | 原作イベント、破滅までの期限、回避行動、第二の目的、断罪・反証・決着 |
| `world.md` | 原作世界の強制力、爵位・婚約・継承・学園・社交界の制度、現実層との乖離 |
| `character.md` | 原作上の役割と現実の動機、主人公の知識の穴、敵役の有能さ、恋愛配置 |
| `_meta.md` | 既知／未知の原作情報、改変済みイベント、世界線の乖離、未回収フラグ、誤解と評価の変化 |

設計時は、最低限次を決める。

- 三つの快感の主軸を一つ選び、他二つは補助に置く。
- 主人公が知っている原作情報と、知らない・誤認している情報を先に固定する。
- 破滅回避の期限と、回避後も主人公を動かす第二の目的を用意する。
- 主要人物には「原作に書かれなかった動機」を一つずつ与え、勝利のために周囲を愚かにしない。
- 定番の反転は原則一箇所に絞り、残りの定番を読者との共通言語として使う。
- 爵位・敬称・婚約制度は架空世界向けの定型であり、特定時代・地域の史実として扱わない。人物名を採用するときは作品の文化圏と既存人物との重複を確認する。

## 0. ジャンル契約（読者が黙って期待しているもの）

このジャンルの読者は、以下を「約束」として読み始める。破ってもよいが、破ると分かった上で破る。

| 契約 | 内容 | 破ったときに起きること |
|---|---|---|
| 主人公は知っている | 世界の未来を知る唯一の存在である | 情報優位の快感が消える。別の優位（能力・血筋）で埋める必要 |
| 主人公は理不尽に嫌われている | 原作設定という不当なレッテルが貼られている | 「かわいそう」の初期投資がなくなる |
| 努力は必ず報われる | 破滅回避の行動は、遅れてでも評価される | 徒労の物語になる。文芸としてはあり、ジャンルとしては重い |
| 悪意は最終的に暴かれる | 冤罪・讒言は白日の下に晒される | 読後感が濁る。連載では離脱要因 |
| 主人公は自分の価値に気づかない | 周囲の高評価と自己認識がズレ続ける | ラブコメの燃料が消える |

**核となる快感は三つ。**

1. **情報優位** — 読者と主人公だけが未来を知っている
2. **評価のズレ** — 本人は必死、周囲は感嘆（勘違いコメディ）
3. **逆転** — 溜めた不当な評価が、一点で反転する（断罪・ざまぁ）

この三つのうち、どれを主軸に据えるかで作品の顔が決まる。三つ全部を等分にやると平坦になる。

## 1. 世界の三層構造

悪役令嬢ものは、常に三つの層が重なった状態で進行する。ここの整理を怠ると中盤で破綻する。

```text
[原作層]   ゲーム／小説のシナリオ。既定のイベントと結末。
    ↕
[現実層]   実際に生きている人々。原作に書かれなかった動機と生活がある。
    ↕
[主人公層] 前世の記憶と価値観。原作知識という不完全な地図。
```

### 設計上の要点

- **原作知識の解像度を、最初に決めて固定する。**
  「メインルートは覚えているが、サブキャラの背景は知らない」「攻略した1キャラのルートしか知らない」「攻略本の情報だけ知っている」など。ここが曖昧だと、都合よく思い出す主人公になり信頼を失う。
- **原作層と現実層の乖離を、物語の推進力にする。**
  原作では「悪役の父」だった人物に、実は理由があった——この落差が中盤の栄養になる。
- **「強制力」を出すなら、ルールを明文化する。**
  発動条件・回避条件・コストを決めておく。何となく強制力が働く世界は、都合のいい脚本装置に見える。

## 2. プロット骨格の四類型

### A型｜破滅回避型（王道）

```text
覚醒 → 猶予期間（準備・鍛錬・人脈）→ 原作イベント接近 → 断罪 → 逆転 → 新生活
```

- 覚醒タイミングは「幼少期」（準備期間が長い＝内政・成長を描ける）か「断罪直前」（緊迫感重視）の二択がほぼ全て。
- 中盤は「回避のための行動が、別のフラグを立てる」で回す。
- 最大の落とし穴は**中弛み**。猶予期間に山を最低二つ置くこと。

### B型｜断罪後開始型

```text
断罪・追放（冒頭）→ 底からの再起 → 元の国の衰退 → 再会 → 拒絶
```

- 開幕から最大の見せ場を消費するので、読者を掴む速度は最速。
- 「ざまぁ」を主軸にする場合はこの型が最も効率がいい。
- 課題は**後半の目的設定**。追放先での新しい目標（商会・王妃・研究）を早めに立てる。

### C型｜ループ型

```text
死 → 巻き戻り → 別解の試行 → 死 → …… → 真相の露見 → 解決
```

- 各周回に「前回得られなかった情報」を必ず一つ置く。
- 周回を重ねるごとに主人公が摩耗する描写を入れると、ジャンル内で頭一つ抜ける。
- 三周目以降はダイジェスト化してよい。全周回を等しく書くと読者が飽きる。

### D型｜開き直り型（本物の悪役令嬢）

```text
覚醒 → 回避を試みて失敗／最初から放棄 → 悪役として全力で勝ちに行く
```

- 「善行と誤解される」の逆。**本気の悪辣さで、正しく恐れられる**。
- 読者の共感は「痛快さ」で維持する。倫理ではなく手際で好かれる主人公。
- 攻略対象を敵として処理できるので、逆ハーレムを避けたい作品に向く。

## 3. 登場人物ロール表

| ロール | 原作での役割 | 本編で担う機能 | 外し方の例 |
|---|---|---|---|
| 悪役令嬢（主人公） | 断罪される嫉妬深い令嬢 | 視点・情報優位・成長 | 転生していない本物／記憶が偽物 |
| 王太子（婚約者） | ヒロインを選び婚約破棄する | 最大の破滅フラグ／後の後悔役 | 政治的に婚約破棄が不可能 |
| ヒロイン | 純真な平民の少女 | 対立軸／もう一人の転生者 | 実は被害者、共闘相手 |
| 攻略対象たち | ヒロインを取り合う | 好感度の誤爆先 | 全員がヒロインを回避する |
| 父（公爵など） | 厳格・無関心 | 家門の力＝国家級リソース | 娘の変化に最初に気づく人 |
| 母 | 厳しい淑女教育 | 社交界のラスボス／後ろ盾 | 母もまた転生者 |
| 兄・弟 | 敵対または不在 | 過保護／シスコン化 | 兄こそが真の黒幕 |
| 侍女 | モブ | 忠誠の可視化装置 | 監視役として送り込まれた密偵 |
| 宰相・国王 | 背景 | 断罪の是正装置 | 断罪そのものを仕組んだ側 |
| 隣国の王子 | 未登場 | 追放後の受け皿 | 主人公を政治利用しに来る |

**運用の要点** — 「原作では書かれなかった動機」を、主要人物一人につき一つ用意する。それだけで人物が現実層に立ち上がる。

## 4. 定番トロープ・カタログ（機能別）

### 4-1. 導入

- 前世の記憶が蘇る（きっかけ：頭を打つ／既視感／断罪の宣告そのもの）
- 「ここ、前世でプレイした乙女ゲームだわ」
- 婚約成立・入学式・断罪直前のいずれかで覚醒
- 死亡／処刑エンドという明確なタイムリミットの提示
- 前世は日本の一般人（社畜・学生・OL）
- ゲーム知識がうろ覚え、推しキャラのルートしか覚えていない
- 鏡を見て「知っている顔」に驚く

### 4-2. 回避行動

- 攻略対象と距離を取る → 逆に好感度が上がる
- 婚約破棄を歓迎する → 相手が動揺する
- 幼少期から人格を改める（使用人に優しく、弟妹を虐げない）
- 学業・魔法・剣術に打ち込む（追放後の自活準備）
- 領地経営・商売を始める（石鹸、化粧品、菓子、カフェ、衣料）
- 国外・修道院への逃げ道を確保する（資産の分散、隣国人脈）
- 原作の悲劇的事件を、発生前に潰す

### 4-3. 勘違い／評価のズレ

- 悪役ムーブのつもりが善行になる
- 高笑いが妙に板についてくる
- 生存戦略の結果、聖女扱いされる
- 冷淡な態度が「照れ隠し」と解釈される
- 婚約者が離れるどころか執着を強める
- 攻略対象全員の好感度が上がり、シナリオが崩壊する
- 本人だけが「まだ破滅フラグが折れていない」と焦っている

### 4-4. 恋愛配置

- 王太子が実は一途だった
- 第二王子／腹黒宰相子息／騎士団長が参入
- ラスボス・魔王ルート（「悪役同士」の構図）
- 隣国の王子が追放後に厚遇する
- 義弟・従兄弟の重い執着
- ヒロインとの百合ルート
- 誰とも結ばれず、事業と自立を選ぶ

### 4-5. ヒロインの変奏

- ヒロインも転生者（悪役令嬢を倒せば主人公になれると信じている）
- ヒロインが純粋な善人で、普通に友人になる
- ヒロインが猫を被った悪女で、冤罪を仕掛けてくる
- ヒロインが天然の人たらしで、意図せず全員を落とす
- ヒロインもまたシナリオに怯えていて、二人で逃走を図る
- ヒロインの背後に、彼女を操る第三者がいる

### 4-6. 舞台イベント

- 王立学園への入学（身分差の集約装置）
- 入学式での攻略対象一斉登場
- 生徒会＝攻略対象の巣窟
- お茶会という名の政治
- 魔法実技での無双
- 舞踏会・文化祭（告白・冤罪・断罪の発生地点）
- 社交シーズンとデビュタント

### 4-7. 断罪

- 卒業パーティーでの公開婚約破棄
- 大勢の前での罪状読み上げ
- 提示される証拠が妙に杜撰（手紙、証言、破れたドレス）
- 主人公側が全ての反証を用意済み
- 国王・宰相の途中介入
- 婚約破棄を宣言した王子が廃嫡される
- 断罪の場が、そのまま主人公の独立宣言になる

### 4-8. ざまぁ

- 追放後、国が傾く（主人公が裏で支えていた）
- 実家の商会が撤退し、経済が停止する
- 有能な人材（使用人・騎士・職人）が主人公について行く
- 元婚約者が後悔し、復縁を申し出て断られる
- ヒロインの虚偽が魔道具・記録・証言で露見する
- 追放先の方が豊かで、実質栄転
- 隣国の王妃となり、格差が最大化する

### 4-9. 内政・生活改善

石鹸／マヨネーズ／砂糖菓子・チョコレート／衛生改革（手洗い・上下水道）／農業改革（輪作・肥料）／簿記・複式簿記／印刷／学校設立／医療知識

> 注意：内政パートは「効果が出るまでの時間」を省略しがち。一冬越す、収穫を待つ、といった時間経過を挟むだけで説得力が跳ね上がる。

### 4-10. メタ・特殊

- シナリオ強制力が存在する
- 好感度ゲージや選択肢が視界に表示される
- 原作知識が中盤から役に立たなくなる（世界線の乖離）
- 悪役令嬢本人ではなく、侍女・母・執事・モブに転生する
- ゲームではなく小説世界（読者知識として未来を知る）
- 「悪役令嬢という役割」自体が世界の要請であり、誰かが必ず担わされる

## 5. 雰囲気をつくる語彙・話法

### 5-1. 爵位と敬称

- **爵位** 公爵 ＞ 侯爵 ＞ 伯爵 ＞ 子爵 ＞ 男爵（＋辺境伯・準男爵・騎士爵）
- **呼称** 陛下（国王）／殿下（王族）／閣下（高位貴族・将官）／〜卿／〜様／お嬢様
- **家名の扱い** 「アルデンヌ公爵令嬢カタリナ」のように〈家名＋爵位＋令嬢＋個人名〉が定型
- **場面語** 夜会、茶会、社交シーズン、デビュタント、王妃教育、婚約者、後見人、家令、侍従、領民、王都、離宮

### 5-2. 令嬢口調

| 要素 | 例 |
|---|---|
| 一人称 | わたくし |
| 語尾 | 〜ですわ／〜ますの／〜ですのよ／〜ですこと／〜かしら |
| 挨拶 | ごきげんよう |
| 依頼 | 〜してくださいまし／〜していただける？ |
| 高笑い | オーッホッホッホ！ |
| 決め台詞 | 「わたくしを誰だとお思い？」「身の程をお弁えなさい」 |

**運用のコツ** — 地の文まで令嬢口調にすると可読性が落ちる。**地の文は前世由来の現代的な言葉、台詞だけ令嬢口調**という二層構造が主流であり、そのギャップ自体がこのジャンルの笑いの源泉になっている。

```text
「ごきげんよう、殿下。本日はよいお日和ですこと」
（うわ出た本命。頼むから話しかけないでほしかった）
```

### 5-3. 定番の一言

- 「貴様との婚約を破棄する！」
- 「わたくし、破滅フラグを回避いたしますわ」
- 「これは……あの乙女ゲームの世界？」
- 「かしこまりました、お嬢様」
- 「どうぞ、お好きになさいませ」

## 6. 断罪シーンの構成テンプレート

このジャンル最大の見せ場。以下の七拍で組むと安定する。

1. **場の設定** — 卒業パーティー、全校生徒と貴族が集う。逃げ場がない構図を明示
2. **宣告** — 王太子が指を突きつけ、婚約破棄を宣言
3. **罪状** — ヒロインへの嫌がらせ、階段から突き落とした、持ち物を捨てた等
4. **証拠提示** — 証人、手紙、破れたドレス。杜撰であることを読者にだけ悟らせる
5. **反証** — 主人公が淡々と一つずつ潰す。ここは順番が命（弱い証拠から潰し、最後に決定打）
6. **崩壊** — 真犯人・黒幕の露見、王太子の狼狽
7. **裁定と離脱** — 国王または宰相が現れ処断。主人公は感謝も謝罪も受け取らず退場する

**外し方の例**

- 主人公が反証を一切用意せず、全て認めて自ら出て行く
- 断罪される側が王太子で、主人公が断罪する側に回る
- 反証に成功した結果、主人公が新たな厄介事（王位継承争い）に巻き込まれる

## 7. 「ざまぁ」の設計

痛快さは、**溜め × 落差 × 主人公の無関心**で決まる。

- **溜め** — 主人公が受けた不当な扱いを、序中盤で具体的に積む。抽象的な「嫌われていた」では効かない
- **落差** — 相手が失うものを事前に価値づけておく。王太子の地位、ヒロインの居場所、家の名誉
- **無関心** — 主人公が復讐に執着しないほど効く。「もう興味がありませんの」が最強の一撃
- **第三者の口** — 主人公が自慢しない。周囲が「彼女がいなくなってから、この国は」と語る形にする

**避けたい形** — 主人公が長広舌で相手を罵倒する。溜飲は下がるが、主人公の格が落ちる。

## 8. 定番を一箇所だけ反転させる

このジャンルは定番が読者との共通言語になっている。**全部崩さず、一箇所だけ捻る**のが最も効率がいい。

| 定番 | 反転 | 生まれる物語 |
|---|---|---|
| 婚約破棄されて追放 | 政治的に婚約破棄が不可能 | 逃げられない主人公が、内側から関係を作り直す話 |
| ヒロインと敵対 | 二人とも攻略対象から逃げたい | 共闘・逃走劇・百合 |
| 断罪を回避する | 回避した結果、世界が破綻する | 「悪役の空席」を巡るメタミステリ |
| 未来を知っている | 知っているのは主人公以外の全員 | 監視され誘導される恐怖 |
| 前世は日本人 | 前世の記憶が捏造だった | 誰が、なぜ植えつけたのか |
| 破滅を回避する | 破滅こそが唯一の救済だった | 悲劇的アイロニー |
| 攻略対象に好かれる | 好かれるのは主人公ではなく「役割」 | 誰も自分を見ていない孤独 |
| ざまぁで終わる | 断罪した相手が本当に破滅し、後味が悪い | 復讐の代償を問う話 |

## 9. 陥りやすい失敗

- **原作知識が便利すぎる** — 必要なときに必要なだけ思い出す。地図の穴を先に決める
- **周囲が馬鹿になる** — 王太子やヒロインを愚かにすればするほど、勝利の価値が下がる。敵は有能に
- **中盤の目的が消える** — 「破滅回避」は達成後に目的を失う。第二の目的（家族・国・自分の望み）を中盤で立てる
- **内政チートの時間感覚** — 発明した翌週に国が豊かにならない
- **善行の連鎖が単調** — 良いことをして褒められるだけの章が三つ続くと読者が離れる。必ず代償か誤解を挟む
- **登場人物が多すぎる** — 攻略対象を五人全員書こうとして全員薄くなる。二人に絞って厚くする
- **令嬢口調の全面採用** — 読みにくさで離脱される
- **説明の前倒し** — 冒頭で世界設定と原作あらすじを一気に語ると三ページで飽きられる

## 10. 冒頭とタイトル

### 10-1. 冒頭パターン

| 型 | 一行目の例 | 効果 |
|---|---|---|
| 断罪開幕 | 「——貴様との婚約を破棄する」 | 最速で掴む。以降を回想で処理 |
| 覚醒開幕 | 頭を打った瞬間、わたくしは自分が誰なのか思い出した | 王道。共感の導線 |
| 日常先行 | 茶会の席で、わたくしは今日も嫌われていた | 状況説明が自然。掴みは弱い |
| 追放開幕 | 国境を越えたとき、雨が上がった | 静かに始まる文芸寄り |
| メタ開幕 | この世界には、悪役令嬢の席が一つある | 特殊設定を先に提示 |

### 10-2. タイトルの型

- `【状況】＋【主人公の意志・宣言】` — 「破滅フラグしかない悪役令嬢に転生したので、領地経営で生き延びます」
- `【誤解】の構造を示す` — 「悪役令嬢として振る舞っているのに、なぜか全員好感度が上がります」
- `【逆張り】の明示` — 「わたくし、断罪されたいのですが」
- `【短い象徴語】` — 文芸寄り・単行本志向のときはこちら。「令嬢の空席」「オーッホッホの作法」
