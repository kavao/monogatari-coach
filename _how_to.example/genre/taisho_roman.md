# 大正ロマン 執筆リファレンス（物語様式）

後世が「大正ロマン」として抽出・再構成した物語様式の、中心原理・対立軸・参照系統・定番の型・年代の注意をまとめた作劇用資料。
袴や洋館といった表層ではなく、新旧の世界が同居する時代の語り型を設計するための足場とする。

---

## Monogatari Coach での使い方

「大正ロマン」「大正もの」「帝都」「ハイカラ」「女学生」「書生」「華族・没落旧家」「モガ・モボ」「帝都怪奇」など、明治末〜昭和初期の日本を様式として扱う作品の Plan Mode で参照する。
定番を全部採用するための一覧ではなく、参照系統、年代レイヤー、境界人の置き方、時代が踏みに来る一点を選ぶためのリファレンスである。

| 作品資料 | 主に反映する項目 |
|---|---|
| `proposal.md` | 参照系統（白樺系・耽美系・通俗系・二段ロケット系・乙女/BL再構成系・帝都怪奇系）、中心原理の約束、結末の型（選択ルート／剥奪ルート） |
| `config.md` | 年代レイヤー（early／middle／late）、トーン、恋愛・家・社会の比重、扱う大事件の有無 |
| `design_specification.md` | 基幹文法の各段、定番の対立軸、展開フェーズ、季節の拍子、時代が踏みに来る場面、回想枠の有無 |
| `world.md` | 家制度・身分・学校・職業の制度、場所の物語機能、年代に合った風俗・技術・通信、画面外に置くもの |
| `character.md` | 境界人としての主人公、許嫁・家族・使用人の立場と動機、属性に埋め込んだ対立軸、語り手の階級 |
| `_meta.md` | 手紙・電報など時間差のある情報の所在、形見になる小道具、誤報・すれ違いの状態、使った大事件 |

設計時は、最低限次を決める。

- 参照系統（§3）と年代レイヤー（§11）を一つずつ選ぶ。
- 主人公を旧世界と新世界の境界に置き、存在するだけで矛盾が露出する属性を与える。
- 自由の経験が中盤以前に一度「戻される」場面を置く。
- 同一作品で扱う大事件は二つ程度までに絞る。
- 許嫁や親を便利な悪役にせず、家制度に縛られた側として描く。
- 年代・制度・風俗・実在の出来事と人物の記述は創作上の定型を含む。史実として本文で確定させるときは別途資料を確認する。
- 身分差・家制度による恋愛の関係設計を細かく詰めるときは `genre/romcom.md` を併読し、一話・一場面単位のフックは `episode/` の葉を使う。

## 0. 前提：この「様式」が指すもの

- ここでいう大正ロマンは、当時の文学そのものではなく、**後世が抽出・再構成した語り型**
- 白樺派の理想主義、耽美派の感覚、新聞小説的な通俗恋愛、戦後少女漫画の再構成、現代の乙女・BL的再解釈が混線している
- 各あるあるには、次の三層が混在する。本書では物語設計を優先し、区別が効く箇所のみタグを付ける
  - `[史実]` 当時実在した社会・文化
  - `[同時代文学]` 当時の文学・演劇・歌の表現
  - `[後世様式]` 後世の大正ものが追加・典型化した型
- 設計時は、先に「どの系統を参照するか」（→ 3. トーン／参照系統）と「どの年代レイヤーか」（→ 11）を決めると破綻しにくい
- 「袴＋洋館＋ステンドグラス」は表層。様式の核は次の中心原理にある

## 1. 中心原理

> 古い世界がまだ死んでいないのに、新しい世界がもう始まっている。

> 昨日まで当然だった規範が、今日から疑えるようになった時代。

- 「ロマン」の正体は幸福ではなく、**変われるかもしれない、という予感**
- 華やかさは常に儚さとセットで語られる（甘さと冷たさの同居）
- 自由と民主の気分が満ちているが、長くは続かない予感が画面の外にある

### 基幹文法（物語テンプレート）

```
旧い秩序の中で暮らしている
↓
近代的な人物・場所・思想に出会う
↓
「別の人生」が存在すると知る
↓
一時的にその自由を経験する
↓
家・身分・経済・世間・国家がそれを阻む
↓
旧世界にも守るべきものがあると知る
↓
新世界にも代償があると知る
↓
終盤分岐
├─ 選択ルート：どちらかを完全否定せず選択する
└─ 剥奪ルート：時代が踏みに来て、選択肢そのものを消される
↓
以前とは違う日常を作る（剥奪ルートでは、残された側が作る）
```

### 設計語

| 用語 | 定義 |
|---|---|
| 境界人 | 旧世界と新世界の両方を見られる主人公。存在するだけで世界観の矛盾が露出する（→ 5） |
| 一時的自由空間 | 身分の外に出られるが、出れば戻される場所（カフェー、避暑地、学校）（→ 4-6） |
| 不在者の代理 | 本人が不在になるほど、物が雄弁になる（→ 7） |
| 時代が踏みに来る | 人物の選択に歴史が割り込み、選択肢そのものを消す（→ 4-7, 8） |
| 苦い中間解 | 旧世界を捨て切らず、元にも戻らない結末（→ 9） |

「時代が踏みに来る」の構造：

```
通常のドラマ：人物が選択する → 結果が起きる
本様式　　　：人物が選択しようとする → 歴史が割り込む → 選択肢そのものが消える
```

## 2. 定番の対立軸

```
家        ↔ 個人
伝統      ↔ 近代
見合い    ↔ 自由恋愛
和        ↔ 洋
地方      ↔ 東京
身分      ↔ 能力
格式      ↔ 資本
親世代    ↔ 若者世代
男社会    ↔ 新しい女性
家業      ↔ 職業選択
義務      ↔ 夢
共同体    ↔ 自由
過去      ↔ 未来
```

- 様式らしさは、**右側が正しく左側が悪いとは限らない**こと
- 同一人物の内部で衝突させると強い（「恋せよ乙女」と「二夫にまみえず」が一人の中に同居する）

## 3. トーン／参照系統

文学史の再現ではなく、**どの文化的系譜を参照して物語を組むか**の分類。

| 系統 | 特徴 | 終わり方の傾向 |
|---|---|---|
| 白樺系 | 理想主義・人道主義・自我の肯定 | 個人の尊厳や相互理解に出口を求める |
| 耽美系 | 美・官能・執着・倒錯が倫理より優先される | 破滅・頽廃・美の成就 |
| 通俗・新聞小説系 | 事件と因果を明示し、連載的に運ぶ | 大団円か悲劇、どちらもはっきり |
| 二段ロケット系（後世少女漫画由来） | 前半で近代化の楽しさを描き、後半で近代化の代償を払わせる | 喪失を越えての成就、または喪失そのもの |
| 現代乙女・BL再構成系 | 主従・運転手・書生・公爵など、職業衣装と身分差が主旋律 | 関係の成就が中心 |
| 帝都怪奇系 | 洋館・見世物・探偵・霊媒。近代化で消えゆく怪異の哀愁 | 謎の解明と喪失 |

### 二段ロケット型の文法

```
前半：自由・恋愛・洋装・学校・都市（お転婆コメディも可）
↓
読者に「新しい時代は素晴らしい」と思わせる
↓
後半：家・国家・病・災害が押し寄せる
↓
その新しい時代自身が人物を傷つける
```

### 笑いの文法（二段ロケット前半など）

- **安全な笑い**：格式と身体の不一致。袴で走る、洋食の作法を失敗する、慣れない洋装で転ぶ、横文字の誤用
- **トーンが現代に寄る笑い**：身分・出自そのものを笑う、世間の侮蔑を笑いで処理する
- 前者は後半の悲劇と共存できるが、後者は後半の重さを支えられない

## 4. あるある本体（8分類）

### 分類早見表：設計語との対応と最小構成

最小構成＝人物2・場所1・小道具1・対立1。

| 分類 | 主に効く設計語 | 最小構成の例 |
|---|---|---|
| 4-1 時代衝突 | 境界人 | 上京した商家の娘／下宿の書生・銀座・電話・和↔洋 |
| 4-2 家制度 | 苦い中間解 | 令嬢／父・実家の応接間・家系図・家↔個人 |
| 4-3 恋愛 | 不在者の代理 | 女学生／書生・駅・手紙・見合い↔自由恋愛 |
| 4-4 自立 | 一時的自由空間 | 女学生／女性教師・女学校・自転車・学問↔嫁入り |
| 4-5 階層移動 | 苦い中間解 | 没落華族の息子／成金の娘・洋館・借用証書・格式↔資本 |
| 4-6 近代遭遇 | 一時的自由空間 | 令嬢／女給・カフェー・新聞記事・身分↔自由 |
| 4-7 喪失 | 時代が踏みに来る・不在者の代理 | 病の文士／看取る妹・療養地・懐中時計・約束↔期限 |
| 4-8 認識錯誤 | 時代が踏みに来る | 帰還した将校／再婚しかけた許嫁・駅・電報・過去↔現在 |

### 4-1. 時代衝突型 — 和洋・旧新・地方と都市

- 新旧が一つの画面に同居する。**近代化が完了していないこと自体が景観になる**
  - 和服に革靴、袴で汽車、日本家屋に電話、洋館の隣に長屋
  - 人力車・市電・自動車が同じ道を走る
  - 毛筆の手紙と電報、畳の部屋で西洋文学、着物で珈琲
- 和洋折衷の屋敷。応接間だけ洋風で、奥は畳
- 地方出身者にとっては「東京の街を見る」だけでイベントになり、価値観が変わる

### 4-2. 家制度型 — 家督・縁談・家名・没落

- 本人「私はこう生きたい」／家「お前一人の人生ではない」
- 親が決めた縁談、許嫁の突然の登場（最初のエンジンになりやすい）
- 家業を継げ、長男なのだから、娘なのだから、家名を守れ
- 弟妹のために我慢する、父の借金を背負う
- 悪いのは親個人というより、**家という制度そのものが人物を拘束する**
- 男も家の後継として動けず、奔放な女主人公に憧れる、という逆転が起きやすい
- 家の秘密：妾の子、出生の秘密、養子、隠された兄弟、母の昔の恋、没落の原因、隠された借金
  - 世界を滅ぼす秘密ではなく、**その家の中では世界が滅ぶほど重い秘密**
- 屋敷の古参女中・ばあや・執事が秘密を全部知っている

### 4-3. 恋愛型 — 自由恋愛・身分差・手紙・別離

- 恋愛結婚そのものが「新思想」。問題は誰を選ぶかの手前、**自分で選んでよいのか**
- 身分差の組み合わせ：書生と令嬢、女中と主人の息子、華族と平民、将校と女学生、教師と元教え子、モガと保守的青年
- 許嫁と想い人の三角関係
- 温和で縛られた許嫁（多くは将校）。先に惚れるのは男側、という型が多い `[後世様式：二段ロケット系・乙女系]`
  - 通俗・新聞小説系では、逆に女側の一方的な思慕も多い
- 許嫁を悪役にしない。許嫁もまた家制度に縛られた側として描くと、制度の複雑さが残る
- 幼馴染は安全圏。本命が消えたあとの代替婚の候補になる
- 兄の友人（書生）に憧れる妹という配置
- 女学生同士の「エス」。卒業が別れの期限になる `[史実＋後世様式で増幅]`
- 教育恋愛（育てた相手が理想を超えて離れていく）は破綻しやすい `[同時代文学]`
- 駆け落ち未遂、心中の気配
- **手紙が万能装置**。通信が遅いので、気持ちと情報に時間差を作れる
  - 密かに届く、家族に見つかる、女中が取り次ぐ、誤配される
  - 返事が来ない、汽車が出る直前に届く、外地・療養地・外国から届く
  - 焼かれる、死後に発見される、書かれなかった手紙

### 4-4. 自立型 — 女学生・書生・職業婦人・芸術家

**女学生**
- 袴、編み上げ靴、大きなリボン、自転車、文学少女、西洋音楽、寮生活
- 先輩や女性教師への憧れ
- 最大の装置：学校では「女性も学問を」、卒業すると「では嫁に行きなさい」
  - **自由を教えられた直後に、その自由を取り上げられる**

**書生・学生**
- 下宿暮らし、金がない、本だけは大量にある
- 帝大志望、文学青年、社会主義や自由主義に触れる、カフェーで議論する
- 実家の仕送り頼み、裕福な友人との格差、令嬢の家庭教師になる
- 思想は壮大だが生活能力がない

**新しい女性・職業婦人**
- 記者、タイピスト、教師、女優。自分で稼ぎ、男性と対等に議論する
- 周囲からは「はしたない」「西洋かぶれ」「家の恥」と見られる
- 本人は現代的には普通のことを言っているのに、世界側が異端扱いする
- はいからな女主人公（剣術・新聞記者・男勝り）。家に反抗するが、相手を選ぶ自由はなお限定される `[後世様式]`

**芸術・文学**
- 小説家・画家・音楽家・女優志望、同人誌、文芸誌投稿、サロン
- 芸術は趣味ではなく**新しい生き方の象徴**。そして親は「そんなもので食えるか」と言う

### 4-5. 階層移動型 — 華族・平民・成金・没落

- **没落**：格式はあるが金がない（元華族・旧家・士族・地主・名門商家）
  - 使用人を減らす、美術品を売る、土地を手放す、娘を政略結婚させる
  - 巨大な屋敷の「使っていない部屋」が増えていく
- **成金**：格式はないが金がある（財閥・貿易商・工場主・鉱山主・百貨店経営者）
  - 没落旧家と縁組みすれば、それ自体が「旧身分と新資本の融合」の物語になる
- **身分反転**：偉かった人が偉くなくなり、低かった人が金や学問で上がる
  - 例：子供時代は地主の息子＞小作人の息子 → 十年後、没落した地主の息子＜大学を出た小作人の息子
- **金が恋と自立を止める**（家制度×階層移動の交差）
  - 仕送りが切れる、女学校の月謝が払えない、持参金が用意できない
  - 下宿代の滞納、家庭教師の口を失う、実家の借金が縁談の条件になる
  - 金は家の命令より静かで、反論できない障害になる

### 4-6. 近代遭遇型 — 汽車・映画・カフェー・百貨店・新聞

- 銀座・浅草・百貨店・活動写真館・帝劇が、都市の「見える場所」として視線を交差させる
- **カフェー**は身分制度の外側にある一時的な自由空間。学生・記者・作家・令嬢・女給・外国人・思想家が同じ席につける。ただし店を出れば身分に戻る `[史実：特に大正後期〜昭和初期]`
  - **解放の相**：議論・出会い・身分の一時停止（白樺系・二段ロケット系で使う）
  - **消費の相**：女給の接客業化、遊興、金で買われる親密さ（耽美系・通俗系で使う）
  - 史実上は後期ほど消費の相が強まる。女給は二相の境界に立ち、純愛と消費が同じ席で起きる
- **世論が人物を先行して定義する**
  - 新聞・雑誌・噂・醜聞が、本人が語る前に「どういう人間か」を決めてしまう
  - 人物は、自分について書かれた記事と戦うことになる
  - 活動写真・雑誌の口絵・流行歌が、「新しい女」「不良少年」などの型を先に配る
- 外地（ロシア・シベリア・大陸）や混血・亡命貴族・洋行帰りが「もう一人の自分」を運んでくる
- 洋行帰りは舶来品と横文字を振りまく気障役にもなる
- モガ・モボは主役というより、都市の空気役か、主人公が「なる／ならない」を映す鏡になりやすい `[史実：大正末〜昭和初期]`
  - モガを「解放された正解」として置かない。モガにも代償と世間の侮蔑がある

### 4-7. 喪失型 — 病・国家・震災・時代の終わり

- **病**：結核、療養所、海辺や高原の別荘、病弱な令嬢・文学青年
  - 限られた時間 → 手紙 → 季節の移ろい → 会えない時間 → 再会（または死）
  - 死が暴力ではなく静かに近づくため、**美しいものほど失われる**情緒と相性がいい
  - 看取る／看取られる他者が、本命への選択を倫理的に封じる
- **国家**：出兵・外地勤務・転任・政治的弾圧などが、個人の時間や関係を中断する
  - 大正期なら第一次世界大戦、シベリア出兵、軍人の転任、植民地・大陸赴任に具体化すると年代感が安定する
  - 「大規模戦争への出征で引き裂かれる」像は昭和戦時ものの影響を受けやすいので注意
- **災害・社会変動**：関東大震災、スペイン風邪、米騒動、不況、労働運動
  - 震災は決着装置になりやすい。火災・崩落が個人の選択を物理的に塗り替える、あるいは断ち切られた縁を再会させる
  - これらは「試練」ではなく、**個人の意志を無効化する外圧**として置くと様式らしい
  - 比重を上げると「大正ロマン風日常劇」から「歴史ドラマ」へ作品の重心が移る点に注意
- **情死・後追い**：有島武郎の心中（1923）、島村抱月の死後の松井須磨子の自死（1919）は、同時代社会に強い印象を残した「恋愛と死」の実例 `[史実]`

### 4-8. 認識錯誤型 — 誤報・失踪・取り違え・記憶

> 通信も身元確認も不完全なので、「知らないこと」が事件になる。

- 戦死誤報・死んだと思われていた人の帰還 `[後世様式で頻出]`
- 記憶喪失、生き写し、異国の影武者。同一人物が二つの名を持つ
- 取り違え、誤配、偽名、失踪、身元不明
- 手紙・電報の遅延と誤配が、すれ違いを構造的に生む（→ 4-3）
- 幸福な結末でも、直前に誤報や記憶喪失を一度くぐるのが定石 `[後世様式]`

## 5. 人物配置あるある

- 主人公は**境界人**（二つの世界を見られる人）。生成時はほぼ必須
  - 地方↔東京、家↔学校、和↔洋、旧身分↔新職業、親世代↔若者世代を往復する
  - 人物の属性そのものに対立軸を埋め込む：華族×新聞記者、地方×東京、女学生×許嫁、旧家×洋行帰り、家業×芸術家志望
  - 外部から事件を足さなくても、**主人公が存在するだけで世界観の矛盾が露出する**
  - 典型：女学生、書生、新聞記者、小説家・画学生、医学生、教師、女給、華族子女、没落華族、商家の跡取り、上京青年、洋行帰り、混血・外国育ち
- 結核を病む文士・画家は美しく儚く、だいたい長くない
- 探偵役（素人探偵・記者・警視庁の変わり者）は帝都怪奇系で必須

## 7. 小道具＝物語機能

> 大正ロマンでは、小道具は装飾ではなく「不在者の代理」である。

- 現代劇なら電話すれば済むことも、ここでは物が「あの人がここにいた」を証明する
- **本人が不在になるほど、物が雄弁になる**（→ 4-7 喪失型と直結）

| 小道具 | 機能 |
|---|---|
| 手紙 | 時間差のある感情 |
| 電報 | 急報 |
| 写真 | 記憶・秘密 |
| 懐中時計 | 近代・約束・形見 |
| 本 | 新思想 |
| 楽譜・レコード・蓄音機 | 西洋文化 |
| 電話 | 新技術 |
| 自転車 | 女性・若者の自立 |
| 汽車の切符 | 出発 |
| 指輪 | 西洋式恋愛 |
| 家系図 | 家制度 |
| 借用証書 | 没落 |
| 新聞記事 | 社会との接続・醜聞・消息 |
| 押し花・リボン・栞 | 形見になる小物 |

- 風物：洋燈、万年筆、日傘、矢絣、マント、インバネス、ライスカレー、ソーダ水、珈琲、ビスケット、絵葉書

### モチーフ＝予言装置

- 歌・詩・台詞が、物語より先に結論を言ってしまう
- 例：「ゴンドラの唄」（1915）の「命短し恋せよ乙女」
  - 歌そのものは `[同時代文学]`、予言装置としての用法は `[後世様式]`

```
冒頭で歌（モチーフ）が流れる
↓
人物はその意味をまだ理解していない
↓
物語を経験する
↓
最後に同じ歌が流れる
↓
意味が反転する
```

## 8. 展開フェーズの型

**起（出会いの装置）**
- 許嫁の突然の登場／都市の見える場所での視線の交差／身分差の出会い／形見や写真が縁を運ぶ

**中盤（摩擦の装置）**
- 自由恋愛対家制度／世間の噂と醜聞／国家による引き離し／病による期限の設定／誤報・すれ違い

**終盤（時代が踏みに来る）**
- 選択ルート：人物が中間解を選び取る
- 剥奪ルート：震災・出兵・病が個人の選択を上書きする
- 二段ロケット系では、ここで前半の自由の代償が一気に請求される

### 季節の拍子

季節循環が様式の拍子になる。特に喪失型は、季節で時間経過を刻むと安定する。

| 季節 | 定番の場 | 機能 |
|---|---|---|
| 春 | 入学・卒業・花見 | 出会いと別れの期限 |
| 夏 | 避暑地・海辺 | 身分の一時停止、非日常の恋 |
| 秋 | 療養地・高原 | 衰えと予感 |
| 冬〜正月 | 実家・家族の集まり | 家制度への帰還、縁談の持ち込み |

## 9. 結末の型

共通条件：**結末は開始時の規範を完全には再現しない**。

### 本命：苦い中間解（選択ルート）

- 家を完全には捨てない。しかし以前と同じ生き方にも戻らない
- 例：縁談を断る → 家とは絶縁しない → 東京で教師になる → 数年後、実家と手紙が再開する
- 革命ではなく、**一歩だけ世界を進める**

### 派生1：剥奪ルート

- 震災・病・家の事情で引き裂かれ、形見だけが残る
- 生き残った側が喪服や断髪で時代の傷を着る
- 時代の終わりとともに青春も終わる

### 派生2：社会への転位

- 震災後の炊き出しや職業婦人として、「個人から社会へ」ずらして閉じる

### 派生3：振り切れた結末（系統を選ぶ）

- 家を捨てて二人で新しい生き方を選ぶ（白樺系・乙女系寄り）
- 洋装の結婚式で晴れやかに閉じる（二段ロケット系・乙女系寄り）
- 情死・後追いによる哀しい完結（耽美系・通俗系寄り）

### 回想枠

「大正ロマン」という概念自体が後世の懐古なので、回想枠は語り口の一例以上の意味を持つ。**作品そのものが後世の視線を再現する**。

```
現在（昭和・戦後・現代）
↓
遺品（手紙・写真・時計）
↓
大正時代の物語
↓
喪失
↓
現在に戻る
```

## 10. 語り口・文体

- 書簡体・日記体・私小説的独白の挿入
- 「ああ、私は何という夢を」系の感嘆が地の文に混ざる
- 第三者の噂と当事者の告白が交互に来る
- てよだわ言葉（「よくってよ」「〜ですわ」）
- 漢字当て字の外来語（珈琲、洋燈、倫敦、硝子）、旧字体・歴史的仮名遣い
- 色彩と服装が心情の字幕になる（海老茶の袴、派手な銘仙、喪の白）
- 歌・詩の予言装置（→ 7）、回想枠（→ 9）

### 語り手の階級

- 誰が語るかで、画面に映る世界が決まる
- 女学生・令嬢・書生の視点では、労働争議・貧困・差別は背景化しやすい（→ 11「画面外の貧困」）
- 女中・女給・小作人の子を語り手にすると、同じ屋敷やカフェーが別の場所に見える
- 語り手を選ぶことは、何を画面外に置くかを選ぶこと

## 11. 年代レイヤー（visual / cultural preset）

厳密な年表ではなく、生成時の風味プリセット。

| レイヤー | 主な記号 |
|---|---|
| early（明治末〜大正前期） | ハイカラ、女学生の袴とリボン、書生、白樺派、自我の目覚め |
| middle（大正中期） | 都市文化、大正デモクラシー、職業婦人、活動写真、米騒動・シベリア出兵 |
| late（大正末〜昭和初期） | モガ・モボ、断髪・洋装、カフェー最盛、ジャズ、消費都市、震災後の復興と退廃 |

```yaml
era_flavor:
  early: haikara
  middle: democracy
  late: modernism
```

### 運用注

- 作品内時間を詰めすぎない。**同一作品で扱う大事件は二つ程度まで**を目安にする
- ただし米騒動とシベリア出兵は同じ1918年で、因果的にも連動している（出兵を見込んだ米価高騰）。この二つは一組の出来事として扱ってよい
- 震災を使うなら late レイヤー。early の記号（袴リボン）と組むなら、登場人物が年を重ねる時間経過を入れる

### 年代ズレの注意

- 大正は15年しかないため、明治末〜昭和初期が混ぜて描かれがち
- 袴にブーツは明治後期からの流行で、大正専用ではない
- **ハイカラ女学生と昭和初期型モガの記号を一人に詰め込むと年代が歪む**
- 「大正ロマン」自体が後世の懐古的なラベル
- 実際の貧困・差別・労働争議は、たいてい画面外に置かれている（入れるかどうかは設計判断）

## 12. 検査規則

**MUST**
- 主人公または主要人物が、旧世界と新世界の境界にいる
- 対立の少なくとも一つが、時代固有の制度・価値観から生じる
- 新旧の同居が、衣装だけでなく制度・通信・金・場所のいずれかで一度は起きる
- 自由の経験が、物語の中盤以前に一度は「戻される」

**SHOULD**
- 新旧文化を同一場面に同居させる
- 小道具に感情・記憶・不在者の代理機能を持たせる
- 小道具が、所有者の不在時に一度は単独で働く
- 「自由には代償がある」ことを一度は示す
- 結末が、開始時の規範を完全には再現しない
- 参照系統（§3）と年代レイヤー（§11）を一つずつ選んでおく
- 語り手の階級を意識的に選ぶ（§10）

**MAY**
- 病・震災・出兵など「時代が踏みに来る」イベントを使う
- 回想枠を使う
- 認識錯誤（誤報・記憶喪失・取り違え）を使う
- 怪奇・探偵要素を加える

**AVOID**
- 袴・洋館・珈琲だけで大正らしさを済ませる
- 伝統＝悪、近代＝善に単純化する
- ハイカラ女学生と昭和初期型モガの記号を無造作に同居させる
- 震災・病・戦争を単なる便利な恋愛障害として消費する
- 昭和戦時の出征イメージを大正期にそのまま持ち込む
- 許嫁を悪役化して、家制度の複雑さを消す
- モガを「解放された正解」として配置し、世間の侮蔑を笑いで処理する
- 身分・出自そのものを笑いの種にする
