# ヤンキー美学を人物・集団の設計に使う

このガイドを読むと、ヤンキー的な人物や集団の規範、仲間意識、装飾の意味を物語へ取り入れる方法が分かります。

## このガイドを使う場面

「ヤンキー美学」の適用を明示した場合、または不良文化の筋・意地・仲間・地元・過剰装飾が人物・集団の主要な軸となる相談で使います。既定では選定せず、「友情」「義理」「派手」だけでは選びません。

「地元と仲間への筋を重んじる人物を作る」のように依頼すると、Monogatari Coach は、その人物が誰との関係を引き受け、集団の規範が誰を守り、誰を排除するのかを整理します。服装や名前などの装飾も、誰への帰属や覚悟を示すのか考えます。

## 設計の進め方

創作技法 [_how_to.example/yankee_aesthetics.md](../../_how_to.example/yankee_aesthetics.md) は、次の見方をまとめています。

- 作品が理想とする姿（L1）、作中集団の実践（L2）、外部からの解釈（L3）を区別します。
- 様式、倫理、社会的な関係をつなげ、必要な要素だけを選びます。
- 筋や仲間意識を美談だけで終わらせず、排除、見栄、恐怖、金、地域差などとのずれも検討します。

全員に七原則を当てはめる必要はありません。作品に合う問いを選び、回答を人物・世界・設計資料へ反映します。倫理的な選択とその代償を具体化する場合は、必要に応じて ETHOS の創作技法も参照します。

## 名前だけを考える場合

「族系の当て字を3案」のように名前だけを求める場合は、漢字エンブレム命名で完結します。人物・集団の帰属、価値観、装飾の意味まで設計する依頼で、ヤンキー美学を組み合わせます。具体的なチーム名や異名、刺繍文言の当て字は[漢字エンブレム命名](kanji-emblem-naming.md)を参照してください。

## 史実を説明する場合

このモデルは創作上の整理です。ヤンキー文化の歴史や特定の地域・集団を事実として説明する場合は、この資料の要約だけで断定せず、個々の主張を別途確認してください。

作品資料の選定条件と詳細は [ヤンキー美学の創作技法](../../_how_to.example/yankee_aesthetics.md) を参照してください。

プロジェクトに作業用 `_how_to/_index.md` がある場合は、標準資料を `_how_to/yankee_aesthetics.md` にコピーし、作業用索引へ追加してから作品で選定します。コピー前の標準新葉は、作業用索引がある環境ではまだ選定対象になりません。[_how_to/ のガイド](../project-structure/how-to-area.md) に手順があります。
