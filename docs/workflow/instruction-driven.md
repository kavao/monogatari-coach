# 指示出しベースのワークフロー（ユーザー視点）

このページは、Monogatari Coach を使い始めるときに「ユーザーがチャットでどう指示するか（コピペ用）」を中心に可視化したものです。  
正本（`/.rulesync/`）の詳細を読まなくても、まずはこの導線で動かせることを目的にしています。

---

## 初回導入（最初の会話でやること）

### 1. 状態確認（不足がないか洗い出し）
最初に、次を貼り付けてください。

```text
ユーザは初回導入の設定を行ってください。
このリポジトリの状態（初期化済みか、.env が整っているか、.rulesync の生成物が必要か）を確認し、
次に私がやるべきことを「最小手順」で列挙してください。
また、不足があればMonogatari Coach に具体的にどのファイルをどう直すべきかもコンソールから指示してください。
```

期待する出力イメージ:
- 「次に実行するコマンド」（例: `uv run python howto_init.py`、`rulesync generate` など）
- 「.env に埋めるべきキー」（例: `NOVELAI_ACCESS_TOKEN`、`XAI_API_KEY` など）
- 「現時点の不足（ファイル未作成・未同期）」の指摘

### 2. 次の目的を確定（ここから制作へ）
状態確認が終わったら、作りたい作品の情報を入れてください。

### 2.1 新規作品を作成する場合
Monogatari coach は短い会話で小説を作成することができます。
指示が不足している場合、肝心な行動の場合には事前に確認を入れるようにしております。  

#### (1) 「新規作品」を一から展開する

以下は新規作品開始の指示例です。
```text
新規作品としてプロジェクトを開始したいです。
これらを元に、必要なファイル一式を作って、
まず計画の段階まで進めてください。
作品情報は以下です：
- 作品名：
- ジャンル／テイスト：
- ログライン（1〜2文）：
- 主人公（仮でOK）：
```

### 2.2 既存作品をインポート／更新する場合
既存のファイル（過去に生成した `novels/<作品>/...` の成果物、importフォルダに入れた任意のファイルなど）を起点に指示を出せば、別の会話でも続きを行うことが出来ます。


#### (1) `novels/_import/` を使って「新規作品」として展開する
```text
_importの入力を元に、新規作品として必要なファイル一式を作って、
まず計画の段階まで進めてください。
```

## 作品制作の最短サイクル（ユーザーの指示テンプレ）

### A. 「執筆」へ進める
Monogatari coach 側からすでに執筆が可能という話がでている場合など、

```text
まず第1章（または指定した章）を執筆してください。
```

### B. 「清書（文章校正）」へ進める

```text
第1章の文章を清書してください。
```

### C. 「下読み（足きり判定）」へ進める

```text
第1章を下読みして、書評を出してください。
```

## 画像生成を絡める場合（任意）

画像タグや漫画ページは、作品本文が進んだ段階で別モードとして動かせます。  
必要になったタイミングで、以下のような入力をしてください。

### 1) キャラクター画像タグ（Tag Mode）

```text
プロフィールからタグを作成してください。
```

簡易コピペ例（1行）:

```text
作成いただいたタグからキャラクター画像の生成をお願いします
```

### 2) 漫画ページタグ（Manga Tag Mode）

```text
本文から漫画タグを作成してください。
```

### 3) 漫画画像出力（ページ／コマのどちらか）

ページ（ページ単位の出力）簡易コピペ例（1行）:

```text
作成いただいた漫画ページタグから漫画ページの出力をお願いします
```

コマ（パネル単位の出力）簡易コピペ例（1行）:

```text
作成いただいた漫画ページタグから漫画パネルの出力をお願いします
```

## 出力の確認ポイント（重要）

- 文章の正本は `novels/<作品>/_novel_text/novel_text*.md` です（会話に書かれただけでは完了しません）。
- 清書の成果物は `_novel_text/` へ上書きされます（バックアップは `_novel_text_backup/` に退避）。
- 文字数は `tools/novel_char_count.py` の集計結果を根拠にします。
