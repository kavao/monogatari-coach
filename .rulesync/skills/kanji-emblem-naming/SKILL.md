# 漢字エンブレム命名

名前を文章として説明するより、音と漢字の組合せを読める紋章として設計する。作品名、人物名・二つ名、技名などに使う。人物名では `character-naming` と連携し、人物設定や文化圏の確認はそちらに任せる。

## 発動と入力

漢字の当て字、義訓、漢字エンブレム風の表記、既存の名前の読みを保った漢字改修を求められたときに使う。「和風の名前」「漢字の人物名」だけでは発動しない。

依頼から用途、題材または元の名前、系統、音源、生成法、字圧・音圧・意味圧・文化圧、表記の過剰さ、字義の整合度、避ける字や意味、候補数を読み取る。推定できる項目は仮定を短く示す。

- 既存名の改修では、元の表記・読み、残す字や音、変えてよい箇所、改修の狙いを確認する。明示条件が優先。
- 改修範囲の指定がなく、元の読みが分かる場合は、読みと中心的な意味を保ち表記を改める前提を示す。読みの維持に必要な情報が欠けるときだけ質問する。
- 音源の指定があればそれを候補生成の軸にする。たとえば読みが指定され、題材が未指定でも、題材不足を理由に質問せず候補を出す。
- 音源の指定がなく題材が分かる場合は、題材から音源候補をいくつか作って選ぶ。題材も音源も不明で候補を作れない場合だけ質問する。
- 候補数が指定されていればその件数を出す。指定がない企画工程のタイトル命名では最低5件を出して比較する。それ以外の既定候補数は3〜5件。
- 必要情報が依頼や会話の文脈から分からず、候補生成に影響するときだけ確認する。

## 人物命名スキルとの分担

- 人物の時代・地域・文化圏・種族・立場、既存人物との識別は `character-naming` を参照する。
- 当て字・読みの組合せ、意図した難読表記の扱いは本スキルを使う。
- 本スキルの創作的な組合せに抽選を必須としない。ユーザーがランダムな候補抽出を求めた場合だけ、既存の `weighted-pick` 手順を使う。
- 意図した難読表記は「ルビ前提」と明記する。その場合、「読みにくい・誤読されやすい」ことだけで候補から落とさない。指定読者にルビが届かない、読み上げ用途に合わないなど、用途上の問題は別に判断する。
- 名前の候補だけを求められた場合、ヤンキー美学を自動適用しない。**族系の当て字だけではヤンキー美学を適用せず、人物・集団の帰属、価値観、装飾の意味まで設計する依頼で参照する。**
- 上記の依頼ではヤンキー美学を選定候補にする。作品の `selected` と `_how_to/` の索引ルールに従い、作業用索引がある場合は実効版の作業用葉を使う。作業用索引に未登録の標準新葉を直接読まず、命名の依頼は美学資料の選定と切り分けて進める。

## 生成の組み立て

音源を定め、用途・系統に合う表記を作る。表記の過剰さや字義の整合度は指定を優先する。字は音の根拠だけでなく、字形・意味カテゴリ・文化的な連想を踏まえて選ぶ。

よく使う生成法は次のとおり。複数を組み合わせてよい。

| ID | 型 | 仕組み |
| --- | --- | --- |
| A1 | 外来語の音訳当て字 | 外国語の音に漢字を当てる |
| A2 | 和語・俗語の音訳当て字 | 日常語や俗語の音に漢字を当てる |
| A3 | 義訓 | 漢字の意味に別の読みを重ねる |
| A4 | 擬音の漢字化 | 擬音や口語を漢字に分解・変換する |
| A5 | 実在難読語の転用 | 古語・地名・宗教語など実在する語を用いる |
| A6 | 掛詞・合成 | 複数の語や意味を一つの表記に重ねる |

系統は題材と依頼から選び、指定があればそちらを優先する。

| 系統 | 方向性 | 表記の目安 |
| --- | --- | --- |
| 族系 | 威圧、激情、権威、過剰な盛り | 過剰な当て字。字義の整合は低め |
| 呪術・異国系 | 宗教・古代文明を思わせる怪しさ | 過剰な当て字。怪異や文化の圧 |
| 雅系 | 古典的な格、静けさ | 標準表記の難読語を使える。字義の整合は高め |
| 耽美・ゴシック系 | 硬質なものと美しいものの対立 | 過剰な合成。字義の整合は中程度 |

系統指定がなければ題材から仮定する。系統を混ぜる指定では、主系統の方向性に副系統の意味要素を加える。

字の意味は、激情・暴力、死・宗教・終末、危険な生物、棘・毒、権威、古典・雅、硬質・工業、夜・闇、愛情・粋などのカテゴリから、系統や題材に合うものを選ぶ。カテゴリは連想上の分類で、字の辞書的な意味と同一視しない。複数カテゴリの字を混ぜると異質さを出せる。

### 変形操作

次の操作を必要に応じて組み合わせる。

- **過剰修飾**: 強い字や語をさらに足す。
- **異物接合**: 通常は結び付かない概念を一つにする。
- **舶来語の和風化**: 外来語を漢字で表す。
- **聖語の俗用**: 宗教語や死生観の語を、敬意を損なわない形で意外な用途へ使う。

### 音と字の対応

各字の読み方の根拠を説明できる候補を作る。音読み・訓読み・名乗り読み・義訓・音の一部の使用・長音や促音の変化・清濁の変化・外来音の近似・擬音の分割を使える。変形を使った場合は、どの変化か説明する。

創作上の読みを辞書にある読みとして述べない。根拠が確かでない読みは確認するか正式候補から外し、「要確認」のまま候補数に数えない。

## 用途別の形

- **タイトル**: 横一列のロゴに収まりやすい長さを意識し、副題や英字は必要に応じて提案する。
- **人物名**: 本名型（姓＋名）と二つ名型を分ける。本名は発音できる読みを優先し、過剰さを姓か名に寄せる。
- **技名**: 漢字本体とルビを示す。叫びやすい長さにし、技の効果と字の連想を合わせる。

## 検品

候補ごとに以下を確認し、不合格なら理由を短く示して除外する。

1. すべての字に読みの根拠、または明記した読みの変形がある。
2. 指定された系統・過剰さ・字義の整合度・圧に沿っている。
3. 元の名前を改修する場合、指定された読み・字・意味を維持している。
4. 既知の有名作品名、技名、人物名をそのまま、または少し変えただけでなぞっていない。ユーザーが改修を依頼した元の名前は、この条件で除外しない。
5. 表記や読みの全体、短い部分が、意図しない卑語・差別語・隠語になっていない。
6. 宗教や文化的な語を、特定の信仰や集団を嘲る形で使っていない。
7. 用途、読者、発音しやすさ、ルビの有無に合っている。

実在の人物・団体・商品・作品との一致を網羅的に保証しない。外部照合をしていない場合は未確認とし、確認した場合も調査範囲を超えて保証しない。既知の衝突があれば候補から外すか注意として示す。

## 出力

冒頭に仮定した用途・系統・音源を一行で示す。候補ごとに次を含める。

- 表記と読み
- 用途、系統、音源
- 各音と字、読みの根拠、意味カテゴリを示す表
- 生成法（A1〜A6）、変形操作、表記の過剰さ、字義の整合度
- 字圧・音圧・意味圧・文化圧を各 0〜2 で評価
- 狙いと注意点（ルビ前提、要確認事項、既知の衝突など）

読みの表は「音」「字」「読みの根拠」「意味カテゴリ」の列を持たせる。圧の評価値は厳密な測定値ではなく、候補間の印象を比較する目安として使う。

ユーザーが「名前だけ」と指定した場合は分解表を省略してよいが、読みの根拠と検品は内部で行う。候補数の指定、呼出元工程の採用・記録条件を守る。商用利用で外部照合が必要なときは、商標や既存作品との重複確認を別途行う旨を簡潔に添える。
