# 物語の倫理観（ETHOS）

> 標準雛形: [`../_how_to.example/ethos.md`](../_how_to.example/ethos.md)
> 
> この作業用ファイルは、標準雛形を作品選定・記入に使うための入口である。標準本文を正とし、ここにはローカル運用上の補足だけを置く。

## 使う場面

既定では読まない。次の場面で選定する。

- 倫理的な決断や規範の違いを物語の推進力にする。
- 忠義と恩義、共同体と個人、法と救済などを衝突させる。
- ユーザーが ETHOS の適用を明示する。

## 作業用の記入入口

まず標準雛形の簡易版で、視点人物について次を一文ずつ書く。

| 要素 | 問い |
| --- | --- |
| 義務 | 何をしなかった自分を許せないか |
| 禁止線 | 何だけは絶対にできないか |
| 代償 | それを選ぶと何を失うか |

場面は `design_specification.md` に「何を選び、何を失い、何が残ったか」を散文で記録する。数値の `scene_stakes` は保存しない。

人物へ採用するときは、`character.md` の既存人物節へ任意ラベルとして追加する。恩の対象・授受・返済状況の台帳は倫理ラベルに重複記録せず、作品側の人物関係記録へ置く。

詳細版を使う場合も、標準雛形の深度表・倫理基盤・配慮の範囲・制裁・点検を参照する。簡易版へ深度表を強制しない。

## 作品資料の記録先

| 作品資料 | 所有する情報 |
| --- | --- |
| `world.md` | 世界・集団の規範、建前と慣行、制裁と執行、語り手の姿勢 |
| `character.md` | 優先価値、配慮の範囲、禁止線、義務、服従の理由。恩の台帳は人物関係記録へ分ける |
| `design_specification.md` | 場面ごとの選択・喪失・残余を散文で記録する。数値の `scene_stakes` は保存しない |
| `_meta.md` | 採用した技法の selected、実施記録、作者がその規範を描く理由 |

## 実装境界

CHRONOS の自動登録、ETHOS 専用 validator、数値による倫理判断、本文の自動矯正、生成時の倫理・恩義情報注入は現行の執筆手順に含めない。構造検査は次期計画 P2、変化記録と CHRONOS 接続は P3、生成時注入は P4 で別途検討する。

詳細な分類、現代と前近代・架空社会の記入例、点検項目は標準雛形を参照する。ローカルの `_how_to/` を編集した場合でも、既存作品の selected を自動変更しない。
