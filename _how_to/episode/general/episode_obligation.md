# 恩義設計論（ON）

一般エピソード・人物関係技法のうち、恩・義理・返報の設計。索引は [episode_.md](episode_.md)。

創作における「恩」「義理」「返報」を設計するためのフレームワーク。
救助・庇護・承認などの「与える行為」を起点にした関係構築や、恩義と恋愛・恩義と正義などの衝突プロットを扱う。

> **注釈**：本書は創作論（物語の受容と構成についての考察）です。現実の男女の心理や性差を論じたり、実証したりするものではありません。本書でいう「イベント型」「ストリーム型」は、読者が**主に**期待する文法の傾向を指す便宜上の呼び方です。読者層や作品がどちらかに完全に該当するものではなく、作品ごとに調整するパラメータとして扱います。

---

## 0. 本書の使い方

### 0.1 対象

- 恩・義理・忠義を動機や関係の軸にする人物設計
- 救助・庇護・承認などの「与える行為」を起点にした関係の構築
- 恩義と恋愛、恩義と正義などの衝突を使ったプロット設計

ETHOS との分担: [ETHOS](../../ethos.md) は、人物や集団が何を優先し、何を禁止し、どの代償を引き受けるかを扱う。こちらは、誰から何を受け、どの回路で恩として計上し、どう返すかという人物関係の設計を扱う。`OS-ON` の重みと倫理的な優先関係は ETHOS、作品に記録する恩の対象・授受・返済状況の台帳は人物関係記録へ置く。

### 0.2 ID体系

| 接頭辞 | 領域 | 問い |
|---|---|---|
| D | 定義 | 恩・義理とは何か |
| M | 全体モデル | 恩はどう生まれ、どう終わるか |

| W | 重さ | その恩はどれだけ重いか |
| L | 記帳 | その恩はどの回路に計上されるか |
| S | 精算 | どう返し、いつまで持つか |
| R | 役割 | 誰が何の債権者・債務者か |
| C | 衝突 | 恩義は何とぶつかるか |
| P | 型 | プロットにどう実装するか |
| X | アンチパターン | 何をすると読者が割れるか |
| Q | 点検 | 書いたあと何を確かめるか |

## 1. D — 定義

**D-1 恩**  
他者の行為によって、自分の現在が成立しているという認識。

**D-2 義理**  
その認識を、将来の自分の行動に反映させる規範。恩は原因、義理は行動規範である。

**D-3 恩義**  
「昔してもらったから返す」という単純な交換ではない。「あのとき相手が自分をどう扱ったか」を、現在の関係から消さない規範。

**D-4 隣接概念との区別**

| 概念 | 時間の中心 | 意味 |
|---|---|---|
| 恩 | 過去 | あの人にしてもらった |
| 義理 | 現在〜未来 | だから自分はこう振る舞うべきだ |
| 報恩 | 行為 | 受けたものを返す |
| 忠義 | 関係 | この人物・集団を裏切らない |
| 情 | 感情 | 損得を越えて放っておけない |
| 愛 | 個人的価値 | 相手そのものを特別視する |

**D-5 三つの回路**  
一つの行為には、次の三回路が同時に乗りうる。創作上のすれ違いの多くは、これらの混同から起きる。

1. **恩義回路**：受けた恩恵に報いる義務。契約・忠誠・面子に近い。嫌いな相手にも返しうる。
2. **実利回路**：生存・地位・生活水準・安全といった可視の利得。
3. **親密回路**：理解・尊重・継続的な応答。恋愛感情は主にここに落ちる。

**D-6 当然ライン**  
その物語世界と読者が「そのくらいは当然」と見なす水準。行為が恩になるかどうかの閾値（→ G-1）。

**D-7 特定性**  
その行為が、どれだけ「*この相手だから*」行われたか。誰にでも行われうる行為ほど低く、この相手でなければ起きない行為ほど高い（→ L-2）。

## 2. M — 全体モデル（恩のライフサイクル）

**M-1 六段階**

```
発生 → 認識 → 義理化 → 返報 → 精算／永続化 → 衝突
 G      L       L〜S     S        S            C
```

| 段階 | 内容 | 主な設計判断 |
|---|---|---|
| 発生 | 行為が当然ラインを超える | 代償・自発性・希少性 |
| 認識 | 受けた側が恩として記帳する | 回路の振り分け、特定性 |
| 義理化 | 恩が行動規範に変わる | 人物の会計方式 |
| 返報 | 何かを返す | 返報の通貨 |
| 精算／永続化 | 帳消しにするか、自己定義に組み込むか | 返済型／帰属型 |
| 衝突 | 他の価値とぶつかる | 正義・愛・家族など |

**M-2 中心命題**

> 恩とは、他者の行為によって自分の現在が成立しているという認識である。  
> それが恩として立つかは、行為が当然ラインを超えたかで決まる。  
> それが恋や忠誠に変わるかは、行為がどれだけ自分を特定していたかで決まる。  
> どう返し、いつまで持ち続けるかは、人物ごとの会計方式による。

## 3. G — 発生（恩が立つ条件）

**G-1 当然ラインを超える**  
恩になるかは、行為の絶対的な大きさではなく、当然ラインの上か下かで決まる。前提として計上された行為は、感謝は生んでも関係を更新しない。関係を更新するのは、前提を超えた余剰である。

**G-2 代償**  
救助者が損失を払ったか、余力で済ませたか。代償がなく、役割として当然なら、恩は立ちにくい。

**G-3 自発性**  
命令・職務・契約による行為より、自ら選んだ行為のほうが恩として立つ。

**G-4 例外性**  
その世界で、その行為は例外か、役割の履行か。騎士が民を守るのは履行、敵兵が民を守るのは例外。

**G-5 受け取り拒否**  
「借りを作りたくない」人物は、恩の発生そのものを拒む。救助を断る、礼を即座に払って帳消しにする、などの行動で、人物の警戒心や過去の傷を示せる。

---

## 4. W — 重さ

**W-1 額面と意味**  
恩の重さは客観的利益の大きさと一致しない。

```
恩の重さ ≒ 額面（利益・代償） × 困窮度 × 希少性 × 自発性 × 関係的意味
```

大富豪からの大金より、誰からも見捨てられていたときの一人の味方のほうが重い場合がある。恩とは資源の移転であると同時に、「あの状況で、あなたは私をどう扱ったか」の記憶でもある。

**W-2 恩の四分類**

| 分類 | 例 | 形態 | 特定性の傾向 | 流れやすい先 |
|---|---|---|---|---|
| 救命恩 | 命を救う、危険から逃がす | 一回で巨大な債権 | 低（誰でも助けうる） | 恩義回路 |
| 救済恩 | 居場所・名誉を与える、信じる | 一回〜短期 | 中（個人として扱われた度合いで振れる） | 恩義〜親密 |
| 庇護恩 | 養う、育てる、身分を保証する | 継続（関係が恩を生み続ける） | 中 | 忠義 |
| 承認恩 | 能力や作品を最初に認める | 一回〜継続 | 高（*私の*価値を認めた） | 忠誠・親密 |

**W-3 小恩大返**  
「一宿一飯の恩」で命を張る展開が成立するのは、額面ではなく、その行為で成立した関係を裏切らないために動くからである。過剰返済そのものが、その共同体では美徳として読まれる。

---

## 5. L — 記帳

**L-1 回路への振り分け**  
同じ行為でも、受け手がどの回路に計上するかで、その後の関係が変わる。作者は「何を支払ったか」と「どの回路に記帳させたいか」を明示的に決める。

**L-2 特定性は恩義と親密の橋**  
恩が恋や忠誠に変わるかを決めるのは、恩の大きさではなく特定性である。危機救助は「この人は善人だ」の証拠にはなるが、「この人は*私を*選んだ」の証拠にはなりにくい。

例：シンデレラにおいて、魔女は条件を満たす誰かを助けた存在であり、王子は群衆の中から*彼女を*特定し、その後の生活を引き受けた存在である。魔女への恩返しが描かれないのは、恩と愛が別の帳簿だからと読める。

**L-3 文法パラメータ**  
読者の文法差は、主に次の二つの設定の違いとして扱う。

1. 当然ラインの位置（救助が恩になるか、前提になるか）
2. 恩義回路から親密回路への換算レート

| | イベント型の文法（主に） | ストリーム型の文法（主に） |
|---|---|---|
| 関係の根拠 | 一回の大きな貢献 | 人格の理解と日常の応答の蓄積 |
| 換算レート | 高く見積もる | 低く見積もる |
| 救助の位置 | 当然ラインの上（恩） | 当然ライン付近（前提） |
| 読者の違和感 | 実利がない愛はリアリティがない | 助けただけで尽くすのは無条件に見える |
| 典型 | 救助 → 献身 | きっかけ → 相互理解 → 恋愛 |

どちらの読者も「無条件の愛」を拒んでいる点は共通する。違うのは、何を条件として認めるかである。

**L-4 前提の上の余剰**  
救助が前提として割り引かれる文法では、救助そのものより、救助の仕方と後の扱いが関係の核になる。余剰になりやすい要素：

- 助けたあと、返済を要求しない
- 判断権を奪わない
- 公の場で面子を守り、私的な場で弱さを見せる
- 一度きりでなく、同じ原則で再登場する
- 生活（居場所・仕事・安全・言葉の自由）を再配置する

**L-5 非対称な記帳**  
与えた側は忘れていて、受けた側だけが一生覚えている。あるいはその逆。再会の場で「覚えていない」と言われる債務者は、それだけで一本の話になる。

## 6. S — 精算

**S-1 返報の通貨**  
恩は同じ通貨で返されるとは限らない。  
金銭／労働／情報／保護／忠誠／名誉／秘密保持／仲間であり続けること／困ったときに必ず駆けつけること

**S-2 支払と返済の種類**  
支払ったもの（命・実利・時間・面子）と、返させるもの（礼・協力・忠誠・恋愛）の種類が大きくずれると、読者が割れる（→ X-1）。

**S-3 返済型と帰属型**

| | 返済型 | 帰属型 |
|---|---|---|
| 恩の扱い | 借金 | 関係の変化 |
| 流れ | してもらった → 相応に返す → 貸し借りなし | 助けてもらった → 特別な人物になった → 以後裏切らない |
| 精算後 | 恩は消える | 恩は消えず、自己定義になる |
| 典型的な台詞 | 「借りは返した」 | 「俺はあの日、あの人に拾われた人間だ」 |
| 向く人物 | 傭兵、商人、合理主義者 | 武士、騎士、任侠、忠臣 |

**S-4 一回の恩が永続する条件**  
債権者が同じ救助を繰り返しても、親密は増えない。一回の恩が永続するのは、**債務者がそれを自分の記憶と自己定義に組み込んだとき**である。ただし、そこで維持されるのは主に忠義であり、愛とは限らない。

**S-5 返す通路の複数化**  
立場の弱い人物が「返すものは自分自身しかない」状態で返済させられると、ある読者には献身に、別の読者には非対称な取引に見える。情報・技術・仲介・決断・留守を守る、など複数の返済手段を用意すると、恩義が人格の従属にならない。

**S-6 時間による変質**  
放置された恩は、重くなる（利子がつく）場合と、風化する場合がある。どちらになるかは人物の会計方式による。長期連載や世代をまたぐ物語で効く。

## 7. R — 役割

**R-1 債権者**  
命・面子・生活・秘密を与えた側。返済期限が物語の圧力になる。庇った犬、部下、一宿一飯の相手、亡き者の遺言も債権者になりうる。

**R-2 債務者**  
受けたが、返す通路が狭い側（→ S-5）。

**R-3 清算人**  
義理を破った者を排除・断罪する側。

**R-4 誤認者**  
恩を愛と読み替える側、あるいは愛を恩の返済と読み替える側。

**R-5 恩着せ（債権者の請求）**  
与えた側が恩を口にして請求すると、恩は減価する。「あのとき助けてやっただろう」と言った瞬間、債権者は悪役寄りに移る。請求が強まり、相手に不利益を推論させて行動を縛る段階に入ると、恩義の物語は威圧の物語に変わる。

---

## 8. C — 衝突

**C-1 恩義と他の価値**  
恩義は、人物に過去から制約を掛ける仕組みである。次の衝突がドラマを生む。

- 恩義 vs 正義：正しいことをすれば恩知らずになり、恩を守れば悪に加担する
- 恩義 vs 愛
- 恩義 vs 家族
- 恩義 vs 国家・組織
- 恩義 vs 契約
- 恩義 vs 自己保存

**C-2 敵への恩**  
「敵だ。だが、この人には借りがある」。敵／味方の一軸では説明できない関係ができ、人物に厚みが出る。

**C-3 義理は信頼のテストになる**  
第三者への義理の扱い方は、その人物の忠誠を予測するシグナルとして読まれる。

例：主人公を庇って負傷した愛犬を「置いて逃げよう」と言うヒロインが強く拒絶されるのは、薄情さそのものより、「自分を庇った者を捨てる人物は、いずれ主人公も捨てる」と判定されるからである。帰属型の主人公にとって、これは最重要の関係規範の否定になる。庇った対象は、新しく魅力的な人物より優先されうる。

**C-4 最大の悪は不返報ではなく、恩の否定**  
恩を返せなかった人物は悲劇になりうる。恩を受けた事実そのものを否定する人物（「あんなものは偶然だ」「死んだのだからもう関係ない」）は、過去の関係を書き換えて責任を消そうとしているため、悪役になりやすい。

## 9. P — 型（プロットへの実装）

**P-A 恩は立つが恋にはしない**  
救助 → 物品・情報・協力で清算 → 関係は同盟のまま。恋愛は別ルート（日常の応答）で立ち上げる。どちらの文法でも破綻しにくい。

**P-B 恩が原則を開示する**  
救助そのものより「なぜ助け、何を捨てたか」を見せる。恋愛対象より先に、人物の価値の優先順位が見える。

**P-C 当然ラインをずらす**  
序盤は役割として助け、読者も当然と見る。中盤で役割を超えた損失を払わせ、そこで初めて恩を立てる。

**P-D 特定性を上げて救助を恋の起点にする**  
「彼女だからこそ、この代償を払って助けた」と読める要素を加える。または救助の後に、主人公が彼女個人の事情や癖を理解していく過程を置く。

**P-E 恩と恋を別トラックで走らせる**  
ヒロインに「恩は返したい。でもそれと好きは別」と自覚させ、その後で恋が追いつく。ロマコムと相性がよい。

**P-F 恩の誤認を主題にする**  
片方は返済済みと見なし、片方は愛の前払いと読む。説教ではなく、計上規則の衝突として中盤の対立に使う。

**P-G 報われない恩を火種にする**  
恩を与えたのに返されなかった「魔女」の立場の人物を置く。恨み・執着・歪んだ献身の強い動機になる。ダーク寄りの作品で効く。

**P-H 非対称な記帳の再会**  
一生の恩を抱えた債務者と、それを覚えていない債権者を再会させる（→ L-5）。

**P-I 義理の踏み越え**  
信頼していた人物が義理を踏み越える瞬間を、関係崩壊の決定打にする（→ C-3）。

---

## 10. X — アンチパターン

**X-1 大きな一回で親密回路の全額を請求する**  
救助一回で恋愛や終身の献身を当然とする構図。読者が割れる。特定の読者層に最適化する作品なら使えるが、広く読ませるなら請求を同盟・保護・一回の協力に限定する。

**X-2 当然の行為で生涯を要求する**  
当然ライン以下の行為に大きな返報を付ける。行為を大きくするより、代償を増やすか、請求を小さくする。

**X-3 返す手段が自分自身しかない**  
身体や忠誠だけで返済させる（→ S-5）。

**X-4 意図しない恩着せ**  
作者は美談のつもりでも、債権者が恩を口にすると減価する（→ R-5）。

**X-5 救助の反復で親密を積もうとする**  
同じ救助を繰り返しても、実利は増えるが「この人だから」は増えない。

**X-6 庇った対象より新しい人物を優先させる**  
犬・仲間・恩人を軽んじて新ヒロインを立てると、そのヒロインの信頼判定が崩れる（→ C-3）。

**X-7 性別を説明装置に使いすぎる**  
「男は」「女は」で人物の会計方式を決めると、反例ですぐ崩れ、作品の幅も先に狭まる。会計方式は人格・文化・関係規範で決める。

## 11. Q — 点検項目

場面を書いたあと、次を確認する。

- [ ] 1. この行為は、作中の当然ラインの上か下か。（G-1）
- [ ] 2. 救助者は代償を払ったか。自発的だったか。（G-2、G-3）
- [ ] 3. 支払ったのは命・実利・時間・面子のどれか。（S-2）
- [ ] 4. 返させるのは礼・協力・忠誠・恋愛のどれか。支払と種類は釣り合っているか。（S-2、X-1）
- [ ] 5. その行為の特定性は高いか。恋や忠誠に変えたいなら、「この相手だから」が読めるか。（L-2）
- [ ] 6. 作品はどちらの文法を主に想定しているか。換算レートの前提は読者と合っているか。（L-3）
- [ ] 7. 債務者に、自分自身以外の返済手段はあるか。（S-5）
- [ ] 8. この人物は返済型か帰属型か。台詞と行動は一貫しているか。（S-3）
- [ ] 9. 債権者が恩を口にしていないか。口にするなら、それは意図した減価か。（R-5）
- [ ] 10. 庇った対象より、新しい魅力的な人物を優先させていないか。（X-6）
- [ ] 11. 「当然のことをしただけなのに、生涯を要求している」と読まれる余地はないか。（X-2）
